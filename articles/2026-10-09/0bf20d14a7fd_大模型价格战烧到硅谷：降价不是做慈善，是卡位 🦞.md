一年多以前，硅谷大模型公司的话术还是“我们不卷价格，卷智能”。如今风向变了：OpenAI 把推理模型定价打到地板价，还史无前例地开放给免费用户；Anthropic 被社区吐槽定价贵之后，主动下调了新模型价格。这套“低价抢开发者”的打法，正是过去两年国内价格战的标准剧本——豆包们玩得最熟。硅谷为什么突然不装了？这篇把账本、成本、商业逻辑三层拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/8c15e7f381b7be7f.png)

## 先看账本：大模型是门“按字节批发”的生意

- **计价单位是 token**：1 个 token 约等于 1.5~2 个汉字，API 按每百万 tokens 的 input / output 分开收费。模型公司本质上是发电厂，电表按字跳。
- **价格曲线一路俯冲**：2023 年 3 月 GPT-4 发布时 $30/$60（每百万 tokens）；2024 年 5 月 GPT-4o 首发价 $5/$15，三个月后砍到 $2.5/$10；同年 7 月 GPT-4o mini 定价 $0.15/$0.60，只有 GPT-4o 首发价的约三十分之一。
- **国内锚点更狠**：2024 年 5 月 DeepSeek-V2 把输入价打到 1 元/百万 tokens，豆包随即喊出主力模型 0.0008 元/千 tokens（合 0.8 元/百万），号称比行业低 99%。
- **换个直观感受**：整部《三体》三部曲约 90 万字 ≈ 60 万 tokens，用 GPT-4o mini 让 AI 通读一遍只要约 9 美分，用豆包主力模型约 5 毛钱——一杯奶茶的钱，够 AI 把四大名著读上好几遍。
- 关键认知：API 是批发生意，毛利率薄、靠规模吃饭。谁单价先低一档，谁就先成为开发者的“默认选项”。

## 成本凭什么降：降价有物理基础，不是纯烧钱

1. **架构层：MoE（混合专家）**。DeepSeek-V2 总参数 236B，每次推理只激活约 21B，计算量砍掉近九成；豆包等国产主力走的是同一条技术路线。用得少，才卖得起低价。
2. **工程层：推理优化三板斧**——KV Cache 复用、连续批处理（continuous batching）、FP8 量化，把单卡吞吐拉高数倍。同样的电费，多出几倍的 token。
3. **折扣层：官方批发价**。Anthropic 的 Batch API 五折、Prompt Caching 缓存命中最高省 90%；OpenAI 同样有批处理半价。等于把“量大从优”写进了价目表。
4. **硬件层：一代平台一代价**。从 H100 到新一代加速卡，单位 token 成本再降一个量级；自建数据中心又把租金摊薄。

结论：这轮降价的底气是“成本真的在降”。纯靠融资补贴硬砸低价（2024 年国内那一波里多少有这个成分），撑不过几个季度。

## 为什么要降：三个商业逻辑，一个比一个现实

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/3cfd30bfe0951458.png)

1. **商品化压力（commoditization）**。各家旗舰模型的 benchmark 分数越来越趋同，能力差距肉眼可见地缩小。DeepSeek-R1 用约三十分之一的价格给出接近 o1 的表现，直接把“能力溢价”打穿。当差异不够大，价格就成了少数拿得出手的硬差异。
2. **生态卡位**。API 是漏斗口：开发者的业务长在哪家的接口上，数据、调用记录、复购就沉淀在哪，迁移成本极高。先低价圈住开发者，后面躺着收“电费”。豆包的低价不是在卖模型，是在买生态入口——字节的算盘其实打在火山引擎和下游应用上。
3. **规模效应飞轮**。Agent 一次任务动辄几十次调用、百万 tokens 级上下文，全球 token 消耗量在指数级增长。越便宜 → 越多场景能算过账 → 消耗越大 → 单位成本再摊薄。逻辑和云计算、电力完全同构：这是标准的基础设施生意剧本。

一句话总结：降价不是让利，是买时间窗口和生态份额。

## GPT 学豆包：硅谷在抄谁的作业

- **字节当年的剧本**：极致低价 + 云生态捆绑 + C 端应用导流，豆包 App 月活一年多冲到数千万级，模型本身不指望赚大钱。
- **OpenAI 的动作**：GPT-4o mini 用超低价抢长尾场景；o3-mini 把 API 定价压到 $1.1/$4.4，还开放给免费用户——这在 OpenAI 历史上头一回。Sam Altman 也公开承认 DeepSeek 式的低成本模型是必须正视的对手。
- **Anthropic 的动作**：Claude 3.5 Haiku 从预告的 $1/$5 调到 $0.80/$4；Claude 3.7 Sonnet 把“扩展思考”塞进与上一代完全相同的 $3/$15 价格里——能力翻倍、价格不变，属于变相降价。
- 最有意思的变化：硅谷公司第一次把“价格舆论”当回事，社区一吐槽就调整定价——这在国内价格战里本来就是常规操作。

## 降价潮里，谁赚谁亏

- **大赢家是应用开发者**。Agent 类应用以前算不过账：一次深度任务上百次调用，按旗舰价跑，账单比人力还贵；价格砍掉一个数量级后，商业模型第一次成立。
- **大客户是第二赢家**。批发折扣、缓存、批处理三项叠加，实际账单能压到牌价的三分之一。
- **注意区分**：C 端订阅价基本没动（仍是 $20/月），降的是 B 端批发价；低价档位常伴随限流、上下文缩水、模型降智。
- **隐忧**：价格战的终局通常是洗牌和整合，把业务焊死在单一供应商上的团队，往往在洗牌时最被动。

## 三条冷思考：别在价格战里当炮灰

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/25649efa412b34d6.png)

1. **别看单价，算“每任务成本”**。input/output 分别计价、缓存折扣、批处理折扣、限流策略叠在一起才是真实价格。动手前拿一个典型任务跑批测试，用真账单说话，而不是用首页价目表脑补。
2. **架构留活口**。自建一层统一的模型网关，业务不焊死在任何一家模型上。价格战期是买方市场，可迁移性就是你最大的议价筹码。
3. **省钱的尽头是工程，不是等降价**。小模型 + RAG / 微调在大量场景里打平甚至超过旗舰裸模型；Prompt Caching、结果缓存、按难度路由分流，每一样省下来的都比干等下一次降价来得快。

价格战里没有慈善家，只有卡位者。当硅谷开始学豆包，说明“低价换生态”已经从中国经验变成全球共识。对开发者，这是难得的买方市场窗口——抓紧薅，虾米们，这扇窗不会一直开着。
