每隔几个月，国产大模型圈就重演同一出戏：新模型发布、榜单屠榜、社交刷屏，一周后热度归零，各家回到同一条起跑线继续憋下一代。36kr《国产大模型，正在沦为“产品周期股”》点破的正是这个节奏——资本市场已经不再按成长股逻辑给模型公司估值，而是像对待钢铁、化工、航运那样，按周期定价。这篇文章拆一下：周期化怎么发生的，代价是什么，谁能跳出来。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/7485ff8b6264d873.png)

## 一、先对齐概念：什么叫“产品周期股”

- **周期股**：盈利与行业景气度强绑定，钢铁、化工、航运是典型。景气高点利润好看，但利润不沉淀成壁垒，下一轮周期重新洗牌。
- **成长股**：收入可累积、壁垒可复利，用户、数据、生态逐年滚动。
- **“产品周期股”**是混合体：估值锚不是持续增长的收入，而是“下一代模型何时发布、能领先多久”。每次发布像一次财报季——发布前预期拉满，发布后利好出尽，进入下一段等待。

残酷之处在于：**模型能力是会过期的资产**。辛苦半年训出的权重，在开源社区两轮迭代之后，先进性就折旧完毕。厂房能用二十年，模型权重的“有效寿命”可能只有几个月。

## 二、周期化的三个底层机制

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/9d09231cea7d9c2a.png)

**1. 能力同质化的速度远超想象**

- 主流评测集上，头部模型的分数挤在很窄的区间里，领先窗口从“半年一代”压缩到“几周被追平”。
- 开源把追赶成本打了下来。DeepSeek-V3 技术报告口径：约 278.8 万 GPU 小时、预训练成本约 557 万美元。这个数字未必是全口径，但标志着一个数量级的下探——前沿能力从“巨头专属”变成“二线团队咬牙也够得着”。
- 结果：任何一家发布的领先，都是**租来的领先**，不是买断的领先。

**2. 用户切换成本趋近于零**

- OpenAI-compatible 接口成了事实标准，换模型 ≈ 改一行 base_url 加重跑一遍评测。
- 价格战加速商品化：2024 年 5 月，阿里云把主力模型 API 价格最高下调 97%，各家迅速跟进。当同能力档位的 token 价格短期内跌去一个数量级，“模型”就从技术资产滑向大宗商品。
- 而大宗商品的价格由供需决定——备案上线的大模型服务数以百计，供给端还在扩产。

**3. 收入结构“项目化”，缺少复利**

- ToB 侧大量收入来自定制开发和私有化部署，本质是一次性交付：项目做完钱结完，下个项目重新投标。这是集成商现金流，不是订阅制现金流。
- ToC 侧付费率不高，且用户忠诚度跟着产品体验走，不跟底层模型走。
- 连续的研发投入对上脉冲式收入，现金流错配，估值自然按周期给，而不是按成长给。

## 三、历史参照：钱流向了哪几层

技术浪潮里“层与层的命运分化”不是第一次出现：

- **智能手机时代**：摄像头模组、面板供应商随机型周期起落，一个定标调节一个季度的营收；握住生态的 Apple 和 Android 是另一套估值逻辑。
- **云计算时代**：AWS 把“卖服务器”改写成“卖订阅加数据引力”，客户的应用和数据长在云上，迁移成本逐年升高，收入变成年金。
- **这一轮 AI**：目前真正穿透周期的是两头——卖铲子的算力层，和拿走用户时长的应用层。模型层夹在中间：往下不掌握用户，往上不掌握产能，成了周期感最重的一层。

DeepSeek 时刻让这一点更刺眼：训练成本下降 → 更多玩家入场 → 供给增加 → 价格下探 → 模型层利润更薄。技术进步本身是好事，但对“以模型为唯一资产”的公司，它恰恰是通缩。

## 四、代价与例外

**代价**：研发是连续函数，收入是脉冲函数，缺口只能靠融资填，而按周期定价的市场，融资窗口恰好也随发布节奏开合；团队为发布日赶工、为榜单调优，工程资源向“可展示的能力”倾斜，长期基础设施建设被挤压。

**例外探讨——什么样的公司能挣脱周期**：

- **数据飞轮**：用户使用产生独有数据，反哺下一代模型，形成别人抄不走的闭环；
- **生态绑定**：工具链、Agent 框架长在自己身上，切换成本重新长出来；
- **行业纵深**：金融、医疗、法律的壁垒在数据合规和行业 know-how，不在公榜跑分；
- **C 端留存**：把模型藏进产品里，让用户记住产品而不是版本号。

注意这四条的共同点：**都在模型之外**。这正是“周期股化”这个判断最锋利的地方——单靠“训模型”这一件事，撑不起成长股的估值。

## 五、冷思考：三条判断框架

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/16bec404a986f27f.png)

**1. 看发布，更要看留存。** 判断一家模型公司，别只看榜单跑分，看 API 客户续用率、C 端次月留存、头部客户收入集中度。跑分是流量，留存才是收入；流量按次结算，收入按复利结算。

**2. 把周期品当周期品用。** 如果你是选型者，接受“模型能力是快消品”这个前提：架构里留好抽象层（统一网关、可替换 provider）、维护自己的评测集、关键业务双供应商。别把业务逻辑绑死在任何一家模型的脾气上——这是工程对冲，不是不忠诚。

**3. 积累反周期的资产。** 模型权重按月贬值，但行业真实数据管线、严谨的评测能力、把模型变成可靠系统的工程经验，是按年增值的。对从业者，这些是随身携带的壁垒；对创业者，应用层的工作流占位和数据沉淀，通常比“再训一个更强的模型”更抗周期。

周期不丢人，钢铁厂也能是好生意，前提是按周期品的规矩经营：控制每一轮投入产出，别用成长股的杠杆赌周期股的生意。龙虾换壳是为了长个，不是为了重新当虾苗——模型会过期，不必惋惜；值得花力气的，是那些不随权重一起过期的东西。
