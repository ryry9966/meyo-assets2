最近，36kr 一篇分析把一个词重新带回大众视野：国产大模型，正在沦为“产品周期股”。意思是，这些公司的市场热度、融资节奏和估值，越来越系在“下一代模型什么时候发”这根发条上——发布会即情绪顶点，之后进入漫长的静默期。这不是唱衰。恰恰相反，一件事能被套进“周期股”的分析框架，往往说明它已经从玄学变成了有规律可循的生意。这篇我们把三个问题拆开：周期从哪来、谁在周期里受伤、谁能跳出去。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/b1a85beb4bd07ac2.png)

## 一、“产品周期股”是个什么物种

这个词不是发明出来骂人的，它来自两个成熟行业：

- **制药业**：经典剧本是一款重磅药上市，营收曲线陡峭上扬；专利到期那天，仿制药进场，销售额断崖式下跌，业内称为“专利悬崖”（patent cliff）。辉瑞的立普妥在核心专利到期后，销售额几年内跌去大半。药企的估值，本质是“研发管线里还剩几款新药”的期权定价。
- **消费电子与半导体**：苹果秋季发布会前后，供应链备货、市场情绪起伏；存储芯片更极端，扩产周期直接决定价格周期。

它们的共同特征只有一条：**公司价值高度绑定一个周期性事件，事件之间是漫长的衰减**。

对应到大模型，映射几乎严丝合缝：

- 模型发布会 = 财报电话会
- 榜单成绩 = 季报关键数字
- 发布后的 token 调用量脉冲 = 新品上市冲量
- 两次发布之间的静默期 = 估值阴跌

这条曲线，写代码的人其实最熟：开源项目 README 更新那天 star 涨飞，三个月后 issue 区开始还债。

## 二、周期怎么形成：三个互相咬合的齿轮

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/9620c4dbf29d21af.png)

**齿轮一：技术扩散速度 > 商业化速度。**

- 开源权重（Llama、Qwen、DeepSeek 系）、论文复现、蒸馏，让头部模型的“独家能力”平均只能维持几个月；
- 观察近两年格局：一次代际领先，通常 6~12 个月内就会被开源阵营追近，差距的“半衰期”越来越短；
- 结论很残酷：能力是漏斗，不是水库。存不住水，就只能一直挖井。

**齿轮二：边际定价 + 价格战。**

- 在用户眼里，“能干活的模型”之间高度同质，比价逻辑天然成立；
- 2024 年起，国内主力模型 API 价格经历多轮大幅下调，部分一次性降超九成，推理单 token 价格的下降速度远超摩尔定律；
- 没有定价权的生意，毛利只能靠成本曲线硬扛。

**齿轮三：叙事依赖榜单。**

- 主流 benchmark 快速饱和，不少经典榜单上头部模型已逼近或超过 90 分，区分度下降；
- 数据污染（contamination）让“刷榜分”与“真实生产力”之间出现裂缝；
- 资本市场没有更好的锚，只能拿榜单当 KPI——于是每次发榜都是一次“财报事件”。

三个齿轮咬合的结果：**必须持续发布更强的模型，才能维持注意力与融资叙事**。发布本身从手段变成了义务。

## 三、逐条对照：它确实长着一张周期股的脸

- **收入呈脉冲状**：发布前后调用量冲高，随后回落到由留存用户决定的基本盘；
- **研发开支阶梯上涨**：有研究机构估算，每代旗舰模型的训练算力成本约按 10 倍量级抬升，开支永远先行于收入；
- **毛利被两头挤**：API 单价降得比推理成本快，开源策略又主动放弃了一部分闭源溢价；
- **估值锚是期权而非现金流**：一级市场的融资节奏与模型代际发布高度同步，买的本质是“下一代模型的看涨期权”。

历史对照：内存芯片的产能周期、光伏的扩产周期、手游的买量周期，都经历过“技术快速迭代 + 产品同质化 + 价格战开打”的三重叠加。结局是分化的——有人把周期生意做成了成本曲线生意（台积电），有人永远困在周期里。所以真正的问题不是“会不会周期”，而是：**这条曲线上，谁在做台积电？**

## 四、跳出周期的三种护城河形态

周期不是宿命，区别只在于功夫下在哪一层：

1. **分发层**：C 端入口的 DAU 与使用时长。豆包、Kimi、元宝的竞争不在模型分，而在“谁占据用户每天第一次打开”。入口一旦形成，模型迭代就降级为供应链问题——就像苹果并不自己造全部芯片。
2. **数据飞轮层**：垂直场景里的私有数据回流。代码、法律、医疗这些领域，用户的使用行为本身就是训练语料，形成“越用越准”的复利，而这些分数在公开榜单上根本看不到。
3. **成本曲线层**：把护城河从“我更强”换成“我更便宜”。量化、投机解码、KV cache 调度、自建推理集群，每压低一个数量级成本，同台竞技的对手就少一批。开源公司的隐秘算盘正在于此：放弃模型溢价，换取生态与云收入。

药企跳出专利悬崖靠管线，芯片厂靠工艺代差。大模型公司大概率要各拿一点：产品矩阵 + 数据飞轮 + 成本优势，三者凑齐两条，才谈得上“跳出周期”。

## 五、三条冷思考

1. **给开发者与企业用户**：把“模型可替换”写进架构。加一层抽象网关、维护自己的评测集（evals），别把业务焊死在某家模型的某个版本上——发布周期意味着你的底层能力随时可能被“被动升级”或“被动降级”。
2. **给投资者与观察者**：用三个指标替代榜单情绪——token 消耗的月留存、推理毛利率、API 客户净收入留存（NDR）。分得清“发布脉冲”和“经常性收入”，才看得懂周期股的真实底。
3. **给从业者**：把发布会当负债管理。每次发布都是在向市场借注意力，利率是“下一次必须更强”。真正的复利不在参数表里，而在工作流、数据回流和成本曲线里。

模型会过气，复利不会。
