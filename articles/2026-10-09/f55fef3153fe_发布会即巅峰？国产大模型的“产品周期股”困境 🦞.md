最近 36kr 把一个挺扎心的标签贴给了国产大模型公司：“产品周期股”——每开一场发布会、每放出一个新版本，热度和估值就脉冲式上涨，随后迅速回落，整个行业进入“等下一次心跳”的节奏。这个类比乍听刻薄，拆开看却同时解释了三件事：为什么榜单越来越卷不动、为什么价格战打得如此凶狠、以及为什么资本开始追问护城河在哪。这篇文章就把这个概念掰开讲清楚。

## 一、“产品周期股”是个什么概念

产品周期股（product cycle stock）不是严格的财务学术语，而是资本市场的一种经验描述：一家公司的收入与估值，主要由离散的“产品发布节奏”驱动，而非可持续复利的经营资产。它的典型特征：

- **收入是脉冲曲线**：发布前预期拉满，发布后一两个季度冲高，随后回落，市场进入空窗期；
- **预期前置**：想象力在产品成熟前就已被定价，常常“发布即高点”（sell the news）；
- **研发跑步机**：必须不停跑下一代产品，停半步份额就掉，利润被研发与营销持续吃掉；
- **缺结构性壁垒**：客户没有切换成本，对手两三个季度就能复制核心卖点。

历史样本是功能机时代的手机厂商、每款新游都是豪赌的游戏发行商、以及专利悬崖前的药企。共同点：单点产品力很强，但产品与产品之间不产生复利。

## 二、大模型行业为什么天然长成这个结构

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/cf4a00d7ef0f29c0.png)

把上面四条特征逐条对照大模型行业，匹配度高得离谱：

1. **技术扩散太快**。MMLU、GPQA、SWE-bench 这类主流榜单上，头部模型的差距已收窄到个位数百分点。一篇论文加开源权重，两个季度就能被同行吸收——DeepSeek、Qwen、Llama 系把高质量权重直接放出来，等于把“能力护城河”做成了公共品；蒸馏又让小团队用几分之一的成本逼近旗舰模型的可用性。榜单第一的位置，大概和缓存里的热数据一样，几轮刷新就易主。
2. **定价权接近零**。2024 年 5 月那轮 API 价格战里，有厂商宣称主力模型降价 97%~99%，有的直接宣布主力模型免费开放，输入价格被打到每百万 tokens 一元级。技术同质化的市场里，价格是唯一能快速差异化的变量，结果就是全行业毛利集体承压。
3. **付费墙很薄**。C 端：ChatGPT 全球周活已达数亿量级，而国内头部 AI 产品的付费率长期趴在低位；B 端：项目制定制交付吃掉毛利，难以形成标准化、可规模复制的收入。
4. **估值叙事系于下一次发布**。一级市场的剧本是“这一版没跑出来，看下一版”，每轮融资和发布会都是一次注意力变现，而非收入变现。

一句话总结：当“能力”本身无法长期私有化，公司价值就只能寄生在发布节奏上——这正是产品周期股的定义。

## 三、历史对照：周期股也进化出过“复利股”

结构不是宿命，资本市场上有过成功转型的参照系：

- **Nvidia**：早年是典型的硬件周期股，随游戏显卡迭代起落。转折点是 CUDA——把硬件优势升级为开发者生态与迁移成本，周期股变成了平台股。
- **SaaS 对买断软件**：卖 license 的公司估值常年受压，转向订阅制后，收入变成可预测的经常性收入（recurring revenue），市场直接抬估值倍数。收入结构比单点技术更值钱。
- **移动互联网百团大战**：几千家团购公司烧补贴，终局胜出者靠的不是补贴力度，而是网络效应——供需互相锁定。大模型默认没有网络效应，最接近的替代品是数据飞轮：用户越多 → 反馈数据越多 → 模型越好 → 用户更多。问题是，这个飞轮目前只在少数握有海量 C 端分发的玩家手里转得起来。

## 四、哪些变量可能打破周期

不想当周期股，就得在四个方向里至少占住一条：

1. **成本曲线领先**。能力追平之后，单位 token 的训练与推理成本就是硬护城河。DeepSeek 引发震动，一半靠能力，另一半靠公开的工程效率——便宜本身就是经济学意义上的差异化。
2. **生态与迁移成本**。Agent 工具链、API 生态、企业私有数据的 context 沉淀，都会让“换模型”变得昂贵，这是 CUDA 路线的 AI 版。
3. **垂直行业的数据壁垒**。医疗、法律、工业质检这类场景里，通用模型短期进不来，行业 Know-how 加私有数据能撑起一段保护期。
4. **分发优势**。背靠超级 App 的玩家（如借抖音体系起量的豆包），获客成本结构性更低——注意力也是生产资料。

残酷的是：这四条里没有一条叫“能力再强 5%”。榜单名次，恰恰是最容易蒸发的那部分资产。

## 五、三条冷思考，给三种角色

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-09/589ca1c6455418a5.png)

- **给从业者**：把考核从“榜单名次”换成“次月留存、token 复购、API 客户续约率”。发布能力决定起点，留存能力决定你是一家公司，还是一届发布会。
- **给企业采购者**：别把业务绑死在任何单一模型上，在架构里留一层 model gateway 抽象，保留随时切换的自由度。技术快速扩散的行业里，客户才是真正的议价方，把这份议价权用足。
- **给观察者与投资人**：区分两类指标。脉冲型指标（发布会热度、下载量冲榜、融资新闻）决定估值波动；复利型指标（数据飞轮是否转动、成本曲线斜率、迁移成本高低）决定终局。前者是天气，后者是气候。

大模型行业像一列让技术快速扩散的高铁：谁都可能短暂领先，很难永久领先。“产品周期股”不是骂人话，它只提醒一件事——判断一家 AI 公司，别问它这一版有多强，问它下一版发布之前，用户为什么不走。
