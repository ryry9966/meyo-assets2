2025 年国产 GPU 圈的关键词，正从"单卡对标 A100"悄悄换成"超节点"。华为把 CloudMatrix 384 搬进商用机房，Atlas 950 SuperPoD 规划到 8192 卡；寒武纪、摩尔线程们的发布会，主角也从一颗芯片变成一整面机柜墙。热闹背后藏着一个朴素的问题：这么重的资产、这么高的电费，到底谁来买单？这篇把"超节点是什么、为什么是它、账怎么算、钱从哪来"一次讲清。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-17/6a36cb33e7318b53.png)

## 超节点是什么：把一个机房"焊"成一颗大芯片

- **定义**：把几十到上万颗 GPU，用超高带宽、超低时延的专用互联连成一个"逻辑大芯片"，统一调度、共享显存。业内管这叫扩大 scale-up 域。
- **类比**：单机服务器像多核 CPU 里的一颗 die，超节点相当于把整个机房变成"一颗 CPU"的硅片。NVIDIA 的 GB200 NVL72 是标杆：72 颗 Blackwell GPU 全 NVLink 互联塞进一个机柜，单卡卡间双向带宽 1.8TB/s，与显存带宽同一量级。
- **国产激进解**：华为 CloudMatrix 384 用 384 颗昇腾 910C，以全光互联跨机柜组网，聚合算力反超 NVL72——代价是机柜数、光模块用量和功耗全上去了，公开测算整机功耗约为 NVL72 的四倍量级。
- **和传统集群的区别**：传统 scale-out 走以太网/InfiniBand，时延在微秒到毫秒级；超节点要求百纳秒级、带宽接近卡内显存。一句话：让"借邻居的显存"像"借自己的显存"一样快——快到邻居以为自己住你家。

## 为什么国产厂商集体押注超节点

1. **单点追不上，就换赛道。** 受先进制程与 HBM 供应限制，国产单卡性能与国际旗舰有 1~2 代差距，短期难抹平；而高速互联、光通信、液冷、电源、整柜交付恰是中国供应链强项。以系统补单点，是现实约束下的理性解。
2. **大模型架构推着走。** MoE 的专家并行（EP）会把一个 token 激活的不同专家摊到几十上百张卡上，卡间 all-to-all 通信量暴涨；长上下文又把 KV cache 显存需求推高几个量级。主流推理部署普遍采用 prefill/decode 分离 + 大规模 EP，这些玩法全建立在超节点级互联之上。不是厂商想卷互联，是大模型的通信模式决定了必须卷。
3. **头部也在这么走。** NVIDIA 的路线图同样是把 scale-up 域越做越大。国产厂商对齐"超节点"叙事，既借行业共识减少生态孤岛感，也方便用"聚合算力对标"讲一个客户听得懂的故事。

## 竞逐者图谱：各家手里的牌

- **华为**：唯一实现超节点规模商用的选手，CloudMatrix 384 已落地；下一代 Atlas 950 SuperPoD 规划 8192 卡、2026 年推出，并开放互联协议灵衢（UnifiedBus），想把超节点标准做成公共地基——颇有"卖铲子"的味道。
- **寒武纪**：思元系列搭配自研 MLUlink 互联，绑定头部互联网客户的私有化集群。
- **海光/曙光系**：深算系列 DTU 依托曙光整机与行业渠道，走稳妥的行业客户路线。
- **摩尔线程**：夸娥（KUAE）集群从千卡向万卡推进，主打全功能 GPU + 自研互联。
- **燧原、壁仞、天数智芯等**：或绑定云厂商定制，或扎根地方智算中心。
- **共同点**：发布会比拼的不再是单卡跑分，而是互联带宽、集群规模、聚合算力和整柜交付——芯片公司的竞争，正在变成系统工程公司的竞争。

## 一笔经济账：算力翻倍，账单也在翻倍

- **电费**：以 CloudMatrix 384 量级的整机功耗估算，按 0.6~0.7 元/度工业电价，单套一年电费就在数百万元级别。功耗换来互联带宽，这笔钱最终摊进每 token 成本。
- **网络与器件**：全光互联意味着海量 400G/800G 光模块、背板连接器与大功率电源，这部分 BOM 成本远超传统集群，也是光模块产业链跟着起飞的原因。
- **折旧与利用率**：GPU 服务器通常按 4~5 年折旧，芯片迭代却以年计；部分地方智算中心"建得起、用不满"的问题已见诸公开报道。超节点把更多资本开支压在互联上，利用率一旦不足，账面会非常难看。

## 谁来买单：三只钱包与一个闭环

1. **政策与国资**：地方智算中心、国资云平台，买的是数字基建与产业招商，对回报率容忍度高，是 2023~2024 年国产算力的主力买家。但池子有天花板，行业也在强调防止盲目建设，这口井会越抽越慢。
2. **运营商与行业国企**：三大运营商近年 AI 服务器集采中国产芯片占比明显上升；逻辑是合规、自用加算力对外服务，节奏稳定，是超节点最确定的现金流。
3. **互联网大厂与模型公司**：字节、阿里、腾讯们掏钱更挑剔，只买"用得值"的场景。推理侧对单点性能容错更高、迁移成本可接受，是国产超节点先落地的地方；阿里三年 3800 亿元 AI 基础设施投入中，国产算力占多大比重，直接决定这条赛道的市场厚度。
4. **终极买单人：Token。** 前两只钱包本质是产业资本预付，超节点要形成健康循环，必须等应用侧收入闭环，API、Agent、行业模型每天烧掉的 token 变成持续现金流。头部云厂商 token 调用量确实在高速增长，是好信号，但目前的量级还养不起全部在建智算中心。

## 写在最后：三条冷思考

1. **别把"聚合算力对标"听成"单点对标"。** 超节点赢在系统，也脆在系统：互联故障域变大、运维复杂度指数上升，断点续训与故障恢复能力，比发布会上的峰值算力更值得关注。
2. **采购先算"每 token 成本"，不是"每卡价格"。** 电费、光模块、液冷、机房承重改造全要摊进 TCO；同样预算，多问一句：跑我的真实业务，这套超节点的实际吞吐到底是多少？
3. **软件生态决定残值。** 硬件三年一换，软件资产却要沉淀五年以上。买单人真正该投资的，是各家语言栈、编译器与迁移工具的成熟度——生态留得住开发者，下一轮预算才轮得到它们。
