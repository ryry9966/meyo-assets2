最近半年盯「个人 Agent」这条赛道，会发现动作出奇一致：一批喊着「你的 AI 全能助理」的产品，要么砍掉通用功能收缩进垂直场景，要么转身去做协议和基础设施，要么改口卖「企业工作流」。36kr 抛出的问题很直接：这波集体转向，是不是说明行业的底座换了？我的判断是——换了，而且不止一层。下面按「现象 → 机制 → 原因 → 出路」拆开讲。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-17/22e269c199b96177.png)

## 一、先看现象：转向不是乱转，四个方向高度一致

1. **通用 → 垂直**。不少通用助理悄悄砍掉日程、订票这类「什么都干」的承诺，聚焦 coding、深度调研、招聘、财务分析这些能交付「可验证结果」的场景。
2. **C 端 → B 端**。个人订阅难收费，转向按席位或按结果向企业收钱。
3. **应用 → 基础设施**。把自己攒的编排、记忆、工具接入能力做成协议和服务，转行「卖水」。
4. **全自动 → 人机协作**。默认把控制权交还用户，补上审批、审计和回滚。

四个方向看似分散，其实都在离开同一个位置：夹在基座模型和用户之间的「薄壳通用助理」。

## 二、底座换了什么（一）：Agent 能力被压进了模型本身

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-17/94e0f3ea162adf8f.png)

2023 年那批 Agent 的配方是：基座 LLM + prompt + function calling + 外挂记忆。本质是薄壳——模型每走一步都要靠提示词「被说服」去用工具，任务链条一长，误差层层放大，断在第五步是常态。

变化发生在 2024–2025：主流实验室开始用 RL 把工具调用、长程规划、computer use 直接 post-train 进模型。证据在 benchmark 上很直观：SWE-bench Verified 上「真实修 bug」的成绩，一年多从个位数爬到七八成；OSWorld 这类「让 AI 操作真实电脑」的基准，也从百分之十几一路往上蹿。

这意味着以前靠外挂编排实现的「会干活」，正在变成基座自带。你在薄壳里写的很多编排工程，会被模型的一次版本升级直接收编。这是「底座换了」的第一层含义：**从「模型即 API」变成「模型即 Worker」**。

## 三、底座换了什么（二）：协议、执行环境和成本结构

Agent 不只是模型，它是「模型 + 工具 + 环境 + 记忆」的系统。换代的另一半发生在模型之下：

- **协议层**：MCP 把「接工具」标准化成了公共插座，OpenAI、Google 相继跟进；A2A 则在尝试标准化 Agent 之间的协作。私有集成变成了行业接口。
- **执行环境**：computer use 需要浏览器、沙箱虚拟机、鉴权与支付通道——Agent 的「身体」本身成了新中间件。
- **成本结构**：一个长任务动辄几十万 token，环境开销另算。行业里流传的说法是，早期 computer use Agent 完成一单任务，token 成本按美元计，不是按厘。

当模型、协议、环境三层同时换代，只做提示词编排的通用个人助理，恰好站在三层夹缝里——最先被挤压，合情合理。

## 四、为什么偏偏是「个人」Agent 最先受伤

- **入口被攥着**：ChatGPT、Claude、Gemini 天然就是每个人的对话入口，通用助理很难说服用户再装一个 App。
- **数据飞轮缺位**：通用场景没有独占数据，迭代速度拼不过基座厂商的版本节奏。
- **信任成本极高**：让 AI 动你的邮箱、文件和钱包，失败一次的代价是灾难级的。通用产品拿不出「单点成功率 99%」这样的故事。
- **账算不平**：C 端愿为「省时间」付的溢价有限，任务成本却在涨，订阅制两头受挤。

一句话：个人 Agent 的护城河，恰好是这次换代冲掉的那部分。

## 五、这不是溃败，是行业分工在收敛

历史上演过两次：云计算时代，倒下一批「转售服务器」的中间商，但长出了垂直 SaaS 和 infra 巨头；移动时代，通用门户 App 死了一茬，垂直工具活得很好。

这一轮同理——底座厂做「Worker」，基础设施层做「水电煤」，应用层要活命只有两条路：要么扎进有独占数据和专属环境的垂直场景，要么沉下去做协议和执行环境。所谓「集体转向」，其实是市场在重新划定每一层的边界。转向的动作越整齐，越说明大家在向同一个新结构对齐。

## 六、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-17/066ca0f8cf275d32.png)

1. **别把编排当护城河**。Prompt 和工作流迟早被基座收编，独占数据、垂直环境、行业 know-how 才是能带进下一代的资产。
2. **押注可移植性**。按 MCP 这类开放协议设计工具与记忆层，底座再换代，你的资产还能跟着走；锁死单一模型的薄壳，每次版本发布都是一封拆迁通知。
3. **卖「可验证的结果」，不卖「全自动的承诺」**。设计好 human-in-the-loop 的检查点、审计与回滚，按结果计费——在 Agent 时代，信任是唯一硬通货。

底座换代的噪音很大，但方向很清楚：能力下沉，分工上移。看懂这一层，「集体转向」就不再是坏消息，而是一张路线图。
