最近「Token 出海」被 36kr 等科技媒体反复提起：大模型公司把 API 与开源模型卖向海外，token 这个原本冷僻的技术词，正在变成一种按量计价的「出口商品」。它怎么定价、钱从哪来、门槛在哪，这篇把它拆开看。

## 一、Token 是什么商品：智能的「度数」

- Token 是大模型处理文本的最小单位。一个英文单词约合 1.3 个 token，一个汉字通常对应 1~2 个 token（取决于分词器）。
- 主流模型 API 按 token 计费，输入、输出分开计价，输出一般更贵，因为「生成」比「理解」更耗算力。
- 类比水电煤：电按度、水按吨，token 就是「智能」的计量单位。你在 AI 应用里的每句问答，背后都在跑表。
- 新变量：o1、DeepSeek-R1 这类推理模型会先生成大量隐藏的「思考 token」再作答，且通常按输出计费。单次任务的消耗量因此放大几倍到几十倍，跑表速度变快了。

## 二、出海的两台发动机：价格差与开源外溢

1. **价格差**。2024 年以来国内 API 价格战打得极狠，部分模型降到每百万 token 一两元人民币量级；海外主流模型的输出定价普遍在每百万 token 数美元到数十美元。同一份算力卖到哪里更值钱，账很好算。
2. **开源是流量入口**。DeepSeek-R1 发布时定价约为同级闭源模型的几分之一，还在 2025 年初登顶美区 App Store 免费榜；据阿里方面披露，其开源 Qwen 系列的全球衍生模型已超过十万个。开源先把海外开发者的心智占住，商业版 API 再承接付费需求。
3. **应用出海带动消耗**。AI 陪伴、视频生成、跨境电商客服这类应用在海外获客，推理发生在云端，token 用量随用户增长滚动，收入以美元结算。

## 三、成本结构：毛利藏在工程效率里

- 成本端主要是 GPU（自购或租用）、电力与机房。卡价不菲，但真正的变量是利用率。
- 推理优化是利润杠杆：请求批处理（batching）、KV cache、量化、MoE 架构，每一项都能把单 token 成本压低一截。
- a16z 曾提出「LLMflation」：同等能力的模型，推理价格大约每年下降 10 倍。这意味着你今天的价格优势，明年可能只是行业均价。
- 所以这门生意的本质是「规模 × 效率」的正循环：用量越大 → 单位成本越低 → 有底气降价 → 换来更大用量。跑不出规模的玩家，会被价格战一点点磨掉毛利。

## 四、真实门槛：不是把 API 挂上网就有人买

- **合规**：GDPR、数据本地化、内容审核标准，各市场差异很大；企业客户采购前会审供应商的安全资质。
- **基础设施**：海外节点、延迟与带宽直接决定体验，跨境网络的不确定性需要冗余设计。
- **支付与账务**：美元收款、企业账期、发票税务，都是写代码之外的脏活累活。
- **生态与信任**：英文文档、开发者社区、公开基准成绩、企业级 SLA，海外客户买的是可预期，不只是便宜。

## 五、谁在赚钱：四种典型姿势

1. **API 直销（MaaS）**：按量计费赚差价，吃规模。
2. **开源 + 托管服务**：模型免费，部署、微调、私有化收费，吃服务溢价。
3. **应用层打包**：把 token 成本折进订阅费，卖结果而不是卖 token，就像没人按水表买奶茶。
4. **聚合网关**：把多家模型的 API 打包调度，帮企业统一计费、故障切换，赚通道与工具的钱。

## 冷思考：给准备上船的人三条提醒

1. **低价不是护城河**。推理价格每年降一个数量级，纯价格优势保质期极短；沉淀在工程效率和场景理解上的东西，才算资产。
2. **算清「有效 token」**。客户要的是任务完成质量，不是 token 数量。思考 token 既是成本也是体验，定价与产品设计都该围绕「每块钱买到多少有效智能」重构。
3. **合规与生态先行**。数据架构、本地化部署、开发者关系这些慢变量，决定你能走多远；它们比再降十次价更值得投入。

说到底，Token 出海就是大模型时代的加工贸易：进口算力与电力，出口按 token 计价的智能。生意能否长久，看成本曲线、合规功底和对场景的理解，和所有外贸一样，没有躺赢的航线。
