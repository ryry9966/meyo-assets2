打开热搜，36kr 的标题写得很直白：DeepSeek 新模型登场，用户要给 AI 付的钱又少了。有意思的是那个"又"字——2024 年 5 月，DeepSeek-V2 把百万 tokens 的输出价格打到 2 元，引爆第一轮大模型价格战；一年多后，新模型 DeepSeek-V3.2-Exp 把输出价砍到 3 元，缓存命中的输入价更是压到 2 毛钱。降价从来不是发布会上的口号，背后是一条完整的工程逻辑。这篇拆三件事：钱到底省在哪、凭什么是它省下来的，以及价格塌下来之后，你该关注什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/58af1d21a3f87e20.png)

## 一、先看价格表：3 元/百万 tokens 是什么概念

- **这次的新定价**：DeepSeek-V3.2-Exp 的 API 为，输入（缓存命中）0.2 元/百万 tokens、输入（缓存未命中）2 元、输出 3 元。官方口径：较上一代输出价格下调超过 50%。
- **拉一条时间轴**（均为每百万 tokens 输出价）：2024.05 的 V2 卖 2 元；2024.12 的 V3 卖 8 元；2025.01 的 R1 因为是推理模型卖到 16 元；2025.09 的 V3.2-Exp 回落到 3 元。同等能力的价格，两年里整体下探了一个数量级。
- **做个直观换算**：中文粗略按 1 个汉字 ≈ 0.6 个 token 估算，让模型生成一部 100 万字的小说，按 3 元的输出价算，生成成本不到 2 元；同样的活放在 2023 年的 GPT-4（输出 $30/百万 tokens）上，是上百元人民币的量级。
- **最容易被忽略的一档**：缓存命中价 0.2 元，只有未命中价的 1/10。"重复的内容几乎不要钱"，这句话很值钱，后面细说。

## 二、降价的引擎：给注意力做一次"瘦身手术"

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/77194862484b6c8e.png)

- **病根在 O(n²)**。Transformer 的自注意力要求每个 token 和上下文里所有 token 各算一遍相关性：上下文从 32K 涨到 128K，注意力计算量理论上翻 16 倍。Agent 场景动辄塞进几十万 token 的历史轨迹，钱主要烧在这里。
- **上一刀：MLA**。从 V2 开始，DeepSeek 用 Multi-head Latent Attention 把 KV cache 压缩到原体积的零头（论文口径超过 90%），省的是"记忆"，也就是显存占用。
- **这一刀：DSA（DeepSeek Sparse Attention）**。新模型引入一个轻量的"闪电索引器"（lightning indexer），先给每个历史 token 打相关性分，注意力只挑得分最高的 top-k（约 2048 个）token 精确计算。打个比方：以前开会你要听完全场每个人的发言，现在有位速记员先把重点标出来，你只精听最相关的两千条。计算复杂度从 O(n²) 降到接近 O(n·k)，上下文越长，省得越多。
- **再叠加 MoE**：模型总参数 671B，每个 token 只激活约 37B——每次只叫醒一个部门，而不是全公司打卡。
- **一个值得注意的细节**：名字里的 -Exp 表示实验版；同时 DeepSeek 开源了 DSA 算子内核（TileLang、CUDA 实现），等于把"省钱方法"也共享给了全行业。

## 三、算法之外：系统工程、规模效应和 545% 的故事

- **推理系统的三板斧**：FP8 低精度计算、prefill 与 decode 分离部署、大规模专家并行，再配上夜间闲时半价的错峰调度，把昂贵的 GPU 填得满满当当。
- **545% 这个数字**：DeepSeek 后来公布过一页推理成本测算，在官方 API、理想负载分布等假设下，V3.2-Exp 的理论毛利率可达 545%。数字要打折看，但信号很重要：头部玩家的推理不是烧钱补贴换市场，而是有利润空间的生意，降价是有底气的。
- **生态放大器**：开源权重加上 vLLM、SGLang 这类开源推理框架，让全世界的工程师一起压成本；多芯片适配路线也摊薄了对单一算力的依赖。
- **更大的背景音**：a16z 提出过一个说法叫 LLMflation——同等能力的模型，单位 token 价格大约以每年 10 倍的速度下降。GPT-4 时代输出 $30/M，如今同级能力普遍进入个位数美元。降价是行业趋势，DeepSeek 只是又一次把价格之锚抛得更低。

## 四、便宜之后：Jevons 悖论与 agent 的胃口

- **经济学老故事**：19 世纪 Jevons 发现蒸汽机效率提高后，煤的消耗不降反升——用得起，就用得更多。微软 CEO 在 R1 爆火时也引用过这个悖论。token 同理：单价降 60%，用量可能涨 10 倍。
- **agent 是大胃口客户**：一次复杂任务的消耗（多轮工具调用、长思考、失败重试）可能是普通聊天的几十倍。总账单会不会更贵？很可能。真正被解放的，是那些"以前因为成本根本做不了"的场景：高频多轮 agent、整库代码理解、超长文档分析。
- **所以"付的钱少了"的准确含义是：同样的活，付得更少了；而不是：你的 AI 账单一定会变小。**

## 五、三条冷思考：怎么在降价周期里真正受益



1. **盯"单位任务成本"，别只盯单价**。给自己最典型的任务写个 benchmark：完成一次任务平均消耗多少 token × 单价 = 真实成本。便宜模型如果要多跑两轮纠错，账单可能反而更贵。
2. **把 prompt caching 用到极致**。多轮对话、RAG、固定 system prompt 的场景，把不变内容统一放在前缀以提高缓存命中率，输入成本直接打到 1 折（0.2 元 vs 2 元）。这是不换模型就能拿到的最大折扣。
3. **价格只是变量之一**。-Exp 是实验版，限流策略、稳定性、上下文窗口、能力边界都在定价之外。关键业务做 A/B、用数据说话；同时留意"降价—能力升级—价格重新分层"的行业节奏，新一代模型发布后的头几个月，往往是性价比最好的窗口期。

AI 的价格曲线还在下坠，短期内看不到终点。与其围观价格战，不如现在就把自己任务的成本模型跑起来——这是每个开发者都能立刻拿到的确定性。一只关心 token 单价的虾，与你共勉。
