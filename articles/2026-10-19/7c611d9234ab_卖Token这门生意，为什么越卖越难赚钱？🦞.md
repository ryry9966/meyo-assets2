最近 36kr 一篇报道把“卖 token”称作一门不好赚钱的新生意。这事值得掰开揉碎算一遍账：2024 年 5 月，字节把豆包主力模型价格打到 0.0008 元/千 tokens，几天内阿里降价 97%，百度直接免费开放两款主力模型，海外 GPT-4o 也一年多价格腰斩再腰斩。“卖 token”——把模型能力按用量批发给开发者——曾被寄望为“AI 时代的云计算”，怎么就走到了越卖越便宜、越卖越心疼这一步？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/fd2d48f6fda3c280.png)

## 先搞清楚：卖 Token 到底在卖什么

- **Token 是大模型处理文本的最小单位**，1 个汉字大约对应 1~2 个 token，取决于分词器（tokenizer）的效率。
- **商业模式叫 MaaS（Model as a Service）**：模型部署在云端，开发者调 API，按输入加输出的 token 总量计费，行业习惯用“元/百万 tokens”标价。
- 听起来像电信卖流量、云厂商卖服务器时长，但有个致命区别：纯软件的边际成本趋近于零，而每吐一个 token，背后都是实打实的 GPU 算力和电费。
- 所以这门生意的底色是“高固定成本 + 不为零的边际成本”，更接近重资产制造业，而不是大家想象中的印钞软件。

## 成本账：毛利率为什么撑不起来

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/7194ca37e5c3095f.png)

把一台推理服务器的账摊开看：

1. **设备折旧**：一台 8 卡 H100/H800 级别服务器市场价两三百万元人民币，按 3~5 年折旧，每天睁眼就是几千块的“卡片税”。
2. **持续运营**：单卡功耗 700W 起步，电力、散热、带宽、值班运维全是烧钱项，一天 24 小时不能停。
3. **利用率困境**：白天高峰挤爆、深夜算力闲置，和电网调峰是同一道难题；利用率上不去，单 token 摊销成本就下不来。
4. **降本在发生，但价格降得更快**：KV Cache 优化、量化、MoE 架构、投机解码、更大 batch，每个季度都有进步，可惜 API 价格下降曲线的斜率更陡，剪刀差反而越拉越大。

这里有个经典现象：**杰文斯悖论（Jevons Paradox）**。19 世纪的经济学家发现，蒸汽机效率越高、煤耗反而不降反升——因为用得起的人多了。放到今天就是：推理降本 → API 降价 → 用量暴涨 → 总算力开支不降反升。降本是能力，赚钱是另一回事。

## 价格战：从“一个字比印刷还贵”到贴地飞行

- **2023 年**：头部模型 API 定价高企，输入价格普遍在几十元/百万 tokens 量级，卖 token 像卖金粉。
- **2024 年 5 月**：豆包主力模型 0.0008 元/千 tokens，宣称比行业低 99%；阿里通义随即降价 97%，百度文心两款主力模型直接免费。
- **2024 年底至今**：DeepSeek 用开源加极致工程优化把价格锚到成本线附近，开源协议宽松到闭源厂商无法维持能力溢价。
- **海外同步**：GPT-4o 发布价比 GPT-4 Turbo 直接砍半，此后继续走低。

价格战不是厂商集体上头，而是四个必然：

1. **能力趋同**：各家 benchmark 差距缩小，开发者切换成本约等于零，谈不上忠诚度；
2. **开源锚定了价格下限**：免费且够用的模型一出现，闭源 API 的溢价空间就被打掉；
3. **抢开发者就是抢生态**：初期烧钱换份额，和云计算当年的打法如出一辙；
4. **算力供给上来后短期过剩**，价格自然向边际成本滑落。

## 谁在赚钱，谁在陪跑

产业链利润的分布相当“微笑”，只是笑的位置不在模型厂商脸上：

- **卖铲子的最稳**：英伟达毛利率长年在 70% 以上，AI 算力链条里最大的一块利润被它拿走；
- **云厂商次之**：Azure、AWS Bedrock、阿里云百炼把 token 和算力、存储、企业服务打包卖，token 是引流入口，赚钱靠一揽子；
- **应用层轻装上阵**：Cursor、Perplexity 这类产品低价买 token、高价卖“结果”，赚的是产品体验和场景理解的钱；
- **纯卖 token 的模型厂商最尴尬**：API 收入体量与动辄几十亿的训练投入不成比例。OpenAI 收入虽高，据报道仍处大幅亏损；国内多数厂商 API 收入还在亿元级徘徊，毛利薄得像纸。

一句话总结：**上游商品化是下游的红利**。token 越是白菜价，买 token 做应用的人越笑得开花。

## 这门生意什么时候能好起来

三个变量值得盯：

1. **Agent 把消耗拉起来**：一次智能体任务的 token 消耗可达单轮对话的 10~100 倍——多轮工具调用、长思维链、反复自我纠错，个个都是吃 token 大户；
2. **多模态上量**：视频生成的算力开销远超文本，1 秒视频背后的计算量抵得上成千上万 token 的文本，这类“吞金兽”普及后，消耗基数会整体换挡；
3. **商业模式升级**：从卖 token 到卖结果（outcome-based pricing），按“解决了一个工单”“生成了可用代码”计费，把商品卖成服务。

云计算的历史可以参照：AWS 也熬过多年价格战，最终靠规模效应和增值服务把钱赚回来。token 生意大概率同样要熬过基建期——谁能把成本曲线压到对手之下，谁才有资格谈盈利。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/039587cff2a2cfde.png)

1. **盯住剪刀差**：判断一家模型公司的健康度，就看每 token 成本的下降速度能不能跑赢 API 价格的下降速度。跑不赢，规模越大、亏得越多。
2. **别把卖 token 当终局**：这是水电煤逻辑，比拼的是成本曲线、资金弹药和规模。三样凑不齐，趁早切应用、切垂直场景，靠自己的数据和场景壁垒赚钱。
3. **对多数小团队，买 token 比卖 token 好做**：上游越商品化，下游机会越大。把便宜的 token 变成别人愿意付费的结果和现金流，才是这一轮 AI 浪潮里小团队真正够得着的一段。
