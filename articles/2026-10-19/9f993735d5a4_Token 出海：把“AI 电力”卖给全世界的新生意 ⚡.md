2025 年 AI 行业最值得盯的一个变化：token 从论文里的计量单位，变成了财报上的收入科目。国内大模型把百万 token 的价格打到“地板价”之后，厂商们几乎同时把摊位摆到了海外——卖 API、上国际云市场、开源权重让全球服务商托管。36kr 把这概括为“Token 出海正成为一门新生意”。这门生意到底怎么运转、钱从哪来到哪去？这篇拆开讲清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/8f1bfd41d81f5b39.png)

## 一、Token：从技术名词到商业计量单位

- **Token 是模型眼里的“最小文字单元”**。模型不直接读汉字或单词，先由 tokenizer 切分：英文大约 1 token ≈ 4 个字符（约 0.75 个单词），中文常见汉字通常 1 个 token，长词和生僻字会更碎。一段 500 字的短文，粗略对应 600~900 token。
- **计费是“电表式”的**：主流 API 按每百万 token 计价，输入、输出分开算，命中缓存（prompt caching）的部分再打折。可以类比成：输入是进水，输出是出水，缓存是循环用水。
- **收费模式的三级演进**：卖 License（一次性）→ 卖订阅（SaaS，按月）→ 卖用量（按 token）。最后这种叫效用计费（utility pricing），和电力公司按“度”收费完全同构。它把“模型好坏”翻译成了“每 token 成本”——从此可比较、可压缩、可出口。这就是整个故事的物理基础。

## 二、为什么出海：三重推力撞在一起

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/cfcca87c47e1f404.png)

1. **国内价格战，把毛利卷薄了**。2024 年起国产模型 API 接连降价，部分百万 token 输入价格进入“几毛钱”区间；同样能力档位下，国内价格常常只有海外旗舰模型的零头。国内把价格打穿的副产品是：练出了一身低成本内功。
2. **成本结构确实能打**。以 DeepSeek 公开的论文数据为例：V3 训练约 2048 张 H800、557 万美元量级；配合 MoE 架构、FP8 低精度、MLA 注意力机制和 KV cache 优化，推理端单位 token 成本显著低于行业平均。R1 发布时输出 token 定价约为同档旗舰闭源模型的 1/20~1/30，直接把“性价比”做成了全球开发者社区的话题。
3. **开源是零成本的全球分销网**。公开数据显示，基于 Qwen 的开源衍生模型已超过 10 万个；DeepSeek 开源后，Hugging Face 下载量与第三方托管热度长期霸榜。开发者先用开源权重自己搭，量起来之后自然升级到官方 API 或云托管——开源即获客，token 负责变现。

一句话总结推力：**内功（低成本）× 口碑（开源）× 市场（海外价差）**。同样的 token 换个市场卖，价格弹性大得多，差不多是大模型界的“汇率套利”。

## 三、三条航道：token 是怎么“漂”出去的

1. **官方 API + 聚合网关**。通过 OpenRouter 这类聚合器，或国际云厂商的模型目录上架。聚合器替厂商解决支付、合规、多模型路由，代价是分走一层利润。
2. **开源权重 + 第三方托管**。Groq、Together、Fireworks 等海外推理服务商自行部署开源模型。厂商不直接收这笔 token 钱，但赚到了市占和生态位。DeepSeek 爆火时官方 API 一度限流，溢出流量被全球第三方托管承接——“权重出海、推理本地化”是很独特的姿势。
3. **云平台捆绑 + 私有化部署**。借国际云的数据中心把推理节点铺到用户附近——时延是硬约束，token 是流式吐出来的，物理距离直接决定体验。对东南亚、中东这类有数据主权和私有化需求的客户，卖的是 license、一体机和交付服务。

三条航道并不互斥，头部玩家基本全都要。

## 四、账本：毛利、利用率与 Jevons 悖论

- **推理毛利 ≈ token 单价 × 有效吞吐 − GPU 折旧 − 运维带宽**。命门是利用率：GPU 空转就是纯烧钱。所以厂商拼命做批处理（batching）、错峰调度、缓存命中，本质上都是把“电”卖得更满。
- **规模效应真实存在**。集群越大、调度越精细，单位 token 成本越低，降价才有底气。这和云计算的飞轮是同一个物理结构——所以能看到头部玩家动辄三年千亿级的 AI 基础设施投入计划。
- **Jevons 悖论在托底**：效率提升、价格下降，反而刺激总消耗上涨。单价跌一个数量级，调用量可能涨得更多——“以量补价”是行业当前的共识剧本。
- **风险也很具体**：高端算力供给的稳定性、各市场的数据合规（如 GDPR、数据本地化存储要求）、跨境支付与回款链路、以及 7×24 小时的海外运维。出海不是把界面翻译成英文就完事，每一项都是工程量。

## 五、收尾：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/ddf304716a4af1ec.png)

1. **买 token 的人（开发者/企业）：上抽象层**。用 LiteLLM、OpenRouter 这类多模型路由，业务别绑死单一供应商；对比报价时重点看三处——缓存定价、长文本与多模态计费、限流与并发政策。很多“便宜”和“贵”都藏在这些细节里。
2. **卖 token 的人（创业者）：想清楚卖的到底是什么**。纯拼 token 单价，窗口期不会太长——单价长期会逼近边际成本。真正扛得住周期的是工具链生态、微调与部署服务、和具体行业场景的绑定。参考云计算的历史：卖电的利润率有限，赚大钱的是电器和用电方案。
3. **看热闹的人（行业观察）：盯两个指标就够**。一是头部玩家单位 token 成本的下降斜率，它决定这门生意打不打得动；二是开源生态的衍生模型数量与第三方托管广度，它决定海外开发者来不来。Token 出海不是故事的终点，它只是 AI 基础设施全球化递来的第一张账单——账单才刚开，电表还在转。
