大模型行业有个反直觉的现象：手里握着人类最前沿的技术，卖的东西却越来越像大白菜。2024 年以来，主流模型 API 价格经历多轮腰斩再腰斩，「每百万 token 几毛钱」成了货架常态。36kr 最近把这门生意总结为一句话：卖 Token，不好赚钱的新生意。技术最热，利润最薄，中间到底发生了什么？这篇我们把账本拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/ab192c43ebfa08bf.png)

## Token 是怎么计价和卖出去的

- 先说单位。token 是模型眼里的最小文本单元，1 个 token 约合 0.75 个英文单词、0.5~1.5 个汉字。一次日常对话大约消耗几千 token，一小时会议转写可能上万。
- 计费公式很朴素：输入按 input tokens 收钱，输出按 output tokens 收钱，输出价通常更贵，因为生成是逐 token 自回归解码，比并行读入更烧算力。
- 成本端三座大山：GPU 采购与折旧、电力机房、集群运维。别以为瓶颈是算力，多数时候显存带宽才是那个先爆的项。
- 感受一下降价速度：GPT-4 发布时输入 $30、输出 $60（每百万 token）；一年多后 GPT-4o mini 用约 $0.6 的输入价做到接近的能力档位，相差约 50 倍。国内 2024 年 5 月字节豆包把主力模型压到 0.8 元/百万 token，各家连夜跟进，行业进入「厘时代」。

## 降价为什么停不下来：一年降一个数量级

Sam Altman 在 2025 年初公开撰文：同等能力的 AI，使用成本大约每 12 个月下降 10 倍。听着像口号，背后却是三台真实的发动机：

1. **硬件迭代**：从 Hopper 到 Blackwell，单片 GPU 的 token 吞吐持续上升，单位成本一路下探；
2. **推理工程**：continuous batching、speculative decoding、FP8 量化、KV cache 复用与「缓存命中打折」——DeepSeek 的缓存命中价只有原价的几分之一，就是这套工程的红利；DeepSeek-V3 公开论文口径约 558 万美元的训练成本，也证明算法侧能亲手拉低成本曲线；
3. **开源压价**：模型跑分趋同后，价格成了最顺手的武器；Llama、Qwen、DeepSeek 的开源权重免费可得，闭源 API 头顶永远悬着一块「开源天花板」。

结果是杰文斯悖论上场：单价跌 10 倍，总量可能涨 30 倍。用量确实在爆发，微软披露 2025 财年一季度处理超 100 万亿 token、同比 5 倍，但「卖得更火」和「赚得更多」，从来不是一回事。

## 不好赚钱的根子：商品化 + 重资产

- **商品化**：跑分差距缩小、迁移成本趋零，token 就成了无差别商品。商品生意的宿命，是毛利被压到「社会平均」，除非你有一条别人抄不走的成本曲线。
- **重资产**：一片旗舰 GPU 上万美元，万卡集群光采购就是十亿美元级，折旧摊 3~5 年；利用率不满载，GPU 空转烧电，像一张闲置的健身房年卡，钱照付，人不来。
- **毛利结构像公用事业，不像软件**：传统 SaaS 毛利 70% 起步，token 生意的毛利率要看算力利用率脸色。不少公司的「AI 收入」实质是贴着成本的转售差价——那是贸易，不是软件。
- **历史剧本并不陌生**：云计算把服务器卖成了「电」，运营商把流量卖成了「管道」，价值随后都向上层迁移。这一轮剧本相似，只是节奏被压缩了十倍。

## 那钱去哪了：往产业链上头看

- **卖铲子的最先结账**：训练/推理芯片厂商毛利率 70% 上下，行业利润的相当一部分在硬件层就落袋了。
- **云厂商打的是组合拳**：模型当入口，云资源当利润区。有厂商干脆把自家模型 API 白送，靠带云生意回本，看着像慈善，其实是超市里用来引流的特价鸡蛋。
- **真正的消耗大户在应用层，尤其是 Agent**：会反思、会调用工具、带长上下文的 agent，单任务 token 消耗可能是一问一答 chatbot 的几十到上百倍。单价再便宜，密度上来了，账才立得住。
- **侧门在垂直与私有化**：金融、医疗、制造愿意为确定性、合规、私有部署付溢价，这是绕开通用价格战的活路之一。

## 三条冷思考

1. **看毛利率，别只看收入增速**。判断一家「AI 公司」是软件还是贸易，先问两个数：毛利率多少？成本是否随收入线性增长？贴着成本转售 token 的收入，听听就好。
2. **用「消耗密度」替代「用户数」评估应用**。DAU 漂亮但每次只烧几百 token 的产品撑不起账单；用户为结果付费、单任务消耗大的场景，才接得住这门生意。
3. **把「单价通缩」写进你的模型里**。做收入预测，按年度数倍到十倍降价推演；反过来，把推理降本（缓存、蒸馏、智能路由小模型）当成核心工程能力——在通缩的商品生意里，成本曲线几乎就是唯一的护城河。
