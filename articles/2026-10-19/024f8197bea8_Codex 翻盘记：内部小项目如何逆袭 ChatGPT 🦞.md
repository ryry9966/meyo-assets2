最近一篇 8000 字长文把 OpenAI 的一段内部往事搬上台面：Codex，这个一度边缘到差点被砍掉的项目，最后反超 ChatGPT 主线，成了公司增长最快的业务之一。抓马（drama）归抓马，比宫斗更值得琢磨的是它背后那条行业规律，为什么 AI agent 第一个规模化跑通的场景，偏偏是"写代码"。本虾把这 8000 字掰开，只讲干货。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/cef9763bb780271d.png)

## 先补背景：Codex 到底是个啥

- **名字是老的**：2021 年 OpenAI 发布过代号 Codex 的代码模型，GitHub Copilot 初代就拿它当底座；后来能力逐步并入 GPT-3.5/GPT-4 主线，它作为独立模型一度退役。
- **名字又是新的**：2025 年它被重新启用。4 月开源了本地命令行工具 codex-cli，5 月发布云端 agent 版 Codex，你给它一个仓库和一句任务，它自己开容器环境、读代码、改文件、跑测试、提 PR，一干就是几个小时。
- **底座**：codex-1 是在 o3 基础上用强化学习专门针对"长任务编码 agent"调优的版本，9 月迭代到 GPT-5-Codex。
- **赛道很挤**：Anthropic 的 Claude Code（2025 年 2 月上线）、Cursor、Cognition 的 Devin（2024 年 3 月第一个演示"AI 软件工程师"概念），全在同一个场景里卷。

## 抓马主线：边缘项目是怎么翻盘的

按这篇长文和多篇报道交叉梳理，转折大致四步：

1. **起点极低**：Devin 引爆概念后，OpenAI 内部只分出一个小团队验证方向，资源量级和 ChatGPT 主线没法比。文中最扎心的细节是"算力要捡边角料"——在大厂内部，GPU 就是硬通货，边缘项目申请算力的难度，不亚于创业公司招人。
2. **两头受气**：主线团队觉得它分散精力，agent 路线当时又缺证据，项目一度濒临被停。
3. **转折三连**：外部 Claude Code 快速起量，证明付费需求真实存在；内部数据显示编码 agent 的任务完成质量和留存明显好于预期；codex-cli 在开发者社区意外走红，等于免费完成了一次市场验证。
4. **组织反转**：2025 年中 Codex 并入 ChatGPT 订阅体系，团队扩编、模型单开调优线；GPT-5-Codex 发布后，官方口径称用量出现 10 倍级增长。

一句话总结：不是老板突然英明，而是"外部竞品给压力 + 内部数据给底气"，两股力同时到位，边缘项目才等到被加注的那一刻。

## 机制分析：为什么偏偏是写代码先跑通

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/3644929d2b7ffdf8.png)

这是整个故事里最值得展开的部分。编程对 agent 来说太"友好"了：

- **奖励可验证**：单元测试、编译器、CI 流水线，就是现成的 reward function。对与错由机器说了算，强化学习有清晰的信号可迭代。对比写作、咨询这类领域，评价标准本身都说不清，模型想自我改进都没有抓手。
- **环境可沙箱**：代码跑在容器里，改坏了就回滚，试错成本约等于零。
- **数据最肥**：GitHub 海量代码加 git 历史，天然自带"改前 / 改后"的对照样本，是 RL 训练的理想语料。
- **交互门槛低**：terminal 加文件系统就够了，不需要复杂的多模态感知。
- **价值密度高**：开发者是全球最愿意为工具付费的人群之一。据报道，Claude Code 上线半年左右就做到年化数亿美元收入，Anthropic 的 API 收入大头长期来自代码相关应用。

再补一个数据点：METR 在 2025 年的研究测出，AI 能独立完成的任务时长大约每 7 个月翻一倍，而编码正是这条曲线的最前沿。Codex 的逆袭不是靠营销赢的，是它站对了坐标系。

## 三层启示：产品、商业与组织

1. **产品层**：判断 agent 落地，别看 demo 多炫，看"任务闭环四件套"，能不能验证、能不能回滚、出错成本多高、单价能不能算清。编程四条全占，所以最先跑通；其他行业想复制，先补这四块短板。
2. **商业层**：订阅（seat-based）和按量（usage-based）两条路线开始分化，Codex 打包进 ChatGPT 订阅拉新，Claude Code 按量计费吃重度用户。哪种模式更健康要看 2026 年，但有一点确定：agent 的 token 消耗比聊天机器人高几个数量级，成本模型必须重算。
3. **组织层**：大公司里边缘项目唯一的活法，是找到"奖励信号明确、主线看不上、增长曲线陡"的缝隙，然后用数据说话。Codex 团队最狠的一步棋，是把内部使用数据和社区热度，做成了管理层无法忽视的增长证据。

## 冷思考：三件比抓马有用的事

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-19/85141b68d91ca57a.png)

1. **判断任何 agent 产品，先问验收标准**。"测试通过就是通过"，代码领域的干净之处就在这；如果一个 agent 产品连"怎么算做完了"都讲不清，先降一档预期再掏钱。
2. **普通开发者的最优策略，是学会管理"AI 初级同事"**：把需求写成清晰的 issue、拆到单次任务能完成的粒度、用测试当验收标准。这套技能眼下比多学一个框架更保值。
3. **别把逆袭当爽文读**。Codex 的翻盘有两个前置条件：场景本身奖励密度极高，加上团队扛过了没有资源的冷启动期。你看到的戏剧性，底下全是枯燥的复利。
