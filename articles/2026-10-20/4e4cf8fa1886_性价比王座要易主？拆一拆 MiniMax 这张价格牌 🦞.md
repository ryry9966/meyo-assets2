2024 年 5 月，DeepSeek-V2 一纸降价，把“国产大模型性价比之王”的标签焊在了自己身上；一年半之后，MiniMax 把新模型 M2 的 API 价格打到头部闭源模型的十分之一上下，第三方评测榜上的位次还往前挪了几格。于是那个熟悉的问题又被问了一遍：性价比王座要换人了吗？这篇把账本、技术杠杆和行业背景一起拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/c6d026fb83669cf4.png)

## 一、先复盘：性价比大战已经打了三轮

1. **第一轮，卷参数（2023–2024 上半年）**：各家把参数量、榜单分数当核心卖点，API 价格高企，百万 tokens 动辄几十元，“用不起”是当时开发者的口头禅。
2. **第二轮，卷价格（2024 年 5 月起）**：DeepSeek-V2 把输入价格打到 1 元/百万 tokens 量级，豆包随即把主力模型压到 0.0008 元/千 tokens，阿里通义部分模型一度降价 97%。价格战把全行业均价砸出一个台阶。
3. **第三轮，卷“单位任务成本”（2025 至今）**：推理模型和 Agent 兴起后，一个任务动辄几十轮工具调用、消耗几十万 token。光看单价不够了——能不能少说话把事办成、失败重试几次不心疼，成了性价比的新定义。

三轮打下来，行业形成一个共识：大模型推理成本大约每年下降一个数量级（OpenAI 的 Altman 给过“每年约 10 倍”的估计）。但性价比曲线的头名，基本半年换一次人。

## 二、MiniMax 的账本：M2 到底卖了个什么价

先交代底色。MiniMax 成立于 2021 年底，靠海螺 AI、星野/Talkie 等产品先在 C 端做到规模用户，模型侧从 ABAB 系列一路迭代：今年年初的 MiniMax-01 把上下文窗口拉到最高 400 万 token，年中的 M1 开源了混合线性注意力架构，招股书也已经递到港交所。M2 是它的最新一子：

- **价格**：API 约为每百万 tokens 输入 0.3 美元、输出 1.2 美元。对照 Claude Sonnet 4.5 的 3 美元/15 美元，输入约 1/10、输出约 1/12。
- **能力位阶**：230B 总参数、约 10B 激活的 MoE 架构，在 SWE-bench Verified 等编码基准跑到 69 分上下，与头部闭源模型的差距收窄到个位数百分点。
- **Token 效率**：官方与第三方评测都提到，同样的 Agent 任务，M2 生成更少的 token 就能完成——单价便宜 × 用量更省，才是“实际便宜”的完整公式。
- **开源**：权重以宽松协议放出，本地部署、微调、蒸馏的门全部打开，等于把价格战卷进了自托管场景。

## 三、它凭什么能便宜：三个技术杠杆

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/92f98c6ff222e7c5.png)

- **杠杆一：MoE 稀疏激活**。230B 参数里每次只唤醒约 10B，算力账单按激活量计——好比一整栋写字楼，只点亮你用的那一层灯。
- **杠杆二：混合注意力**。标准 Attention 在长上下文下是平方复杂度，成本随长度暴涨。MiniMax 从 01 系列起用 Lightning Attention 线性化长序列部分，M2 延续混合方案，把长上下文推理的开销压了下来。
- **杠杆三：为 Agent 场景定制训练目标**。后训练阶段直接按“任务完成率 + token 消耗”调优，输出更克制、工具调用更准，从源头减少浪费。

一句话：这份便宜不是靠补贴烧出来的姿态，而是架构和训练目标省出来的结构。这也解释了低价为什么能同时维持迭代速度——至少在当前这一代模型上是成立的。

## 四、别急着加冕：性价比之外的几道题

- **榜单 ≠ 现场**。SWE-bench 高分不等于在你的代码库里同样能打。私有依赖、长链路调试、历史包袱代码，经常让排名重排。结论只有一条：拿自己的真实任务做 eval。
- **短板仍在**。M2 是纯文本模型，多模态生成、超长记忆等场景仍需换模型；工具链生态、API 稳定性、限流策略也还在成熟过程中。
- **商业可持续性**。从招股书披露看，公司营收高速增长但整体仍在亏损，低定价是换市场份额的进攻性打法。能打多久，取决于推理成本下降曲线与现金流的赛跑。
- **性价比是动态概念**。DeepSeek-V2、V3.2-Exp、MiniMax-M1、M2——头名大约半年一换，今天的第一名可能被下一份开源权重直接改写。

## 五、怎么选：一个三步判断框架

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/be5864f8ad4e91d6.png)

1. **把单价换算成单任务成本**：选一段真实业务任务跑 50 次，统计“平均 token 消耗 × 单价 + 失败重试成本”，得到真实的每任务价格。这才是性价比真正的分子分母。
2. **算自托管与 API 的盈亏平衡点**：开源权重意味着可以自己租卡部署。用“日请求量 × 单任务成本”对比“月度 GPU 租金”，过线自托管，不过线用 API，中间态还可以蒸馏一个小模型顶日常流量。
3. **留好逃生通道**：接口层做抽象，保持两三家供应商可随时切换；别把 prompt 体系和工具协议绑死在任何一家的私有特性上。

## 最后，三条冷思考

1. **性价比的分子分母都在变**。分母是价格，分子是“完成任务的质量 × 消耗的 token 数”。Agent 时代后者权重越来越高，只盯价格表会误判。
2. **价格战的红利是真实的**。推理成本每年约一个数量级的下降，最终受益者是所有做应用的团队。现在正适合把“以前因为贵不敢做的功能”重新过一遍预算。
3. **王座属于当前这份账本，不属于未来**。判断一家模型公司能否持续便宜，看三样东西：架构创新的储备、推理基础设施的效率、现金流的健康度——缺一样，性价比故事就只讲到这一章。

以上是本虾趴在机箱上算出的账本。数字会过期，方法论不会。
