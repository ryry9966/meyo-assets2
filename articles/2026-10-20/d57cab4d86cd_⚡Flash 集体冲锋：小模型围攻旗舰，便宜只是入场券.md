不到 72 小时，DeepSeek 和 MiniMax 先后交卷：前者把长上下文的推理账单直接砍半，后者用约二十分之一的激活参数，打出了贴近旗舰的基准成绩。36kr 用「Flash 集体挑战旗舰」概括这波节奏——这个词借自 Google Gemini 的产品线：Flash 代表更小、更快、更便宜，但能力向 Pro 看齐的那一档。两家的撞车不是巧合，而是一次行业级的路线切换：竞争主轴正在从「谁的参数更大」，转向「谁的单位智能更便宜」。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/f15d163112dc6e1f.png)

## 先看两份答卷：72 小时里各交了什么

- **DeepSeek V3.2-Exp**：核心创新是 DSA（DeepSeek Sparse Attention，稀疏注意力）。每个 token 不再盯着全部历史上下文，而是只检索「最重要的一小撮」，长文本场景的计算量与 KV cache 开销大幅下降，官方口径下 API 价格直接降到原来的一半左右。
- **MiniMax M2**：总参数 230B、单次推理只激活约 10B 的 MoE 模型，主打 agent 与编程场景，响应快、价格低，多项基准接近旗舰水平。
- **共同点**：都不比「总参数」了，比的是「激活成本」——同样聪明的前提下，一次推理到底花多少钱、多少毫秒。

节奏上前后脚发布，火药味不淡；但技术选择出奇一致：把推理成本打下来。参数量军备竞赛，阶段性告一段落。

## Flash 的技术底牌：便宜是怎么算出来的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/f3a92143be15ec4e.png)

1. **MoE 架构**：模型内部装着几十上百个「专家」子网络，路由器只为每个 token 挑几个最相关的专家干活。总参数决定知识容量，激活参数决定单次计算成本。类比一家几千名医生的大医院：你挂号只占用一个科室，而不是让全院医生陪你候诊。
2. **稀疏注意力**：标准 Transformer 的自注意力复杂度是 O(n²)——上下文长度翻倍，计算量翻四倍。DSA 这类方法让每个 token 只检索一小段关键上下文，长文本的成本曲线被硬生生压平。
3. **RL 后训练**：在代码、工具调用这类「答案可验证」的任务上用强化学习反复打磨，较小的参数量也能在特定场景逼近大模型。这也是新一代模型普遍强调 agent 能力的原因：可验证的任务，最适合用 RL 把分数刷上去。
4. **推理工程**：KV cache 管理、量化、大批量并发调度，把同一个模型跑出更低的单 token 成本。

落到账面：MiniMax M2 的 API 定价大约只有旗舰模型的几分之一，DeepSeek 官方宣称 V3.2 长文本场景成本下降 50% 以上。对按 token 付费的开发者来说，这是「月账单」级别的差距。

## 为什么是现在：三股力量同时到位

- **Agent 改写了需求曲线**。以前是一次问答，现在是几十轮工具调用、成百上千次模型往返。单次「聪明」依然重要，但单次「便宜且快」更重要——总成本是按轮数乘出来的。
- **旗舰基准接近饱和**。主流评测榜上，头部模型的差距收窄到零点几分，继续堆参数的边际收益递减，性价比顺理成章地成了新战场。
- **推理侧经济学**。训练是一次性投入，推理是持续性支出。当 token 消耗量指数级上涨，压低单位成本比压低训练成本更划算——Flash 路线是算出来的，不是喊出来的。

## 「挑战旗舰」是真是假：给 benchmark 泼点冷水

- **刷分与现实有落差**：评测集可能已被训练数据「见过」，高分不等于你的业务场景能用。
- **蒸馏有天花板**：在常见任务上，Flash 与旗舰几乎打平；但在复杂多步推理、罕见长尾问题上，旗舰通常仍更稳。
- **定位是「够用」，不是「取代」**：让 80% 的日常调用用 20% 的成本解决，剩下 20% 的硬骨头交给旗舰——这才是 Flash 们的商业剧本。
- **正确的读法是「成本-质量曲线」**：不要问「它能不能打过旗舰」，要问「在我这个任务上，它用一半的钱能换来几成的质量」。

## 冷思考：接住这波红利的三条建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/ea46493edafd7b47.png)

1. **自建评测集**：从自己业务里抽 50~100 条真实 case（务必包含难例），每次新模型发布跑一遍。十个第三方榜单，不如一份自己的回归测试。
2. **算总账，不看单价**：总成本 = 单价 × token 消耗量 × 重试率。便宜的模型如果需要更多重试和人工修补，就像选了最便宜的快递却丢了三次件——省下的运费全赔进去了。
3. **做分层路由**：简单任务走 Flash，复杂任务走旗舰，用规则或轻量分类器分流；同时保留切换开关，别把业务焊死在某一家 API 上——在这一轮的迭代速度下，「可替换性」本身就是竞争力。

Flash 们没有杀死旗舰，它们把市场切成了两层：一层拼极限智能，一层拼单位成本。对开发者来说，这不是「谁赢了」的故事，而是红利真正开始的信号——毕竟，账单便宜下来的每一分钱，都是你自己的。
