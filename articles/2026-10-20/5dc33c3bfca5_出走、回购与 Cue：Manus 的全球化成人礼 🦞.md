2025 年 3 月，Manus 带着"通用 AI Agent"的光环一夜爆红，邀请码一度被炒到上万元；年中，它把总部搬去新加坡，未随迁员工的股权回购引发争议；年底，又交出了新产品 Cue。三件事连起来看，其实是一部完整的"中国背景 AI 创业公司全球化成人礼"。这篇把它拆开讲清楚：它为什么红、为什么走、回购到底怎么回事，以及 Cue 想解决什么问题。

## 先补课：Manus 当初为什么能红

- **发布即顶流**：2025 年 3 月 6 日上线，主打"不止对话、直接交付结果"，邀请码在二手平台被炒到上万元。
- **产品形态**：底层调度 Claude、GPT、Qwen 等模型，外加任务规划器 + 工具调用 + 云端虚拟机。用户下指令后任务在云端异步执行，交付的是网页、表格、代码库这类"成品"，而不是一段聊天记录。
- **争议也来自这里**：不少人批评它"套壳"。创始人肖弘的回应逻辑是：模型是发动机，Agent 的壁垒在底盘和变速箱，任务拆解、上下文管理、错误恢复这些工程能力。
- **资本背书**：4 月完成 Benchmark 领投的 7500 万美元融资，估值约 5 亿美元。这家投出过 Uber 的基金出手，本身就成了传播素材。

一句话总结：Manus 红在把 Agent 从演示视频变成了可用产品，这一步它确实走得早。

## 出走新加坡：那笔账其实算得清

公司搬家从来不是情绪决策，本质上是三根"管子"能不能接上的问题：

1. **用户管子**：爆红后流量大头来自海外，海外用户订阅付费习惯成熟，一条 Stripe 通道就能自动扣款，国内反而要绕路。
2. **供给管子**：云端虚拟机要跑在 AWS/GCP 上，模型 API 依赖 Claude/GPT——这两样在境内主体手里都拿不稳。
3. **资本管子**：美元基金已经进来了，后续融资和退出路径都要求一个干净的海外架构。

新加坡恰好是三根管子都能接上的折中点：税制友好、人才国际化、地缘形象相对中立。据公开报道，其全球业务已由新加坡实体承接。所谓"出走"，更准确的描述可能是：它从一开始服务的就不是国内市场，搬家只是让组织和业务对齐而已。

## 回购风波：期权不是工资，回购也未必是情分

随迁之外员工的股权处理，是这轮舆论风暴的中心。媒体报道口径下，争议点集中在回购价格与最新一轮融资估值之间的落差。这里值得做一次期权科普：

- **期权 = 一张权利凭证**：约定未来按某个价格购买公司股份，不是确定的现金。它的价值取决于公司是否长大、能否退出、以及退出时你的顺位。
- **回购是标准动作**：员工未满足服务条件或离职时，公司按协议收回股份。坑往往藏在条款细节里，按"最近一轮估值"还是"上一轮估值"？打折系数多少？有没有利息？
- **信息差才是刺痛感的来源**：员工在新闻里看到 5 亿美元估值，回购单上却是另一个数字，心理落差可想而知。

给打工人的实操提醒：签字前问清行权价、回购触发条件、定价基准和支付周期这四件事。条款平时像废纸，等公司搬家、融资、清算的时候才会显灵。

## Cue：从"你叫它干活"到"它主动补位"

Cue 是 Manus 年底推出的新产品，官方定位是"主动式 AI 队友"：接入 Slack、Notion、GitHub 这类日常工作工具，持续积累团队上下文，在合适的时机主动认领任务、给出建议。

为什么要走这一步？逻辑有三层：

1. **通用叙事撑不起护城河**。OpenAI、Anthropic、Google 全都在做 Agent，"我什么活都能干"的差异化窗口很短。
2. **通用 = 高 token 成本、低复用**。一个长任务烧掉的算力是真金白银，毛利率天然承压。
3. **场景 = 粘性 + 数据飞轮**。Agent 在固定工作流里待得越久，积累的上下文越值钱，用户的迁移成本也越高。

技术上的硬骨头同样明确：长期记忆怎么做、自动执行的权限边界怎么画、出错时谁来兜底。"Proactive"这个词听起来性感，本质是把信任管理做成了产品功能。

## "本土化"大考：换了考场，卷子更难

标题里的"本土化"，指的不是回国，而是反过来，离开之后要在新考场重新落地：

- **竞争密度陡增**：在欧美市场，它从"新鲜事物"变成众多 Agent 创业公司之一，直面平台级选手的碾压。
- **信任门槛**：企业客户会问数据存在哪、谁能看到、有没有 SOC 2 认证。新加坡主体只是入场券，合规是必修课。
- **组织成本**：原本集中办公的团队变成跨多地远程协作，时区、文化、招聘都是隐性开销。
- **收入结构**：订阅收入据公开报道增速可观，但要证明 Agent 生意不是"烧算力换流水"的故事，Cue 这类场景化产品就是它给出的答案之一。

## 三条冷思考

1. **看懂 AI 创业公司，先看三根管子**：算力、支付、资本。断任何一根，叙事再漂亮也转不动。
2. **期权要按"彩票 + 合同"双重心态持有**：按彩票的心态别 all in，按合同的心态逐条读条款，尤其是回购的定价基准和触发条件。
3. **通用 Agent 的红利期很短**：护城河正在从"能跑通 demo"转移到"垂直场景 + 信任 + 数据飞轮"。选工具时别问它有多通用，问它能不能替代你每周都在重复的那件具体的事。

Manus 的故事还没到章节结尾。它至少证明了一件事：在 Agent 这个赛道，产品发布那一刻只是发卷，真正的考试在发卷之后。
