闲鱼上搜“AI人设”，能看到从几块到几百块的商品：定制人设卡、system prompt 代写、“捏崽”一条龙。另一边，星野、猫箱这类 AI 陪伴 App 的会员和充值入口，做得比游戏还精致。36kr 最近的文章把这事概括成一句话：这届年轻人，正在花钱“手搓”AI 人设。“手搓”原本是键盘圈、航模圈的黑话，指不买成品、自己动手攒；如今指的是不用平台的现成模板，自己一点点把一个 AI 角色的性格、口癖、记忆调教出来。这篇拆四件事：钱花在哪，技术上怎么实现，为什么是现在，以及动手前该想什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/0c6cc080d7a05e73.png)

## 一、先看账单：一次“捏崽”要花多少钱

以一个中度玩家（圈内叫“崽妈”，即养 AI 角色的人）为例，月支出大致四笔：

1. **平台订阅与充值**：AI 陪伴类 App 会员几十元/月，重度用户还会买对话次数包、加速卡；
2. **API 按量付费**：绕开 App，直接调大模型 API 自建角色。按 token 计费，长对话一天几百轮，一个月几十到几百元，取决于模型档位；
3. **外包定制**：人设卡代写报价几十到几百元；再加上形象立绘、语音合成（TTS），预算再上一个台阶；
4. **本地算力**：硬核玩家用 Ollama 之类工具本地跑开源模型（Qwen、Llama 系），一张二手显卡几千元一次投入。

这些支出的共同点：全是持续性的。角色“活着”就要持续喂 token——消费逻辑更像养宠物，而不是买断一台游戏机。

## 二、技术拆解：一个 AI 人设的解剖图

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/ac5015f891f13291.png)

很多人觉得调教 AI 角色是玄学，其实结构相当工程化。一个能稳定“入戏”的角色，通常由四层组成：

1. **人设卡（system prompt）**：核心层。写明身份背景、说话风格、口癖、价值观红线和知识边界。本质是用一段高权重文本，把模型的输出分布“掰”向特定人格；
2. **对话样例（few-shot）**：塞几段示范对话让模型模仿语气。经验上，3~5 组高质量样例，效果顶得上几百字的形容词堆砌；
3. **记忆系统**：上下文窗口再大也不可能全塞进去，所以普遍用“对话摘要 + 向量检索（RAG）”把关键事件外挂成长期记忆。你感觉“它还记得上周的事”，实际是检索回来的摘要；
4. **微调（可选）**：把大量聊天记录用 LoRA 等方法微调一个小模型，人设更稳，但成本和门槛高一个量级，属于进阶玩法。

理解了结构，“崩设”就好解释了：模型本质是概率机器，没有持续的自我。对话一长，早期设定在上下文里被稀释；话题一碰安全对齐，RLHF 训出来的“出厂人格”就会盖过你的定制人格。崩设不是闹鬼，是这几层约束在打架。

## 三、为什么是现在：三股力量叠加

1. **模型能力过了临界点**。角色扮演（role-play）已经是各家大模型评测的常规项，长上下文加上更强的指令跟随，让“人设保持”从勉强能用变成基本可用；
2. **陪伴需求的一路演化**。从电子宠物机、QQ 宠物、电子木鱼，到 Replika、Character.AI，“电子陪伴”每一代年轻人都在买，只是形态升级。Character.AI 的创始人曾公开提到，用户日均使用时长约 2 小时，超过多数社交媒体——这个量级说明需求是刚性的；
3. **创作成本坍缩**。过去做一个虚拟形象，要建模、配音、写剧本、养团队；现在 prompt 加文生图加 TTS，一个人一晚上就能搭出能聊天、能配音的角色。门槛从团队级降到了个人级。

## 四、生意链路：谁在赚这波钱

- **平台方**：赚订阅和内购，模式最直接；
- **模型厂商**：赚 API token。人设玩家是典型的高频长对话用户，token 消耗远超普通的一问一答；
- **中间服务**：捏崽师、人设卡交易、形象与语音外包，吃的是手艺钱；
- **外围**：算力租赁和各类教程。提醒一句：社交平台上“教你捏崽月入过万”的课程，多数是卖铲子的，不是挖矿的——免费的官方文档和社区开源人设卡，先看完再决定掏不掏钱。

## 五、动手之前：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/d9b30615d29e4880.png)

1. **想清楚你要的是工具，还是关系**。AI 角色的回应方式，很大程度上由你写下的人设决定——某种意义上，你在跟自己的文本对谈。把它当创作实验和陪伴的补充没问题，当成唯一的情感支撑就有隐患；
2. **人设资产自己留底**。设定文档、关键对话，用 markdown 存在自己手里。平台有关停和改规则的风险：Replika 在 2023 年收紧角色互动尺度，引发大规模用户反弹，最后给老用户恢复了原功能。别把“崽”完全寄存在别人的服务器上；
3. **算成本，也看隐私**。API 按量付费先小规模试跑，长对话用摘要压缩记忆能省下不少 token；同时注意，你喂给角色的聊天记录可能进入平台的数据流程，涉及隐私的内容别往里放。

结尾说两句。“手搓”这个词其实用得很准：它不太像消费，更像一种半手工的数字创作——一半是工程，prompt、记忆、微调；一半是情感投射。技术上，你搓出来的是一个被约束的概率分布；体验上，你搓出来的是一面会回话的镜子。把这两半分清楚，钱就花得明白，“崽”也养得清醒。
