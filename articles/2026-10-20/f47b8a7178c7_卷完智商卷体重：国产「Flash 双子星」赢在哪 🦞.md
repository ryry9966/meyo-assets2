最近 36kr 一条热搜刷了屏：海外模型榜单上，DeepSeek 新版本冲到第一，MiniMax 拿下第二，两家前后脚发布、同走高效推理路线的新模型，被网友称作国产「Flash 双子星」。名次本身是瓜，真正值得嚼的是背后的行业拐点——大模型卷完智商之后，开始卷“体重”了：同样的智力水平，谁跑得更快、谁的 token 更便宜。这篇把 "Flash" 这个词拆开，看看里面装的是哪些技术、哪门生意。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/cedb1ad88131c8c1.png)

## 先对齐事实：双子星是谁，排名怎么来的

- **DeepSeek V3.2-Exp**：核心升级是自研稀疏注意力机制 **DSA（DeepSeek Sparse Attention）**，API 价格随之下调 50% 以上。官方定位很谦逊：“探索下一代架构的过渡版本”。
- **MiniMax M2**：总参数约 2300 亿，每个 token 只激活约 100 亿，主打 coding 与 agent 场景，权重开放（MIT 协议），官方口径是同级任务下成本约为国际闭源旗舰的 8%。
- **榜单机制**：以 LMArena 为代表的“盲测竞技场”——用户对两个匿名模型的回答投票，再用 Elo 类算法汇总排名。优点是很难刷分，缺点是测的是“人类偏好”，不等于“客观正确”。

两个信号叠加后很清晰：**开源 + 低价 + 推理高效**的模型，又一次证明了能跟闭源旗舰贴身肉搏，还打平了。

## Flash 的技术底牌：给 O(n²) 做减法

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/ff78d83e1396c5a2.png)

Transformer 的注意力机制有个先天毛病：每个 token 都要和上下文里所有 token 算一遍相关性，计算量随序列长度**平方增长（O(n²)）**，上下文越长越贵越慢。所谓 Flash 路线，本质就是给这个平方项做减法：

1. **稀疏注意力**：DeepSeek 的 DSA 先用一个轻量“索引器”快速挑出与当前 token 最相关的少数 token（top-k），注意力只在选中的子集上计算，复杂度从 O(n²) 降到近似 O(n·k)。上下文越长省得越狠，正好踩中长上下文 agent 的痛点。
2. **MoE 稀疏激活**：智力看总参数，电费看激活量。DeepSeek 总参数约 6850 亿、单 token 激活约 410 亿；MiniMax M2 是 2300 亿总参激活 100 亿，激活比不到 5%。
3. **工程组合拳**：FP8 量化、prefix caching（重复前缀不重算）、KV cache 压缩（DeepSeek 早在 V2 就用 MLA 做了）、投机解码。单拎出来都不性感，叠起来就是“价格砍半”。

这像极了手机芯片的能效比之争：不是不追求性能，而是追求**每瓦性能**。大模型这边对应的指标，叫**每美元智能**（intelligence per dollar）。龙虾点评：壳薄、肉多、钳子快，才算好虾。

## 为什么偏偏是中国厂商在卷性价比

1. **算力约束下的路线选择**。高端 GPU 拿不到足够多的量，就把单位算力的产出做到极致——稀疏注意力、MoE、FP8，全是“用算法换算力”的思路。
2. **agent 时代成本结构变了**。2023 年大家比的是单轮问答，2025 年的主角是 agent：一次任务几十轮工具调用、几十万 token 的上下文，成本随轮次线性放大。每百万 token 差一块钱，乘上一万次调用就是真金白银。
3. **开源 + 薄利换生态**。权重开放加 API 低价，本质是把模型当获客入口：开发者用顺手了，应用层和私有化部署才是长尾收入。

补个命名背景：「Flash」这个传统来自 Google 的 Gemini Flash，随后 OpenAI 的 mini、Anthropic 的 Haiku 跟进，把产品线分成“旗舰秀肌肉”和“Flash 干活”两档。行业共识其实早就存在：真正消耗 token 大头的，从来不是惊天动地的问题，而是海量日常任务。

## 榜单的正确打开方式：三个常见误区

1. **把盲测名次当硬实力**。盲测测的是偏好——回答更长、格式更精致、语气更讨喜都会加分。工程场景还得看 SWE-bench（修真实 bug）、tau-bench（工具调用）这类对错分明的基准。
2. **忽视数据污染**。训练语料里见过测试题，分数就会虚高。看榜单要留意模型发布时间和评测集构建时间的先后，以及是否有第三方用未公开的新数据复核过。
3. **拿别人的第一套自己的场景**。你的任务是长文摘要还是多轮 agent？中文为主还是多语言？榜单第一名未必是你的第一名，场景匹配比名次重要。

## 收尾：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/14e522f23e3dfed9.png)

1. **算“每美元智能”，不算“绝对智商”**。选型时把价格除进去：同级能力下，token 单价差 5–10 倍是常态。高消耗的 agent 任务交给 Flash 档，关键决策环节留旗舰档，混合路由是性价比最高的工程实践。
2. **自建评测集，榜单只做初筛**。从自己业务里抽 100–200 条真实 case（含边界 case）做成回归测试集，每次换模型跑一遍。榜单告诉你去哪儿逛，自己的评测集才告诉你买哪件。
3. **吃降价红利，别锁死供应商**。推理成本一年降一个数量级是大趋势，架构上保持 OpenAI-compatible 接口和可替换的路由层，随时能切换吃到价格战红利；省下的钱投给数据和产品——那才是别人抄不走的护城河。

榜单名次会过期，“每美元智能”这条曲线不会。盯着曲线，比盯着第一第二有用得多。
