2025 年的国内大模型圈，前半年的叙事基本被 DeepSeek 包揽："开源、便宜、能打"，性价比王座看起来短期无人能撼。直到 6 月中旬，MiniMax 开源了 M1——456B 参数的 MoE 模型、1M token 上下文、官方口径称强化学习阶段只花了约 53 万美元算力租金。性价比之王的归属，突然又有了悬念。这篇不站队，只拆三件事：性价比到底怎么算、MiniMax 靠什么压成本、普通开发者和企业该怎么接住这波红利。

## 先把账算清：性价比不是一个价格数字

很多人把"性价比"简化成首页报价，这在 API 时代是个坑。完整的公式至少包含三个变量：

1. **单价**：每百万 tokens 的输入价、输出价，以及常被忽略的缓存命中价；
2. **能力**：benchmark 跑分只是参考，真实任务成功率才作数；
3. **速度与稳定**：首 token 延迟、每秒输出 tokens、长任务中途崩掉的概率。

举个例子：一个日均处理 1000 万 tokens 的客服机器人，如果输出单价从 8 元/百万降到 2 元/百万，一个月（约 3 亿 tokens）的账单就是 2400 元和 600 元的差别。更要命的是 agent 场景：输出 tokens 往往是输入的好几倍，推理模型还会先"思考"几百上千 tokens 再回答——这些都要计费。所以真正的性价比公式是：**完成任务的总成本 ÷ 任务质量**，而不是首页那个大字价格。

## MiniMax 的家底：从 character 应用卷出来的推理能力

MiniMax 成立于 2021 年底，最初出圈的不是大模型，而是星野、Talkie 这类 AI 陪伴应用——Talkie 在海外长期是头部 AI 应用之一。C 端生意有个特点：海量免费用户、单次对话利润极薄，推理成本每压低一分都是真金白银。这是它死磕推理架构的原始动力。

技术路线上有两个关键节点：

- **2025 年 1 月，MiniMax-01 系列**：456B 总参数、45.9B 激活的 MoE，首次把 lightning attention（线性注意力）用于生产级模型，商业版支持 1M context；
- **2025 年 6 月，M1 开源（Apache 2.0）**：同样 456B/45.9B 的 MoE，1M 输入上下文，还提供 thinking budget——可以手动限制"思考长度"来省输出 tokens；
- 另一条腿：海螺的视频生成模型在海外市场持续贡献 API 收入。

一句话总结：它不是忽然来真的，而是被 C 端的成本压力逼着练了两年内功，现在把内功拿出来卖。

## 核心机制：为什么"线性注意力"能省钱

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/2e1975835ea87e9e.png)

标准 Transformer 的 softmax attention 有个宿命：必须为每个历史 token 保存 KV cache。上下文越长，显存和带宽开销线性膨胀——1M 上下文的传统架构，光缓存就能把一个推理节点拖垮。

MiniMax 的解法是混合架构：按约 7:1 的比例，把 softmax attention 和 linear attention 交错堆叠。linear attention 不逐字保存历史，而是把历史信息"滚动压缩"成一个固定大小的状态。

打个比方：softmax 像把所有聊天记录逐条抄在白板上，每次回复都要回看全部；linear 像把旧记录整理成一份持续更新的摘要，回答时只看摘要。结果就是：长上下文下 KV cache 占用降了一个数量级，长文本推理的成本曲线被压平。短对话里优势不明显，但代码库分析、长文档问答、多轮 agent 这些场景，差距会被成倍放大。

训练侧同样抠门：官方口径 M1 的 RL 阶段用 512 块 H800 跑了约三周，租金约 53.47 万美元。当别家还在讲"一次训练几千万美元"的故事时，把工程效率本身当卖点，这步棋挺聪明。

## 第二回合价格战：从卷单价到卷"单位智能成本"

把时间线拉长看，这其实是国内大模型价格战的第二回合：

- **2024 年 5 月**：字节豆包把价格打到 0.0008 元/千 tokens，宣称比行业低 99.3%。第一轮价格战主打"便宜"，但头部开源模型尚未到位；
- **2024 年末至 2025 年初**：DeepSeek V3/R1 相继发布，"开源 + 便宜 + 强"三件套重新定义性价比，王座易主；
- **2025 年以来**：Qwen3、MiniMax M1、Kimi K2 等密集开源，竞争维度从"API 单价"升级为"单位智能成本"——每花一块钱，能买到多少有效推理。

对开发者来说，这个阶段的格局比单点价格更重要：开源权重 + 低价 API 双通道并存，迁移成本低，议价权第一次真正到了用户手里。

## 三个冷思考：怎么选，怎么不上头

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-20/62b806d5b409edb7.png)

1. **别只盯输入价。** agent 和代码场景里，输出 tokens 经常是输入的好几倍。优先比较输出价、缓存命中价和思考 tokens 消耗。M1 的 thinking budget 这类"能限流"的功能值得试——能限流的，就是能省钱的。
2. **用真实负载测，别信榜单。** 把你自己的长文档、代码仓库灌进去跑 A/B：长上下文利用率、中途退化情况、延迟尾部分布。一周的实测，比任何跑分榜都可靠。
3. **给架构留退路。** 开源权重意味着你可以"API 起步、私有化兜底"；关键业务做好双供应商 fallback。价格战的红利是动态的，今天的低价不构成明天的 SLA 承诺。

至于王座最后归谁？说实话没那么重要。重要的是这一轮竞争把"每 token 成本"实打实往下压，把开源权重变成了行业标配。对用模型的人来说，2025 年下半场的最优策略就一句话：多测、多换、别锁定。
