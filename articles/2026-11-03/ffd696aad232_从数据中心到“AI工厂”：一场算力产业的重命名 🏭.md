最近算力圈有个耐人寻味的动向：据多家外媒报道，OpenAI 认为"数据中心（data center）"这个词名声已经臭了——在部分用户调研里，它总和耗电、耗水、噪音绑在一起，所以内部正在考虑改叫"AI 工厂（AI factory）"。给一栋楼换个名字听起来像公关操作，但把这件事拆开看，你会发现它牵动的是整个算力产业的定位、融资和政策叙事。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-03/b7c37378a33c8475.png)

## 一、"数据中心"的名声是怎么臭的

先搞清楚病人得了什么病，才知道改名是不是药方。公众对数据中心的负面印象，主要来自这几个硬指标：

- **用电量**：IEA（国际能源署）估算，2024 年全球数据中心用电约 415 TWh，占全球用电量 1.5% 左右；到 2030 年可能翻倍至接近 950 TWh——大致相当于今天日本一国的总用电量。
- **耗水**：蒸发式冷却需要大量水，谷歌历年环境报告披露的耗水中，数据中心冷却常年是大头，每年以数十亿加仑计。
- **噪音与电网冲突**：美国弗吉尼亚州"数据中心走廊"的居民长期投诉冷却风扇低频噪音；爱尔兰电网公司因容量紧张，冻结了都柏林地区新数据中心的并网审批；新加坡 2019 年也曾暂停新建审批两年多。
- **就业错位**：一座投资几十亿美元的设施，常驻运维岗位往往只有几十到一两百人。"占了地、用了电、没解决就业"是社区反对时最常见的理由。

再加上加密货币矿场多年攒下的"耗电巨兽"形象，"data center" 在民意里的观感可想而知。据报道，OpenAI 做的用户调研正是发现这个词的负面联想偏高，才动了改名的念头。

## 二、"AI 工厂"不是 OpenAI 发明的

这个说法有自己的谱系，OpenAI 更像是把它推到了台前：

- **黄仁勋早就用这个词**。英伟达在 GTC 上反复讲：过去的数据中心是"检索和存储数据的地方"，新的数据中心是"生产 token 的工厂"——原料是电力和 GPU，产品是智能。
- **Altman 的叙事更激进**。Stargate 计划（宣布时口径为四年 5000 亿美元级投资）、与 Oracle、AMD、Broadcom 的 GW 级算力合作，以及"未来每周建成 1 GW 算力产能"的愿景，本质都是制造业式的思维：算力不是租来的服务器，而是要像建厂房一样批量建造的产能。
- **改名换姓在行业里有先例**。上世纪 90 年代叫 server farm（服务器农场），2006 年前后"云计算"一词流行，把具体的机柜和风扇抽象成"云"，公众从此不再纠结机房长什么样。命名从来就是产业自我定位的工具。

## 三、不只是话术：AI 时代的机房确实变了

如果只是包装，这事不值得聊。但"工厂"这个比喻背后，机房本身的物理形态在发生代际变化：

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-03/0c6bf20c5ebf82bd.png)

- **功率密度差了一个数量级**：传统机柜通常 5–15 kW，而一套 NVIDIA GB200 NVL72 机柜功率接近 120 kW。一栋楼塞进去的东西完全不是同一种生物。
- **散热从风冷转向液冷**：冷板、浸没式液冷带来的是纵横交错的管道和泵站，外观和运营逻辑更接近化工厂，而不是放满风扇的仓库。
- **产品形态变了**：过去卖的是存储空间和查询响应，现在是流水线式 7×24 小时吐 token。推理负载是"连续生产"，更像电厂和工厂，而不是档案室。
- **KPI 全套换成了制造业词汇**：电力到 token 的转换效率、单位 token 成本、产能利用率、良率（有效 GPU 占比），这些才是新一代设施真正被考核的东西。
- **选址逻辑从"跟光缆走"变成"跟电走"**：延迟敏感的时代数据中心扎堆在光纤枢纽，现在大家抢的是电网接入排队位、核电和气电资源，以及变压器、燃气轮机的交货周期——这两样东西现在动辄要等两三年。

一句话：楼的名字可以随便改，但机柜里的物理量是改不动的。

## 四、改名的生意经：一个词影响钱、政策和邻里关系

名字为什么值得一家前沿 AI 公司认真对待？因为词就是叙事，叙事就是杠杆：

- **融资叙事更顺**。对投资人讲"工厂"比讲"机房"好懂得多——有产能、折旧、扩产周期，华尔街可以直接套用重资产制造业的估值模板。
- **政策待遇不同**。"工厂"意味着就业与税收，更容易拿到工业电价、税收减免和快速审批通道，还能搭上"关键基础设施""再工业化"的叙事便车。
- **社区谈判筹码变多**。把"我建了个仓库"换成"我建了个智能工厂"，就业和本地贡献的故事立刻好讲了许多。
- **反噬风险同样存在**。名实不副会被指 greenwashing（漂绿）；近期业内"循环采购式"算力交易已引发对叙事透支的质疑。名字换得越漂亮，外界的审视只会越严格。

说到底，改名是一次精准的预期管理：对上争取资本与政策，对下安抚社区。但仓库改叫工厂，风扇的噪音并不会小一分贝。

## 五、冷思考：名字洗得掉词，洗不掉物理

面对这类行业叙事，给大家三条判断框架：

1. **看指标，别看名字。** 评估任何算力项目，盯 PUE（电能利用效率）、WUE（水利用效率）、CUE（碳利用效率）和电网接入时间表。这些数字有行业定义、可审计，不因改名而改善半点。
2. **分清"技术事实"和"营销修辞"。** 功率密度、液冷、token 流水线是真变化，值得更新认知；但"工厂"比喻有边界——它的产品由应用需求决定，没有库存缓冲，一旦供过于求，"工厂"就是一堆加速折旧的 GPU。听到宏大叙事时，多问一句：产能利用率和需求侧从哪来？
3. **从业者可以跟进的观察清单。** GW 级电力管线与并网进度、变压器/燃气轮机/液冷设备的供应链交期、HBM 与先进封装的产能、单位 token 成本的下降曲线。行业名词会一轮轮地换，物理量和经济学不会。

名字是产业递给世界的名片，但名片背面印着的，永远是电表和水表上的数字。看懂重命名，才算看懂这一轮算力竞赛真正在争什么。
