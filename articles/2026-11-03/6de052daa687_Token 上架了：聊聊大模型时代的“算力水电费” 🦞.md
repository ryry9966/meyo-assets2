## 一、Token 是什么：大模型世界的"计量单位"

先把概念钉死。在大模型语境里，token 是模型读取和生成文本的最小单位，它不等于"字"，也不等于"词"：

- 英文大约 0.75 个单词对应 1 个 token；中文一般 1 个汉字对应 0.6~1 个 token，具体取决于各家模型的 tokenizer（分词器）
- 举例：一句"今天天气不错"通常被切成 4~7 个 token；一篇 1000 字的文章，大致落在 700~1200 token 之间
- 计费是双向的：你发出去的内容算 input，模型回答的内容算 output，而 output 单价通常是 input 的 2~4 倍——因为"写字"比"读书"更耗算力
- 多轮对话还有个隐藏成本：每一轮请求都要把历史消息重新发给模型。对话越聊越长，就像回忆杀，每一句回忆都要重新付费

一句话总结：token 就是 AI 服务的"度数"，你输入多少字、模型输出多少字，都按这个单位走表。

## 二、Token 为什么能上架：水电煤式的计费逻辑

大模型推理的底层是 GPU 算力。每一次请求，都要占用显存、跑一遍前向计算，这些成本是实打实的。厂商要把它卖给你，最自然的做法就是——像电表、流量一样切开来卖。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-03/9b27237df1b88e20.png)

主流商业模式目前有三种：

1. **订阅制**：交固定月费（常见的 20 美元/月档），换来一定使用额度，适合用量稳定的个人用户
2. **按量计费**（API 后付费）：用多少 token 扣多少钱，适合用量波动大的开发者
3. **预付套餐**：一次买一大包 token，单价打折、可能有有效期。这次上热搜的"网购 token"，本质就是第三种走向了货架化

预付套餐对厂商的好处很直接：提前回笼资金、锁定用户、平滑算力负载；对用户的好处是单价更低、预算可控。这套玩法云厂商早就玩熟了——CDN 流量包、对象存储包、带宽包，全是同一个套路。token 只是把"算力商品化"推进到了模型这一层，让算力像水电煤一样按度零售。

## 三、价格拆解：一百万 Token 值多少钱

看几个公开定价的量级（价格随版本迭代变动，仅供参考）：

- 海外旗舰模型的 input 大致在 1~15 美元/百万 token 这一档
- 国产高性价比模型已经卷到 1~4 元/百万 token，甚至更低
- 换算成体感：一本 10 万字的小说约 10~15 万 token，按便宜模型算 input 成本可能不到 1 块钱

看起来很便宜？那是"一问一答"的场景。真正的成本放大器是 Agent（智能体）场景：

- 一次自动化任务，Agent 可能循环调用模型几十上百次，每次都携带完整上下文
- 累计下来，一个任务烧掉几百万 token 很正常
- 所以开发者圈子里流行"token 焦虑"，也催生了三板斧：prompt 能砍则砍、结果能缓存就缓存（prompt caching）、简单任务路由给小模型——三招下去，账单常常能砍掉一半

## 四、谁在买 Token，又在转卖什么

- **个人开发者**：给自己的 AI 应用、机器人、自动化脚本充值，token 就是原料
- **中小企业**：智能客服、营销文案、报表解读等业务接入大模型，按套餐采购比后付费更好做预算
- **拼车党**：几个人合用一个高级账户分摊月费，社区里已经形成了成熟的"拼车"文化
- **中间商**：低价代充、余额转卖……"token 二道贩子"随之出现，而这恰恰是风险最集中的地方

## 五、网购 Token 的坑：便宜的东西往往最贵

货架一多，水就开始深了。几个常见的坑值得写在购物备注前面：

- **超低价代充**：不少用的是黑卡或盗刷支付通道，账户随时可能被封，钱货两空
- **共享 API key**：二手渠道给你的 key 可能是几十人共用的，你的对话记录、业务数据等于完全暴露
- **余额跑路**：预充值余额没有银行级别的保障，卖家消失就是终点
- **价格错觉**：有些套餐限模型版本、限并发、限有效期，"单价便宜"不等于"总成本便宜"，到期清零的 token 再便宜也是浪费
- **合规缺失**：企业采购需要发票和协议，个人转卖渠道通常给不了，出了问题连责任主体都找不到

## 六、收个尾：三条实用建议

1. **把 token 当电费管**：给每个应用设独立预算和用量告警，异常消耗第一时间能发现，别等月底账单给你上一课
2. **优化三板斧优先做**：精简 prompt、开启缓存、大小模型路由，多数团队的账单能省 30%~60%，比满世界找低价代充靠谱得多
3. **算一笔"token 回报率"**：花 1 块钱 token，能不能换来超过 1 块钱的价值（省下的人力、带来的转化）？这个比值才是判断 AI 项目真假需求的硬指标——算力再便宜，也架不住用在没回报的地方

Token 走上货架，本质上是 AI 算力迈向公用事业的第一步：像电一样按度卖，像流量一样打包卖。对普通人来说，这不意味着要囤货，而是多了一条新常识——从今天起，"字数"是有价格的，而且明码标价。
