36kr 报道，Anthropic 最新单季营收达到 168 亿美元，环比再涨 45%。大多数人看到这条热搜的反应是"哇"，但对工程师来说，更有价值的三个问题是：这个数字该怎么读？钱具体从哪个水龙头里流出来？它还能流多久？这篇文章按"读数 → 拆结构 → 看机制 → 看成本 → 下判断"五步，把这条热搜拆开来看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/62d06a53d86e9dbc.png)

## 第一步：把数字读对，45% 环比意味着什么

- **复利很吓人**：45% 的 QoQ 如果维持一年，1.45⁴ ≈ 4.4 倍，单季就是 700 亿美元级别。历史上 SaaS 公司能在 40%+ QoQ 上站稳的，基本都处在产品-市场契合后的爆发窗口（早期 Zoom、Snowflake 都经历过），窗口关闭后一般会回落到 20%~30%。所以看点不是"涨得快"，而是"能涨多久"。
- **三个口径必须分清**：

| 口径 | 含义 | 失真风险 |
|---|---|---|
| Bookings | 合同签订金额 | 大单可能分摊数年确认 |
| Run rate | 月/季收入 ×12 或 ×4 | 最好看，也最容易失真 |
| 确认收入 | 会计准则下真正确认 | 最保守，但滞后 |

看到"单季营收 168 亿"，先问一句：这是确认收入还是年化 run rate？两种口径可能差出一倍以上。这不是抬杠，是读 AI 公司财报的基本功。

## 第二步：钱从哪来——营收结构拆解

- **背景**：Anthropic 由前 OpenAI 团队于 2021 年创立，靠 Claude 系列模型起家。2025 年初，外界估计其年化 run rate 还在几十亿美元量级，一年内冲到这个量级，斜率非常陡。
- 结构上，据多方报道它是一家典型"B 端驱动"的公司，收入大致来自三条管道：
  1. **API 直连**：企业和大客户直接调用模型，签的是百万美元级的年度合同，客单价高、留存好；
  2. **云渠道**：AWS Bedrock、Google Vertex 帮它分发模型——注意，云厂商既是渠道又是股东，这层关系后面还会再提；
  3. **订阅与编程产品**：Claude Pro/Max 订阅，加上 Claude Code 这类编程工具，是过去一年增长最猛的一条线。
- 作为对照，OpenAI 的收入更多靠 C 端订阅撑基本盘。两家走了两条路：一个吃开发者和企业的预算，一个吃消费者的钱包。编程相关负载被普遍认为是 Anthropic 最大的单一收入场景，这也是理解下一个环节的钥匙。

## 第三步：为什么"写代码"成了印钞机——Agent 的 Token 经济学

这是全文最关键的机制。人肉时代与 Agent 时代的成本结构完全是两回事：

1. **聊天时代**：一个 prompt 一句回答，几千 token，撑死几美分，商业模式近似"零售"；
2. **Agent 时代**：你丢一句"重构这个模块"，Agent 会读整个仓库、做规划、改代码、跑测试、失败重试。读 50 个文件就是几十万输入 token，中间的推理和重试再翻几倍，一个任务轻松烧掉百万级 token——放大倍数 100 倍起步；
3. **付费意愿极高**：程序员时薪摆在那，工具省一小时就是几十上百美元，ROI 清晰到财务都挑不出毛病，企业采购阻力自然小。

一句话总结：Agent 越能干，token 消耗越指数级增长，客户越愿意为结果付钱。这是目前唯一同时满足"用量随自动化程度指数增长 + 按结果付费"的负载，所以所有模型厂都在卷 coding。程序员一加班，营收曲线就上扬——"话痨"第一次成了一种商业模式。

## 第四步：成本那一面——GPU、折旧与"循环交易"

收入要和成本放在一起看，否则就是只踩油门不看油表：

- **Inference 成本随用量线性上涨**。收入涨 45%，推理算力账单大概率同向涨，LLM 公司的 gross margin 长期被质疑不是没有原因的；
- **折旧的会计时间差**：GPU 通常按 5~6 年折旧，如果模型迭代快于硬件寿命，账面毛利会显得比现金流健康得多；
- **循环交易**：云厂商投资 Anthropic，Anthropic 又承诺巨额采购云算力，投资与收入在生态内循环。这是行业普遍现象，不算黑幕，但读数时要打个折扣——这类收入的现金含量和利润率，通常低于表面数字。

单季 168 亿如果按 run rate 口径理解，背后对应的算力开支同样是天量。营收增速 ≠ 赚钱能力，这条铁律在 AI 行业尤其灵。

## 收尾：三条冷思考

1. **看结构，别只看总量**：收入高度集中在企业 API + 编程场景，既是增长引擎也是风险敞口。值得持续观察的是第二曲线——Agent 办公、科研计算——什么时候接棒，单一场景的依赖度有没有下降。
2. **用审计思维读 AI 财报**：区分 bookings / run rate / 确认收入，盯住 gross margin 和自由现金流，对"投资-采购闭环"里的收入保持一分清醒。数字越性感，越要多问一句口径。
3. **给开发者的实际建议**：token 支出正在变成新的"云账单"。选模型先算单位任务成本，用好 prompt caching 和小模型分流，给 Agent 的用量设预算——别让你的毛利被它的"话痨"吃掉。

168 亿美元不是魔法，是 token 一颗一颗烧出来的。看懂钱的流向，比惊叹数字本身有用得多。
