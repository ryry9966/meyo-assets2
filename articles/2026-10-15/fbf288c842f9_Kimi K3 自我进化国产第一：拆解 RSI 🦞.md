## 一、RSI：1965 年的老想法，正在变成工程问题

- **起点**：1965 年统计学家 I.J. Good 提出，能设计出更好机器的机器，会触发"智能爆炸"。这概念躺了六十年，最近十年才开始有工程原型。
- 先纠个偏：RSI 在医学语境里是"重复性劳损"，程序员职业病；AI 语境是 Recursive Self-Improvement。缩写撞车，纯属巧合。
- 已经跑出来的原型，按时间排：
  1. **AlphaGo Zero（2017）**：不喂人类棋谱，纯自我对弈，从零超过所有前代；
  2. **FunSearch（2023）**：LLM 生成数学猜想 + 程序验证器筛选，在 cap set 问题上找到新构造；
  3. **AlphaEvolve（2025）**：进化式代码搜索，改进了 4×4 复数矩阵乘法——这是 Strassen 算法 56 年来的首次突破，还把 Google 全球数据中心的算力调度抠回约 0.7%；
  4. **Darwin Gödel Machine（2025）**：agent 直接修改自己的代码，SWE-bench 成绩从约 20% 提到 50%。
- 目前行业共识：**弱形态** RSI（生成数据、改 agent、搜代码）已经跑通；**强形态**（模型改自己的训练管线和架构）还站在门口。

## 二、"自我进化"进化的是什么：三层机制

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/54ad4dad204928de.png)

媒体语境里"自我进化"是个大词，工程上其实至少分三层：

1. **数据飞轮层**：模型生成解题轨迹 → verifier（验证器）打分 → 筛选高分样本回流训练。代表路线：STaR、ReST，以及 self-play RL——2025 年的 Absolute Zero 更激进，连外部数据都不要，让模型自己出题、自己做题、代码执行器当裁判。
2. **Agent 自改造层**：模型改自己的 prompt、工具配置、工作流甚至源代码，以基准分数当"适应度"做进化搜索。上文的 Darwin Gödel Machine 属于这一层。
3. **管线搜索层**：模型提出训练方案（数据配比、超参、课程），自动化平台跑实验，存活下来的改动合并进下一代。这一层最接近"AI 研究 AI"。

三层有个共同前提：**可验证奖励（verifiable reward）**。代码能不能跑通、测试过不过、数学答案对不对，机器自己就能判——所以自我进化总是先在代码和数学上冒头，纯主观任务暂时轮不到。

但天花板也写在这句话里：自我进化是在环境给的奖励地形里爬山，爬不出地形本身。verifier 覆盖不到的盲区，飞轮转得再快也是原地空转；self-training 还会放大基座模型的既有偏差。

## 四、"国产第一"怎么核对：榜单三问

"自我进化"目前没有公认 benchmark，这类排名要过三道安检：

1. **基准是什么？** 是公开 agent 基准（SWE-bench Verified、LiveCodeBench 这类），还是厂商自建评测？评测集是否防污染、有没有混进训练数据？
2. **基线是谁？** 正确姿势是"同基座、关闭自进化"对照"开启自进化"，增益才可归因。拿自己进化后的模型去比别家的静态模型，属于修辞学，不是科学。
3. **算力对齐了吗？** test-time compute 一加，谁的分数都会涨。增益必须按同等推理预算归一化，否则"进化"和"堆算力"分不清。

补一个背景：Moonshot 的 K 系列一直走开放权重路线，K2 是总参数 1T、激活 32B 的 MoE，权重公开。开放权重意味着外部社区能复现、能改造、能往上叠——等于把一部分"进化"外包给了生态。国产模型这条开源飞轮路线，和闭源实验室的路线差异，本身就是看点。

## 五、能带走的：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/ac86fabbd8aee7dd.png)

1. **看榜先三问**：基准、基线、算力预算。三问答不上来的榜单，按营销物料处理。
2. **给宣称分层**：数据飞轮（可信度较高）→ agent 自改造（中等，看演示）→ 管线自动搜索（需要技术报告佐证）。宣称的层级越高，越要等一手材料，越别急着转发。
3. **工程上可以抄作业**：在 verifier 质量高的任务（代码、测试、规则明确的业务流程）搭最小回路——生成 → 验证 → 筛选 → 回流。顺序很重要：先建评分器，再谈进化；评分器烂，飞轮越转越歪。

收尾一句：RSI 眼下是工程加速器，不是奇点开关。真正值得盯的不是"第一"这个名词，而是 verifier 质量、增益归因和可复现性——这三样，决定自我进化到底是爬坡，还是转圈。
