双11 预售一开闸，天猫不少电脑商品页的赠品栏多了个新物种：买机送 token——有送百万 token 额度的，也有送大模型会员时长的。围观数码圈这么多年，赠品从鼠标垫、电脑包、碎屏险一路卷到大模型的“燃料”，这件事本身比赠品值多少钱更有信息量：token 已经便宜到可以当赠品发，同时有一批厂商在抢一个新入口。这篇把它拆开讲清楚：token 到底是什么，为什么送得起，平台图什么，以及下单前怎么把账算明白。

## Token 是什么：大模型的“电表”

- 大模型不按“提问次数”计费，按 token 计费。token 是文本被切分后的最小单位：英文大约每 4 个字符折 1 个 token，中文各家分词器差异较大，常见 1~2 个汉字对应 1 个 token。
- 换算成体感：一篇千字文章大约几百到一千多个 token；一次普通问答来回通常几百到几千 token；如果是 Agent 自动干活——读网页、写代码、自我检查、循环重试——一轮任务烧掉几十万 token 也不稀奇。
- 为什么按 token 收费：推理时 GPU 的开销主要花在显存读取和矩阵运算上，模型每生成一个 token，解码器就要完整跑一轮计算。所以 token 就是“算力的产出单位”，跟电表走字一个道理：用多少算力，跳多少字。
- 顺着这个逻辑，“送 token”送的不是虚拟积分，而是一段实打实的 GPU 推理额度——等于厂商替你垫付了一部分推理账单。

## 为什么送得起：推理成本这两年在“跳水”

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/87aa56b8da0135cc.png)

- 回看价格曲线：2023 年初，一线闭源模型还在每百万 token 几十上百元人民币的量级；2024 年 5 月国产模型掀起 API 降价潮，轻量模型的输入价格被压到每百万 token 几毛到几元；到 2025 年，主流厂商入门款模型的输入价格普遍进入“每千 token 几厘到几分”的区间（各家口径不同，看量级即可）。
- 降价来自三股合力：模型小型化与蒸馏（能力接近、参数砍半）、推理框架优化（KV Cache、批处理、量化），以及算力供给增加带来的规模效应。能力相近的模型价格两年掉了两个数量级，“百万 token”就从一顿大餐变成一杯奶茶。
- 于是营销账很好算：送 100 万 token 的轻量模型额度，按当前 API 价格折算，实际成本大概率在几元到十几元。用这点边际成本，在客单价几千元的商品页上做出差异化卖点，还附赠一次大模型用户教育——比送个机械键盘便宜，故事却好讲十倍。
- 这套打法历史上有原型：合约机送话费、打印机便宜卖靠墨盒回血、电脑预装 Office 引导订阅。共同逻辑都是把一次性的硬件买卖，改造成持续消耗的服务关系。这一轮，token 扮演的就是当年的“话费”。

## 天猫 × 电脑厂 × 模型方：三方各取所需的一笔账

- 阿里的算盘：天猫是卖电脑的场子，通义、夸克是模型的出口。买电脑送 Qwen 系 token，等于在自己的生态里把“硬件入口—云端模型”这条链路焊死，还顺手给通义 App 导了一波新用户。
- 电脑厂的痛点：AI PC 喊了两三年，卖点是 NPU 算力（新一代移动芯片的 NPU 普遍做到 40+ TOPS），但消费者体感一直偏弱——本地能跑的模型能力有限，真正惊艳的能力大多在云端。送云端 token，等于给 AI PC 补上缺的半边体验，让“AI 电脑”三个字第一次有了可验证的用法。
- 模型方的视角：聊天时代的增长见顶后，Agent 才是 token 消耗的下一个放量场景。趁推理成本低洼期把额度塞进新电脑用户手里，培养“开机就有 AI 可用”的习惯，是一次典型的前置获客。
- 对用户也有实惠：本地 NPU 负责低延迟、离线、隐私敏感的小任务，云端大模型负责高质量的重任务，这种混合模式是当前业内比较公认的方向。赠品恰好让你免费体验云端那半边。

## 下单前，把这三笔账算清楚

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/4ee29b9a6d32f734.png)

- 用量账：轻度用户（聊天、翻译、改邮件）一个月大概几万到十几万 token；内容创作者几十万起步；真跑 Agent 的重度玩家一天就能烧掉几十万。对照赠品额度，判断它是“够用一年”还是“三天用完”，落差会非常大。
- 条款账：重点盯三处——有效期（不少赠品 30~90 天，过期清零）、限定模型（通常只送入门款，旗舰模型不在范围）、绑定方式（是否要开会员、是否默认勾选自动续费）。
- 隐私账：云端推理意味着你的提问会离开本机。涉及敏感资料的处理，要么走本地 NPU 模型，要么先读一遍服务商的数据政策，别嫌麻烦。
- 主线账：电脑本身值不值这个价。赠品折算上限也就十几二十元，别为了凑赠品加钱上不合适的配置——为一把调料买了盘不喜欢的菜，不划算。

## 冷思考：当 token 成为“营销货币”

- 赠品升级史就是一条成本曲线史：软件授权贵的年代送实体小件，SaaS 兴起后送会员时长，token 便宜到今天，成了新的赠品硬通货。赠品永远追着边际成本最低的那个东西跑。
- 更值得记住的是信号：Agent 时代人均 token 消耗会比聊天时代高一到两个数量级，各家现在抢的是“第一个把 token 递到你手里”的位置。用过、注册过、账户里有余额，之后的续费转化完全是另一个概率。
- 三条实用建议收尾：
  1. 把赠品当体验券，别当资产：领了就在真实需求里尽快用掉——长文总结、代码解释、批量翻译，用掉的额度才是价值，囤着只会过期。
  2. 借这波免费额度测出自己的用量基线，再决定要不要自费订阅。大多数人其实高估了自己对大模型的日常需求。
  3. 购机决策回归硬件本身：CPU/GPU/NPU、内存、屏幕、售后才是主菜，token 是调料。主菜不对，调料白送也别端。
