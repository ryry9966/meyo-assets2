双11 的电脑商品页里，今年多了一行没见过的新赠品：下单送数百万 tokens。手机时代送壳送膜，笔记本时代送包送鼠标，到了 AI 时代，赠品变成了大模型的“燃料”。这行小字背后，是推理成本跳水、硬件厂商的 AI 叙事、以及模型厂抢用户的获客逻辑三股力量的交汇。这篇就把“买电脑送 token”拆开看清楚：token 是什么、商家为什么送得起、以及这份赠品到底怎么估值。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/28e8227d0ead8b39.png)

## 先搞清楚：Token 到底是什么

- LLM 不按“提问次数”计费，按 token 计费。token 是模型处理文本的最小单位：一个英文单词约 1~1.5 个 token，一个汉字大致对应 0.6~1.5 个 token，不同分词器（tokenizer）差异很大。
- 计费分两段：你输入的内容算 input tokens，模型生成的回答算 output tokens，输出单价通常比输入贵数倍。
- 价格量级：2023 年主流商用模型的 API 价格普遍在几元到几十元/百万 tokens，海外旗舰更高；到 2024-2025 年，国产主力模型的输入价已被打到几毛到几元/百万 tokens，轻量款甚至更低。
- 估算示例：假设赠 500 万 tokens，按“1 token ≈ 1 个汉字”粗算约 500 万字，相当于十几本长篇小说的阅读体量；按中档市价折算，价值大约几元到几十元。它是真金白银，但通常不到整机价格的百分之一。

## 商家为什么送得起：一门经典的补贴生意

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/af7df7f874f64381.png)

- 剃刀-刀片模型反着用。吉列的经典打法是低价卖刀架、靠刀片持续赚钱；如今硬件这台“刀架”照常卖，“刀片”（token）却便宜到可以直接当赠品——因为推理的边际成本已经降到了营销预算可以覆盖的量级。
- 对模型厂商，这是获客成本（CAC）逻辑。拉新一个活跃 API 用户的成本，往往高于塞给一位新用户几百万 tokens 的推理开销；闲时算力闲置是纯损耗，不如兑换成用户习惯。赠 token 本质是把市场预算换了个科目入账。
- 对硬件厂商，这是 AI PC 叙事的“凭证”。AI PC 的卖点是内置 NPU，但大量用户买回去后 NPU 几乎闲置。捆上 token，等于给“这台电脑真的能跑 AI”一张立刻可验证的体验券，帮厂商把故事讲圆，顺带制造差异化卖点。
- 对平台，这是新品类的话题制造机。三方各取所需：硬件厂要卖点，模型厂要习惯，平台要声量——token 恰好是三方都能低成本支付的那张“通用券”。

## 更深一层的信号：Token 正在“话费化”

- 先看价格曲线：2024 年 5 月，字节跳动把豆包主力模型输入价打到 0.8 元/百万 tokens，掀起国产大模型价格战；此后一年多，推理单价整体下降了一个数量级。价格跌到几毛钱级别，token 就从“计费单位”滑向了“促销赠品”。
- 类比通信业：运营商当年把话费、流量做成充赠、包月、加油包，路径是“按量计费 → 打包成额度 → 变成赠品与会员权益”。token 正在重走同一条路，不少厂商已经推出月度 token 包和订阅制。
- 供需错位是根因：训练端军备竞赛放缓后，各家囤积的推理算力需要真实负载来摊薄固定成本；而消费端多数人根本没有“烧 token”的场景。送 token，本质是把过剩供给搬运到潜在需求端的一根管子。
- 价值上移：当推理层快速商品化（commoditization），利润会向上迁移到模型能力、Agent 工作流和订阅服务。下一次大促，赠品也许会从“500 万 tokens”变成“Agent 席位 3 个月”——那才是更值得盯的信号。

## 这份赠品怎么估值：三个判断维度

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/1d3a4236901d68b9.png)

1. 用途匹配度：先问自己有没有消耗 token 的真实场景——写代码调 API、批量处理文档、搭自动化 Agent。如果只是日常问答聊天，各家免费额度基本够用，赠品大概率放到过期，价值趋近于零。
2. 条款细节：能用哪些模型？是不是旗舰型号？有没有限速（如 RPM/TPM 上限）？有效期多久、过期是否清零？走谁的网关、数据如何处理？这些条款比 token 的数字本身更决定实际价值。
3. 折现比较：把“500 万 tokens”按对应模型的市价折成钱，再和“直接降价”“内存硬盘升级”的同类商品横向比。对多数人，直接的硬件升级更实在；赠品更适合本来就打算进 AI 生态折腾的用户。

## 收尾：三条建议与一点冷思考

- 建议 1：把赠品当“体验券”，别当“资产”。它的真实价值 = 你实际用掉的量 × 对应模型市价，用不掉的部分价值为零，不要为赠品改变购机决策。
- 建议 2：如果你是开发者，先确认送的是标准 API 额度，还是只能在厂商内置助手里消耗的“封闭额度”。后者灵活性差得多，调试和迁移都不方便。
- 建议 3：购机权重仍放在硬件本身——CPU、显卡、内存、屏幕。AI 能力可以后期补，硬件短板很难后期换。
- 冷思考：当一家公司开始把核心资源当赠品送，说明它在为下一个收费环节铺路。token 免费不等于 AI 免费，只代表收费点正在从“按字收费”迁向别处——大概率是订阅、Agent 与数据。
