最近 AI 圈又翻出一条“考古”热搜：媒体梳理 A 社（Anthropic）的研究脉络后指出，今天火出圈的编程智能体 Claude Code，核心思路大约五年前就已埋下伏笔；而当年那些被调侃“画大饼”的预言，如今一个个应验。预言家靠的不是水晶球，而是研究曲线。这篇我们就把这条暗线拆开看：产品到底从哪儿“长”出来的？蓝图和预言又该怎么读？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/9938d8cef448d7ad.png)

## 一、时间线考古：Claude Code 不是灵光一现

把关键节点排开，会发现它是某条研究线自然的“收口动作”：

- **2020 年**：GPT-3 发布，scaling laws 论文把“模型越大、能力越强”第一次量化成曲线；同年底，Dario Amodei 等核心研究员出走创业。
- **2021 年**：Anthropic 成立，班底里就有 scaling laws 与 RLHF 路线的一线作者，定位“安全优先的前沿实验室”。
- **2022 年**：Constitutional AI 论文发布，给出可自我批评、可迭代的对齐路线。
- **2023–2024 年**：tool use、computer use 相继落地，模型从“会聊天”进化到“会操作工具”。
- **2025 年**：Claude Code 以命令行编程智能体形态爆火，本质是“强模型 + 终端 + 工具循环”的工程化收口。

五年里每一步都在给最后一步铺路。所谓“蓝图曝光”，不过是把这条暗线拿到明面上看。埋伏笔用了五年，收网只用了一个季度，研究复利的时间结构，大概如此。

## 二、拆开看：agent 三件套，缺一环都跑不起来

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/4103c3a82ed50279.png)

Claude Code 拆到最简，就是三件套：

1. **强模型底座**：代码能力来自海量代码预训练 + 后期的强化学习。衡量基准也从早期的 HumanEval（写单个函数）升级到 SWE-bench Verified（在真实仓库里改 bug），2023 年底主流模型在后者上只有个位数百分比，2025 年头部模型已冲过 70%。这道门槛跨不过，后面全是空谈。
2. **Agent loop**：模型在终端里循环执行“观察 → 思考 → 调用工具 → 看结果 → 再决策”，直到任务完成。这个循环本身不神秘，2023 年的 AutoGPT 就画过同样的饼；当时跑不通，卡在模型“走三步忘一步”。
3. **工具与环境**：读写文件、跑测试、操作 git，再配上 MCP 这类协议，让模型能标准化接入外部世界。

结论很朴素：产品形态五年前就有了，缺的是底座能力。同一套 harness，换个模型效果天差地别，这也解释了为什么 agent 概念不新，爆款却出现在模型跨过阈值之后。

## 三、预言家的底牌：外推曲线，而不是复述口号

- **算力曲线**：研究机构 Epoch AI 的统计显示，2010–2024 年头部模型训练算力大约每 5–6 个月翻一倍，年化 4–5 倍。这条曲线公开可查，谁外推谁占先。
- **基准跳变**：SWE-bench Verified 从 2023 年 10 月的约 4%，到 2024 年底的约 50%，再到 2025 年的 70% 以上，斜率一直摆在那儿，“AI 自主改代码”只是顺着斜率的自然外推。
- **组织意图**：Amodei 在 2024 年的公开长文里就预测过“绝大多数代码不久将由 AI 完成”。愿景文档与带时间戳、带指标的预测要分开看，但多次方向一致，本身就是信号。

预言家真正做对的事，是把“论文 → 曲线 → 产品形态”三件事连起来读，而不是盯着发布会惊呼。说白了，他们只是把 Excel 图表多拖了一年，玄学含量为零。

## 四、蓝图与产品之间，隔着五年的“不可见功”

蓝图上画的是终点，跑起来才知道每公里都有坑：

- **上下文管理**：长任务里如何压缩、检索、遗忘，让模型在滚动的 context 窗口里不迷路；
- **工具颗粒度**：给一个大而全的 bash，还是拆成十个精细工具，成败差在工程师对失败模式的理解上；
- **安全与权限**：agent 能动真实代码库，就得配沙箱、审批流、回滚机制，这是对齐研究落到工程侧的地方；
- **数据飞轮**：早期用户跑出的轨迹数据反哺训练，agent 越用越强，护城河就是这么一圈圈垒起来的。

所以“来自 5 年前”的另一半含义是：这五年没有一天在原地踏步。蓝图人人会画，复利只属于天天记账的人。

## 五、三条实用判断：怎么读蓝图与预言

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/101c1966b5244230.png)

- **学 agent，重点学 harness 而不是 prompt 模板**：context 管理、工具抽象、错误恢复，这三样是可迁移能力，今天绑定 Claude Code，明天换模型照样能用。
- **读预测先过三道滤网**：有没有明确时间戳？有没有可验证指标？作者中途有没有修正过？愿景文档只看方向，可证伪的预测才值得分配权重。
- **冷思考**：蓝图曝光不等于路径可复制。同样的技术谱系摆在全行业面前，跑出来的只有少数几家，差别在执行力、数据回路，以及敢把研究周期拉到五年的组织耐心。

下一份“五年前的蓝图”，此刻大概正躺在某篇没几个人读的论文里。与其追热搜，不如把 arXiv 当朋友圈刷。
