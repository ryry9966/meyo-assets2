双11 预售刚开闸，天猫上不少电脑商品页悄悄换了一种“送法”：赠品栏里不再只有鼠标垫和电脑包，而是多了一行“下单送 XXX 万 token”。这个以往只出现在开发者账单里的词，第一次被印进了消费级硬件的促销话术。买电脑送 token，送的到底是什么？厂商图什么？到手又值多少钱？这篇把账本一层层拆开。

## Token 是什么：大模型的“字数计量表”

先把单位讲清楚。大语言模型并不直接逐字阅读文本，而是先用 tokenizer（分词器）把文字切成更小的单元，这个单元就是 token：

- 英文里 1 个 token 大约对应 0.75 个单词（约 4 个字符）；
- 中文受各家 tokenizer 影响较大，1 个汉字大约折算 0.5~2 个 token；
- 直观感受：一篇 3000 字的文章，大约就是 3000~5000 token。

token 同时也是计费和上下文长度的基本单位：

- API 调用按“输入 token + 输出 token”分开计价，输出通常更贵。公开报价里，主流模型的输入价格多在每百万 token 一元到几元的量级，旗舰模型会再贵上一截；
- 常见的 128K 上下文窗口，大致装得下一本十几万字的小说；
- 如果跑 Agent 类工作流，system prompt、多轮工具调用、思维链全部计入消耗，单次会话烧掉几十万 token 并不稀奇。

理解了单位，才谈得上估算赠品的含金量。

## 厂商图什么：一次促销背后的三本账

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/0861a1f411de8349.png)

“买硬件送 token”听起来像赔本赚吆喝，拆开看其实是三方各算各的账：

1. **电脑厂商的账：token 的边际成本极低。** 模型训练是一次性沉没成本，推理按批发价走量，送出千万级 token 的实际支出可能只有几元到几十元。比送实体外设便宜，还自带话题度，顺手把"AI PC"的叙事落到一个用户可感知的权益上。
2. **模型厂商的账：这是精准获客。** 买电脑的人里藏着大量从没调过 API 的普通用户，免费额度负责“拉新—养成习惯”，后续再靠订阅或按量付费转化。云厂商送免费额度、运营商合约送话费，走的是同一个剧本。
3. **平台和品牌的账：差异化卖点。** 双11 参数卷到头了，整机配置大同小异，“送 token”让商品页多了一个可传播的记忆点，也把“买电脑”从买参数往买服务的方向带了一步。

一句话总结：这是“剃须刀送刀片”的镜像版——硬件负责引流，模型方出耗材，三方各取所需。

## 到手之后：token 怎么领、怎么用

多数活动的链路是：下单后拿到兑换码 → 去对应模型的开放平台注册账户（通常要实名）→ 兑换进账户余额 → 生成 API Key 使用。

几个容易踩坑的点：

- **聊天 App 的会员 ≠ token。** token 是按量计费的 API 额度，要在客户端或脚本里填 Key 才用得上。如果你只习惯在网页里聊天，先确认自己愿不愿意折腾一下。
- **常见玩法：** 把 Key 填进第三方对话客户端、翻译插件、IDE 编程助手，让额度花在真实工作流里，而不是躺在账户里吃灰。
- **留意两个隐藏字段：** 有效期（常见 3~12 个月，过期清零）和是否限定指定模型使用。

## 值多少钱：一个三步估算框架

赠品没标价，那就自己算：

1. **套公式：额度 × 官网单价 ≈ 市值上限。** 以送 1000 万 token 为例，按“输入约 ¥2/百万、输出约 ¥8/百万”的公开档位，假设输入输出各半，市值大约在 50 元上下；若是亿级额度，或按旗舰模型计价，可能到几百元。
2. **按真实用量打折。** 一年用不满 100 万 token 的人，“1 亿”和“100 万”对你等价——价值取决于使用，不取决于数字。
3. **再打两折。** 同一批额度，旗舰模型和轻量小模型的体验差距巨大，先看送的是哪个模型；临近过期的额度要按“清零风险”折现。

## 和 AI PC 的 NPU 什么关系：本地与云端是互补

促销话术里"AI PC"和“送 token”经常成对出现，它们其实是两条技术路线的拼盘：

- **NPU 路线（本地）：** AI PC 通常要求 NPU 算力达到 40+ TOPS 档位，能在本地跑 7B~14B 的量化小模型。优势是隐私、离线可用、零边际成本；短板是小模型能力上限有限，而且吃内存。
- **Token 路线（云端）：** 旗舰大模型能力上限高、迭代快，但按量花钱、依赖网络。

厂商打的是组合拳：硬件 NPU 承接“随时在线的轻任务”，云端 token 承接“旗舰级重任务”。对应到选购上，NPU 看的是未来几年的兼容性，token 看的是当下这段时间的使用权，两者别混为一谈。

## 三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/512ef94951330d84.png)

1. **先查模型清单，再看额度数字。** 确认送的是哪家、哪个版本的模型，覆盖不覆盖你的高频场景（写作、翻译、编程）。小厂轻量模型的“1 亿”，体验可能不如旗舰模型的“100 万”。
2. **用估算框架算出市值，别为赠品牺牲整机配置。** 如果算下来只值几十元，散热、屏幕素质、内存硬盘、售后政策的优先级都应该排在它前面。羊毛是赠品，电脑才是本体。
3. **把它当一次低成本的“体验装”。** 如果你早就想试试 API Key + 第三方客户端的玩法，这波是顺手上车的好机会；但要是打算长期重度使用，先按自己的用量估一估按量付费或订阅的真实成本，再决定要不要续。

token 从开发者的账单走进双11 的卖场，本质上是大模型的边际成本已经降到了可以“白送”的程度——这本身就是行业变化的一个信号。羊毛可以薅，但按工程师的习惯来：先看规格表，再算单价，最后才激动。
