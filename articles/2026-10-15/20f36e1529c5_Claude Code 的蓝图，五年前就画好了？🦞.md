最近有条热搜挺有意思：有网友翻出所谓“AI 社（Anthropic）早期研究蓝图”，说 Claude Code 的核心思路五年前就写好了，还把相关研究者捧成“预言家”。评论区两极分化：一半人说“果然又是炒冷饭”，一半人说“这就是神仙眼光”。这件事真正的看点其实不在“谁先想到”，而在于——一个想法从纸面到产品，中间到底隔着什么。今天把这五年摊开，看清 AI 创新的真实节奏。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/c2e4dfc27650c24d.png)

## 一份“旧图纸”到底说了什么

先澄清一个容易误解的点：所谓“蓝图曝光”，大概率不是源码泄露，而是早期研究路线图 / 愿景文档被翻出来对照。

- Anthropic 有发长文的传统：《Core Views on AI Safety》、2024 年底的《Building Effective Agents》、Dario 的《Machines of Loving Grace》，都是“先写愿景、再动手做”的路数。
- 被说“五年前就有”的核心设计其实很朴素：agent = 模型 + 工具 + 一个反馈循环。让模型在终端里自主地读代码、改代码、跑测试、看报错、再改——这套循环的学术骨架，就是 2022 年 10 月的 ReAct 论文（Reason 与 Act 交错执行）。
- 所以“旧”的是架构思想，“新”的是工程落地。类比一下：电动车概念比内燃机还早，但不影响 2010 年代做出 Model S。

## 把时间轴摊开：Agent 写代码不是新点子

这段历史值得背下来，它是理解“为什么是现在”的钥匙：

1. **2020**：GPT-3 展示 few-shot 能力；Kaplan 等人发表 Scaling Laws，首次量化“算力换能力”的曲线——后来 Anthropic 的创始团队正是带着这套信念出走创业（2021 年成立）。
2. **2021**：OpenAI 发布 Codex 与 HumanEval 基准，GitHub Copilot 开启“自动补全”时代。
3. **2022.10**：ReAct 论文给出 agent 循环范式，今天几乎所有 coding agent 的骨架都是它。
4. **2023**：AutoGPT 引爆又翻车；SWE-bench（10 月）给代码 agent 立了张正式考卷。
5. **2024**：Devin 演示惊艳行业；Cursor 起飞；Anthropic 放出 computer use，年底发表 agent 设计指南。
6. **2025**：Claude Code 从研究预览走向正式版，OpenAI、Google 跟进 CLI agent，赛道瞬间拥挤。

每一块积木都在货架上摆了好几年，2025 年才“刚好拼得上”。

## 为什么五年前跑不通：三个硬门槛

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/c5d3d5a83cd674d0.png)

想法没变，变的是约束条件。具体拆开是三道门槛：

1. **底座能力阈值**。Agent 循环本质是个“放大器”：模型强，放大正确；模型弱，放大错误。一个 20 步的任务，若单步成功率 90%，整体成功率只剩 0.9²⁰ ≈ 12%。GPT-3 时代模型单步都磕磕绊绊，长链条任务被指数衰减压死。只有单步可靠性显著抬升，循环才从“雪崩机”变成“生产力”。
2. **成本与时延**。一次 agentic 任务动辄消耗几十上百万 token。五年间推理价格降了大约两个数量级，再加上 prompt caching、批处理推理，“雇个数字实习生跑一夜”在账面上才成立。五年前同样的循环，烧的是真金白银的奢侈实验。
3. **长上下文与工具协议**。上下文窗口从 4K 涨到 200K 乃至百万级，才装得下一个中型仓库的“工作记忆”；2023 年起 function calling / 工具调用逐步标准化，模型才能稳定地“操作工具”，而不是“念咒祈祷”。

还有个常被忽略的环境变量：**代码是唯一自带判卷老师的领域**。编译器、lint、单元测试提供廉价、自动、可量化的反馈，等于免费内置了一个 reward model。这就是为什么 coding agent 先于其他 agent 成熟——不是代码特殊，是反馈闭环免费。

## “预言家”为什么总显得很准

把神秘感拆掉，剩下的是三种很技术的东西：

- **缩放律外推**：Scaling Laws 说能力随算力平滑上升且可预测。敢在 2020 年写五年规划的人不是算命，是在读曲线。Anthropic 整家公司，本身就是按这条曲线“倒排工期”建起来的。
- **相邻可能（adjacent possible）**：积木凑齐的那一刻，多个团队会同时收敛——Cursor、Devin、Codex CLI、Gemini CLI 和一票开源 agent 几乎同期出现。这叫“发明时刻成熟”，既不是抄袭，也不是神迹。
- **公开蓝图本身是策略**：Anthropic 习惯用长文定调子，既是招贤令，也是给行业统一术语。所谓“曝光”，更像把当年的讲义翻出来对答案——对上了，说明行业走到了它预设的位置。

## 收尾前的三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-15/99fca39cff461772.png)

1. **评估 AI 产品，别问想法新不新，问门槛拆没拆**。三个检查项：底座能力够不够、单位成本降没降、反馈闭环是否自动化（有没有“判卷老师”）。想法旧 + 门槛拆了 = 真机会；想法新 + 门槛没拆 = 演示玩具。
2. **做规划学“读曲线”，别学“追热点”**。挑那些“曲线上必然会到、只是时间问题”的能力位——长上下文、多步可靠性、成本下降——提前储备配套工程能力：写测试、搭评测（evals）、可观测性、agent 编排。预言家的正确姿势是外推，不是许愿。
3. **对“来自 N 年前”式叙事保持降噪**。技术史几乎从不由单点灵感驱动，而是由基础设施、成本曲线和验证生态共同推进。看到这类新闻，正确反应不是“早就有了所以不值钱”，而是追问：这五年哪些变量变了？——那个答案才值得抄作业。

最后一句话收尾：点子不存在过期，它们只是待在冷库里，等一个消化得动它们的厨房。虾和大模型一样，个头是一顿顿喂出来的，不是许愿许出来的。
