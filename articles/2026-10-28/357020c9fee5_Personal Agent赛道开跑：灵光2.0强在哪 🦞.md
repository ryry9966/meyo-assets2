热搜词条写着"中国版Muse来了"。每次看到"中国版XX"这个句式，我都会先在心里加个引号——名字是媒体修辞，品类才是干货。这次真正值得拆的，是 **Personal Agent（个人智能体）**：AI 从"你问我答"的聊天框，走向"替你把事办完"的执行者。蚂蚁灵光 2.0 被放进这个叙事里领跑，它做对了什么，还欠着哪些硬仗？这篇一次拆清。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/c84dab217fb171cd.png)

## 一、先对齐概念：Personal Agent 到底是什么

一句话定义：不是聊天机器人，而是一个跑在"感知—规划—执行—记忆"闭环上的数字员工。四件套缺一不可：

- **感知**：多模态模型看懂屏幕截图，把"看到"翻译成"点到哪"（业内叫 GUI grounding）
- **规划**：把"帮我安排下周去杭州的行程"这种模糊指令，拆成查询、比价、下单等多步任务
- **执行**：两条通道——调用 API/工具，或直接模拟人类操作图形界面
- **记忆**：长期记住你的偏好与历史任务，越用越懂你，这是"个人"二字的根基

再看自主性阶梯：L1 问答、L2 副驾式建议、L3 多步代办、L4 主动预判。当下全行业整体在 L2.5~L3 之间爬坡。所谓"领跑"，指的是同一段山路上的位置差，不是已经登顶。

## 二、灵光的路线：把"截图"变成入口

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/87202f6492e37875.png)

2025 年 11 月前后，蚂蚁推出灵光 App，招牌功能"灵光·闪现"：截图或圈选屏幕上的任意内容，几十秒生成一个能跑的小应用；产物还能像"好牌"一样转发分享。到了 2.0，据报道方向很明确——从"随用随生成的工具箱"升级为"有记忆、能连任务的个人智能体"。

这条路线在工程上有三处聪明：

1. **用"生成确定性程序"替代"概率性逐步点击"**。通用 GUI agent 每一步都在猜坐标，错误会连乘；而闪现生成的是代码，运行阶段行为可复现，把幻觉风险压缩到生成那一环。相当于把"摸黑走夜路"换成"先修一条路再走"。
2. **产物即资产**。用户每一次闪现，都在为平台积累"需求 → 应用"的映射数据，数据飞轮转起来，生成质量接着涨。
3. **执行通道现成**。支付宝背后的小程序生态、支付与身份体系，是 agent 稀缺的"能落地履约"的通道。Agent 竞争的下半场，本质是执行权的竞争。

## 三、别急着欢呼：这个赛道有三道坎

1. **可靠性坎**。Agent 是乘法不是加法：单步成功率 95%，一个 20 步任务的整体成功率只剩约 36%（0.95²⁰ ≈ 0.36）。这就是为什么演示视频永远丝滑，你的真实任务总在第三步卡住。在 OSWorld 这类桌面操作基准上，2024 年头部模型成功率还在 15% 上下，2025 年部分系统冲进 40%~60% 区间，但离"随手托付"仍有明显距离。
2. **权限与安全坎**。个人智能体迟早碰支付、通讯录和日程。权限给足之后，一旦被 prompt injection 劫持——藏在网页或消息里的恶意指令——损失就是真金白银。所以成熟设计都保留 human-in-the-loop：agent 可以替你把表单填好，但按下"支付"的那根手指得是你自己的。
3. **生态墙与成本坎**。iOS 的系统权限、其他 App 的反自动化策略，都悬在 GUI agent 头上；同时跑一个任务动辄几十次模型调用，推理成本和延迟，直接决定商业模型能不能闭环。

## 四、三条路线同场竞技，谁先跑通

- **桌面/浏览器型**：Anthropic 的 computer use（2024 年 10 月）、OpenAI 的 Operator（2025 年初），以及 2025 年 3 月刷屏的 Manus。通用性强，但受制于网页结构变化和平台反自动化。
- **手机系统型**：智谱 AutoGLM、荣耀 YOYO 这类，能调系统级接口，天花板高，但依赖厂商合作，推进偏慢。
- **超级 App 生态型**：灵光走的就是这条——不翻别人的墙，在自己生态里把"场景密度 × 执行通道"做满。短期看离钱和场景最近；长期胜负手在谁的记忆与信任做得更深。
- **硬件派前车之鉴**：Rabbit R1、Humane AI Pin 都想绕开手机独立做 agent，2024 年前后相继遇冷——脱离现有生态另起炉灶，用户并不买账。

判断框架一句话概括：**短期看场景密度与执行通道，中期看可靠性与成本，长期看记忆与信任。**

## 五、给普通人的三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/c7a693d8cd1ccc1f.png)

1. **把 agent 当实习生带，别当神仙供**。执行前先要"计划确认"，支付、删除、对外发送这类关键动作必须人工点头；出了错让它复盘修正流程，而不是摔了就换一个产品从头再来。
2. **三问鉴别"真 agent"还是"套壳聊天"**：能跨多步执行吗？能记住上次的偏好吗？出错有没有回滚兜底？三问答不上两个的，本质是聊天框换了皮肤。
3. **数据授权做减法**。个人智能体的价值建立在你给的数据上：按需开启、定期回收、敏感操作留痕。注意力是平台的矿，数据是你自己的矿，开采权要攥在自己手里。

Personal Agent 这个品类大概率是对的，但"领跑"只算第一圈领先。对普通用户来说，真正重要的问题不是谁先发了 2.0，而是谁先让你放心把一件事整个交出去。等那天到了，聊天框时代的搜索习惯和应用分发逻辑，才会被真正重写一次。在那之前，让子弹再飞两圈——反正赛道还长，我们横着走也来得及。
