最近 AI 圈吵得最凶的，是一组不太性感的数字：把 token 消耗结构和实际支出结构叠在一起对比，消耗的大头只对应账单的小头——流传最广的口径是「约 72% 的 token 消耗，仅对应约 27% 的支出」。多头说这是需求爆发的前夜，空头说这是价值从指缝里漏走。同一组数字，能推出两个完全相反的剧本。这篇把账本摊开：为什么会脱钩、双方各在赌什么、以及普通人该怎么跟踪这件事。

## 先补课：Token 是什么，账单怎么算

- LLM 不按「条」收费，按 token 计价。1 个 token 约等于 0.75 个英文单词，中文大致一个字对应一个 token 上下，具体取决于 tokenizer。
- API 分输入/输出两条价目表，输出价通常是输入的 3~5 倍；旗舰模型每百万 token 从几美分到几美元不等。
- 真正烧 token 的不是「一问一答」，而是上下文：多轮对话要反复携带历史，RAG 要塞进检索到的文档，agent 还要读写文件、调用工具、思考复盘。一个自动编程任务跑完一轮，几十万 token 很常见。
- 所以在本语境下，token 消耗 ≈ 算力消耗 ≈ 模型厂商的现金流出——顺便也是 CFO 的血压来源。

## 消耗和支出为什么脱钩：四台「减压阀」

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/7b285465ac9a40ef.png)

1. **单价通缩**。业内有个词叫 LLMflation：同等能力的推理单价大约每年下降一个数量级。GPT-3 水平的推理价格 2021 年约 60 美元/百万 token，两年半后同类能力已跌近千倍。用量涨 10 倍、单价跌 10 倍，账单可以纹丝不动。
2. **免费与包月**。订阅制 20 美元包月随便用，重度用户的推理成本可能远超订阅费。消耗实打实发生了，支出却被「摊平」了。
3. **工程降本**。prompt caching 对缓存命中的部分最高打到一折，batch API 五折，再叠加蒸馏到小模型、MoE 架构、KV-cache 优化——同样一块 GPU，每小时能吐出的 token 越来越多，实际单位成本降得比挂牌价还快。
4. **结构错位**。高消耗的负载（闲聊、摘要、长文档问答、免费额度）单价低；高支出的负载（编程、企业级 agent、生产 API）用量占比小。两条曲线自然对不齐。

不同报告的切法不同——按免费/付费切、按开源/闭源模型切、按消费/企业切，具体百分比各有出入——但方向一致：**消耗和支出，已经不是同一条曲线上的两个点了。**

## 多头剧本：消耗是收入的前导指标

- **Jevons paradox**。1865 年经济学家杰文斯发现：蒸汽机效率提升后，煤的消耗不降反升，因为需求被释放了。今年初 DeepSeek 引发算力恐慌时，纳德拉引用的就是这个概念——单位成本下降会放大总需求。
- **用量确实在跳变**。谷歌披露每月处理约 480 万亿 token，一年涨了约 50 倍；微软称一个季度处理超 100 万亿 token，同比涨 5 倍。这个量级说明需求是真的，不是 PPT 需求。
- **agent 化是下一棒**。一个任务从一问一答变成几十轮工具调用，单任务 token 消耗放大一到两个数量级，而这类负载恰恰付费意愿最强。
- **历史类比**。早期互联网也是「流量巨大、收入很小」，流量先到，变现后至。多头赌的正是：消耗曲线是收入曲线的前导。

## 空头剧本：被摊薄的算力与价值捕获困境

- **算术不站在自己这边时，别谈信仰**。收入 = 用量 × 单价。如果单价降幅追平甚至超过用量涨幅，收入不涨反跌。这是等式，不是观点。
- **开源模型的贴脸压价**。DeepSeek、Qwen、Llama 这类开源模型把「够用」的智能变成近乎免费的水电，头部闭源模型的定价权被持续压缩。
- **缺口仍未闭合**。Sequoia 那道著名的「6000 亿美元之问」——算力资本开支与应用端收入之间的鸿沟——至今没有被完整回答。折旧在前跑，收入在后追。
- **支付意愿的断层**。如果 27% 的支出集中在少数高价值场景，意味着大部分消耗来自低付费意愿需求。一旦补贴和免费额度退坡，这条曲线可能断崖。

## 与其站队，不如盯这四个变量

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/26afb6074e048ec6.png)

1. **弹性赛跑**：用量增速 vs 单价降幅。收入增长只有一个充分条件——用量涨得比价格跌得快。这是一场每天都有新数据的赛跑。
2. **高价值负载占比**：编程、agent、企业 API 的支出份额是否持续抬升。它决定消耗结构会不会向「愿意掏钱的部分」迁移。
3. **单位经济**：模型厂商的推理毛利、包月用户的单用户推理成本。重度用户是在养平台还是在掏空平台，财报电话会里有线索。
4. **成本曲线的斜率**：专用推理芯片、MoE 与蒸馏等架构演进、能源供给，还能把单位成本压低多少。斜率一旦变平，Jevons 效应就会减弱。

## 三条冷思考

1. **看付费 token，别只看总 token**。总消耗涨 50 倍很壮观，但收入函数的自变量是「有人为之付账的那部分 token」。前导指标和幻觉指标，区别就在这一步。
2. **效率提升既是需求放大器，也是利润挤压机**。Jevons paradox 的两面同时成立：总需求确实在膨胀，单位经济确实在被压薄。最后的赢家，往往是成本曲线下探最快的那一家。
3. **把 token 当电费管**。无论多空谁赢，对用 AI 的团队结论都一样：caching、请求路由（简单任务走小模型）、必要时蒸馏自建，这三板斧能把推理账单砍掉一大半。省下来的全是自己的，这一条不依赖任何剧本。
