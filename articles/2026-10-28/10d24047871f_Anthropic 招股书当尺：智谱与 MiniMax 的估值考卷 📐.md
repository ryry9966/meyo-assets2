大模型行业苦“估值玄学”久矣：私有市场里一轮融资一个故事，价格全靠信仰支撑。最近 Anthropic 被曝启动上市流程，招股书中的财务细节陆续见光，等于把一家头部 frontier lab 的真实账本摊在了阳光下。同一时间窗口，智谱据报推进科创板上市辅导，MiniMax 据传已就港股递表。三件事撞在一起，“中国大模型公司到底值多少钱”这道题，第一次有了可对照的参考答案。这篇只拆三件事：招股书能看见什么、Anthropic 的账本长什么样、智谱和 MiniMax 的叙事差在哪。

## 招股书是一把尺子：S-1 里到底有什么

私有市场估值靠“故事 + 可比交易”，公开市场只认审计过的数字。用工程师的话说：私有市场跑的是 demo，公开市场跑的是生产环境。一份招股书会把过去靠小道消息流传的东西变成硬数据：

- **收入与增速**：ARR（年化经常性收入）、逐季增速，以及收入结构——API、订阅、企业合同各占多少；
- **毛利率**：对大模型公司格外关键，推理成本直接吃掉每一 token 的毛利，低价套餐补贴重度用户是行业通病；
- **烧钱与承诺**：研发投入之外，还有与云厂商签下的巨额算力长约，这些是未来刚性支出，本质上接近负债；
- **客户质量**：NDR（净收入留存率）、大客户集中度，决定收入是可复利的资产，还是随时搬走的租客。

这四项一旦公开，整个赛道的估值锚就会被重写：头部公司的 P/S 倍数与毛利率曲线，会成为后面所有玩家的对照表。

## Anthropic 的账本：增长是真的，贵也是真的

先交代背景，数字均为公开报道口径，以最终披露文件为准：

- Anthropic 2021 年由前 OpenAI 团队创立，靠 Claude 系列起家；2025 年 3 月估值约 615 亿美元，9 月新一轮据报道投后约 1830 亿美元，半年多翻了两倍；
- 收入侧，据报道其年化收入从 2024 年约 10 亿美元量级，涨到 2025 年中的 30 亿美元以上，增速仍是翻倍级别；
- 成本侧才是看点：一次前沿模型训练动辄数亿美元，推理侧为抢市场大量补贴 API 与订阅，再叠加与 AWS、Google 的天量算力承诺——招股书大概率呈现“收入高增长 + 巨额亏损 + 长约压顶”的组合。

这里有一个反直觉的机制：**亏损不是失控，而是策略**。前沿实验室的打法是“能力领先 → 企业客户锁定 → 用未来的定价权摊平今天的算力成本”，只要增速和留存撑得住，资本市场就愿意持续供油。招股书若坐实这条曲线，等于给“烧钱换复利”这套叙事第一次盖章。

## 智谱：ToB 工程师路线，卖的是确定性

智谱脱胎于清华 KEG 实验室，GLM 架构自主演进至今，是少数坚持“基座自研 + 开源 + 商业落地”三条腿走路的公司。

- **收入结构偏 B 端**：金融、政务、电信、制造等行业的私有化部署与智能体项目，单笔金额大、周期长，但粘性高；
- **产品形态**：GLM 基座 + AutoGLM 类智能体 + 本地化方案，主打“模型跑在你自己机房”，这在数据敏感行业是硬需求；
- **资本路径**：据报道已完成科创板上市辅导备案，若成行将是标志性事件；
- **与 Anthropic 的对照**：同样做企业级 agent、把模型能力变成工作流，但生态不同——国产芯片适配、开源权重、行业 know-how 构成了另一套护城河。

用招股书这把尺量智谱，要回答的问题更接近 SaaS：毛利率多少？项目制收入能否转化为按量计费的经常性收入？

## MiniMax：模型公司 + 消费互联网的混血

MiniMax 2022 年成立，押注全模态：文本（M1 推理模型）、图像、视频（海螺）、语音全线自研，再把能力直接做成用户产品。

- **C 端矩阵**：国内的星野、海螺 AI，海外的 Talkie，靠订阅和内购变现。这是与 Anthropic 最本质的差异——Anthropic 的订阅是给 API 导流的漏斗，MiniMax 的 C 端本身就是主营业务；
- **收入弹性大**：随买量和留存波动，毛利结构更像内容/游戏公司，而非 SaaS；
- **资本路径**：据报道已在筹备港股上市，若走通将成为头部大模型公司里最先交卷的选手之一；
- **估值难点**：消费业务看 DAU、ARPU、LTV/CAC，模型业务看 API 增速与开发者生态，两套账本捏在一起，是它估值最麻烦也最有趣的地方。

## 三套估值逻辑，别用一把尺量所有人

把 Anthropic 的数字直接套在所有公司头上，是本轮讨论最常见的错误。至少要分清三种定价框架：

1. **前沿实验室逻辑**（Anthropic 型）：为“能力领先 + 企业锁定”付溢价，看增速、NDR、算力承诺的可控性；
2. **SaaS/MaaS 逻辑**（智谱偏此类）：看经常性收入占比、毛利率、大客户续约，估值倍数向企业软件收敛；
3. **消费互联网逻辑**（MiniMax 偏此类）：看用户规模、付费率、单用户变现，估值倍数向内容公司收敛。

Anthropic 招股书最大的作用，是校准第一类逻辑的天花板：如果连领头羊都是高增长 + 深亏损，二线实验室的故事就得打折；反过来，若它展现出惊艳的毛利改善，全赛道都会被重估。这就是尺子的传导机制。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/907f8f764ce7ec24.png)

1. **招股书是尺子，不是圣旨**。公开市场给“增长质量”定价：毛利率、现金转化、留存曲线，比 ARR 的大数重要得多——上市不是终点，而是考试的开始。
2. **别拿 Anthropic 直接套智谱和 MiniMax**。客户结构、算力供给、市场环境完全不同，智谱该用 SaaS 框架看，MiniMax 该用“模型 + 消费”双框架看，框架错配得出的结论只是噪音。
3. **盯住单位经济，而非融资轮次**。每 token 的推理毛利、每 DAU 的变现成本、算力长约占未来收入的比例——长期叙事最终都会收敛到这些数字上。叙事决定你上车的价格，单位经济决定这辆车能开多远。

大模型行业从信仰驱动走向报表驱动，不一定是坏事——至少，真正算得清账的公司，会先浮出水面。
