最近 36kr 的一篇文章在技术圈刷了屏，标题很损但很准：《"AI之王"Anthropic，给马斯克、黄仁勋们打工》。拆开看，它指向一层很多人忽略的商业结构：Anthropic 的 Claude 在模型能力上确实站在第一梯队，但这家公司每赚一块钱，都有相当大的比例要原样交给上游——买 NVIDIA 的卡、租微软/谷歌/亚马逊的云、为数据中心和电力买单。模型层当的是"国王"，账本上过的却是"佃农"的日子。这篇我们把这笔账拆开算一算。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/bccafd42d88112fd.png)

## 先立住人设：Anthropic 到底强在哪

- 2021 年由前 OpenAI 研究核心成员（Dario Amodei 兄妹等）出走创立，主打安全优先，技术上以 Constitutional AI（宪法式对齐）路线著称。
- 2025 年 Claude 4 系列加上 Claude Code 命令行编程工具，精准踩中 "vibe coding" 风口，在程序员群体和企业 API 市场口碑极强；据报道 Claude Code 单产品年化收入一度进入十亿美元量级。
- 商业数据同样亮眼：整体年化收入冲到数十亿美元量级，估值从 2025 年 3 月的 615 亿美元一路涨到 9 月的 1830 亿美元，增速在头部实验室里排第一档。

按剧本，这该是主角高歌猛进的故事。但翻到成本那一页，画风突变。

## 一块钱的旅行：从客户口袋到黄仁勋的报表

把 Anthropic 的成本结构极简化，每一块钱收入大致经历这样一段旅程：

1. **训练成本摊销**：一次旗舰模型训练，公开测算普遍在亿美元级，绝大部分变成 GPU 时长。
2. **推理成本**：用户每问一句，云端 GPU 就烧几毫秒电费。据报道其毛利率只在 50% 出头——对比传统 SaaS 普遍 80% 起步的毛利率，这个数字相当扎眼。
3. **上游抽成**：买卡的钱流向 NVIDIA（黄仁勋），租云的钱流向 Azure、GCP、AWS，扩建数据中心的土地、变压器和电费流向能源与基建方。

马斯克出现在这张图里，不是因为 Anthropic 直接给他转账，而是他代表了另一种成本压力：xAI 在孟菲斯的 Colossus 集群把 GPU 规模卷到 20 万卡量级仍在扩建，全行业跟着抢卡、抢变压器、抢电力容量。算力军备竞赛把上游价格打了上去，模型公司成了集体被动接受报价的一方。黄仁勋那边则更直白：NVIDIA 数据中心业务毛利率长期 70% 以上，站在整条产业链利润分配的最顶端。一句话总结：模型公司负责突破智能，算力公司负责收割现金流。

## 为什么不自己造卡、自己建云？

- **重资产陷阱**：自建超算意味着一次性锁死数百亿美元资本开支，而 GPU 架构每一到两年换代一次。2024 年囤的卡，到 2026 年可能跑不过新一代单机。租，本质是买"随时升级"的权利。
- **巨头用股权绑定采购**：2025 年 11 月 NVIDIA、微软与 Anthropic 的交易是教科书案例——NVIDIA 至多投 100 亿美元、微软至多投 50 亿美元，Anthropic 则承诺采购 300 亿美元 Azure 算力；另与谷歌签下数百亿美元级 TPU 合同；亚马逊累计投入 80 亿美元并供应自研 Trainium 芯片。钱的路径是转圈的：投资方同时是供应商，采购承诺同时是股东回报的保证。业内把这类交易称作"循环交易"——订单与估值互相放大，好看，但经不起需求端一点风吹草动。
- **电力成了新的稀缺品**：Anthropic 官方口径表示到 2028 年需要 30 GW 量级的算力，大致相当于三十座百万千瓦级核电机组的总输出。未来的瓶颈可能根本不是 GPU，而是电网。

## 一面历史镜子：光纤泡沫的镜像

上世纪 90 年代，电信运营商疯狂铺设光纤，产能严重过剩，泡沫破裂后一批公司倒下——但白菜价的光纤，最终养活了整个互联网应用层。今天的 GPU 很可能复刻这条曲线：

- **供给端**：各家签下天量算力长约，账面承诺以百亿美元计；
- **技术端**：MoE、蒸馏、推理优化、专用芯片在持续压缩单位智能的成本；
- **结果**：一旦效率曲线追上需求曲线，算力从稀缺品变成库存，长约反而变成沉没成本，推理价格雪崩，红利流向应用层。

有机构测算，同等能力的推理价格大约每年下降一个数量级。所以"给算力打工"是特定阶段的产业位置，不是永久判决——手握用户与场景的公司，等的正是那个"算力过剩时刻"。

## 三条冷思考

1. **看 AI 公司，先看毛利率，再看 ARR**。收入增速会骗人，单位经济不会：算一算每个活跃用户消耗多少 GPU 时长、赚回多少钱。毛利率不足 60% 的"AI 应用"，本质是算力二道贩子，抗风险能力远比估值曲线看起来脆弱。
2. **长约是双刃剑**。签几百亿算力合同之前，先问一句：三年后跑出同样的智能，还需要这么多卡吗？当技术曲线的斜率超过合同锁定量，长约就从护城河变成负债。
3. **普通开发者站在好位置**。你不需要囤卡，只需要吃推理降价的红利：今天用不起的模型，明年的价格大概率让你用得起。把精力花在场景、数据和工作流上，那才是不会贬值的东西。

模型给了 Anthropic 王冠，但王座是算力焊的，房租照交。写完这篇，我默默看了眼机箱里吃灰的那块显卡——至少它的电费，是我自己交的。
