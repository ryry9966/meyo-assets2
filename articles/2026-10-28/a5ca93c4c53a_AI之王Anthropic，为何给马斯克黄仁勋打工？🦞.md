最近 36kr 一篇文章的标题在朋友圈刷了屏：「AI之王」Anthropic，给马斯克、黄仁勋们打工。乍看像段子，其实是个严肃的产业信号：一家做模型的头部公司，收入里相当大一块来自“同行”——包括正在自研大模型的科技巨头；而它账上的流水，又有一大笔转身交给了上游的算力供应商。AI 产业链里“谁在给谁打工”，比发布会上的关键词精彩得多。这篇咱们把它拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/8ef2d520da20d49c.png)

## 先对齐信息：Anthropic 是谁，凭什么叫“AI之王”

- **出身**：2021 年成立，创始团队（Dario Amodei、Daniela Amodei 等）来自 OpenAI 研究团队，定位从第一天起就是“安全优先”，技术上主打 Constitutional AI——用一组明确原则约束模型行为，替代部分人工标注。
- **产品**：Claude 系列从 2024 年的 3.5 Sonnet 开始，在编程类基准（SWE-bench 等）上长期处于第一梯队。真正的爆发点是 2025 年的 Claude Code：不是聊天框，而是直接在工程师终端里自主读代码、改代码、跑测试的 agent。
- **生态**：2024 年底开源 MCP（Model Context Protocol），把“模型接工具、接数据”的接口标准化；2025 年 OpenAI、Google 相继宣布兼容——标准先行，是典型的平台打法。
- **数据**（均为公开报道口径）：2024 年底年化收入约 10 亿美元，2025 年年中据报道已冲到 40 亿美元上下。据 Menlo Ventures 2025 年中的企业级调研，其 API 市场份额约 32%，反超 OpenAI 的约 25%，编程场景占比更高。
- **资本**：亚马逊累计投资 80 亿美元，Google 投资累计约 30 亿美元级别——云厂商既是股东，也是算力供应商。

“AI之王”不是官方封号，更像开发者在编程这个最高频、最烧 token 的场景里，用钱包投出来的票。

## “给马斯克、黄仁勋们打工”：钱从哪来，又流向哪

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/33d0744ebeb191a0.png)

这条热搜的真正信息量在两个字：**同行**。

收入端，巨头在给 Anthropic 付费：

- 据 The Information、36kr 等多家媒体报道，马斯克的 xAI、英伟达等公司的工程团队也在内部使用 Claude（尤其是 Claude Code）写代码、做评测。一边自研模型，一边给对手付费，听着拧巴，逻辑上却很顺。
- 更大的基本盘是“AI 原生”公司：据报道，编程工具 Cursor 背后的 Anysphere 一家，每年向 Anthropic 支付的 API 费用就达数亿美元量级；GitHub Copilot、Notion、Slack 等也先后接入 Claude。
- Agent 时代 token 消耗指数级上涨：一个自主写代码的 agent，一天“烧”掉的 token 可能顶过去一个月的对话量。token 是新时代的电费，而编程正是电表转得最快的房间。

支出端，Anthropic 也在给上游“打工”：

- 它的算力主要来自 AWS（Trainium 芯片）和 Google Cloud（TPU）。据 2025 年公开报道，Anthropic 承诺向 Google Cloud 采购的算力高达数百亿美元、最多涉及约 100 万块 TPU；而芯片和晶圆的大头，最终仍流向英伟达与台积电。

所以这不是单方向打工，而是一条闭环资金流：巨头买 Claude 的服务 → Anthropic 拿钱买算力 → 算力的钱回到芯片与云厂商手里。**发布会上的对手，账本上是客户。**

## 为什么会出现“同行互买”这种拧巴局面

1. **比较优势**：造大模型和用好大模型是两门手艺。Claude 在长上下文、代码编辑、工具调用上的工程化打磨领先，巨头拿它辅助自家研发，比内部从零造轮子又快又省。
2. **元任务需求**：训练自家模型需要大量代码评测、数据清洗、红队测试——这些“造模型的模型工作”恰好是最强编程模型的舒适区。于是模型公司的内部流水线，成了另一家模型公司的客户。
3. **安全与合规的品牌溢价**：Anthropic 把安全写进公司宪法，对 to B 客户的采购决策链（法务、合规、审计）格外友好，这在企业市场是真金白银的竞争力。
4. **生态锁定**：MCP 被竞对采用后，工具链标准的话语权留在 Anthropic 手里。开发者围绕你的协议写代码，迁移成本自然抬高。

一句话总结：模型能力是流量入口，协议和生态才是护城河。

## 这门生意没那么稳：三个隐忧

1. **收入集中度高**：编程场景贡献了过半收入，且头部客户（如 Cursor 这类 agent 公司）占比很大。头部客户既能带飞你，也可能哪天自研模型“毕业”。
2. **客户即对手**：Google、亚马逊既是股东和算力供应商，又是模型竞争者。这种竞合关系平时是红利，关系生变时就是风险敞口。
3. **重资产化**：承诺数百亿美元级的算力采购，意味着收入必须持续高增长才能覆盖折旧。而模型优势的半衰期越来越短——新模型发布后领先窗口可能只有几个月，编程能力一旦被追平，价格战会立刻侵蚀毛利。

## 冷思考：三条给从业者的判断

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/c0162484d4496a4e.png)

1. **看产业别只看榜单，看现金流**：谁在向谁付费、付多少、周期多长，比 benchmark 排名更能说明产业链的真实结构。榜单是快照，账本才是趋势。
2. **应用层保持“模型无关”**：连巨头都在多模型混用（Copilot 同时接 GPT 和 Claude），中小团队更不该把命押在单一 API 上。架构里做好路由和抽象层，切换成本就是你的议价权。
3. **关注“卖铲人”层级**：模型层厮杀最烈、毛利最薄的时候，机会往往在旁边——agent 基础设施、评测与安全工具、MCP 生态里的垂直工具链。淘金热里稳赚的，从来是卖牛仔裤和铁锹的人。

Anthropic 的“打工”故事，本质是 AI 产业分工开始成熟：没有谁能通吃全链条，最强的玩家也要在某个环节为别人交付价值。看清这条链上每一环的钱从哪来、到哪去，比争论“谁是第一”有用得多。
