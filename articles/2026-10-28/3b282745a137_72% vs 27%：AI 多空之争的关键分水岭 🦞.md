最近 36kr 一篇梳理 AI 多空之争（bull vs. bear）的文章里，有一组被反复引用的数据：**72% 的 token 消耗，只对应 27% 的支出**。空方说这是"需求靠补贴堆出来"的铁证，多方说这是"成本曲线碾压账面"的必然阶段。同一个数字，两个相反结论——问题不在数字本身，而在背后的机制。这篇把 token 经济学拆开看：倒挂是怎么形成的、双方各自逻辑是什么、以及比站队更有用的跟踪指标。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/aa2764dcc59d8069.png)

## 一、Token：AI 时代的"千瓦时"

大模型不按"条"收费，按 token 计费，先把计量单位搞清楚：

- Token 是 BPE 分词切出的最小单位。英文 1 token ≈ 0.75 个单词，中文 1 个汉字大约对应 1~2 个 token。
- 多模态把体积放大几十倍：一张 1024×1024 的图按主流切法要几百到上千 token，几秒钟的视频折算下来常到数万 token 量级——视频天然是"token 吞吐怪兽"。
- 计费有三种姿势：**API 按量计价**（input/output 分开算）、**订阅包月**（$20 上下用到额度为止）、**免费额度与云厂商赠金**。只有第一种里"消耗"和"收入"强挂钩，后两种严重脱钩——这就是理解 72/27 的钥匙。

## 二、倒挂是怎么形成的：三个机制

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/659debdbc82858f7.png)

1. **包月制的"自助餐效应"**：重度订阅用户按 API 牌价折算，一个月可能"烧"掉上百美元的算力，账面只收 20。消耗计入 72%，收入却只按订阅费计入 27%。自助餐的行业规律：饭量最大的客人，往往付得最少。
2. **高消耗 ≠ 高付费**：视频生成、娱乐闲聊这类负载 token 巨大，ARPU 却薄；真正愿意按量掏钱的是 coding 和 agent——Anthropic 靠代码场景把 ARR 做大，就是付费意愿的最好注脚。token 的流向和价值的流向，是两条河。
3. **成本端重资产先行**：GPU 折旧、电力、机房是先砸下去的 Capex，推理的解码阶段卡在显存带宽上，各家靠 KV cache 优化、投机解码（speculative decoding）、prompt caching、模型蒸馏一路压成本。同时价格战打得凶：DeepSeek V3 把同级模型打到 $0.27/M input 的牌价，引发国内外连环降价。GPU 不睡觉，电表在跳舞，"每个 token 卖多少钱"却被持续砸低。

一句话总结：**72% 描述算力被谁用掉了，27% 描述钱从哪里进来**——两套坐标本来就未必重合。

## 三、空方逻辑：倒挂 = 需求是"买"来的

- **单位经济学不成立**：卖得越多亏得越多，规模是放大器不是护城河。据外媒报道，OpenAI 2024 年收入约 37 亿美元、亏损约 50 亿美元量级，推理成本是大头。
- **补贴退坡测试**：一旦 VC 输血放缓、云赠金收紧，价格回到真实成本，低价值用量不是放缓而是断崖式蒸发。
- **历史类比**：2000 年的光纤过剩、共享办公的单店模型——用量是真的，付钱意愿是假的。

## 四、多方逻辑：这是基建期的正常快照

- **价格塌方速度惊人**：同等基准能力的模型，牌价约 18 个月降了两个数量级（GPT-4 级智能从 $30~60/M 跌到 1 美元以内）。72/27 只是剧烈下移的成本曲线中的一个快照，不是终点。
- **杰文斯悖论（Jevons Paradox）**：1865 年 Jevons 发现蒸汽机效率越高、煤耗反而越大；token 越便宜，总消耗指数级上涨，消耗跑在收入前面是常态。Nadella 在 DeepSeek 冲击后专门引用过这条。
- **基建先于需求是历史规律**：1840 年代英国铁路狂热、2001 年后的暗光纤，崩溃的是股价不是技术，过剩产能几年后托起了流媒体和 Web 2.0。今天的 GPU 过剩，可能就是 agent 时代的"电网"。
- **27% 的绝对值在陡峭增长**：企业 API、coding/agent 收入曲线斜率很陡，结构正在自我修正。

## 五、比站队更有用：四个收敛指标

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-28/817dd64e95298a4e.png)

判断倒挂会不会收敛，与其选边站，不如盯这四个信号：

1. **毛利剪刀差**：每 token 实收价与每 token 成本价的差值是否收窄——看 API 降价斜率和推理毛利曲线谁跑得快。
2. **付费结构迁移**：订阅与免费占比下降、按量 API 与企业合同占比上升，说明真实需求正在替换补贴需求。
3. **高价值负载占比**：coding、agent、企业检索这类"肯按 token 付钱"的场景，消耗占比是否持续爬升。
4. **用量弹性**：单位成本每降一个数量级，总消耗涨幅是否超过一个数量级——检验杰文斯效应是否还在生效。

## 三条冷思考

1. **先问口径，再站队**：72/27 没说清是否包含免费额度、按什么牌价折算、视频类负载怎么计 token。同一现象换个口径能差出一倍，数据素养比立场先行值钱。
2. **做产品盯"付费 token"**：别被总消耗这类虚荣指标迷惑，把高成本负载和高付费场景绑在一起——视频配创作者订阅，agent 配企业合同。
3. **看曲线，别看发布会**：融资新闻的信息量，远不如一张 token 单价年降曲线。倒挂会不会收敛，曲线会先于舆论给出答案。
