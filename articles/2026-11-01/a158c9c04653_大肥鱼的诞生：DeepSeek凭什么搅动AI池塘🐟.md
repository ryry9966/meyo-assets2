2025 年 1 月底，DeepSeek 的 App 一口气冲上中美两地应用商店免费榜第一；同一天，英伟达市值单日蒸发近 6000 亿美元，创下当时上市公司单日市值蒸发纪录。紧接着是铺天盖地的接入潮、概念股异动、仿冒 App 和网络攻击。一家 2023 年才成立、团队百余人规模的公司，两年就从池塘里的小虾米长成人见人想捞一把的「大肥鱼」。这条鱼是怎么养肥的？肥了之后，池塘里又发生了什么？这篇拆一下。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/9020219b008edcbd.png)

## 第一层肥肉：把算力账算到极致的技术

DeepSeek 的爆发，首先是一份扎实的工程成绩单，核心思路一句话：同样的算力，榨出更多的智能。

1. **MoE 架构（Mixture of Experts）**：V3 总参数 671B，但每个 token 只激活约 37B。相当于一栋大楼只点亮有人使用的房间，把参数规模和计算量解耦。
2. **MLA（Multi-head Latent Attention）**：把注意力里的 KV cache 压缩到原来的零头，推理显存占用大幅下降——这是它 API 敢卖低价的底气之一。
3. **FP8 混合精度 + DualPipe 流水线并行**：把 GPU 之间的通信开销「藏」进计算间隙，2048 张 H800 用五十多天跑完 14.8T tokens 的预训练。
4. **GRPO 强化学习**：砍掉传统 PPO 里昂贵的 value model，改用「组内采样、相对打分」做基线，训练推理模型的成本骤降。R1-Zero 更进一步：不喂人工标注的推理数据，纯 RL 也能涌现出长链思考，论文里那个 "aha moment" 不是营销话术。

一个关键数据点：V3 那次最终训练约 278.8 万 H800 GPU 小时，按每小时 2 美元折算约 557.6 万美元。注意口径——这只统计最后一次训练，不含前期实验、架构探索和基础设施折旧。数字的宣传成分大于会计意义，但方向是真的：方法论层面的抠成本，幅度远超一个数量级。

## 第二层肥肉：便宜本身就是最强的产品力

技术抠出来的成本，被直接让渡给了价格，这才是池塘沸腾的起点。

- 2024 年 5 月 V2 发布，API 价格定到主流闭源旗舰的几十分之一，几天内点燃国内大模型价格战，几家大厂连夜跟进降价。
- R1 发布时输出百万 tokens 定价 16 元，同期 o1 是 60 美元（约合 430 元），差出一个数量级还多。
- 价格下来，场景就上来：过去「用不起」的批量任务——客服、代码补全、内容审核、Agent 长链条调用——第一次变得可算账。
- 低价的另一半底气是开源：权重可下载、可私有化部署，「用不起」变成「至少用得起」，议价权第一次部分回到用户手里。

经济学上这叫 Jevons 悖论：效率提升不减少资源消耗，反而放大总需求。纳德拉当天就引用了这个梗。推理越便宜，算力总盘子越大——这也是英伟达吓一跳之后股价又能缓过来的逻辑。

## 第三层肥肉：被低估的底牌，组织与存量算力

- 母公司幻方量化自 2020 年起自建「萤火」系列超算，巅峰期上万张 A100。量化基金的孩子，第一课就是算成本，养一支不发愁算力的研究团队压力不大。
- 出口管制下拿不到最新旗舰卡，反而逼出一套「预算受限下的精打细算」方法论——前面那些工程花活，都是在硬件约束里憋出来的。
- 团队以本土年轻博士为主，项目制自组织，研究者可以直接申请大规模算力跑实验，没有层层审批。这套配置在 2023 年的国内相当罕见。

一句话总结：算力是存量，方法论是杠杆，组织是支点，三者缺一鱼都肥不起来。

## 变肥之后：池塘里的连锁反应

鱼一大，网就密了。

1. **接入潮**：云厂商抢着上线一键部署，手机、汽车、券商跟进，连不少高校机房都连夜装了本地部署脚本，一周之内「人人都有 DeepSeek」。
2. **蹭热与打假**：仿冒 App、钓鱼网站、概念股炒作一起冒头，官方专门声明只认官网和官方 App。
3. **蒸馏争议**：有闭源厂商暗示自家模型被它蒸馏（未经证实）；更讽刺的是反向操作——R1 权重采用 MIT 协议开源，蒸馏完全合规，DeepSeek 自己也放出了基于 Qwen、Llama 的 1.5B–70B 蒸馏版，大量团队公开用它蒸馏小模型并发成果。
4. **路线重置**：RLVR（可验证奖励的强化学习）+ 长链思考成为 2025 年推理模型主赛道，开源社区以周为单位跟进复现。
5. **鱼刺也到账**：大规模网络攻击、服务限流到「繁忙请稍后再试」、本地部署的数据安全边界、R1 偏高的编造率（事实性评测表现一般），都是这条肥鱼自带的刺。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/421fc540ed1658b6.png)

1. **先问口径，再被数字打动**。「500 万美元训出 GPT-4 级模型」是真实实验记录的切片，不是全成本核算。以后看到任何成本叙事，先确认统计边界：单次训练、单次实验，还是含人力与折旧的全账。
2. **开源不等于免费**。自己部署要算 TCO：显卡折旧、并发优化、运维人力、峰值扩容一样都省不掉。多数业务的正确顺序是先用 API 验证场景 ROI，跑通了再决定要不要把鱼养进自家鱼缸。
3. **学方法，别只追模型**。MLA、GRPO、FP8、蒸馏，这些公开的技术模块正在被全行业复用；真正值得带走的是「在硬约束下做工程取舍」的思维方式。毕竟池塘会换，鱼会换，会算账的鱼永远先长肥。
