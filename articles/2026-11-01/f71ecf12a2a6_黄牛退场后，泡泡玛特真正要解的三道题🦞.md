最近，「黄牛退场」冲上热搜：曾经加价数倍仍一盒难求的 Labubu，二手报价一路回落，部分款式甚至跌破发行价，黄牛群里开始清仓甩货。36 氪那篇《黄牛退场，不是泡泡玛特最大的问题》点出了关键视角——黄牛只是这套体系最外层的投机环节，他们的进退，反映的是炒作周期走到哪一步，而真正决定泡泡玛特天花板的，是几个更结构性的问题。热搜给的是温度计读数，这篇想看的是锅炉。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/c18995c413df69e7.png)

## 一、机制复盘：黄牛是怎么被“养”出来的

盲盒的原始设计里，天然带着投机接口：

- **概率设计**：常规款 + 隐藏款，隐藏款抽取概率多在 1/72 到 1/144 量级（不同系列有差异），人为制造稀缺；
- **价格双轨**：一级市场统一定价（主流区间约 69~129 元），二级市场自由定价，价差即套利空间；
- **内容放大**：晒隐藏款、改娃、端盒（整箱买断）攻略在社交平台形成传播飞轮，热度反过来继续抬高二手报价。

黄牛在链路里实际承担了三个角色：

1. **流动性提供者**：想立刻出手的和想立刻拥有的之间缺一个撮合市场，黄牛补位；
2. **实时传感器**：二手报价是全网情绪的监控面板，黄牛就是面板上的告警灯；
3. **免费广告位**：“一只娃炒到几千块”本身就是传播力最强的素材。

2024~2025 年，Labubu 借艺人效应在东南亚出圈、再反哺国内，溢价一度达到发行价数倍乃至十倍以上。黄牛的活跃度，约等于营销预算之外的零成本曝光——没人想感谢他们，但确实他们在干活。

## 二、黄牛为什么退：不是良心发现，是套利空间消失

黄牛是市场上最理性的群体之一，集体撤退只有一种解释：无利可图。拆开看是三条线同时收紧：

- **供给放量**：官方加大热门系列产量、加密上新节奏，稀缺叙事被自己稀释；
- **热度疲劳**：同一 IP 反复抽，复购的边际效用递减，“赌感”钝化；
- **资金迁徙**：投机资金永远在找下一个洼地——卡牌、谷子（动漫周边）、黄金，哪里有故事去哪里。

还有一个容易被忽略的反身性：二级溢价本身就是盲盒复购的重要燃料。相当一部分人买的不是玩具，而是“以小博大”的期权；当二手价跌破发行价，期权作废，一部分真实需求会跟着一起蒸发。所以黄牛退场不是问题的结束，而是对真实需求成色的检验刚刚开始。

## 三、比黄牛更结构性的三个问题

**1. IP 集中度：半个公司押在一款娃上。** 2024 年财报口径下，Molly 约 21 亿元、The Monsters（Labubu 所属 IP）约 30 亿元、Skullpanda 约 13 亿元，前三大 IP 合计占营收近一半。爆款是加分项，过度依赖爆款是减分项：任何一个 IP 进入退坑期，收入曲线都会跟着抖。控量、推新、退役的节奏管理才是潮玩公司的核心能力——而这部分目前更像玄学，尚未完全方法论化。

**2. 情绪消费的半衰期。** 潮玩的底层是情绪价值。行为心理学里的“间歇性强化”（variable reward）能解释盲盒为什么上瘾，却解释不了人为什么厌倦。从近几年的热点迁移看，单个潮玩 IP 的全民热度窗口大约只有一到两年。商业模式必须回答：热度退潮后，沉淀下来的是品牌资产（迪士尼路径），还是一批滞销库存？

**3. 供给策略的两难。** 这是最拧巴的一环：

- 控量：保住稀缺与二手溢价，但收入受限，且等于把定价权外包给黄牛；
- 放量：报表好看、铺货顺畅，但亲手戳破稀缺叙事，二级价崩塌会反噬一级复购。

2025 年的放量选择，说明公司在增长与全球铺货之间优先了前者，代价就是本轮“黄牛退场”。这个两难没有完美解，只有阶段性取舍。

## 四、解法空间：从“赌爆款”到“IP 工业化”

泡泡玛特的应对大致三条线：

- **IP 工业化**：签约艺术家 + 内部设计团队 + IP 授权合作，目标是把“押中爆款”从买彩票变成流水线，提高上新命中率；
- **全球化对冲**：2024 年海外及港澳台收入约 50 亿元，同比增速超过 370%，占比接近四成，用海外增量对冲国内热度回落；
- **品类扩容**：毛绒、积木、卡牌、线下乐园，把“盲盒公司”升级为“IP 运营平台”。

三条线的共同指向：把收入引擎从单品炒作热度，切换成 IP 组合的复利。能不能跑通，取决于组织能否稳定产出下一个 Labubu——这恰恰是整件事里最难的零件。

## 五、冷思考：给观察者的三条清单

1. **盯非隐藏款复购率，别盯二手溢价。** 溢价是投机情绪的读数，普通款的稳定复购才是品牌基本盘；二手跌破发行价，反而是挤泡沫的健康信号。
2. **盯 IP 集中度曲线。** 若未来一两年前三大 IP 收入占比仍在近一半徘徊、又没有新 IP 冲进头部，说明“IP 工业化”尚未跑通，估值逻辑就仍停留在彩票逻辑。
3. **对从业者：别学限量，学结构。** 真正值得拆解的不是饥饿营销，而是艺术家签约体系、设计到量产的供应链速度、把情绪价值翻译成工业品的能力。限量人人学得会，稳定出爆款至今无人学会。

黄牛退场，只是滤镜被摘掉。摘掉滤镜之后还有人买单的东西，才叫品牌。
