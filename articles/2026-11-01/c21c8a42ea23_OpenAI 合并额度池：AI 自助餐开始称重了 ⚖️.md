最近 AI 圈两条消息撞在了一起：一边是独立开发者 Tibo 给自己的产品连续 28 天日更，把“高频迭代”卷出了新高度；另一边是据 36kr 等媒体报道，OpenAI 合并了旗下产品的额度池，超出订阅额度的聊天开始走向按量计费。一个在拼命“用”，一个在认真“算账”。这两件事凑在一起，恰好是当下 AI 商业模式转折的一个切片：无限量畅聊的补贴时代正在收尾，计量时代开工了。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/0a90998f497881ed.png)

## 一、先搞懂：什么叫“合并额度池”

过去 OpenAI 的限额是“分灶吃饭”：

- ChatGPT 网页和 App 的对话是一套额度，通常按 5 小时滚动窗口计算；
- Codex 这类编程智能体另有一套小时级加周级的额度；
- Deep Research、图像生成、视频生成又各有各的池子。

用户的体感是：白天把 Codex 用爆，晚上照样聊天，互不影响。这本质上是“算力管够”阶段的粗放补贴。

合并额度池之后，逻辑变成“一个钱包”：

1. 所有功能共享同一份总量，按不同“汇率”折算消耗——一次深度研究的开销可能抵几十条普通对话；
2. 任何单一功能的重度使用，都会挤占其他功能的剩余额度；
3. 平台侧拿到统一的调度与核算口径，能把成本精确摊到每个用户头上。

说白了，这是从“按产品线补贴”切换到“按用户核算”的财务动作，只不过它直接长在了产品体验上。

## 二、“计费聊天”：从包月自助餐到“套餐 + 加量包”

订阅制的精神曾经是包月自助餐：付 20 美元敞开用，用完这一轮就等 5 小时冷却。超额之后只有两条路——等重置，或者降级到 mini 级小模型凑合。

现在多了第三条路：加钱。

- 超出套餐后，可以按量购买额外额度（credits / 加量包），继续使用旗舰模型；
- 定价锚点基本对齐 API：同样的 token，走 API 是按百万 token 计价的真金白银，订阅内则是“看起来免费”；
- 相当于把 API 时代成熟的按量计费机制，反向搬进了消费级订阅产品。

这套“订阅保底 + 超量计量”的混合模式，行业里并不新鲜：手机流量套餐的超套餐计费、云服务预留实例叠加按量付费，都是同一个套路。新鲜的是，它落在了“聊天”这个最被认为应该免费的场景上。

## 三、为什么是现在：一笔推理成本的账

1. 智能体把 token 消耗拉高了两个数量级。纯聊天一轮几千 token 就够；一个 Codex 任务要在上下文里反复读代码库、跑测试、自我修正，一轮下来几十万 token 很常见。重度用户一天烧掉的推理算力，可能超过普通用户一整月。
2. 头部效应极端。一小撮 power user 消耗了不成比例的算力，Sam Altman 曾公开承认，对重度使用的 Pro 档（200 美元/月）订阅者，OpenAI 是亏钱的。
3. 算力是刚性瓶颈。GPU 容量不会因为你付了订阅费就变多，峰值时段的争抢必须有人买单。额度池合并本质上是一次“容量记账”：先看清谁在用、用多少，再决定给谁扩容、向谁收钱。

历史对照一下：宽带“不限流量”最终变成达量限速，云厂商的赠金实验最终变成精细化账单。平台经济的规律都一样——补贴期结束，计量开始。

## 四、谁最受影响：三类用户画像

- 轻度用户：几乎无感。日常聊天离限额很远，合并后界面反而更清爽。这也是这次改动没有引发大规模反弹的原因——多数人的额度本来就用不完。
- 重度用户：体感是“额度变少了”。过去在不同产品之间“多锅吃饭”，白天聊天、晚上跑 agent、周末做深度研究，各花各的池子；现在只有一个钱包，必须真正做取舍。
- 拿订阅当生产工具的开发者：冲击最大的一类。像 Tibo 这样高频迭代的人，如果拿个人订阅账号给自己的产品跑请求——额度瞬间见底不说，还踩着 ToS 的灰色地带。平台的信号很明确：订阅是给人用的，生产环境请走 API。

## 五、应对清单：先看账，再换刀

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/823beead3d7321e3.png)

1. 先看账单再抱怨。打开 usage 面板，弄清额度到底被谁吃了——多数人的答案不是聊天，而是某个 agent 功能。
2. 工具分层用。交互式、探索性的工作留在订阅里；批量、自动化、可排队的工作走 API，并让小模型（mini / flash 级）处理主力任务，难活才请旗舰模型出手。开好 prompt caching，省下的钱往往比换套餐更实在。
3. 开发者做三件事：模型路由（简单请求走便宜模型）、用量熔断（单任务设置 token 上限）、供应商可替换（抽象一层接口，别把命运绑在单一平台的定价政策上）。

## 写在最后：三条冷思考

1. 无限量从来是营销语言，不是物理事实。算力有限，“不限量”的尽头永远是限速、降级或加钱，区别只是时间早晚。
2. “订阅 + 计量”会成为 AI 产品的标准定价形态。额度本身正在变成一种产品体验——怎么折算、怎么展示、怎么提醒，都是新的设计课题。
3. 对独立开发者，平台规则是最大的外部依赖。Tibo 的 28 连更值得尊敬，但真正抗风险的产品，是把“平台随时变卦”当作需求写进架构里的那种。

自助餐没有消失，只是收银台装了秤。早点习惯称重的人，反而吃得更从容。
