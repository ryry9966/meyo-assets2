最近 Anthropic 对 Claude 的订阅体系动了一次不小的手术：原 Max 20x 档位升级为 Ultra，同时取消了一直被重度用户吐槽的“5 小时限额”。消息一出，两拨人反应截然相反：重度用户奔走相告，观望者一脸困惑——限额取消是不是等于无限用？档位涨了到底值不值？这篇文章不聊情绪，只拆机制，把“滚动窗口”“订阅经济学”“agent 用量曲线”这几件事讲清楚，看完你就知道这次升级是给谁准备的。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/52277a39733a360d.png)

## 先划重点：这是两件事，别混在一起谈

很多讨论把“改名”和“取消限额”搅成一锅，其实它们是两个独立动作：

1. **档位重排**：Max 20x（约为 Pro 用量的 20 倍，200 美元/月档）升级为 Ultra。通常这不只是换个名字，还伴随配额口径、模型访问优先级、agent 能力权限的重新打包——本质是给重度用户单独开了一个舱位。
2. **计量方式变更**：取消 5 小时滚动窗口这一约束。注意，“取消小时限额”不等于“无限制”，平台几乎必然用总量控制、周配额或公平使用条款兜底，具体口径以官方文档为准。

一句话总结：**前者决定“卖什么”，后者决定“怎么计量”**。分清这两层，才不会被“无限量”的传言带偏。

## 5 小时限额是怎么运作的：滚动窗口与令牌桶

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/d382191c681230e1.png)

要理解取消它的意义，得先知道它原来怎么卡人。

- **滚动窗口（rolling window）**：系统持续统计你“最近 5 小时”的消耗（通常折算成 token 或等效请求数），超过阈值就锁定，窗口滑过去后额度逐步恢复。比如你上午 10 点开始重度使用，10 点到 15 点就是一个观测窗。
- **它的技术近亲是令牌桶限流（token bucket）**：服务端给每个账号一个随时间补充的“桶”，每次请求消耗桶里的令牌，桶空了就返回限流错误。这是分布式系统里最经典的流控手段，各家 AI 产品的 API 限流基本都是这个思路的变体。
- **当初为什么要设它**：LLM 推理是真实的 GPU 算力消耗，订阅却是固定月费。如果只靠月度总量兜底，重度用户可以一夜之间烧掉普通人一个月的算力，5 小时窗口是最直接的削峰手段。
- **它为什么招人恨**：痛点在“不可预测”。代码写到一半、agent 正在跑长任务，限额突然触发、任务中断——对工作流是毁灭性打击。对写代码的人来说，任务跑一半被锁，比下班前被告知需求改了还难受。

## 为什么是现在取消：Agent 把旧规则逼到了墙角

背后有一个关键变量：**Claude Code 这类编程 agent 彻底改变了用量分布**。

- 传统聊天场景下一问一答，人均消耗平稳，5 小时窗口绰绰有余。
- Agent 场景完全不同：一个自动化任务会自主循环“读文件—改代码—跑测试—再修”，几分钟内发起上百次调用，一次通宵重构能连续打穿好几轮窗口。Anthropic 自己也因此在 2025 年年中给 Max 用户额外加过周限额——等于在小时阀门之上再叠一层总闸。
- 当重度用户占比越来越高，细粒度小时窗口的“管理成本”和“体验伤害”，就超过了它带来的削峰收益。更合理的解法是：**扩容，然后把控制粒度从“小时”放宽到“周/月”**，让用户在一个大周期里自由分配，而不是被频繁腰斩。

一句话：不是平台突然大方了，是计量粒度到了该换的时候。对靠 agent 干活的人，连续性比瞬时额度值钱得多——这条改动可能比档位改名更实在。

## 从 20x 到 Ultra：订阅经济的算力账本

再看档位这一侧，它暴露了订阅制的老问题：

1. **收入固定，成本弹性**。订阅费是常数，推理成本却随用量线性上涨。一个满负荷跑 agent 的重度用户，消耗的算力成本可能远超其订阅费，平台靠轻度用户交叉补贴重度用户。
2. **Ultra 的定位逻辑**：把“重度但不失控”的用户单独圈出来，用更高价格换更大的总量配额和更少的打扰。这是行业通行做法，Google 的 AI Ultra 档位就是类似思路——不是炫富，是把补贴关系摆到台面上。
3. **对平台的真正考验**：取消小时窗口后，峰值并发更难预测，对 GPU 供给和调度是硬仗。敢做这个改动，通常意味着算力储备或推理效率（更高的 cache 命中、更好的批处理、更聪明的模型路由）有了底气。

所以这次升级可以读作一个供给侧信号：**算力供给相对 agent 需求的压力曲线，发生了方向性变化**。这也间接解释了为什么是 Anthropic 先动——Claude Code 的重度用户密度，可能是全行业最高的。

## 三条冷静建议：这波升级和你有没有关系

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/5dec9323668cd6a0.png)

最后给一个判断框架，不劝买也不劝退：

1. **看实际用量曲线，而不是想象用量**。翻一下自己的历史消耗：如果连 Pro 档限额都摸不到，Ultra 的超额配额对你价值为零；如果你经常在窗口期被锁，新规则的价值是“连续性”——长任务不再中途断电。
2. **读官方配额文档，重点盯三个数字**：新档位相对 Pro 的总量倍数、是否引入周/月上限、触发限额后是降速还是降模型。这三个数字比任何营销话术都诚实。
3. **警惕“取消限额 = 无限使用”的误解**。固定费率 AI 产品一定有公平使用条款，小时窗口没了，总量控制和反滥用机制只会更精细。把它理解成“计量粒度变粗、自由度变高”，而不是“闸门拆了”。

工具的限额规则，本质是供需关系的镜像。看懂规则为什么改，比追每一次升级更重要。
