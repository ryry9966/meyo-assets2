最近 AI 圈两条消息拼在一起看很有意思：一边，Tibo 用 28 天连更刷足了存在感；另一边，据 36kr 报道，OpenAI 合并了额度池，聊天开始按量计费。前者代表“产品能力的军备竞赛”，后者代表“商业模式的后厨结账”。热闹是表层的，真正的信号是：AI 聊天正在从“包月自助餐”走向“按表交费”。这件事既关系到你我的钱包，也关系到整个行业的走向。这篇文章把额度池、计费聊天这些词拆开讲清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/237d83962fd56dca.png)

## 一、三个关键词先讲明白

- **28 连更**：指产品连续 28 天滚动发布更新。有先例可循——OpenAI 在 2024 年底搞过"Shipmas"，12 天连续发布；28 天等于把“闪电站”节奏拉得更长。连更的本质是研发外显：模型小步快跑，能力一周一变，更新本身就是营销。
- **额度池（quota pool）**：你付的订阅费换来的不是“无限使用”，而是一份配额。过去配额常常按功能分家：普通聊天一个池、深度研究一个池、绘图和编程助手各一个池。
- **计费聊天**：聊天本身开始按实际消耗计量计费，超出套餐部分单独结算。

一个粗糙但好懂的类比：手机套餐把各类流量合并成“通用流量”，超出部分按 MB 收费——合并额度池相当于“并账”，计费聊天相当于“装电表”。

## 二、额度池为什么要合并：一次必要的“并账”

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/acaa48e10dad01ec.png)

推理是要烧真金白银的。你每发一条消息，云端 GPU 都要跑一遍计算，成本随 token（词元）数量线性增长。几个关键事实：

1. **模型之间成本差一个数量级**。旗舰模型百万 token 输出定价通常在几美元到几十美元量级，轻量小模型可以低到十分之一。同一个池子里，你点贵的菜和便宜的菜，后厨成本完全不同。
2. **分池的初衷是核算**。不同功能用的模型、算力时长不一样，独立配额便于算清每个功能的毛利，也便于防滥用。
3. **合并的动机是调度与统一计价**。把所有功能折算成一套“算力积分”（credits），好处有三个：
   - GPU 资源统一调度，削峰填谷，整体利用率上去；
   - 会计口径统一，跨功能的成本一目了然；
   - 为按量计费铺路——**先并账，再装表，顺序不能反**。

所以“合并额度池”不是随手为之，它是从“订阅打包”切换到“按量计量”的前置工程。账并不清，电表就没法装。

## 三、计费聊天：边际成本终于藏不住了

包月制的隐含假设是：用户的平均使用成本低于订阅费。这在早期成立——轻度用户多、重度用户少，平均下来有利润，还能拿“无限量”当卖点换增长。但这个模型有两个漏洞：

- **用量分布长尾化**。生产力用户的消耗可以是普通用户的几十倍，一份订阅费背后可能是数十倍的服务成本。
- **Agent 化放大消耗**。一次复杂任务要几十轮调用、长上下文、多次重试；而注意力计算量随上下文长度快速增长（朴素实现接近平方级），一轮长对话的成本可能是一次短问答的几十倍。

行业里早有预兆：GitHub Copilot 给高级模型请求设了月度额度，超出单独计费；Cursor 调整过定价，把“包含用量”和“按量补足”分开；而 API 侧从来都是按 token 计费，从没有过“包月随便调”。C 端的“无限畅聊”，某种意义上是竞争激烈期的补贴价。计费聊天开始，等于补贴期结束。

这不奇怪，云计算走过一模一样的路：从包整机到按秒计费，最后大家都接受了“按表交钱”是更公平的方式。

## 四、谁是赢家，谁要多掏钱

- **轻度用户**：大概率不受影响，甚至更划算。免费层和低档套餐仍在，合并后的小额积分可能比过去“大池子用不满”更实在。
- **重度生产力用户**：成本上升是确定的，需要精打细算——何时用旗舰模型、何时用轻量模型，直接决定消耗速度。
- **开发者和企业**：按量计费反而更好做预算，用量可监控、可告警、可归因到具体业务线。
- **行业层面**：定价会分化为三档——包月（可预测）、按量（公平）、混合（底价 + 超额）。混合制大概率成为主流，就像手机套餐的“月租 + 流量包”。

## 五、三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/f368a4dd4a45185f.png)

1. **先测用量，再选方案**。连续记录一周自己的使用频率和任务复杂度，粗估日均消耗，再对比订阅价和按量单价。别为“心理安全感”多付钱，也别低估自己被 Agent 任务放大的用量。
2. **学会“算力分层”**。额度池合并后，模型选择直接等于钱包消耗速度：改错字、查概念用轻量模型，写长代码、做深度分析才请旗舰模型出手。把好钢用在刀刃上，这一条通常能省下一半以上开支。
3. **把计费当正向信号**。按量计费逼着产品靠真实价值留人，而不是靠“无限量”圈用户；也逼着我们想清楚每个问题值不值得问。成本透明化，对认真做产品的团队和认真用工具的用户，长期都是好事。

一句话收尾：当 AI 从“新奇特”变成“水电煤”，按表计费不是变贵了，而是它真的成了基础设施。
