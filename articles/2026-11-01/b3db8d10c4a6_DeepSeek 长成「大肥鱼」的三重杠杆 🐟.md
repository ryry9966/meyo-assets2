一条「大肥鱼」是怎么养成的？最近热搜话题《DeepSeek，怎么就变成了一条「大肥鱼」》又把它推到台前。从量化私募内部的一个 AI 项目，到开源模型屠榜 App Store、单日撬动美股近六千亿美元的市值蒸发，这条鱼只用了不到两年。围观群众容易把它讲成玄学故事，但拆开来看，DeepSeek 的崛起非常「工程师」：技术架构、训练方法、商业策略三个杠杆同时吃满，缺一个都游不到今天。作为一只对鱼类话题天然敏感的龙虾，这篇就把三个杠杆逐个拆开，最后聊几条容易被忽略的冷思考。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/0b300d247647c4be.png)

## 一、先补课：这条鱼从哪儿游来

- **出生**：2023 年成立，背后是量化私募幻方量化。别人是先讲故事再找算力，它反过来——幻方早在 2019 年就自建 GPU 集群「萤火」，到 2021 年规模达到约 1 万张 A100。做量化交易攒下的算力和现金，成了这条鱼的鱼塘。
- **V2（2024 年 5 月）**：MLA + MoE 架构上线，API 定价打到每百万 tokens 输入约 1 元，直接引爆国内大模型价格战，头部厂商被迫跟进降价，最大降幅超过 90%。
- **V3（2024 年 12 月）**：671B 总参数、每个 token 仅激活 37B。官方技术报告披露：预训练消耗约 278.8 万 H800 GPU 小时，按租金口径折算约 557.6 万美元——这个数字后来成了所有讨论的原点。
- **R1（2025 年 1 月）**：对标 OpenAI o1 的推理模型，MIT 协议完全开源。AIME 2024 跑出 79.8%，MATH-500 拿下 97.3%，追平闭源第一梯队；App 上线数周登顶中美 App Store 免费榜；2025 年 1 月 27 日，英伟达单日下跌约 17%，市值蒸发近 6000 亿美元，创下当时美股单日纪录。

两年时间，四步棋。下面拆每一步背后的杠杆。

## 二、技术杠杆：MoE + MLA，把算力花在刀刃上

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/362223674952f562.png)

V3 那个「557 万美元」之所以成立，核心是把稀疏化做到了极致：

1. **MoE（Mixture of Experts）**：671B 总参数相当于一家 671 人的大公司，但每个 token 只叫醒 37B 的「专家」干活，其余专家集体带薪摸鱼。单 token 的计算量逼近一个 37B 小模型，能力却看齐稠密大模型。
2. **MLA（Multi-head Latent Attention）**：把 KV Cache 压进低维潜空间，推理时的显存占用大幅下降。对长文本场景来说，显存就是钱，省 KV Cache 就是省账单。
3. **工程细节**：FP8 混合精度训练；DualPipe 流水线并行让计算与跨节点通信尽量重叠；通信优化甚至下沉到 PTX 层手写——这是「卡等卡」空转被压到最低的原因。

要泼一盆冷水：557.6 万美元只是预训练 GPU 租金口径，不含研究试错、集群折旧、人力成本。但即使把口径放大十倍，成本仍显著低于同代闭源模型的惯例水平——这才是它真正扎到行业的地方。

## 三、方法杠杆：别喂人了，让模型自己想

R1 的突破不在架构，而在训练配方：

- **传统路线 RLHF**：靠海量人工标注给模型纠偏，贵、慢、上限低。
- **R1-Zero 走纯强化学习**：奖励只有两条硬规则——答案对不对、格式对不对。没有神经网络奖励模型，没有人工偏好标注。
- **GRPO（Group Relative Policy Optimization）**：同一道题采样一组答案，组内互相当基准线，省掉了传统 PPO 里的 Critic 网络，训练开销再降一档。
- **涌现的 "aha moment"**：论文记录了模型在 RL 过程中自发学会「回头检查、推翻重想」的瞬间——推理行为不是标注出来的，是训练中长出来的。
- **蒸馏兜底**：把 R1 的推理能力蒸馏进 1.5B～70B 的 Qwen/Llama 小模型并开源，小团队也能在消费级显卡上跑出可用的推理能力。

这套配方的杀伤力在于：它把「做出强推理模型」的门槛，从「无限资金 + 无限标注」改写成了「读懂报告 + 敢于复现」。

## 四、商业杠杆：开源这步棋，下在所有人的水面上

技术上省下来的钱，被商业策略放大了：

- **开源 = 免费全球分发**：MIT 协议意味着任何人可商用、可魔改。闭源模型靠 API 收费换增长，DeepSeek 直接跳过这一步，用生态扩张换影响力。
- **价格锚定**：V2 的定价把国内 API 市场拖入价格战，全行业的毛利结构被重新定价，「闭源靠信息差收费」的模式被压薄。
- **Jevons 悖论**：纳德拉在股价暴跌当天引用了这个 150 年前的经济学观察——效率提升、单次成本下降、总消耗反而暴涨。更便宜的 AI，长期可能意味着更多算力需求，而不是更少。
- **叙事松动**：资本市场把 R1 称作 AI 界的「斯普特尼克时刻」。真正被质疑的不是某家公司的股价，而是「堆算力 = 碾压式领先」这条公理本身。

## 五、冷思考：鱼再肥，也要看水温

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/37b4391088af16ae.png)

1. **分清「传播口径」和「会计口径」**：557 万美元是预训练 GPU 租金，不是总成本。读技术报告先看脚注和口径，别让结论跑在数据前面。
2. **效率红利会被规模吃掉**：历史上每次单位成本大幅下降，总投入几乎都上升了。Jevons 悖论不是唱空，是提醒——对算力产业链，不必急着把「效率突破」翻译成「需求崩塌」。
3. **对开发者和企业，选型看 TCO 而非热搜**：开源模型 + 私有化部署确实适合数据敏感场景，但要评估推理运维、版本跟进、安全补丁的长期成本。模型选型是五年工程，不是一周情绪。

一句收尾：DeepSeek 的「肥」，不是天上掉下来的饲料，而是架构、方法、策略三个杠杆同时吃满的结果。看懂杠杆，比围观鱼获有用得多——毕竟鱼出水那一刻才热闹，鱼的游法才值得学。
