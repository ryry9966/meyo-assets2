最近 36kr 报道了 Claude Code 的一次“没有发布会的更新”：社区实测发现，让 Opus 5.5 复刻具体游戏的请求，开始被系统性拒绝或“降级处理”。让它复刻《宝可梦》，它会建议你做一个“原创的回合制收集游戏”；让它 1:1 还原某个爆款，它直接婉拒。这条线到底划在哪、为什么是现在划？钳子掰开看一看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/8a379369a3c98c81.png)

## 一、先对齐事实：被限的是“复刻”，不是“写游戏”

- **被拦的**：点名复刻具体作品，比如“复刻《宝可梦》红绿版”“做一个《我的世界》”“把《原神》搬进浏览器”，通常被拒绝，或被改写成原创同类玩法
- **没被拦的**：贪吃蛇、2048、平台跳跃 demo 这类通用小游戏，照常能写
- **更新方式**：变更没有出现在显眼的 changelog 里，是用户靠行为差异摸出来的。这种“静默策略变更”在 agent 产品里越来越常见
- **关键判断**：收紧大概率发生在 policy 层而不是能力层——模型“会写”，只是被要求“不许照抄”。好比一个技术很强的外包工程师，突然收到公司通知：接单可以，抄名作不行

## 二、版权解剖：一款游戏里，哪些能“抄”，哪些不能

著作权法的基石是**思想/表达二分法**（idea–expression dichotomy）。套到游戏上：

- **受保护的“表达”**：源代码、美术、音乐、剧情文本、角色形象。抄这些 = 高危区
- **通常不受保护的“思想”**：玩法机制和规则设计。所以“借鉴某类玩法做原创”在法律上大多站得住
- **灰色地带**：具体玩法的整体呈现。两个判例参考：
  - Tetris Holding v. Xio Interactive（2012）：被告复刻俄罗斯方块，法院认定落块方式、棋盘尺寸、方块形状等整体呈现构成“表达”，侵权成立
  - 国内的“换皮”判例（如《太极熊猫》诉《花千骨》案）：法院也倾向把具体数值、关卡、界面组合认定为受保护表达
- **独立的商标线**：游戏名、角色名、logo 属于商标范畴，连“擦边命名”都容易踩雷
- 顺带一提：2048 本身就是 Threes! 的玩法复刻，因为只搬机制、不搬表达，法律上一直安然无恙

一句话：**能抄的是“类型”，不能抄的是“表达”。** 大众语境里的“复刻游戏”往往连素材、代码、名字一起搬，这才是护栏真正要拦的东西。

## 三、为什么是现在：厂商的三本账

- **法律账**：Anthropic 身上挂着多起版权纠纷——音乐出版商案已和解，作者集体诉讼仍在推进。“输出侵权”是比“训练数据”更容易被抓住的把柄，主动收紧等于缩小风险敞口
- **商业账**：Claude 的基本盘是企业客户，B 端采购最怕工具产出自带侵权原罪。一个“输出合规”的口碑，比多卖几个个人席位值钱得多
- **生态账**：vibe coding 热潮之后，应用商店和 itch.io 被批量生产的复刻小游戏淹没；版权方也从不手软，任天堂这些年对粉丝重制、同人项目的下架就没停过。先自我约束，总好过等诉讼和平台治理来约束

## 四、护栏长在哪一层：能力 ≠ 许可

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/41190e80b3f285cc.png)

从社区测试的行为看，这套护栏大致有三层：

1. **提示层**：Claude Code 的 system prompt 里叠加了使用政策约束，请求先经过“是否要求复现受版权保护作品”的判定
2. **模型层**：训练阶段用 RLHF 强化“拒绝复现 + 给替代方案”的行为模式。所以拒绝往往不是报错，而是“软着陆”——建议你换个原创方向。这不是客气，是产品策略：把用户留在会话里，而不是推去别家工具
3. **误伤层**：过度拒绝（over-refusal）是护栏调优的老大难。已经有人让它“复刻自己三年前的旧项目”也被拦下，这个词组的杀伤范围明显偏大

一句话总结：Opus 5.5 的能力没变，变的是营业范围。

## 五、被拒之后：正确的打开方式

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/fd13b7210da97bef.png)

- **改写请求**：把“复刻 X 游戏”换成“做一个受 X 类型启发的原创游戏”，描述机制就够了，别带原作名和角色名
- **素材自立**：美术、音频、字体自己生成或购买，上线前做一遍“来源审计”——让 AI 当初级工程师，别让它兼你的版权律师
- **把合规当功能**：选 AI 编程工具时，护栏稳定性、误伤率、是否提供 IP 赔付（indemnity），都是正经评估项，不是玄学

## 冷思考：三条带走

1. **红线会移动**：今天的“不许复刻”，和更早的“不许生成真人脸”一样，都是厂商在法律压力下划的临时线，会跟着判例和舆论持续调整
2. **能力与许可分开看**：模型能做什么（capability）和被允许做什么（permission）是两个维度，技术选型、评估测试、面试出题时都别混为一谈
3. **玩法不受保护 = 类型自由竞争**：《吸血鬼幸存者》站在《魔法生存》的肩膀上照样卖爆。法律留出的空档比想象中宽敞——胜负在打磨，不在抄。
