最近 36kr 报道了一个相当扎心的行业样本：一家漫剧内容方，作品全网累计播放量做到 60 亿，最后分到手的收入不到 100 万。折算下来，每千次播放的收益不到 0.002 元——比很多行业的“白菜价”还要再砍两刀。播放量在热搜上飞，钱却没落到内容方账上，中间到底发生了什么？这篇从商业模式角度，把这个“播放很肥、报表很瘦”的现象拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/8c71f16bcdf590c1.png)

## 一、漫剧是什么：AI 把短剧成本打下来的新物种

先把概念对齐：

- **漫剧** ≈ 漫画分镜 + 配音 + 简单动效（眨眼、口型、镜头推拉），竖屏、单集 1~2 分钟、上百集连更，叙事底座基本来自网文爽文（逆袭、战神、闪婚那一套）。
- **爆发背景**：2023 年起真人竖屏短剧爆发，但真人短剧单部制作几十万起步、投流动辄百万级。AI 绘画和配音成熟之后，漫剧把单集成本压到几千元量级，产能直接拉满。
- **供给端特征**：几百家公司、数千个工作室涌入，题材高度同质化，本质是“内容快消品工厂”——低成本、大批量、赌爆款。

一句话：技术把生产成本打下来，也把入场门槛打下来，赛道瞬间从蓝海挤成红海。

## 二、60 亿播放 ≠ 60 亿收入：分账漏斗逐层扒

漫剧主流变现是 **IAA 模式**（广告分账）：用户免费看，中间插广告，平台按广告收益和内容方分成。问题在于这个漏斗每一层都在漏：

1. **口径层**：平台结算只认“自家小程序/频道内的有效播放”。你在短视频平台上刷到的切片、二创、矩阵号转发，播放量挂在发布账号上，本质是给平台贡献站内流量，并不计入内容方分账。60 亿里可能有相当大比例是这类“站外水”。
2. **完播层**：分账通常按有效完播折算，用户划走就划走，不算数。
3. **广告层**：竖屏短内容广告加载有限，激励视频 eCPM 常见也就几元到十几元。
4. **分成层**：广告收益还要过平台技术服务费、渠道费、投流成本、原著 IP 授权费几道闸门。

做个简化测算（数字取行业常见区间，仅示意）：60 亿总播放，假设真正进入结算链路的站内播放占 10%（6 亿），完播折算后剩 2.4 亿，对应约 1.2 亿次广告曝光，eCPM 按 15 元估算，广告大盘约 180 万；再被平台和渠道拿走大半，制作方到手确实就被压到百万以内。

这不是算术游戏，而是行业的真实结算逻辑：**播放量是曝光口径，分账是结算口径，两个口径之间隔着好几个数量级。**

## 三、播放量为什么“虚”：流量 ≠ 你的流量

工程师视角看，这是个很经典的指标错位问题：

- 播放量 ≈ **PV**：谁发布算谁的，切片、转发、投流素材都能刷出来；
- 分账要的是**带归因的转化事件**：用户必须进入指定结算环境、看到广告触发，才产生一条可结算记录。

几个常见的“播放膨胀器”：

- **切片二创**：短剧的传播模型天然依赖切片，但播放归属在发布账号，不在内容方；
- **投流买量**：素材投放带来的播放，钱花在投流账上，播放记在平台大盘里；
- **矩阵分发**：一个内容拆几十个账号发，数字好看，结算入口还是那一个。

一句话：播放量更像 GitHub star——看着热闹，不发工资。

## 四、产业链的钱到底流向了谁

沿价值链捋一遍，你会发现“内容生产”恰恰是议价权最弱的一环：

- **平台/渠道**：流量入口 + 结算规则制定者，拿走广告大头和技术服务费，旱涝保收；
- **投流侧**：短剧行业的经验值是投流消耗能占到流水的八成上下，漫剧同样在卷买量，代理与平台赚走投放预算；
- **IP 方**：爽文原著授权，保底 + 分成，稳赚；
- **工具与算力**：AI 绘图、配音、剪辑的订阅费，卖铲子的稳赚；
- **制作方**：垫资生产、承担库存风险，收入高度依赖爆款概率——等于拿彩票逻辑干供应链上的活儿。

供给过剩 + 内容同质化 + 议价权弱，三条叠加，单价必然被压到地板。这不是哪一家平台黑心，而是充分竞争市场里“可替代环节”的宿命。

## 五、给内容从业者的三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/ce7ba2ac8912e414.png)

1. **把分账规则当 API 文档读**。结算口径、有效播放的定义、分成比例、账期、违约条款，逐条过一遍。不看结算规则就开工的内容团队，约等于不看需求文档就写代码——项目跑通了，也不知道为什么没进账。
2. **换 KPI**：别盯总播放，盯 **RPM（每千次播放收益）** 和回本周期。播放是平台的虚荣指标，RPM 才是你自己的现金流指标。立项前先算账：这个题材在这个渠道，历史 RPM 大概多少、投流 CPM 多少，能不能在账期内回正。
3. **降低对单一渠道的依赖**：同一内容多平台分发、沉淀自己的 IP 与粉丝资产；或者转向 B 端——给平台做定制、给品牌做内容代工，把“赌爆款的彩票模式”改造成“有现金流的代工模式”。

## 写在最后

60 亿播放赚不到 100 万，结论不是“漫剧不行”，而是：当 AI 把产能拉满，稀缺的不再是“能做出来”，而是“能结算、能分发、能复用”。流量的水很大，但下水之前，先确认水管接在谁家——这是所有流量生意里最朴素、也最容易被忽略的一条工程原则。
