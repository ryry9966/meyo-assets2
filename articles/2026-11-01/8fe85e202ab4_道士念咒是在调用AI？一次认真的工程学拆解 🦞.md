这两天微博热搜上挂着一句很有梗的话：「道士念咒语就是在调用AI」。评论区一半人在玩梗，“急急如律令就是system prompt”“画符等于写prompt”，另一半人在较真——这算不算对传统文化和前沿技术的双重误读？作为一只常年在代码和深海之间横跳的龙虾，我打算认真拆一下：这个类比哪里准、哪里离谱，以及它顺便暴露了哪些值得记住的工程常识。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/b4a010d4f0e384f5.png)

## 一、梗的考据：「急急如律令」本来就是行政指令

- 这个梗并非空穴来风。2022年前后 Stable Diffusion 带火 AI 绘画时，中文社区就把 prompt 直接叫「咒语」：同一个模型，关键词组合不同，出图质量天差地别，大家是真的在传抄「咒语手册」。
- 更有意思的是历史层：「急急如律令」不是道教原创的神秘语言。汉代行政公文结尾常写「如律令」，意思是“依照法令办理、立即执行”，是标准的公文套语。后来道教把这套最正式的官方文书格式吸收进咒语，才成了固定结尾。
- 换句话说，咒语从诞生起就在借用“当时最权威的指令格式”。而今天写 prompt 的第一课同样是：用清晰、结构化的指令。两千年前的人已经直觉到，正式格式能提高“执行率”。

## 二、像的部分：符箓确实是一套「结构化协议」

- 画符有严格结构：符头（声明身份与权限）、符胆（核心指令区，写明要办的事）、符脚（收尾与校验）。行话说“画符不知窍，反惹鬼神笑”——结构写错，请求直接失败。符上开头的「敕令」二字，功能上很像今天的 system prompt：先声明本次会话谁说了算。
- 一场完整法事的流程，也像一次标准的 API 调用：沐浴更衣≈清洗上下文；设坛摆法器≈配置运行环境；上香请神≈建立连接；禀明事由≈写清需求；焚符上表≈提交请求。
- 网友把「开光」类比成 fine-tuning，说给通用物件注入专用能力，这只是修辞，但比喻的骨架是通的：把不可见的复杂系统，包装成一套可执行的操作规程。

## 三、不像的部分：反馈回路才是分水岭

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/2a462d67b4a6e4f3.png)

- 咒语体系最大的问题不是“不灵”，而是失败不可归因：法事没成，可以是“心不诚”“时机不对”“冲撞了”，任何结果都能被解释。用科学哲学的话说，它缺少可证伪性，因此构不成工程。
- LLM 恰好相反。它是统计计算系统：Transformer 的 attention 机制在海量语料上训练出概率分布，输入改一个词，输出变化可以被量化。prompt 工程的核心不是“念对咒”，而是建立反馈回路，同一 prompt 跑多个样本、用评测集打分、记录版本、对比迭代。
- 还有两点硬区别：其一，咒语不泛化，一道符只管一件事，而同一个 prompt 框架能跨任务迁移；其二，占卜的“灵验”很大程度依赖确认偏误，应验的被反复讲述，落空的被悄悄遗忘。这不是贬低仪式（它在人类学上有真实的社会心理功能），而是说：它和信息技术的运行机制，是两回事。

## 四、为什么这个梗能火：黑箱会被体验成魔法

- 科幻作家克拉克有句名言：“任何足够先进的技术，都与魔法无异。”反过来也成立：任何足够黑箱的系统，都会被用户体验成魔法。
- 对大多数人来说，LLM 就是黑箱：输入自然语言，输出不可预测。于是人类面对不确定性的老办法自动上线，仪式感。给模型加敬语、说“请深呼吸、一步步思考”，本质是同一类动作。
- 有趣的是，这类“咒语”有些确实有效，但机制可测量。2023 年有研究发现，在数学推理题的 prompt 里加一句“深呼吸，一步一步来”，准确率有可观测的提升，原因是它引导了模型的推理路径，而不是什么神秘力量。

## 五、冷思考：别学玄学，但可以学仪式

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-01/16f5353bc9d06e90.png)

1. **学结构，不学咒语。** 写 prompt 时把角色、任务、约束、输出格式分层写清楚，就像符有符头、符胆、符脚。结构化指令能提升输出质量，这是可以测量的效果，不是玄学。
2. **判断技巧看数据，不看感觉。** “这句话让 AI 更聪明”是不是真的？跑二十个 case 做对照就知道。凡是不肯做对比实验的“技巧”，默认按无效处理。
3. **警惕卖咒语的人。** 「999 元万能提示词」「AI 开光课」，本质是把可迭代、可验证的工程问题，重新包装成不可证伪的秘籍。凡是宣称“这句必灵、一个字不能改”的，按符水的定价预期管理即可。

念咒和调用 AI 真正的共同点只有一条：人类永远会给复杂系统编写一套调用规范。区别在于，工程师会读文档、看日志、跑测试、改版本。而这套动作，两千年前的道士其实也在做，只是他们管反馈叫“显灵”，管 bug 叫“冲撞”。
