2025 年的 AI 竞赛里，“更快”几乎是所有实验室的默认选项。但 Anthropic 连续做了两件反直觉的事：8 月带头承诺“对手激进扩张时，自家旗舰模型延后发布”；9 月更新商用条款，把被中资多数控股的实体挡在 Claude 之外。一脚刹车、一道闸门，共享同一个底层逻辑：把风险控制排在市场扩张之前。这篇只拆技术和商业细节，不聊立场。

## 一、踩刹车：RSP 是一套什么样的安全账本

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-14/a53af593d1104dc8.png)

Anthropic 的核心制度叫 Responsible Scaling Policy（RSP），本质是一张“能力换防护”的强制兑换表：

- **分级**：风险划分为 AI Safety Level（ASL-1 到 ASL-4）。等级不按公司名气定，按模型在评测中表现出的能力阈值定——比如辅助生物/化学风险、自主复制、AI 研发辅助等。
- **强制兑换**：能力升一级，防护必须同步升一级：更强的红队测试、访问管控、部署前审查。2025 年的 Claude Opus 4 就因触碰 AI 研发辅助阈值，线上部署直接启用 ASL-3 级防护。
- **减速条款**：2025 年 8 月，Anthropic 公开承诺：如果另一家头部实验室公开推进显著更大规模的训练扩张，自家下一代旗舰模型将延后至多 6 个月发布，安全等级同步上调。随后 OpenAI 与 Google DeepMind 加入了类似承诺框架。
- **哲学层面**：他们押注 Constitutional AI——用一套成文原则约束模型行为，让安全决策可解释、可审计。

从经济学视角看，这是把“囚徒困境”改造成“可核查的阶梯管制”：单方面减速没人愿意干，但当减速由规则触发、可被外部观察时，竞争就从“谁先发”变成“谁在安全边界内先发”。安全预算不是情怀支出，是保险费——平时是成本，出险时决定生死。

## 二、关闸门：条款改了什么，技术上怎么执行

2025 年 9 月，Anthropic 更新商用使用政策，两个关键点：

- 被中资多数股权控股的实体，无论注册地或经营地在哪，都不能直接或经第三方渠道使用 Claude；
- 官方口径是国家安全考量：既担心模型被用于恶意监控场景，也担心前沿技术与知识产权外流（此处仅做事实转述）。

配套事实：Anthropic 称受影响的直接收入占比不到 3%，所以这更像一次“风险敞口切割”，而非收入决策。边界也要划清：限制针对的是商业服务条款，学术交流、公开论文与开源模型权重不在其列。

技术上，闸门落在三处：

1. **实体筛查**：API 开通环节按股权结构穿透识别控股关系，类似 KYC；
2. **渠道下架**：第三方云市场里 Claude 相关商品的审核与撤除；
3. **合同追溯**：既有协议的合规条款与审计安排。

现实地说，条款无法做到物理意义的 100% 阻断——但 API 是模型能力的官方分发“正门”，关正门的实际作用是明确合规责任与法律风险边界，而不是宣告“绝对不可达”。

## 三、波及面：哪些技术依赖需要重构

对工程师，真正的问题是“我的链路里哪些环节踩线”：

- **纯 API 调用型应用**：换供应商或改多模型路由，改动最小，主要成本在评测回归；
- **数据生产链路**：不少团队用 Claude 做合成数据、蒸馏与评测参考模型，这条链路断掉后，双语 benchmark 的参照系会失真，基线要重搭；
- **编程 Agent 工作流**：Claude Code 类产品深度嵌入开发流程，工具调用行为、代码风格、长上下文使用习惯都是磨合出来的，迁移成本最高。

## 四、替代路径：断供给开源按了加速键

可选路径三条，适配场景不同：

1. **其他闭源 API**：能力接近，但同样存在单点依赖，风险只是换了位置；
2. **开源权重模型**：DeepSeek、Qwen、Llama 系在中文任务、长上下文与工具调用上的差距持续收窄，且可私有化部署、数据不出域；
3. **本地部署 + 国产算力**：推理侧对硬件的宽容度高于训练侧，昇腾等路线在推理场景的份额持续上升，供应链被动多元化。

关键的技术判断：模型能力差距 ≠ 产品能力差距。多数商业应用拼的是工程封装、数据飞轮和垂直场景理解，裸模型分数只占最终体验的一小部分。这次事件的一个直接后果，是把“开源到底够不够用”从争论题变成实测题——客观上加速了开源生态的工程成熟。



## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-14/29a35aa972e8d072.png)

1. **判断安全承诺，看可核查性而非口号。** RSP 是否公开、ASL 是否随能力上调、有无第三方审计，这三项比任何声明都诚实。可信度来自机制，不来自语气。
2. **把单点依赖做成抽象层。** API 路由、多模型 fallback、关键链路双供应商冗余——规则变化的速度永远快于你的迁移计划，这次事件给出的教训，便宜得值得立刻买。
3. **分清两套竞争坐标系。** 能力竞争拼算法与算力，准入竞争拼合规与渠道；做技术选型时两套都要看：只盯前者会低估风险，只盯后者会错失机会。

刹车与闸门，本质上都是风险管理工具——一个管自己，一个管别人。对观察者来说，比站队更有价值的问题是：这套“安全优先”的制度实验，会不会成为整个行业的新默认值。
