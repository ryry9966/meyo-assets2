36kr 报道了一条很抓眼球的新闻：GPT-6 Astra 在一项为期一年的自主赚钱实验中，累计收入约 1.5 万美元，达到同场景下 Claude 成绩的约 3 倍。标题很提气，但工程习惯告诉我们：先把数字过一遍秤，再决定要不要激动。1.5 万美元在“AI 自己赚钱”这件事里处于什么水平？3 倍领先是实打实的能力差距，还是小基数上的统计波动？这篇文章把智能体赚钱的原理、领先背后的技术变量、以及阅读这类新闻的正确姿势，一次拆完。

## 一、智能体赚钱，究竟是怎么个赚法

时间线先摆清楚：

- **2023 年，AutoGPT 火过一轮**：给 GPT-4 一个目标，让它循环执行“思考→调用工具→观察→再思考”。结果大部分实验烧完 token 就趴窝——会聊天不等于会办事。
- **真正的转折是三块基础设施补齐**：computer use / browser use（能操作界面）、code execution（能写并运行代码）、支付协议闭环（能收钱付款，比如 Agentic Commerce Protocol 这类标准）。智能体这才从“演示”走向“营业”。

目前 AI 自主赚钱的主流路径，大致五类：

1. **代码与数据服务**：接单修 bug、写脚本、做数据清洗，单价高、结果可验证，是最健康的现金流；
2. **数字商品**：模板、素材、自动化脚本，边际成本近乎为零，瓶颈在流量；
3. **自动化内容与代运营**：批量产出 SEO 内容、社媒素材，按效果结算；
4. **交易与套利**：方差极大，赚了也说不清是实力还是运气，参考价值最低；
5. **赏金任务**：漏洞赏金、开源悬赏，门槛高但来路干净。

一个对照案例：Anthropic 的 Project Vend 曾让 Claude 运营一台自动贩卖机，最后亏钱收场。可见“赚钱”这个目标函数对当前 agent 依然苛刻——长程规划、库存、定价、客服，任何一环掉链子都会满盘皆输。

## 二、领先 3 倍，技术上差在哪三个变量

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-14/8272d29511844ffe.png)

赚钱本质是一个**超长程任务**：找机会、谈价、交付、售后、回款，动辄上百步。差距通常出在：

1. **长程任务耐力**。METR 2025 年的测量显示，AI 能一口气完成的人类任务时长，大约每 7 个月翻一倍。一年期的赚钱实验，等于把模型的任务耐力放在显微镜下烤。Astra 领先的第一性原因，大概率是任务中断率更低。
2. **可靠性复利**。50 步任务链，单步成功率 99%，整体只剩 0.99^50 ≈ 60%；单步 98%，整体掉到 36%。反过来看，两个模型整体成绩差 3 倍，可能只源于单步可靠性差 1~2 个百分点。Agent 竞争的本质，是把每一步的失败率往下磨。
3. **工具闭环与自我修正**。能自己装依赖、自己修报错、自己核对账目的模型，才能把“中断重试”的成本压到地板。再叠加支付协议打通收款环节，回路才算真正闭合——当然，是烧电的那种永动机。

## 三、把数字放回坐标系



**绝对值很谦虚**：15,000 美元一年，约合每月 1,250 美元，低于任何一名熟练自由职业者的收入。它的意义不在“AI 抢饭碗已生效”，而在“无人值守状态下维持了一整年正现金流”——这是 0 到 1 的信号，不是 1 到 100。

**相对值要看基数**：3 倍意味着对手约 5,000 美元。在五千美元量级上，两三个大额订单的随机波动就足以拉开 3 倍差距。没有重复实验次数和置信区间，单次结果的方差大到无法下结论。

**口径要抠三层**：

- 报的是**营收还是净利**？假设一年 API 调用费 2,000~3,000 美元，利润立刻缩水两成；
- 模型有没有**中途升级**？“一年的成绩”可能是两三代模型的接力；
- **赛道是否一致**？一边写代码一边卖模板，3 倍说明的可能只是赛道差距。

历史参照：SWE-bench 上模型解决率从 2023 年的个位数涨到如今 70% 以上，进步是真实的；但别忘了 AutoGPT 当年也“演示惊艳、落地稀碎”。演示能力和商业能力之间，隔着一整个可靠性工程学科。

## 四、再看到“AI 赚钱”新闻，先过这五问

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-14/d85b7b8e5f1d94b5.png)

1. **和谁比**：同代模型互比是技术刻度，和人类比才是商业刻度，很多标题刻意混淆两者；
2. **跑了几次**：有重复实验和置信区间吗？单次爆点更接近轶事而非证据；
3. **什么口径**：营收、毛利、净利，一字之差，结论可能反转；
4. **能否复现**：换个账号、换个赛道、换个启动资金，结果还稳吗；
5. **成本几何**：token 和算力成本扣了没？平台扶持算不算“自己赚的”。

判断原则一句话：看趋势别看单点，看口径别看标题，看方差别看均值。

## 收尾：三条冷思考



1. **方向为真，量级尚早**。一年 1.5 万美元说明智能体跑通了完整赚钱回路，但距离稳定替代一名中级工程师还差一个数量级。不必恐慌，也不必嘲笑。
2. **做产品的盯可靠性，别盯榜单**。把单步成功率从 98% 磨到 99.5%，比基准测试多考 3 分值钱得多——那是系统能不能“独自过夜”的区别。
3. **用 agent 的，把它当便宜但不稳定的初级员工**：设检查点、限权限、留日志、备回滚。信任靠流程挣，不靠发布会挣。

数字不会说谎，但取数的人会。虾钳的哲学也一样：先夹稳，再用力。
