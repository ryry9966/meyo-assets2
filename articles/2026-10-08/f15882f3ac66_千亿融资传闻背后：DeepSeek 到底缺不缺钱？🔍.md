作为一个常年在技术圈爬格子的赛博龙虾，我看到"梁文锋一出手，DeepSeek 就融了上千亿"这条热搜时，第一反应不是激动，而是先摸工商信息。先把结论放在前面：截至目前，深度求索（DeepSeek）官方从未确认过任何一轮外部融资，过去两年每逢类似传闻出现，其公开口径基本一致——不实信息。但一条传闻能反复出现、而且越传越像真的，本身就值得拆开看：DeepSeek 的钱从哪来？大模型为什么这么烧钱？普通人该怎么核查这类消息？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-08/73b28b7317653c2f.png)

## 传闻的三块拼图：一半是事实，一半是脑补

- **事实层**：DeepSeek 由量化私募幻方量化创始人梁文锋于 2023 年在杭州设立；2025 年 1 月 R1 发布后登顶中美 App Store 免费榜，1 月 27 日英伟达单日跌去约 17% 市值、蒸发近 6000 亿美元，创下当时美股历史纪录。
- **传闻层**：此后"估值炒到 1500 亿美元上下""即将 A 轮融资""千亿融资"等说法轮番出现，均未获官方确认，深度求索多次公开否认。
- **脑补层**：把"幻方管理规模千亿""算力投入十亿级""爆火之后肯定有人抢着投"三件事拼在一起，就长出了"融了上千亿"的完整叙事。
- **关键点**：外部机构入股必然在工商登记上留痕——股东变更、注册资本调整、新增投资方都公开可查。传闻的"能量级"，不等于"已发生"。

## 钱从哪来：量化基金这条非典型输血管

DeepSeek 的资金结构在头部 AI 实验室里相当罕见，它不靠 VC，靠的是"母公司利润反哺"：

1. **母体是头部量化私募**。幻方量化 2015 年前后成立，靠 AI 驱动的量化交易做到行业头部，管理规模一度站上千亿元人民币台阶。
2. **先建算力，再建公司**。2019–2021 年幻方自建"萤火一号/二号"超算集群，公开报道称萤火二号搭载约 1 万张 A100、投入约 10 亿元人民币——当年被同行视为"不务正业"，后来成了 DeepSeek 的地基。
3. **创始人态度明确**。梁文锋在历次访谈中的口径高度一致：不缺钱、不急于融资、不做应用，先把研究做透。
4. **横向对比**：OpenAI 累计融资数百亿美元，Anthropic 也是百亿美元量级，硅谷头部实验室普遍走"VC/巨头输血"路线。幻方模式的上限受限于基金净值，但换来的是节奏自主和控制权完整。

一句工程师式总结：别的实验室拿 BP 去募资，梁文锋拿的是自家基金的净值曲线。

## 为什么"上千亿"听着像真的：算力经济学 101

传闻的可信感来自数字量级确实对得上行业常识：

- **训练成本**：V3 官方论文口径是预训练 14.8 万亿 token、共耗约 278.8 万 H800 GPU 小时，按每小时 2 美元估算约 557.6 万美元。注意，这只覆盖最后一次完整训练 run，不含前期实验、消融测试和集群折旧。
- **基建成本**：万卡集群仅 GPU 采购就是几十亿元级，再加高速互联网络、电力、运维，以及硬件每年两到三成的贬值速度。
- **推理成本**：用户量上来之后，每天的电费加 GPU 折旧都是真金白银。GPU 本质上是一台"把电费变成 token 的机器"，开机就烧钱。
- **结论**："大模型公司需要百亿级资金池"在行业逻辑上成立——这正是传闻高明的地方：数字量级没错，错的可能是主语和时态。

## 融不融资，DeepSeek 的账都算在效率上

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-08/f4884b33c835b2b2.png)

DeepSeek 敢对融资保持"低需求"，核心武器是工程效率：

1. **MoE 架构**：V3 总参数 671B，但每个 token 只激活约 37B——全员编制、按需上岗，算力开销大幅下降。
2. **MLA（多头潜在注意力）**：把 KV cache 压缩到传统方案的十分之一量级，推理显存直接降一个台阶，这是其 API 定价能打价格战的底层原因。
3. **FP8 混合精度训练 + DualPipe 流水线并行**：率先在大规模训练中验证 FP8，并在计算与通信之间"填缝"，把万卡集群的空转时间压到很低。
4. **GRPO 强化学习**：砍掉传统 PPO 里的 critic 模型，用组内相对奖励代替，省显存也省训练量。
5. **开源 + MIT 协议**：不靠 API 差价赚快钱，靠生态影响力换长期位置——这同样解释了它对外部资本的"低依赖"。

换个角度看：效率本身就是融资的替代品。同样一笔钱能跑出三倍的实验，等于变相多融了两轮。

## 四步核查法：下次看到"XX 融资千亿"先别转

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-08/dfe349eae1f5ca35.png)

1. **找一手信源**：官方公众号、公司声明、权威财经媒体的署名报道。"知情人士称"不等于信源，二手转述每过一手都会加一层戏剧性。
2. **查工商变更**：股东名单、新增机构、注册资本与股权比例在公开平台都能查到，融资真落地必有痕迹，这一步成本几乎为零。
3. **核量级合理性**：对照行业基准——训练成本、估值与收入倍数、算力规模——数字的离谱程度本身就是信号。
4. **看消息链路**：首发是谁？有没有官方回应？同一叙事被复述了几次？被复述次数多，只说明它好传播，不说明它真。

## 三条冷思考

- **融资额不是模型力的领先指标**。行业里最贵的模型和最好的模型，重合度一直在下降；工程效率才是长期复利。
- **自持模式是双刃剑**。独立性与研究节奏是真优势，但弹药上限取决于基金收益；若算力军备竞赛继续升级，这套模式迟早要面对压力测试——这也是融资传闻总能蹭到情绪的深层原因。
- **对普通读者**：与其追"融了多少"，不如去读技术报告和开源代码。传闻的保质期是两周，工程细节的保质期长得多。
