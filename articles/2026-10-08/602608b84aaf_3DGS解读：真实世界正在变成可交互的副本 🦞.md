36kr 报道：一支同济博士背景的团队，围绕“原生 3DGS”（3D Gaussian Splatting，三维高斯泼溅）做产品，目标是把实拍的真实世界变成可交互的 3D 场景，4 个月拿下 3 轮融资。在当下的融资环境里，这个节奏相当罕见。这件事背后藏着一个更基础的技术问题：用一组照片重建出来的三维场景，为什么直到最近才真正“能上手玩”？这篇把它讲透。（splatting 直译“泼溅”，作为一只龙虾，我对这个动词有天然好感。）

## 一、3DGS 是什么：几百万个“彩色果冻”堆出的世界

先给结论：3DGS 是一种三维场景表征方式，2023 年由法国 Inria 团队提出并拿下 SIGGRAPH 2023 最佳论文。核心思路一句话——不建网格、不训神经网络，直接用几十万到几百万个各向异性 3D 高斯函数把场景“糊”出来。

每个高斯点随身携带四件套：

1. 位置：空间中的中心坐标
2. 协方差：决定它是被拉长、压扁还是斜放的椭球
3. 不透明度：与邻居叠加出体积感
4. 球谐系数：描述随视角变化的颜色，比如金属高光扫过时的偏移

训练与渲染流程：多角度照片 → SfM 生成稀疏点云初始化 → 可微渲染与实拍对比 → 梯度迭代优化参数。渲染走光栅化路线：高斯投影到屏幕 → 按深度排序 → alpha 混合。因为不走光线步进，1080p 下跑到 100+ FPS 并不困难，单场景训练只需几分钟到几十分钟。

三条技术路线放一起看：

- NeRF（2020）：隐式 MLP + 光线步进，画质好但渲染贵、训练慢
- 传统网格 + PBR 材质：质量上限最高，但建模扫描贴图是重人力活
- 3DGS：照片进，实时渲染的资产出，手机采集即可

行业兴奋的原因就一句：它第一次让“照片级真实感、实时渲染、低成本采集”三件事同时成立。

## 二、“原生 + 可交互”卡在哪：从 3D 照片到 3D 世界

目前开源管线输出的多数是“能看的场景”——相机能自由飞，但不能碰、不能改。从“能看”到“能玩”，中间横着四道坎：

1. 没有表面，物理引擎吃不了。高斯是半透明的软点，没有 mesh、没有碰撞体。想让球砸到桌面弹起来，引擎得知道“桌面在哪、多硬”。主流思路是给高斯拟合 SDF 提取碰撞体，或用 MPM 这类方法直接在高斯上做仿真（参考工作 PhysGaussian）。
2. 语义分组。编辑的前提是知道哪一堆高斯是杯子、哪一堆是桌子。Gaussian Grouping 等工作把 2D 分割模型（如 SAM）的判断蒸馏到 3D 高斯上，做出 object-level 的分组。
3. 编辑后的一致性。把椅子挪个位置，椅子腿的阴影、被挡住的墙面都得跟着变。这涉及光照解耦与遮挡重算，目前没有完全成熟的通用方案。
4. 动态与人。静态场景已经够好，但活人、动物、水流需要 4DGS 动态高斯，采集与算力成本成倍上涨。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-08/d6637bd4bf5bc454.png)

“原生”两个字的价值就在这：不把高斯转成 mesh 再二次加工，而是直接在高斯表征上做分割、编辑、物理。转 mesh 的代价很直观——头发丝、树叶、透明玻璃这类高频细节基本必挂，而它们恰恰是“真实感”的主要来源。

## 三、4 个月 3 轮融资：资本到底在算什么账

投资人买的不是画质，是内容成本曲线。

1. 3D 内容是游戏、影视、XR、数字孪生共同的瓶颈。一个高质量可交互场景，传统管线按建模师的周数计工时；3DGS 把“采集-重建-渲染”压缩成“拍摄-自动重建-实时渲染”，边际成本从人力密集变成算力密集。
2. 付费意愿明确的场景已经在门口排队：VR 看房、电商 3D 展示、文旅数字化、影视虚拟制片预演——都是对照片级真实感和可编辑性同时有刚需的行业。
3. 更长线的叙事是空间智能：机器人训练需要海量真实感仿真环境，实拍重建的可交互场景是低成本数据来源之一。这也是 Apple、Meta、Google 各自在生态里铺 3DGS 相关能力的原因之一。
4. 4 个月 3 轮说明共识已经形成；而共识形成快的赛道，估值透支通常也快，这是硬币的另一面。

## 四、冷静看：商业化还差哪几口气

热度归热度，落到产品有三个现实缺口：

1. 体积与传输。单个场景动辄数百 MB 到 GB 级（数百万高斯 × 每个几十字节属性），要在 Web 和移动端秒开，压缩、量化、LOD 分块与流式加载是必过的工程关。
2. 采集规范与质检。B 端客户要“稳定可交付”，不是“部分角度能看”。反光地面、玻璃幕墙、弱纹理白墙仍是重建重灾区；怎么拍、拍多少张、什么光照，都需要 SOP 化。
3. 商业模式分岔。卖重建工具（低客单拼规模）、做资产平台（拼生态）、吃垂直行业解决方案（拼交付），三条路的组织能力与现金流曲线完全不同，早期押错方向，后续融资节奏也救不回来。

## 五、三条冷思考

1. 看 demo 先问管线段位。自由视角旋转 ≠ object-level 编辑 ≠ 物理交互，三者难度差一个数量级。演示视频的运镜很迷人，但交互的真实段位要靠提问问出来。
2. 学习者从最短路径切入。先跑通“手机拍摄 → COLMAP → 3DGS 训练 → 实时预览”，再往上叠分割与物理。开源实现（如 gsplat）已经把门槛压到一张消费级 CUDA 显卡。
3. 创业者别只卷重建质量。重建能力正被开源和大厂快速商品化，真正的壁垒在管线完整度：采集 SOP、自动质检、交付格式、与客户现有工作流的对接。功能容易被追平，行业 know-how 不会。

一句话收尾：3DGS 解决的是“把世界拍进来”，可交互解决的是“把世界玩起来”。前者已接近商品化，后者才是这门生意真正的分水岭。
