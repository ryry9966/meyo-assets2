前几天 36kr 一条编译报道在技术圈刷了屏：因为太贵，微软被曝砍掉超三成 AI 预算，Meta 对第三方旗舰模型的用量直接腰斩，矛头共同指向 Claude 这类高端 API。评论区迅速两极分化：一派喊“AI 泡沫要破了”，另一派说“Anthropic 定价太飘”。把情绪剥掉，这其实是一份很有价值的行业样本——企业 AI 采购正在从“抢门票时代”进入“对账本时代”。这篇把账拆开看：贵在哪、为什么砍、厂商怎么赌，以及普通团队能抄什么作业。

## 先把新闻读准：砍的不是 AI，是“没算过账的尝鲜”

三个容易被带偏的点先澄清：

- **砍的是预算，不是战略。** 从报道口径看，微软的动作更接近内部支出管控：压缩高价 API 调用预算、引导团队换便宜模型或内部方案，而不是放弃 AI 路线。
- **“腰斩”的具体口径不一。** 砍掉的是预算、席位还是调用量，各媒体描述有差异，但方向一致：对旗舰模型的支出被重新审视。
- **拍板的人变了。** 2023 年是 CTO 说“先接上再说”，2025 年是 CFO 拿着账单问“这笔 Claude 开支换来了什么”。工程师眼里的生产力神器，在财务报表上只是一个费用科目。

一句话总结：这不是 AI 的失败，而是 AI 采购的成熟。

## 一枚 token 的账单：旗舰模型到底贵在哪

以公开牌价为例（约数）：Opus 级旗舰大约 15 美元/百万输入 token、75 美元/百万输出；而各家 mini/flash 档大约 0.1~0.6 美元。同一份代码让两边各跑一遍，账单能差出一到两个数量级。差距主要来自四块成本：

1. **算力与吞吐。** 旗舰模型参数更大、单卡有效算力利用率更低，同一台 8 卡 H100 机器每小时能产出的 token 远少于小模型，单位成本天然偏高。
2. **长上下文的隐性开销。** KV cache 随上下文长度线性膨胀，动辄几十万 token 的 agent 会话把显存带宽吃满，推理成本陡增。
3. **服务质量。** 高峰期保供、低延迟、企业级 SLA，这些都是真金白银。
4. **研发摊销。** 前沿模型一次训练动辄数亿美元，这笔投入要从 API 毛利里赚回来，旗舰定价天然带一层“研发税”。

真正的放大器是 agent 工作流。聊天时代一个用户一天几十万 token 封顶；现在一个编码 agent 处理一个复杂任务，几十轮工具调用、反复读代码，烧掉几百万 token 很常见。用量放大两个数量级，再叠上旗舰单价，账单在 CFO 那里就变成了“事故”。

## “腰斩”的另一面：替代品刚好到位了

为什么偏偏是现在砍？因为“够用的便宜货”终于齐了：

- **能力扩散规律。** 上一代旗舰的能力，大约 6~12 个月后就会被中档模型以一折左右的价格覆盖大部分场景。今天的 mini/flash 档，已经能干两年前旗舰才干得了的活。
- **开源与价格战。** DeepSeek、Qwen、Llama 把 API 价格打到地板，开源权重还允许企业自部署，边际成本直接退化成电费。
- **度量方式成熟。** 企业普遍学会了算 cost per task——完成一个任务的总花费，而不是“我们用上 AI 了吗”。

所以“腰斩”更像迁移而非逃离：高价值场景留在旗舰，长尾场景搬去便宜模型。这是教科书式的采购分层。

## 厂商的两难：降价、分层，还是赌 agent

站在 Anthropic 的角度，这道题并不好答：

- **赌注。** 不打最低价，靠编码、agent、企业工作流这些付费意愿最强的场景立住“质量溢价”；Claude Code 和 MCP 生态都是在加厚这层黏性。
- **风险。** 前沿溢价衰减极快——今天的旗舰就是明年的“够用款”；而 API 层切换成本很低，一个 OpenAI 兼容网关就能换供应商。
- **参考剧本。** 云计算早年也打过价格战，最后的赢家靠规模效应和增值服务赚钱，而不是裸算力毛利。AI 大概率走出类似曲线：API 毛利收窄，利润向芯片端和工具链、agent 平台两端迁移。

换句话说，“太贵了”的抱怨声量，本身就会成为定价委员会的重要输入。

## 给团队的可落地建议与冷思考

1. **建分层路由。** 把任务按难度分级，80% 流量走便宜模型，5~10% 的硬骨头留给旗舰。一个简单的 router/cascade 架构，通常能省下过半预算。
2. **用满降本杠杆。** prompt caching、batch API、控制输出长度、裁剪历史上下文——同样的任务，工程细节做没做，成本能差 5~10 倍。
3. **度量 cost per task。** 别只盯 token 单价，要算“完成一个任务的总成本 + 节省的人工时长”，这才是能拿去和 CFO 对话的语言。
4. **保持可迁移。** 用兼容接口或网关做抽象，内置一套评测集，每季度重跑模型对比，确保随时能换供应商。
5. **冷思考。** 预算被砍不等于泡沫破裂。过去两年，同等能力的推理价格大约每年下降一个数量级，这次砍掉的是浪费性支出；等价格曲线继续下探，同样的预算会买回更多的智能。

模型会一直降价，但账单意识不会贬值。早一点把“贵不贵”翻译成“值不值”的团队，无论下一轮谁涨价、谁降价，都站在主动位。
