2025 年 12 月初，AI Agent 公司 Manus 官宣完成 5 亿美元新一轮融资，据公开报道投后估值约 50 亿美元。而仅仅 9 个月前，它上一轮（Benchmark 领投的 7500 万美元）估值还只有约 5 亿——一年不到，估值涨了约十倍。更值得琢磨的是：这家公司既不训练大模型，也不坐拥流量入口，凭什么让国际资本下这么重的注？这篇文章拆三件事：Manus 到底是什么、这笔钱花在哪、Agent 赛道值钱的逻辑，最后聊聊光环之下该冷静的地方。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-08/8c4442006dda6787.png)

## Manus 是个啥：从“聊天”到“干活”的那一层

- 先分清两个词。ChatGPT 这类产品交付的是“答案”：你问它答，剩下的活你来干。Manus 这类通用 Agent 交付的是“结果”：你说“把这份财报和去年的对比，做成表格加一页要点”，它自己去开浏览器、下载文件、写 Python 清洗数据、生成 Excel 和简报，中途不需要你盯屏幕。
- 底层是经典的 Agent 循环：感知（理解任务与环境）→ 规划（把大目标拆成子步骤）→ 行动（调用浏览器、终端、代码执行器等工具）→ 观察（检查中间产出）→ 再规划。某一步出错就回滚重试，像一位不知疲倦、从不嘴硬说“我不会”的实习生。
- 工程重心在“沙箱”：每个任务跑在一台云端虚拟机里，Agent 在其中自由读写文件、执行命令；你也可以中途关机去睡觉，任务在云端异步跑完，醒来收结果。
- 一个关键事实：Manus 不自研大模型，而是编排 Claude、GPT、Qwen 等多家模型，自己做上下文工程（context engineering）、多智能体调度和工具链。它是典型的“站在基座模型肩膀上”的应用层公司——团队此前靠 Monica.im 浏览器插件矩阵起家，强项正是把技术做成顺手的产品。

## 这笔钱怎么看：一年估值 ×10，钱花在哪

- 时间线：2025 年 3 月产品上线即出圈，邀请码一度一码难求，二手平台被炒到数万元；4 月完成 Benchmark 领投的 7500 万美元融资，估值约 5 亿；12 月官宣的 5 亿美元新融资，据报道估值约 50 亿。另据多家媒体报道，其 ARR（年经常性收入）上线数月内已突破数千万美元，在应用层创业公司里属于第一梯队的增速。
- 钱的去向大致三类：一是算力与推理成本——Agent 单次任务动辄消耗数十万 token，比普通聊天贵一两个数量级；二是企业版与开发者平台建设；三是欧美市场扩张（公司总部已迁至新加坡，团队分布多国）。
- 投资人的算盘不难猜：如果 Agent 定位是“数字员工”，对标的就是人力成本而非软件预算。按结果收费的天花板，比按席位订阅高得多——这是整个赛道估值跃迁的核心叙事。

## Agent 赛道为什么突然值钱

- 技术拐点：长上下文、function calling、computer use、推理模型（慢思考式）接连成熟之后，“模型自己干活”第一次从 demo 变成可用产品，GAIA 这类通用助手评测也被 Agent 产品接连刷新。
- 商业拐点：订阅 + credits（按量计费）的组合跑通了收入模型，头部 Agent 产品的收入曲线非常陡，验证了“愿意为结果付费”的需求真实存在。
- 竞争白热化：OpenAI 推出 ChatGPT Agent，Anthropic 手握 computer use 和 Agent SDK，Google 有 Project Mariner，国内字节、MiniMax 等也都在布局。Manus 的差异化在“多模型中立 + 异步云端执行 + 出海优先”——在巨头夹缝里做“最擅长交付”的那一层。

## 冷思考：光环下的三个问号

- 护城河问题：基座模型厂商正在把 Agent 能力内化进自家产品。纯编排层的壁垒会被下一代模型逐层吃掉，真正难复制的是工作流 know-how、评测体系和垂直场景的数据积累。
- 成本问题：多轮工具调用让 Agent 的毛利天然比聊天差，token 像自来水一样哗哗流。“单位任务成本”才是生死线，而不是用户数。
- 评测问题：benchmark 高分不等于真实任务合格。幻觉、格式错误、漏步骤依然常见，GAIA 满分也替代不了人工验收那一道关。

## 收尾：三条冷思考，拿走不谢

1. 把 Agent 当实习生用，别当全托管员工：任务描述越具体、验收标准越清晰，交付越稳；关键产出务必抽查后再签收。
2. 算账看“单位任务成本”：别只看订阅费，算算完成一件事平均烧多少 credits，再决定要不要纳入日常工作流。
3. 判断 Agent 创业公司，盯三个硬指标：任务完成率、单位任务成本、次月留存。三个都硬，故事才成立；只有估值硬，多半是叙事先行。
