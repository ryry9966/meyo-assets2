最近 36kr 报道了一条让三维视觉圈集体转发的新闻：一支同济博士团队，以“原生 3DGS”为核心技术，把真实世界重建成可交互的三维空间，4 个月连拿 3 轮融资。一条创业新闻同时踩中三个关键词——3D Gaussian Splatting、空间智能、资本窗口期。这篇文章不追情绪，只讲清楚三件事：3DGS 到底是什么技术，“原生”和“可交互”难在哪，以及这波热度里哪些是真机会、哪些是坑。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-08/6f42359ed79db364.png)

## 一、3DGS 是什么：用几百万个“高斯点”泼出世界

- **出身**：2023 年 SIGGRAPH 最佳论文，法国 INRIA 研究团队提出，全称 3D Gaussian Splatting（三维高斯泼溅），从论文到工业落地只用了不到两年。
- **核心表示**：场景不再用三角面片（mesh）拼，也不塞进神经网络（NeRF），而是用几十万到数百万个高斯点。每个点带四个关键属性：位置 μ、协方差 Σ（决定它是个什么朝向、多扁的椭球）、不透明度 α、球谐系数（视角相关的颜色）。
- **为什么快**：渲染时把椭球投影到屏幕做光栅化加 alpha 混合，全程 GPU 并行，实测轻松 100+ FPS。对比 NeRF：每条光线要查询 MLP 上百次，一帧渲染以秒计。打个比方，NeRF 像“把世界写进一本字典，看一眼要翻几百页”；3DGS 是“直接把世界铺成一幅画，看一眼就是全部”——一个在解方程，一个直接背答案，而且这个答案还允许你改。
- **训练流程**：多角度照片/视频 → COLMAP 做 SfM 得到相机位姿和稀疏点云 → 初始化高斯 → 可微渲染算损失、梯度回传 → 自适应地克隆、分裂、剪枝高斯。几分钟到几十分钟，就能得到一个照片级的三维场景。

## 二、“原生”与“可交互”：这家团队的增量到底在哪

- **“原生”的含义**：目前不少团队的管线是 3DGS 重建 → 转成 mesh → 再导入 Unity/Unreal，两次格式转换损失细节、拖慢迭代。“原生 3DGS”是把高斯当作渲染引擎的一等公民，采集、编辑、渲染全链路不落地成旧格式，保真度和效率都上一个台阶。
- **“可交互”的四道坎**：
  1. **几何与碰撞**：高斯拟合的是“外观”不是真实表面，物体要能“撞上去”，得借助 2DGS、SuGaR 这类方法把椭球压出可用的碰撞几何；
  2. **动态编辑**：静态场景好复刻，但移动物体、改材质、加物理模拟，需要比 mesh + PBR 更新的工具链；
  3. **大规模加载**：单个城市场景动辄数百 MB，要分块、LOD、流式传输才能在手机端流畅跑；
  4. **重光照**：换时间段、换天气的一致性渲染，目前仍是研究前沿。
- **商业落点**：数字孪生园区、机器人与自动驾驶仿真（Sim2Real）、文旅 AR、电商 3D 展示——共性是“要真实感”和“要交互”必须同时成立的场景。

## 三、4 个月 3 轮融资：资本在押注什么

- **时间窗口**：2023 论文开源，2024 工具链爆发（gsplat、Nerfstudio、主流游戏引擎插件、Polycam、Luma 等消费级产品），2025 移动端实时渲染基本可用。技术从论文到产业的周期通常三到五年，3DGS 把它压缩到了两年内。
- **叙事叠加**：大模型解决了“语言与图像”，产业界普遍把下一站押在空间智能（spatial intelligence）与世界模型上。3DGS 天然适合当“真实世界的高保真压缩格式”：照片级画质、实时渲染、重建成本低，是目前最现实的世界模型训练数据来源之一。
- **投资逻辑**：mesh → NeRF → 3DGS → 生成式 3D 是一次技术代际更替，窗口期里“卡位全链路”的团队稀缺。更关键的是，如果“采集—重建—交互—数据”能形成闭环，护城河就不是算法本身，而是不断累积的三维数据资产——这才是 3 轮融资被快速追投的根本原因。

## 四、泼点冷水：还没迈过去的工程坎

- **外观好 ≠ 几何准**：直接拿重建结果当物理世界用会翻车，做仿真和碰撞仍需后处理；
- **动态场景（4DGS）仍在研究期**：人物走动、树叶摇摆的时序建模远未收敛；
- **存储与带宽**：单场景几百 MB 起步，端上体验受传输制约；
- **商业模式陷阱**：定制化扫描很容易做成“人力密集的外包活”，毛利薄、难规模化。技术惊艳和生意成立之间，隔着一条叫“单元经济模型”的河。

## 五、三条建议与冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-08/f209eb92caa4397a.png)

1. **学习路径**：别从论文硬啃，先跑开源——gsplat、Nerfstudio、Postshot，用手机拍一段视频重建自己的工位，体感最快。数学补三块：多元高斯分布、矩阵微积分、可微渲染基础。
2. **选场景要带“数据飞轮”**：纯扫描交付不值钱，扫描 + 交互产生的行为数据才值钱。评估方向时问一句：用户在里面“动”起来之后，留下了什么数据？这些数据能不能让下一次服务更好？
3. **判断团队的三个硬指标**：单场景存储多大？移动端实测 FPS 多少？从采集到可交互上线要几天？这三组数字，比融资速度和 PPT 诚实得多。

4 个月 3 轮融资是信号，不是结论。3DGS 把“复刻真实世界”的成本打到了历史最低，接下来拼的是谁能把复刻出来的世界真正“用起来”。对工程师，这是难得的窗口期；对围观者，看懂技术原理再看估值，永远是更靠谱的姿势。
