Meta 刚把 Muse Gadgets 开源了。消息不长，含义不短：一套做 AI 外设的完整参考设计，从电路图到 SDK 全部公开，全球开发者可以直接拿去改。过去两年，大家的注意力都在卷模型、卷上下文长度、卷 Agent 编排，现在终于有人对硬件下手了——AI 的“最后一米”，正从云端一路铺到你的手腕、眼镜和桌面上。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-03/0458d45db9488c7a.png)

## Muse Gadgets 是什么：一套“公版”，不是一个产品

先纠正一个常见误会：它不是某个能下单买到的硬件，而是一套开源参考设计（reference design）。拆开看，仓库里大致三样东西：

- **硬件层**：一块核心板（低功耗 MCU + 小型 NPU），配可插拔的传感器子板——麦克风阵列、IMU、微型摄像头、震动马达，接口统一，像积木一样自由组合
- **固件与 SDK**：驱动、BLE/Wi-Fi 协议栈、端侧推理 runtime，模型按 INT4/INT8 量化后直接跑在设备上，还附带预兼容认证的设计文档和 BOM 清单
- **云端钩子**：local-first 架构，本地能算的绝不出设备，算不动的再调 assistant API

类比很好找：Arduino 之于单片机，Raspberry Pi 之于嵌入式 Linux。值得多说的是，硬件开源最难的不是画原理图，而是长期可维护性——这次是带专职维护团队入场的“机构级开源”，和十年前个人项目式的开源硬件，不是一回事。

## 为什么是“外设”：AI 交互的最后一米问题

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-03/9e5a6429c5f86349.png)

大模型再强，它感知不到物理世界：手机不知道你在看哪块仪表盘，音箱不知道你刚放下扳手。外设补的就是这个缺口，逻辑上有三条硬理由：

- **延迟**：语音请求走云端，一来一回 300–800ms；端侧推理可以压到几十毫秒。喊完 wake word 等一秒才回话的体验，和“对话”是两回事。
- **隐私**：常驻麦克风的原始音频不出设备，本地完成唤醒检测和转写——这件事只有贴身硬件能做到，纯软件方案做不到。
- **上下文**：眼镜知道你正在看什么，徽章知道你刚开完哪个会。多模态数据在物理世界里是“顺手”采到的，不需要用户举起手机。

技术上这是典型分层：wake word 常驻在毫瓦级功耗的 DSP 上，触发后才唤醒小模型做本地推理，复杂任务再上云。所谓量化，就是把模型权重从 16 位浮点压到 4 位整数，体积和算力需求降一个数量级，代价是少量精度损失。Ray-Ban Meta 眼镜的“看图提问”、会议徽章自动出纪要，都是这套架构的商业化版本。

## Meta 图什么：开源硬件的商业账本

觉得开源是做慈善的，可以醒醒了。复盘 Meta 的开源史：

- PyTorch 开源，换来了 AI 框架的事实标准；
- LLaMA 开放权重，用社区把“开放模型”的用户心智钉死；
- 这次轮到硬件，剧本没变：**底层免费，标准和生态收费**。

外设市场过去起不来的原因，不是单项技术不行，而是没人敢先统一接口——每家都想做自己的配件生态，结果谁都没生态。参考设计一开源，试错成本从“一个硬件团队 + 18 个月”降到“两个工程师 + 两周”，长尾开发者会替 Meta 把市场铺开。参照历史：Arduino 靠开放硬件协议催生了百亿美元级的开发者市场，RISC-V 用开放指令集撬动了芯片长尾。这些设备最后接谁家的“大脑”不好说，但 Meta AI 一定是默认候选人之一——Android 的旧剧本，换了道具重演而已。

## 动手路线：从原型到小批量的现实路径

想下场的开发者，现实路径大致五步：

1. **定交互**：先写一页纸——设备感知什么、什么时候开口、给谁用。一页纸写不清楚，就别急着画 PCB。
2. **选算力档位**：纯 MCU 方案（Cortex-M + NPU）跑 wake word 加命令词，芯片成本个位数美元；要跑 3B 级量化 LLM，就上能跑 Linux 的 SBC，代价是功耗和体积。
3. **搭 pipeline**：openWakeWord / whisper.cpp tiny / Qwen 或 Gemma 的量化版串起来，本地失败自动降级上云——这是底线设计，不是可选项。
4. **抠电量**：常驻监听靠 duty cycling 硬省，整机待机目标压进 10mW 以内，否则“随身”两个字就是空谈。
5. **小批量验证**：3D 打印外壳先拿手感，一百台以内拼板贴片；FCC/CE 认证周期以月计，别等量产前一个月才想起来。

参考账本：语音徽章类产品的 BOM 大约 $15–40，验证阶段真正贵的不是钱，是时间。

## 写在最后：三条冷思考，也是三条建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-03/ca797e092fbc268f.png)

1. **硬件没有 git revert**。软件出 bug，改一行热更；硬件出 bug，是一仓库库存加一批退货。先用最糙的原型验证交互假设，再谈打磨——方向错了，做工再好也是错。
2. **开源不等于免费**。固件可能是 Apache-2.0，硬件设计可能是 CERN-OHL，模型权重又另有条款，商用前逐条读，别让法务在出货前一周才进场。
3. **把隐私当产品功能，而不是合规负担**。常开的麦克风和摄像头意味着实打实的法律责任面，BOM 里给安全元件留出几毛钱预算，把“数据不出设备”写进说明书第一行——长期看这是护城河，不是成本。

模型的能力曲线终会趋于平缓，但人和物理世界的接口才刚刚开始重画。这一波能跑出来的，大概率不是堆料最狠的，而是最早想清楚“这个设备为什么值得存在”的人。
