最近一篇流传很广的 36kr 文章，标题挺情绪化：「看了招股书，我终于知道为什么 Anthropic 不在乎用户了」。把情绪剥掉，招股书其实是一份最诚实的企业说明书：钱从哪来、往哪花、未来押什么。读完你会发现，更准确的表述不是“不在乎用户”，而是“个人用户在它的生意结构里权重天然不高”。这篇我们用财务和商业逻辑，把这件事拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/31e32ecb17ef7d19.png)

## 收入结构：钱到底从哪来

先摆事实。综合公开披露与多家媒体报道：

- Anthropic 的收入大头来自 **API 与企业客户**——包括直接售卖 API，以及通过 AWS Bedrock、Google Cloud Vertex 这两朵云分发的模型调用，占比普遍估计在七八成以上；
- 个人订阅（Claude Pro/Max）占比小，大致只有一到两成；
- 增长最猛的单品是 **Claude Code** 这类开发者工具，据报年化收入已达数亿美元量级，靠的是把模型嵌进程序员的日常工作流；
- 年化收入（ARR）从年初约 10 亿美元量级，一路涨到下半年 50 亿美元上下。

对比一下镜像：OpenAI 靠 ChatGPT 消费端起家，官方口径的周活跃用户在 2025 年 10 月已达 8 亿。两家头部实验室，一个从消费端往企业端打，一个从企业端往消费端打，商业模式几乎是反着来的。

结论先给：Anthropic 本质是一家“模型即服务（MaaS）”公司，个人聊天产品更像是模型能力的展示橱窗，而不是主战场。

## B2B 与 B2C：两门完全不同的生意

为什么企业客户值钱、个人用户“不值钱”？四个机制：

1. **合同规模**：一笔企业年框从几十万美元到上千万美元，一个企业销售的产出可能顶上几万个免费用户；
2. **推理成本经济学**：每一次对话都要 GPU 算力，免费用户是纯成本中心。消费互联网“先烧钱换规模”的打法，在推理成本面前会失灵——用户越多，烧得越狠，而且烧的是最稀缺的算力；
3. **切换成本**：开发者一旦把 Claude API 写进生产代码、接进 Agent 工作流，迁移成本极高；而消费者换一个聊天 App 只要三秒；
4. **可预测性**：企业合同是可预测的经常性收入，消费端付费率波动大。对一家一级市场估值一度达 1830 亿美元、仍在大幅亏损的公司来说，前者才是给投资人讲故事的硬通货。

所以招股书里的资源配置——销售团队、企业功能（SSO、审计日志、管理后台）、模型迭代方向（代码、Agent、长上下文）——全都指向企业侧。这不是产品团队的审美问题，是收入结构决定的。

## 招股书里最沉重的数字：算力承诺

真正压秤的是成本端：

- 据报道，Anthropic 与 Google Cloud、AWS 签有**数百亿美元级别的长期算力采购承诺**；谷歌一侧涉及百万颗 TPU、吉瓦级数据中心容量，2026 年起陆续上线；
- 公司仍处于亏损阶段，年现金消耗以十亿美元计；
- **毛利率远低于传统 SaaS**：模型推理的毛利率据报在 50%-60% 附近，而传统软件公司普遍 70%-80% 以上——差额基本都烧在了 GPU 上。

这解释了很多被吐槽的产品行为：为什么 rate limit 收得紧、为什么免费额度吝啬、为什么不做图像生成这类“讨好型功能”。每一次调用都是真金白银的电和硅。一句工程师式的总结：**在推理成本面前，情怀按 token 计费。**

还有一层少有人提：亚马逊、谷歌既是重要股东，又是分发渠道，招股书里必然存在关联交易与客户集中度的风险提示。收入里有一部分，本质上来自“自己人的云”。

## “不在乎用户”，还是“优先级不同”？

客观说，Anthropic 不是不在乎用户，而是排序不同：

1. 第一优先：前沿模型能力 + 安全研究，这是它对投资人的核心叙事（公司 2021 年由前 OpenAI 安全团队核心成员出走创立，“安全”本身就是品牌护城河）；
2. 第二优先：企业级可靠性、合规、API 稳定性；
3. 第三优先：消费端体验打磨。

证据很直白：Claude 在编程与 Agent 基准上长期处于第一梯队，企业侧口碑扎实；但消费端功能确实克制。这不是傲慢，而是资本效率的最优解——招股书写给投资人看的从来不是“用户爱不爱我”，而是“每一美元收入要花多少算力”。

## 三条冷思考

1. **判断 AI 公司，先看收入结构，再看发布会**：收入结构决定产品路线图。B2B 为主的公司，个人用户的体验权重天然靠后，别拿消费产品的预期去要求它；
2. **把个人订阅当“工具租约”，别当“会员服务”**：它的定价、限额、功能取舍都跟着算力账本走。限额是涨是收，取决于供需与成本曲线，而不是你对它的感情；
3. **盯住“算力承诺 vs 收入”的缺口**：这是所有前沿模型公司头上的达摩克利斯之剑。缺口大小决定了未来是涨价、限流还是再融资——对开发者做技术选型、设计“多模型备份”策略，都有直接参考价值。
