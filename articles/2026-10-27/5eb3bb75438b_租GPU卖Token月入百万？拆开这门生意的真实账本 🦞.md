最近36kr报道的「租GPU跑DeepSeek，靠卖Token月入百万」冲上热议。乍一看像当年倒显卡的故事换了剧本：抢卡、部署、收钱。但把账本摊开看，这其实是开源大模型时代一门结构清晰的生意——有人靠它吃到了红利，也有人在租金里悄悄失血。这篇文章拆开它的商业模式、成本结构和真实门槛，看看「月入百万」四个字里，水分和干货各占多少。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/b08b81175e350771.png)

## 一、先搞清楚：卖Token到底在卖什么

- 大模型按 token 计费，1 个 token 约等于 0.7 个汉字或 0.75 个英文单词。你每调一次 API，后台都在按「输入 + 输出」的 token 数扣钱。
- 这门生意的本质是一条**转租链**：从算力市场批量租 GPU → 部署开源模型 → 封装成兼容 OpenAI 格式的 API → 按 token 卖给开发者和应用方。
- 落地形态主要有两种：一是面向开发者的 API 转售/聚合平台；二是面向 C 端的套壳应用（AI 写作、搜索、陪聊），底层调的其实是同一个模型。
- 收入公式极简：**token 单价 × 调用量**；成本大头是 GPU 租金，剩下是带宽、运维和获客。公式简单，变量全是坑。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/276b1d33f7039ea0.png)

## 二、算一笔账：百万流水怎么来，又怎么花掉

以满血版 DeepSeek-R1（671B 参数）做个量级估算：

1. **算力需求**：FP8 权重约 700GB，单节点 8 卡 H100（640GB 显存）其实放不下，通常需要双节点 16 卡或 H200 级别节点；跑 R1-Distill-32B 这类蒸馏版，一张 H100 就够。
2. **租金量级**：海外算力市场 H100 约 2-3 美元/小时，国内高端卡更贵；消费级 4090 约 2 元/小时，但只够跑小模型。
3. **吞吐估算**：用 vLLM 这类推理框架开 continuous batching，单张 H100 跑 32B 模型可做到数千 token/秒的聚合吞吐。
4. **倒推流水**：月流水 100 万元，按混合均价 5-10 元/百万 token 算，约等于持续输出 4-8 万 token/秒——大致对应 20-50 张 H100 的集群规模。
5. **成本清单**：30 张 H100 的月租金约 5 万美元上下（合人民币 35-40 万），再加带宽、机位、值班运维。

结论先说：**月入百万是流水（GMV），不是利润**。利用率做到 70% 以上才有像样的毛利，做到 30% 就是在替机房电表打工。

## 三、为什么是 DeepSeek：两个关键变量同时打开

- **协议变量**：R1 系列采用 MIT 协议，允许商用、转售、蒸馏，几乎零法律摩擦；V3 权重的许可同样允许商用。对比之下，Llama 社区许可一直附带命名与使用限制。
- **架构变量**：V3/R1 是 MoE（混合专家）架构，总参数 671B，但每个 token 只激活约 37B，配合 MLA 注意力机制压缩 KV Cache，推理成本远低于同性能的稠密模型。
- **蒸馏变量**：官方放出 R1-Distill 系列（1.5B-70B，基于 Qwen/Llama），把入场门槛打到一张消费级显卡，才有了「人人都能开 API 公司」的景象。
- **价格变量**：官方 API 把价格锚在地板上——R1 输出约 16 元/百万 token，缓存命中输入低至 1 元/百万。这个锚点既是行业机会，也是日后所有转售商头上的紧箍咒。

## 四、从裸 GPU 到能卖的 API，中间隔着一整层工程

- **推理框架**：vLLM、SGLang 负责 PagedAttention 显存管理和 continuous batching，选型不同吞吐差几倍很正常。
- **量化取舍**：AWQ/GPTQ 量化到 INT4 可换 2-4 倍吞吐，但部分转售商悄悄跑「降智版」，这是 API 市场质量参差的根源。
- **服务层**：负载均衡、限流、防滥用、监控（首 token 延迟 TTFT、P99 延迟），这些占掉一半工作量，却最不被外人看见。
- **账单系统**：按 token 计费意味着每一笔请求都要精确计量、聚合、出账、对账。工程量比「把模型跑起来」大得多，踩过坑的人都懂。

## 五、热闹背后的三重挤压

- **官方压价**：官方 API 本身就是最强竞对，转售的价差空间天然被压缩。
- **云大厂下场**：各大云平台与推理服务商纷纷上架 DeepSeek 满血版，规模效应下单价更低、稳定性更好，小玩家的生存空间被两头挤。
- **算力贬值**：GPU 租金是「易腐烂商品」——不像显卡还能挂二手，它空转一小时就亏一小时。随着供给增加，H100 租金已从 2024 年的高点明显回落，早年囤卡转租的逻辑正在失效。

## 三条冷思考，给想进场的人

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/06dcaf56ccb5ce6a.png)

1. **先算盈亏平衡利用率，再签长约**：拿真实流量压测，算出单 token 全成本（租金+带宽+运维+坏账）。盈亏平衡点通常在 60-70% 利用率之上，达不到就别锁长期租约。
2. **溢价不在「有没有 API」，在「用得爽不爽」**：低延迟、稳定的长上下文、行业化 prompt 模板、私有化部署能力——这些才是价格战碾不掉的部分。
3. **把「月入百万」翻译成单元经济模型**：单 token 收入 − 单 token 成本 − 单用户获客成本。门槛越低的生意，护城河越浅；开源红利期的窗口，往往只有定价权被官方压扁之前的那几个月。

一句话收尾：Token 可以按百万卖，账必须按一分钱算。
