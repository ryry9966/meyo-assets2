前两天，36kr 的热搜把一句话顶上了风口：Anthropic 科学家宣布，全球博士生的职业生涯“一夜清零”。评论区哀鸿遍野，不少准博士生连夜打开了简历模板。RY哥的反应是先把原话、技术背景和传播链路扒了一遍——先给结论：**技术信号是真的，“一夜清零”是标题加工的产物**。这篇文章把事情拆开讲清楚：他到底说了什么，AI 为什么突然会“做科研”，博士这项“资产”里哪些在贬值、哪些在升值，以及个体该怎么应对。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/6e120d576cce46e3.png)

## 一、先还原现场：原话和标题之间隔了多远

- **原始语境**：Anthropic 的研究者在访谈中的核心意思是——前沿模型已能胜任博士生的多数日常研究工作（文献综述、代码实现、实验分析），现在入学的人毕业时面对的世界会完全不同，读博的性价比需要重估。Dario Amodei 更早前也预测过，AI 可能把生物学几十年的进展压缩到几年内。
- **传播链路**：访谈原话 →“读博价值遭质疑” →“全球博士生职业生涯一夜清零”。信息每转一手，细节丢失，情绪浓度上升。
- **严格定义**：“清零”指的是入门级科研劳动（entry-level research labor）的市场价值快速归零，而不是“博士”这个身份从地球上消失。
- **历史参照**：汽车普及时报纸预言“马车夫终结”，高级语言普及前有人断言“程序员将消失”。预言的“职业死亡”几乎都错了，但“具体任务被机器接管”几乎都对了。

## 二、技术上发生了什么：AI 为什么突然会“干博士的活”

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/3e8845590142d6e2.png)

博士前几年的工作，本质是一组**可分解、可验证、反馈闭环短**的任务——恰好落在当前 AI 能力曲线最陡的区域。

- **长链推理（reasoning）**：o1、Claude 这类 reasoning 模型把思考过程显式展开，数学推导、证明补全、实验设计的准确率大幅提升。在 GPQA Diamond 这个由博士级科学题组成的 benchmark 上，前沿模型从 2023 年的 30%~40% 涨到如今的 80% 以上，已超过多数领域的人类博士。
- **Agentic workflow**：模型不再只“聊天”，而是能调用工具——检索文献、写代码并真实执行、跑仿真、批量处理数据。一个 agent 跑一个下午，能完成过去硕士生两周的论文复现工作。
- **超长上下文**：百万 token 级 context window 意味着一次“读完”几百篇论文的正文和附录，再交叉比对、找矛盾、搭综述框架。
- **量化视角**：METR 的研究显示，AI 能独立完成的任务时长（50% 成功率的任务长度）大约每 7 个月翻一倍。2024 年还是 1 小时级的任务，两年后可能覆盖“读文献 → 写代码 → 跑实验 → 出图”的完整闭环。

一句话总结机制：科研劳动里最容易被自动化的，是“目标明确 + 结果可验证 + 反馈快”的部分，LLM 加工具调用恰好啃得动这三样。

## 三、博士这项“资产”的资产负债表

**贬值科目（正在被接管的任务）**：

1. 文献综述与情报整理——已接近即时完成；
2. 代码实现与 debug——SWE-bench Verified 上模型解决真实 GitHub issue 的比例从个位数涨到 70% 以上，工程类博士的“初级生产力”首当其冲；
3. 格式化写作：论文初稿、基金申请模板、会议海报；
4. 数据清洗、跑 baseline、调参这类体力活。

**升值科目（反而更稀缺的能力）**：

1. **问题定义能力（taste）**：判断什么问题值得做、什么结果可信。生成答案的成本趋近于零，提出正确问题的成本没降——好问题的价值被急剧放大。
2. **幻觉鉴别与实验验证**：模型会一本正经地编造引用，生成能力越强，越需要强的“审稿人”。
3. **物理世界接口**：湿实验、仪器、样品、长周期纵向数据——AI 只能加速 in silico 部分，搬不动离心机。
4. **学术网络与信誉**：合作、署名、评审，是社会资本，不是模型参数。

类比：Excel 没有消灭会计，它消灭的是“手算总账”，催生了审计与咨询。技术替代的是 task，不是 title。

## 四、三个容易被忽略的变量

1. **说话的人卖什么**。Anthropic 是模型公司，“AI 无所不能”本身就是最高效的营销叙事。实验室的预测值得听，但要按 track record 打折——AGI 时间表这类预测，历史上普遍偏乐观。
2. **“科研”不等于“产出文本”**。理论、算法、综述类工作确实被大幅加速；但实验科学的瓶颈常在设备、样品、经费和审稿周期，不在文字生成速度。“清零”叙事最容易忽略这层物理瓶颈。
3. **时标错位**。模型能力半年一迭代，而博士培养、tenure、基金周期以年计。用 6 个月的能力曲线外推 5 年后的职业图景，等于把指数曲线画成直线——这种外推在乐观和悲观两个方向上都会犯错。

## 五、给在读和准博士生的三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/cdb164827289a451.png)

1. **角色上移**：从“第一作者劳动力”转向“通讯作者思维”。把文献综述、代码复现、baseline 实验尽量交给 agent，省出的时间全部投入问题定义、结果批判和跨组协作。自检标准很简单：日程表上“AI 也能做”的条目占比，应该每周都在下降。
2. **构筑物理护城河**：优先选有独家数据、真实实验、现场闭环的课题。纯理论推导、纯 benchmark 刷分这类“纯文本即可完成”的方向，红海会最先红透。
3. **把人机工作流当必修课**：现在就搭好自己的 agent 流水线——检索、复现、写作三条线。毕业时，你和完全不用 AI 的同行之间，大概率会拉开一个数量级的产出差距。

**最后三条冷思考**：

- “一夜清零”是传播学现象；技术事实是入门级科研劳动的边际成本正在趋近于零，稀缺性正向上游（提出问题）和下游（验证结果）两端迁移。
- 判断一个职业的风险，永远看 task，不要看 title。
- 对个体而言，恐慌是所有策略里性价比最低的那个；重构自己的比较优势，才是唯一可执行的选项。
