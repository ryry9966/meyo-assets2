DeepSeek R1 开源之后，圈子里冒出一批"倒腾算力"的玩家：从算力平台按小时租 GPU，把满血版模型部署起来，对外卖 API、卖 Token，有人把月流水做到了百万级。36kr 把这拨人称作 AI 时代的"倒爷"。这事听起来玄乎，拆开看其实是一道很朴素的算术题：租金、吞吐、售价、窗口期。今天把账本摊开，算一算钱从哪来、门槛在哪、什么时候会失效。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/de85dc1d23dd0e34.png)

## 先算账：Token 生意的底层经济学

- Token 是大模型计费的最小单位，1 个汉字大约对应 0.6~1.5 个 token，API 按每百万 token 收费。
- 成本端：一张 H800 的市价租金大致在 5~10 元/卡时，一台 8 卡机一个月光租金就是 3~7 万元；换 4090 便宜得多，但 24GB 显存跑不动 671B 参数的满血 R1，只能多卡拼显存加量化，或者干脆跑 R1-Distill 蒸馏版小模型。
- 收入端：DeepSeek 官方 API 定价长期贴着成本走，输出约 8~16 元/百万 token，错峰时段还打折；第三方转售普遍溢价 2~5 倍。溢价能成立，靠的是官方开源了 MIT 许可证的权重——商用合法，这是"倒爷"存在的前提。
- 一台 8 卡机满负荷运转，一个月大约产出百亿量级 token，按混合售价折算流水也就十万上下，扣掉租金和运维，毛利薄如刀片。所以月流水百万的玩家，机器一定是一排一排地租，而且绝不止做倒卖这一件事。

结论先行：这不是躺着数钱，而是重资产、高周转、利润被两头挤压的生意，套利空间来自一个特殊阶段的供需错配。

## 钱从哪来：三条真实路径

1. **套利窗口**：R1 爆火的那几周，官方服务被"挤兑"，限流、排队、宕机频发，开发者和企业愿意为"稳定可用"付溢价。这赚的是时间差，窗口以月计。
2. **产品包装**：把裸模型包成写作助手、合同审查、行业客服机器人，按订阅或按次收费。同样的 token，包成产品后单价翻几倍，客户粘性也完全不是一个量级。
3. **卖铲子**：私有化部署一条龙——一体机、微调、内网接入、运维托管，企业客单价几万到几十万。报道里月入百万的那批人，基本都是三条腿走路，纯倒卖 token 只占其中一块。

## 技术门槛：不是插上电就能数钱

- **推理框架**：vLLM、SGLang 这类框架决定吞吐上限。KV cache 管理、continuous batching 做得好与不好，同样的卡吞吐能差 3~5 倍，直接决定毛利是正是负。
- **量化与部署**：FP8、INT4 量化用一点精度换显存和速度；参数怎么切、显存怎么分、多机怎么通信，全是踩坑换来的经验。
- **并发与稳定性**：并发一上来就 OOM、长尾延迟、显存碎片，都是日常。客户不管你背后多难，接口报错两次，下个月就换供应商。
- 一句话总结：DeepSeek 开源的是权重，不是服务。"跑起来"和"跑得又快又稳又便宜"之间，隔着半个工程团队。

## 天花板与风险：套利生意的时间常数

- **官方扩容降价**：官方 API 价格常年贴近成本线，一旦算力供给恢复，倒卖溢价立刻被压扁，窗口说关就关。
- **云厂商跟进**：各大云平台先后上线 R1 满血版托管服务，价格战开打，第三方没有任何品牌和生态优势。
- **合规成本**：面向公众提供生成式 AI 服务，涉及备案、内容安全、数据保护等硬性要求，是绕不开的固定投入。
- **客户忠诚度为零**：模型能力同质化，客户只认两件事——更便宜、更稳定。你有的别人也有，护城河约等于零。

## 冷思考：入场前先想清楚这三件事

1. **别把"窗口期"当"商业模式"**。倒卖 token 赚的是供需错配的钱，入场前先回答一个问题：官方扩容之后，客户凭什么还留在我这里？答不上来，就别重仓。
2. **往价值链的上下游走**。上游做部署、微调、运维服务，下游做垂直行业产品，都比裸卖 token 护城河深，也比拼价格死磕活得久。
3. **用单位经济学做决策**。先算清"每卡时产出多少 token、能卖多少钱、毛利剩多少"，再决定租几张卡。账算不平的故事，最后都是替房东和显卡厂商打工。

淘金热里活得最好的，往往不是挖金子的人，而是把水、铲子和牛仔裤卖出溢价的人。Token 这门生意，道理一模一样。
