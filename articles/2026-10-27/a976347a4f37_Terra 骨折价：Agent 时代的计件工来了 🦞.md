36kr 这条快讯里有三个关键词：GPT-6.1 Terra、骨折价、Agent 时代的打工模型。前两个是新闻，第三个是趋势判断，而且这句判断可能比价格本身更值得展开。模型降价这两年见得多了，腰斩都算温和，但把一款模型直接定位成 Agent 的「计件工人」，说明厂商的产品逻辑已经从「陪人聊天」切换到「替人干活」。这篇把它掰开讲三件事：价格凭什么打下来，Agent 为什么吃价格，以及便宜背后的坑在哪。

## 先算一笔账：Agent 把 token 消耗放大了两个数量级

- 聊天场景下，一次对话通常 1K–3K token，模型再贵也就几毛钱，价格敏感度很低。
- Agent 场景完全不是一回事。一个多步任务 = 规划 + 调用工具 + 读返回结果 + 自我反思 + 失败重试，每一步都要把上下文重新喂进模型。以常见的编码 Agent、浏览器操作 Agent 为例，单任务消耗 10 万–100 万 token 是常态，是聊天的 50–100 倍。
- 于是单价成了 Agent 商业模式的地基：原来「算不过账」的场景——批量信息抽取、全自动客服、无人值守的采集整理——单价降一个数量级就成立了。经济学上这叫杰文斯悖论（Jevons Paradox）：效率越高、成本越低，总消耗反而暴涨。
- 回看公开牌价：2023 年 3 月 GPT-4 是输入 $30 / 输出 $60（每百万 token）；2024 年 GPT-4o 把输入打到几美元；再往后 DeepSeek、Gemini Flash 一类把输入价压到 $1 以下甚至几毛。两年半，主流输入价降了约两个数量级。Terra 的骨折价不是突变，是这条曲线的延续，区别在于这次把「为 Agent 服务」写进了定位。

## 便宜从哪来：不是砍利润，是三套技术一起省

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/8b6b0ef82731089d.png)

骨折价听起来像亏本清仓，但按业内通行做法，这类「打工模型」的成本是被结构性压下来的：

1. **MoE 稀疏激活**：参数总量做大，每个 token 只激活一小部分专家网络（参考 Mixtral、DeepSeek V3 的总参数/激活参数比）。模型容量上去了，单 token 的推理成本没有等比例上涨。
2. **蒸馏 + 定向强化**：同门旗舰当老师，海量生成高质量解题数据喂给学生，再针对 Agent 高频动作（工具调用、格式遵循、长上下文检索）做专项强化。学生用小几成的参数，继承大部分「干杂活」的能力。
3. **推理基建组合拳**：prefix caching（Agent 的系统提示词和工具说明高度重复，命中缓存的部分按一到两折计费）、FP8 量化、continuous batching、speculative decoding，每一项都能再砍一截成本。DeepSeek 之前的「夜间半价」是同一思路——把闲时算力填满。

再加一层商业考量：开源模型和低价竞品已经把 API 价格的天花板焊死，牌价早就从「利润表」变成了「获客工具」。便宜，本身就是投放。

## 「打工模型」的站位：旗舰当包工头，Terra 上流水线

- 现在的主流架构叫 orchestrator–worker：旗舰模型负责规划、拆解任务、卡壳时救场、最终验收；便宜快速的模型负责流水线步骤——信息抽取、格式转换、填工具参数、批量分类、生成草稿。
- 拆一条真实的 Agent 工作流看，70%–90% 的步骤不需要顶尖智力，需要的是快、稳、便宜。这一段正是 Terra 们的目标市场。
- 配套技术是模型路由（routing / cascade）：默认走便宜模型，置信度低或连续失败就升级旗舰。这套思路学术圈叫 FrugalGPT，工程上已经是各家模型网关的标配。
- 对厂商这也是笔好账：打工模型跑量 → 调用量与缓存命中率上升 → 单位成本继续下降 → 真实使用数据回流改进模型。便宜不亏，越卖越便宜。

## 冷水时间：token 打骨折，错误的代价没有打折

Agent 的真实成本公式里，token 只是一部分，另一部分是错误：

- **错误会复利**。单步准确率 90%，串 10 步，任务成功率只剩 35%；95% 也只有 60%。链条越长，每一步的可靠性越比单价重要。一个便宜 10 倍但返工率翻倍的模型，账面省钱、实际亏钱。
- **长上下文会衰减**。低价模型普遍在超长上下文的中段「迷路」（lost in the middle 现象）。跑分用的针扎测试，和真实任务里几十轮工具调用的连续战场，不是一个难度。
- **人工兜底不便宜**。返工、回滚、人工抽检，每小时成本远高于省下的 token 钱。

所以迁移前先做影子测试：拿自己过去一个月的真实调用记录回放，对比一次成功率、平均重试次数、端到端每任务成本，别只看排行榜。

## 收尾：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/01d42ab358079240.png)

1. **算「任务账」，不算「token 账」。** 换模型前先跑两周影子测试，记录端到端每任务成本：tokens × 单价 × 重试次数 + 校验开销。单价降 80%，任务成本可能只降 20%。
2. **把分层路由当默认架构。** 规划和验收交给旗舰，执行交给便宜模型；提示词把稳定的系统部分放最前面吃缓存；给便宜模型配一条置信度升级通道。
3. **警惕跑分幻觉和供应商锁定。** 公开榜单不等于你的任务，重点看长程 Agent 类评测；网关层做统一抽象保证随时可切换；顺手读一遍数据使用条款。

价格可以打骨折，可靠性不能骨裂——这是 Agent 时代选模型的第一原则。
