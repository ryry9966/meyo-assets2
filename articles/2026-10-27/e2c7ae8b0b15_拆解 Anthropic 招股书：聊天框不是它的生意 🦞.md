最近 36kr 一篇《看了招股书，我终于知道为什么 Anthropic 不在乎用户了》刷屏了。"不在乎用户"这五个字情绪张力拉满，但把招股书当情绪读物，就浪费了这份文件的价值。招股书是一家公司最诚实的体检报告：它不表达态度，只暴露结构。看完结构你会发现，结论不是"傲慢"，而是一句更冷的话——在这家公司的商业飞轮里，C 端聊天框本来就不是主传动轴。下面拆给你看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/0ce548d5566455cb.png)

## 一、招股书怎么读：收入结构是公司的 X 光片

看招股书别读故事，先盯四组数字：

- **收入构成**：API 与企业服务占大头，个人订阅（Claude Pro/Max）只占小头。据公开披露，Anthropic 的年化收入一年内从十几亿美元冲到几十亿美元量级，增量主要来自企业 API 和编码产品。
- **客户集中度**：头部几个大客户贡献了可观的收入比例。这是典型的 to B 特征——几十个年付百万美元级的合同，顶得上上百万个订阅用户。
- **成本承诺**：为锁定 GPU 算力，签下百亿美元量级的采购承诺，亏损同步放大。钱押在哪，战略就在哪：造更强的模型，卖给付得起钱的客户。
- **Risk Factors（风险披露）**：客户集中、算力依赖、云厂商"既是供应商又是对手"——这些条款比任何创始人专访都诚实。

把四组数字叠在一起，X 光片就清晰了：它的收入曲线由企业客户驱动，不是由 DAU 驱动。在它的损益表里，你的免费聊天额度是成本项，不是收入项。

## 二、主战场在 API 和 Agent，不在聊天框

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/f9650d2b8a30d7ac.png)

给 Anthropic 的产品重心排个序：Claude API、Claude Code、MCP（Model Context Protocol）、企业级 Agent。据公开披露，Claude Code 上线一年左右，年化收入就摸到了十亿美元量级，增速远超订阅业务。为什么押注编程？三个硬理由：

1. **可验证**：代码能跑单元测试，对错有客观标准。企业为"确定性强"的产出付钱，天经地义。
2. **高消耗**：一个编码 Agent 修一个 bug，要经历写码、执行、报错、自修的循环，token 消耗可能是普通聊天的几十倍。按量计费模式下，烧的是算力，进的是收入。
3. **高粘性**：工作流一旦长在 Claude Code 和 MCP 协议上，切换成本极高。B 端粘性靠基础设施，不靠 UI 好看。

顺带说一句，MCP 这类开源协议是更隐蔽的护城河：协议卡住的是生态入口，生态入口卡住的是下一代开发者。对比一下也更有意思——OpenAI 走"先用 ChatGPT 的 C 端流量立品牌，再向上打企业"；Anthropic 反着来，先把铲子卖给挖金子的人。淘金热里卖铲子的，从来不需要陪每个路人聊天。

## 三、"不理用户"不是傲慢，是单位经济模型

- **毛利结构决定取舍**：训练成本是一次性沉没的前置投入，推理成本却随用量线性上涨。免费聊天 = 高推理成本 + 低付费意愿，在重训练投入公司的账本上，这是负毛利流量；API 和 Agent 则是用多少付多少，收入与算力消耗同步增长。
- **数据飞轮更偏好 B 端**：开发者用 API 跑的是真实任务——写代码、调工具、长链条 Agent 轨迹。这些数据对模型迭代的信号价值，远高于闲聊。
- **安全叙事是 B 端资产**：Anthropic 以安全研究起家（Responsible Scaling Policy、可解释性研究），而企业采购最看重合规、可控、可审计。人设和客户群是咬合的。

所以"不在乎用户"是误读：它非常在乎付钱的用户。C 端额度紧、消费级功能迭代慢，是因为 C 端在收入公式里权重小。产品路线跟着收入走，是商业常识，不是态度问题。

## 四、可以预期的三个变化

- 免费与低价档继续"克制"：推理成本摆在那里，普惠额度大概率只紧不松；
- 资源向重度用户倾斜：Pro/Max 档的性价比会明显好于免费档，写代码、跑 Agent 的重度用户才是它想留住的人；
- 定价越来越像 SaaS：按席位、按用量、按档位分层，而不是消费互联网那套"免费拉新、广告变现"。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-27/65d7b4de75a95a5d.png)

1. **看 AI 公司先看谁在买单**：to B 为主的公司，参数、功能、迭代节奏都会向开发者倾斜。你用得爽不爽，取决于你离它的收入近不近。
2. **别把体验归因于"傲慢"，归因于商业模式**：免费用户是生态位，不是客户。想清楚自己在对方账本上是哪一行，预期就摆正了。
3. **把模型当供应商组合管理**：关键工作流别锁死在单一厂商（vendor lock-in），留好迁移路径；同时学一点 API/Agent 思维——既然这些公司只为"高杠杆用法"优化，那就把自己变成高杠杆用户。

一家公司的招股书永远不会写"我们不在乎谁"，但它会把"我们在乎谁"，端端正正写在收入构成的第一行。
