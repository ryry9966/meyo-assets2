NeurIPS'26 的一篇论文最近在时间线上刷屏，核心主张一句话就能说完：注意力其实也是 FFN。听起来像抬杠，实际上它把 1991 年的“快权重”老思想，和 Mamba、TTT、Titans 这批新模型缝进同一个坐标系，顺手给五年来的“高效注意力”军备竞赛提供了一把统一的尺子。这篇文章把这条线捋清楚：它从哪来、说了什么、为什么值得认真对待。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-12/68b50e37ebdb31f5.png)

## 一、先补课：慢权重 vs 快权重

- 我们平时说的模型参数，都是 **slow weights**：训练时靠梯度下降慢慢烧进去，推理阶段只读不写。
- **快权重（fast weights）** 则相反：推理时根据当前输入现场生成、现场更新的一组“临时参数”。一行外积 `W ← W + v·kᵀ` 就能写入一条记忆，`y = Wq` 完成读取。
- 这不是新概念。Schmidhuber 1991 年就提出 Fast Weight Programmers；Ba 和 Hinton 2016 年的 NIPS 论文又添了一把火。
- 一个粗暴但好用的类比：训练好的权重像硬盘，只读；注意力里的 KV 状态更像内存——读写都发生在运行时。人读完一句话能立刻复述，靠的也不是修改突触，而是短时可塑性。

## 二、线性注意力：一台会现场编程的 FFN

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-12/3b2b6f6ef71ab0ac.png)

- FFN 的本质早有定论：Geva 2021 证明它是 key-value 记忆，`y = Wx`，其中 W 是训练完就焊死的**静态记忆**，存的是从语料里磨出来的语义知识。
- 注意力换个角度写：`(Φ(K)ᵀV)ᵀ Φ(q) = W_t φ(q)`。W_t 是由上下文 token 逐个外积累加出来的矩阵——**权重不是训练来的，是上下文现写的**。这就是“注意力也是 FFN”的字面含义：一台权重由输入现场编程的 FFN。
- 于是 Transformer 的每一层都在做混合读取：FFN 贡献长期语义记忆，注意力贡献上下文里的情景记忆，二者是同一件事（KV 记忆）的两个时间尺度。
- 代价差异也一目了然：softmax 注意力读写都要扫全序列，O(n²)；线性注意力把它折叠成一个 d×d 矩阵状态的 RNN，O(n)。Katharopoulos 2020 的《Transformers are RNNs》是这条路的转折点。

## 三、从“只加不减”到 Delta Rule：学会擦除的记忆

- 朴素外积累加有个致命爱好：只收藏，不删档。状态是全部历史 rank-1 项之和，旧值挤不掉新值，检索干扰随长度恶化，容量还被头维度卡死。
- Delta rule（Schlag 等 2021）给出解法：`S_t = S_{t-1}(I − β k_t k_tᵀ) + β v_t k_tᵀ`——先按相似度擦旧值，再写入新值，本质是 Widrow-Hoff 的一步梯度。合成检索任务上立刻拉开差距。
- 更激进的路线把“更新”升级成真正的学习：TTT（2024）把隐状态当成一个小 MLP，测试时跑几步梯度下降；Titans（2024）用“惊讶度”加动量决定写多深。
- 工程上的关键是可并行性：WY/Householder 分解让 delta rule 能 chunk-parallel 训练（NeurIPS 2024），Gated DeltaNet 再加门控遗忘，并与 Mamba-2 的 SSD 框架对偶打通。RWKV、Gated Linear Attention 也都挂在这条谱系上。

## 四、这套视角真正值钱的地方

- 过去五年，sparse attention、kernel attention、low-rank、SSM 各说各话，跑分互有胜负。快权重坐标系把设计空间压成四个旋钮：**写入方式**（累加 / 覆盖 / 梯度下降）、**遗忘机制**（decay / gate）、**读取方式**（线性 / softmax）、**状态大小**（d²，与序列长度解耦）。
- 它能解释失败模式：线性注意力在 copy、recall 任务上拉胯，因为它只会累加不会覆盖；softmax 注意力难上超长序列，因为读取端非线性没法折叠成 RNN。
- 它还顺手算了一笔参数账：标准 Transformer block 里 FFN 约占 2/3 的参数（8d² 对注意力 4d²）。既然注意力也是记忆层，“记忆放静态 FFN 还是动态状态、各放多少”就从祖传配方变成了可优化的架构预算。

## 五、冷思考与三条实用建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-12/341253337537e5ae.png)

1. **评估别只看 perplexity。** PPL 会把“背得快”记成“记得好”，长程检索（needle-in-a-haystack、电话簿召回）和训练吞吐、显存占用要放在一起看。
2. **选型按场景切。** 8K 以内的上下文，FlashAttention 仍是性价比之王，别折腾；长文档、代码库、agent 长会话这类 state-bound 场景，值得试 DeltaNet / Gated 系，或“每 N 层插一层全注意力”的混合架构。
3. **按谱系读论文。** Katharopoulos 2020 → Schlag 2021 → DeltaNet 并行化 → Mamba-2 SSD → TTT / Titans，一条线读下来，比单篇追热点省一半时间。

最后留一句冷思考：统一框架是地图，不是领土。“注意力 = 快权重 FFN”提供的是设计直觉，而容量上限、状态放 SRAM 还是 HBM 这类硬件约束，才是决定谁能 scale 的硬门槛。
