36kr 最近写了个很典型的话题：面向中小学生的 AI 培训营，标价 13800 元，家长报名时几乎没有还价——在他们的参照系里，这门课不是“商品”，而是“保险”。AI 很重要、孩子要学，这两句话本身没毛病；问题在于，13800 元里到底有多少是知识，多少是为焦虑支付的溢价。今天按工程师的习惯，把这门生意拆开，看看成分表。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/5ce309bbe1a9c63e.png)

## 一门好生意：把“时代风险”翻译成课程表

- **产品形态**：AI 启蒙营、AIGC 创作营、Agent 项目营，课时 20~60 节，价格从几千到上万。目标客群画像非常清晰：一二线城市、教育投入意愿强、自己不从事技术工作的家长。
- **话术三板斧**：制造紧迫感（“AI 窗口期只有三五年”）、社会证明（“某名校孩子已经学完了”）、责任转移（“现在不学，将来孩子怪家长”）。
- **定价为什么敢这么高**：焦虑是非标品，没有比价锚点。奥数再贵，还有竞赛名次和历年真题可参照；AI 课没有统一验收标准，价值全靠叙事支撑，天花板自然被抬得很高。

一句工程师式的观察：焦虑在这门生意里不是 bug，而是核心 feature。

## 焦虑的生成机制：三根杠杆同时发力

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/f77cc5d128a45c24.png)

1. **迭代速度带来失控感。** 2022 年底 ChatGPT 上线，2023 年多模态普及，2024 年视频生成与 Agent 崛起，几乎一年一次范式切换。成年人自己都追不动，更没底气辅导孩子，“外包给专业机构”的冲动由此产生。
2. **信息差导致验证失效。** 多数家长不写代码，分不清课程里的“Agent 开发”到底是真工程，还是调 API 套了个壳。信息经济学里管这叫柠檬市场：当买家无法评估质量时，定价权就交给了营销强度。
3. **军备竞赛的惯性平移。** 奥数退潮后少儿编程接棒，编程之后再补位 AI。2017 年 AlphaGo 战胜柯洁那一年，少儿编程赛道融资额翻了数倍——家长买的从来不是某一门课，而是“不落后”这个心理位置。

三根杠杆叠加，13800 元就不再是一个价格，而是一个“解脱报价”。

## 13800 元的成分表：知识到底占多少

- **拆内容**：主流课程三件套——prompt 技巧、AIGC 工具操作、跟做一个小项目。前两样，大模型厂商的官方文档和公开课基本免费覆盖；最后一样，让 AI 自己生成代码再逐步调试，学习效率未必更低。
- **一个容易被忽略的技术事实**：prompt engineering 正在快速贬值。早期模型需要精心设计的复杂指令，如今自然语言直说即可；下一代 Agent 会自己拆解任务。“教孩子写咒语”这门手艺，保质期存疑。
- **看成本结构**：这类课程的大头支出是投流获客，而不是教研。你付的钱里，为广告买单的比例，很可能高于为内容买单的比例。
- **算一笔 token 账**：一个孩子一年的 API 使用费，大概率不到课程价格的零头。买课时充值的主要不是 token，是信心。

所以准确地说，13800 元买的是“确定性幻觉”，外加一份“我已尽力”的心理安慰。

## 历史视角：每轮技术浪潮都有焦虑周期

- **2010 年代初**：3G 与移动互联网爆发，App 开发培训班学费上万，主打“三个月转行拿高薪”。
- **2016~2019 年**：少儿编程资本热潮，Scratch 积木被包装成“未来刚需”。
- **2021 年前后**：元宇宙、区块链短训班集中出现，如今大多已查无此人。

共同剧本高度一致：概念爆发 → 培训潮 → 供给过剩 → 退潮清算。复盘每轮周期会发现一个规律：真正吃到红利的是先动手做事的人，而不是先交学费的人。技术本身从不割韭菜，割韭菜的永远是“别人都在学”这五个字。

## 写在最后：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/e469571007f2d7cf.png)

1. **分清“用工具”和“造工具”。** 孩子机械地调用十次 API，不如完整做出一个自己真正想要的小东西——比如给家里的绿萝做一个浇水提醒。好奇心驱动的项目才是计算思维的核心，而计算思维比任何单一工具都保值。
2. **用“可验证性”过滤课程。** 敢给完整大纲、允许试听、白纸黑字写明退费条款的机构，可信度天然高一档；只讲“窗口期”叙事、靠站台背书撑场面的，建议直接过滤。
3. **免费资源先吃透，再谈付费。** 大厂开发者文档、公开课平台的基础课程、开源社区的实战项目，质量普遍高于多数高价短训。把 13800 元换成一台顺手的电脑、一年时间和一个真实项目，性价比大概率完胜。

最后留一句冷思考：技术红利的分配从不遵循“焦虑多的人拿得多”，只遵循“动手早、想得清的人拿得多”。家长真正该花力气的地方，不是替孩子抢一个座位，而是帮他们保住提问和验证的能力——这两样，AI 目前替不了。
