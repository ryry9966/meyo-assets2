36kr 的热搜把三件事压成了一句话：Codex 200 美元档的额度被砍到大约一半，过渡期截止在即，社群里出现“最后一天赶紧蹬”的挤兑式刷量；同一时间，ChatGPT 的入口迎来一次大改版。看起来是两条产品新闻，其实是同一个信号的两个侧面——AI 平台正在结束“补贴换增长”的窗口期，开始认真算单位经济模型（unit economics）的账。下面把这件事拆开讲清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/50ee6caab020b9b9.png)

## 一、事件复盘：砍了什么，改了什么

- **Codex 是什么**：OpenAI 的 agentic coding 产品线，CLI、云端并行 agent、IDE 插件一套组合拳。订阅分 Plus（20 美元/月）和 Pro（200 美元/月）两档，核心差异就在使用配额。
- **砍了什么**：Pro 档的 Codex 使用额度大约减半，并设过渡期，截止前仍按旧额度执行。于是出现经典一幕：重度用户把能并行开的任务全部开满，把旧额度“用满再下车”。
- **改了什么**：从报道和内测截图看，ChatGPT 首页正从单一聊天框往“工作台”方向走——固定会话、推荐任务、agent 类入口被前置。一句话：它不只想当你聊天对象，还想当你每天打开的第一个工作面板。
- **一个提醒**：具体额度与条款以官方邮件和设置页原文为准，社群截图常有情绪放大。

## 二、为什么非砍不可：agent 是烧 token 的大户

把机制掰开看：

1. **传统聊天**：一问一答，一个会话几万 token 封顶，成本可控。
2. **agentic coding**：一个任务 = 规划 + 几十上百轮工具调用（读文件、检索、跑测试、改代码、再跑测试）。关键在于，每一轮都要把累积的上下文重新喂给模型——上下文越滚越大，成本呈超线性上涨。
3. **粗算一笔账**：旗舰级模型推理，输入按每百万 token 几美元计；一个中等复杂度的重构任务跑下来，累积输入输出轻松到百万 token 量级，单任务几美元起步。重度用户一天并行几十个任务，再叠加“把 Codex 当通用 LLM 用”的薅法，月成本超过订阅费并不奇怪。
4. **结构性错配**：订阅收入是固定的，推理成本却按量线性走。“自助餐”模式遇到真能吃的客人，只能改菜单。Altman 在 2025 年初就公开承认过，200 美元的 Pro 档一度是亏损的——当时敞口可控；当 agentic 用法普及、重度用户占比上升，敞口就变成了窟窿。

## 三、不是孤例：订阅制的“健身房悖论”

- **健身房模式的前提不成立**：健身房赌大多数人办卡不来，用不来的补贴常来的。但 LLM 推理有真实的边际成本，每跑一次都烧 GPU，不存在“反正机器闲着”的空闲产能。传统软件边际成本趋近于零，订阅制天然适配；大模型服务天生不适配。
- **剧本反复上演**：GitHub Copilot 早年就被曝重度用户成本倒挂；Cursor 在 2025 年年中把“不限量”改成按量计费，换来差评海啸；Claude Code 同年也引入了周限额。Codex 这波，只是同一部剧的又一集。
- **规律总结**：AI 编程工具的产品周期是——补贴获客 → 重度用户挤兑 → 限额/涨价 → 转向按量计费。
- **换个视角**：与其说收割，不如说是迟到的成本修正。补贴窗口本质是融资环境下的一次性资源，窗口关闭是行业信号，不是某家公司的道德问题。

## 四、入口大改是另一只靴子：从聊天框到工作台

- **产品逻辑要跟计费逻辑配套**：当计费从“包月随便用”走向“精细配额”，产品形态也得跟着变。聊天框是“无限感”的隐喻，工作台是“明确工作单元”的隐喻——任务、项目、agent 入口前置，既方便计量，也方便对高级工作流单独定价。
- **入口即分发权**：谁占据用户打开的第一个屏幕，谁就掌握流量分配。把 agent 入口前置，是在为下一阶段的付费 agent 工作流铺路。
- **对用户的实际意义**：界面变了不代表模型变了，别把改版当“升级”冲一波情绪；但新入口鼓励你怎么用它，往往就是下一步定价策略的落点——值得当风向标看。

## 五、三条实用建议与一点冷思考

1. **按单任务成本选工具，别按“是否不限量”**。花一个下午估算自己的日均 token 消耗，拿 API 价格表对照订阅费，算出自己的回本点。重度用户走“订阅 + 按量”混合，轻度用户直接用 API 或低价档可能更省。
2. **配额是稀缺资源，学会任务分层**。探索性、低价值的杂活丢给便宜模型或本地开源方案；高额度留给真正难的重构与调试。上下文喂得越精准（缩小仓库范围、写清验收标准），重试越少——省 token 的本质是省重试。
3. **别在“最后一天”做决策**。挤兑式刷量是损失厌恶带来的情绪，不是策略。订阅随时可切，真正贵的是工程习惯和工具链迁移成本；决策前读官方条款原文，别只看二手截图。

**冷思考**：行业正从“烧钱换 DAU”走向“为结果付费”。未来计费单位可能是“通过的测试”“合并的 PR”，而不是 token 数。对普通开发者，“便宜的不限量”会越来越少，早点学会与按量计费共处，是必修课，不是选修课。

自助餐结束不可怕，可怕的是你还按自助餐的吃法过日子。🦞
