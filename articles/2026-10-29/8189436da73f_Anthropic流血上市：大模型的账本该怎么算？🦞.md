最近一条 36氪 热搜把不少从业者的午饭吃成了行业研讨会：Anthropic 被曝筹备上市，而公司账上仍在大额亏损，媒体称之为“流血上市”。先厘清一个事实——它还没正式挂牌，但上市传闻与巨额融资并存是真的。这家由前 OpenAI 团队创办、靠 Claude 系列模型起家的公司，一边烧钱一边被资本追着给估值。为什么？国产大模型厂商又能从这份亏损成绩单里读到什么？这篇不喊口号，把账本摊开算。

## “流血”流在哪儿：大模型的成本结构

先看钱烧在哪里。大模型公司的成本结构和传统互联网完全是两个物种：

- **训练成本**：一次 frontier 级模型训练动辄上万张 H100/B200 级 GPU，加上失败实验和多次重跑，几亿美元起步只是入场券。
- **推理成本**：模型上线才是烧钱的开始。每生成一个 token 都在消耗显卡、电力和带宽。订阅用户付的是固定月费，而重度用户（尤其把模型当生产力工具的）消耗的推理成本可能逼近甚至超过月费——“用得越多亏得越多”就是这么来的。
- **折旧压力**：GPU 大约三到五年一代技术更替，等于年年重新购置“生产资料”，账面折旧跑不掉。
- **人才成本**：顶尖研究员的年薪 package 普遍在七位数美元量级，几家头部公司还在互相抬价。

一句话概括：大模型是“重资产 + 边际成本不为零”的生意，和“一次开发、无限复制”的纯软件逻辑恰好相反。亏损不是管理层不努力，是商业模式的物理属性。

## 明知亏损，资本为什么还在抢？

资本市场买的从来不是“现在的亏损”，而是三样东西：

1. **收入斜率**。据报道，Anthropic 的年化收入已达数十亿美元量级，增速在软件行业极其罕见。SaaS 估值的老配方——高增长 × 高留存 × 大市场——它全占。
2. **企业粘性**。API 和企业客户客单价高、迁移成本高，工作流一旦跑起来很难换供应商，是典型的 SaaS 护城河。
3. **最优变现场景已现形**：编程与 agent。Claude Code 这类编程工作负载付费意愿强、token 消耗大、且直接对应企业降本，是目前最健康的单位经济模型。

还有两个容易被忽略的背景：其一，上市本质是给算力军备“融资续命”，私有市场融资越来越贵，公开市场通道更宽；其二，云厂商既是 Anthropic 的股东又是供应商，投资款相当部分会以云消费形式回流，这类“循环交易”让收入和融资额都更好看——看账时记得打个折扣。

历史上，Snowflake、Datadog 上市时同样亏损，靠增速和留存撑住估值。大模型只是把这个剧本的燃料费放大了一个数量级。

## 国产大模型的三种活法

把 Anthropic 的剧本对照国内，会发现国产厂商走的是三条不同路线：

- **成本工程派**：以 DeepSeek 为代表，用 MoE 架构、MLA 注意力机制、FP8 混合精度训练等手段把训练和推理成本压到极低，再以开源权重 + 低价 API 换开发者生态。它证明了一件事：算法效率上的创新，可以对冲硬件获取上的劣势。
- **开源生态派**：Qwen、GLM 等持续放出 open weights，目标不是直接卖模型，而是占据开发者心智和下游微调生态，把变现交给应用层。
- **应用与出海派**：MiniMax、Kimi 等把重心放在 C 端产品和海外市场，用产品与运营能力弥补基础模型上的资本差距。

同期，智谱已在科创板递交上市申请，MiniMax 转道港股——国产阵营正以自己的节奏接入公开资本市场。路径不同，底层逻辑相通：先解决“钱从哪来”，再回答“利润在哪”。

## 三个真正值得抄的信号

- **推理成本下降快于售价**：单位 token 成本几乎以年为单位快速下探（硬件迭代 + 量化 + 架构优化 + 缓存命中）。谁先把“打价格战”变成“扩毛利率”，谁先上岸。
- **变现场景排序清晰**：编程/agent > 企业 API > C 端订阅。国内 C 端付费意愿偏弱，B 端与开发者工具是更实的生意，别硬抄国外订阅制。
- **数据与合规是本地护城河**：私有化部署、行业语料积累、与业务系统的深度打通，是国际厂商短期进不来的区域，值得重投。

## 收尾：三条冷思考

1. **看亏损别只看绝对值，看单位经济**：单 token 成本曲线、毛利率趋势、客户净留存（NDR）。只有“亏损收窄 + 收入高增”同时成立，流血的故事才讲得下去。
2. **技术选型别押注单一模型**：在 API 层做好抽象与路由（model router），按任务把请求分发到性价比最高的模型，采购指标看 TCO（总拥有成本），而不是单价。
3. **别把上市当终点**：它只是给算力军备续了一次弹药。这个行业的终局竞争在效率与场景——烧钱能买到时间，买不到护城河。
