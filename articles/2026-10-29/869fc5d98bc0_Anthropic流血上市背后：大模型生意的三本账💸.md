最近"Anthropic 考虑 IPO"的消息被反复讨论：这家 Claude 背后的公司，公开报道显示一年内估值从约 615 亿美元跳到约 1830 亿美元，但多家媒体测算它每年的净消耗达数十亿美元量级。"流血上市"指的就是这种状态——带着亏损和巨额算力订单冲进公开市场。对国产大模型公司来说，这不只是大洋彼岸的热闹，而是一本被摊开的财务教材：大模型这门生意，到底怎么算账。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/bcb530763ce03654.png)

## 第一本账：收入账——跑通付费闭环的是"场景"，不是"参数"

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/e3c7bdd0458c7bb3.png)

- **收入大头来自 API 和企业订阅，而不是 C 端聊天。** 真正引爆增长的是编码场景：据报道，Claude Code 的年化收入很快迈过十亿美元线，成为公司增长最快的产品线。原因不复杂——写代码的 ROI 最容易量化，一个工程师每月一两百美元订阅费，只要省下几天工时，采购单就批得下去。
- **增速结构值得注意。** 公开报道显示，其年化收入从年初约十亿美元量级冲到年底三五十亿美元量级，客户以企业为主。这验证了一件事：大模型的第一桶金来自"愿意为结果付费"的场景，而不是跑分榜单的名次。
- **对照国内：** C 端订阅打价格战，API 单价一降再降，To B 长期以项目制交付为主——毛利低、复制慢。差异不在模型能力，而在有没有找到高频、刚需、ROI 可量化的场景。国内已出现同款思路的样本：智谱的 GLM Coding 套餐一度卖爆，就是把"编码订阅"做成了便宜好用的入口。

## 第二本账：成本账——推理成本和算力 capex 吃掉毛利

- **训练贵，推理更贵。** 前沿模型一次训练就要数亿美元，推理成本则随调用量线性上涨。行业普遍测算，推理型业务的毛利率约在 30%~60%，远低于传统 SaaS 的 70%~80%。换句话说，卖得越多未必赚得越多，关键看单位 token 的成本与定价之差。
- **Anthropic 的解法是用长期算力协议换价格和容量：** 深度绑定 AWS 和 Google Cloud；2025 年 11 月又据报道拿下微软与英伟达合计最高 150 亿美元的投资，附带约 300 亿美元的 Azure 算力采购承诺。注意，这不是"买便宜货"，而是把算力变成资产负债表上的长期负债——收入还没到，账单先到，像极了上线前夜的临时扩容，只是规模大了六个数量级。
- **对国产大模型，这道题约束更多：** 先进芯片供给受限、国产芯片需要生态适配（推理框架调优、算子迁移）、数据中心与电力同样吃紧。算力问题本质上是财务问题和供应链问题，不是单点技术问题。

## 第三本账：估值账——一级市场讲故事，二级市场要报表

- **一级市场的逻辑：** 云厂商当战投，既买股份也买云消费，钱在体系内循环，估值越推越高。OpenAI 把这套推到极致——据报道年化收入百亿美元级，估值一度摸到 5000 亿美元。
- **二级市场的逻辑完全不同：** 公募基金要收入质量、毛利走向、现金流路径，而且每季度验收一次。"流血上市"的真实含义，是估值锚从"故事"切换到"报表"的那一刻。
- **这对国内同样成立：** 据报道，智谱等一梯队公司已启动上市辅导。大模型的上市窗口取决于三个变量的交集——产品代际切换的节奏、毛利改善的曲线、算力供需的周期。踩错节奏，"流血"就不只是形容词。

## 国产大模型真正看到的四个信号

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/aa825c0917730fa0.png)

1. **场景优先于参数。** 编码和 Agent 是第一个跑通订阅闭环的场景。国内 Labs 应该问自己：我所在市场的"Claude Code"是什么？
2. **定价权来自交付，不来自低价。** Token 价格战打不出粘性；B 端真正付费的是评测体系、可观测性、私有化部署和 SLA，这些"卖水生意"毛利反而更稳。
3. **算力要进财务模型。** 自建、租用、国产替代怎么组合，芯片利用率、折旧周期、并发成本直接决定毛利——这应该是 CFO 和 CTO 一起开的会，而不是 CTO 一个人加班的会。
4. **资本节奏对齐产品周期。** 不追最高估值，留足 12~18 个月 runway，在产品代际交替、收入结构改善之前完成融资，而不是被弹药耗尽逼到窗口最差的时候。

## 三条冷思考

- **把毛利当体检报告。** 每月盯"单位 token 成本 vs 单位 token 收入"，别只看收入增速——增速可以烧出来，毛利改善只能运营出来。
- **找你所在行业的 Claude Code。** 高频、刚需、ROI 可量化，三个条件缺一个，订阅就会变自觉。场景护城河往往比模型跑分更可靠。
- **别把融资当里程碑，把留存当里程碑。** 续费率和净收入留存比收入规模诚实得多。IPO 只是工具，不是终点——Anthropic 这本账真正教人的，是如何在烧钱和造血之间找到自己的节奏。
