最近 36kr 一篇文章把一句挺扎心的话顶上了热搜：Muse 和灵光来了，但月薪八千的你不在牌桌上。前者是微软登上《Nature》封面的“世界模型”，后者是字节豆包团队推出的新一代 agent 应用。它们共同把 AI 从“生成文字和图片”推进到“生成可交互的世界和软件”。这句热搜值得掰开看——“不在牌桌上”到底指什么？是谁的桌子？真的没有你的座位吗？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/d4ad877746b5f17c.png)

## 一、Muse 和灵光，到底新在哪

- **Muse**：微软研究院与 Ninja Theory 合作的世界与人类行为模型（WHAM），2025 年 2 月登上《Nature》封面。约 16 亿参数，训练数据是多人对战游戏《Bleeding Edge》七年不间断的人类游玩记录，超过 10 亿对“游戏画面 + 手柄操作”。关键在于它学的不是像素，而是环境动态：给它一段历史操作，它能推演出视觉一致、可交互的未来画面。同方向的还有 Google DeepMind 的 Genie 3——一句话生成一座可以走进去的 3D 世界。
- **灵光**：字节豆包团队推出的 agent 应用，代表能力“妙搭”是——你用一句话描述需求，它几十秒生成一个能直接运行、可分享的小应用。做软件的门槛，从“会写代码”降到了“会说话”。
- 两件事指向同一个信号：**软件与互动内容的边际成本，正在被压向零**。这才是“牌桌”焦虑真正的来源。

## 二、三张入场券：算力、数据、人才

“不在牌桌上”严格来说指的是基座模型训练，这张桌子的门票确实贵得离谱：

- **算力**：GPT-4 级别的训练约需 2×10²⁵ FLOPs，对应上万张顶级加速卡连续跑数月。一张顶配卡市价 20–30 万元，大致等于月薪八千者不吃不喝两三年的税后收入；前沿实验室一次训练动用几万张，外加一座小型水电站级别的电力预算。
- **数据**：Muse 用了七年、10 亿量级的操作配对；通用大模型背后是全网级的清洗数据，采集、标注、合规，每一项都是重资产。
- **人才与工程**：分布式训练、推理优化、显存与集群调度，全球能稳定维护万卡集群的团队屈指可数。

结论很朴素：预训练是资本游戏，入场单位是亿美元。拿月薪去对标它，属于计量单位错误。

## 三、“牌桌”隐喻的漏洞：桌子不止一张

这个隐喻有个技术性 bug：它默认整场游戏只有一张桌子。真实的 AI 产业链是分层的——芯片层 → 云与算力层 → 基座模型层 → 工具链层 → 应用层 → 用户层。“不在牌桌上”只对其中一层成立。

- **PC 时代**：英特尔和微软在桌上，但吃下最大就业的是装机店、软件公司、网吧和后来的电商。
- **移动时代**：iOS/Android 双寡头锁死系统层，可小程序开发者、外卖骑手、主播撑起了千万级的就业生态——没有一个人“坐在桌边”。
- **关键机制是推理成本的坍塌**：a16z 的 LLMflation 测算显示，同等能力的推理成本约以每年 10 倍的速度下降；2024 年 5 月豆包把 API 价格打到 0.0008 元/千 tokens，直接引发国内价格战。基座能力正以水电费的方式向下渗透——你买不起发电机，但你用得起电。
- 还有一张常被忽略的**旁桌：开源**。Llama、Qwen、DeepSeek 开放权重，配上 LoRA 微调，一张消费级显卡就能养出一个垂直领域的小模型。你训练不了前沿大模型，但你完全可能“拥有”一个比通用模型更懂你所在行业的模型。算力民主化从来如此：大型机排队提交 → 个人电脑 → 云按量付费，模型能力正在走同一条曲线。

## 四、真正该焦虑的，不是上不了桌，而是看不见牌

对普通人，风险不在训练侧，而在认知侧和分配侧：

- **技能差**：会把工作拆解成“模型可执行任务”的人，与只会点按钮的人，效率差距在指数拉大，而薪资体系的调整速度远慢于此。
- **岗位结构**：世界经济论坛《Future of Jobs 2025》预测，到 2030 年约 9200 万个岗位被替代、1.7 亿个新岗位产生，净增 7800 万——但结构剧烈换血，被替代的集中在客服、基础文案、模板化设计这类可标准化岗位。
- **分配顺序**：AI 创造的价值，最先流向资本与稀缺技能的持有者。“月薪八千”之所以刺痛，是因为它点名了“既无股权也无壁垒”的中位状态。

## 五、普通人的三种座位

- **用工具：把自己升级成高级操作员**。核心不是写 prompt，而是任务拆解。程序员用 agent 做 code review 和回归测试；运营用 agent 批量生成 A/B 测试落地页；设计师用生成模型做前期 moodboard，把时间留给判断。
- **造工具：在应用层卡位**。巨头模型的缝隙恰是垂直行业——法律合同审查、跨境客服、工厂质检。小团队的真实角色是模型的“传感器”和“手”：你懂的行业 know-how，模型没有。有意思的是，灵光这类“应用工厂”恰恰把做软件的成本打到了地板——巨头卷得越狠，应用层越便宜。
- **被工具用：加入 human-in-the-loop**。数据标注、模型评测、红队测试、领域专家校验——world model 和 agent 越强，越需要海量真人反馈，这是正在扩张的真实岗位类别。

## 最后：三条冷思考

1. **用任务拆解能力重新给自己定价**：把工作拆成 20 分钟颗粒度的清单，逐项标注“AI 可替代性”。剩下的部分——判断、责任、跨域整合——才是你的定价权。
2. **押注缝隙，别押注正面**：不要在通用能力上和基座模型赛跑。选一个你比模型懂的具体领域（行业流程、合规、本地化），做“模型 + 你的 know-how”的垂直组合。
3. **每月做一张个人损益表**：AI 工具花了多少钱、省了多少小时、多了什么产出。推理成本每年降 10 倍意味着红利持续外溢，但红利只落在“正在用它产出”的人头上。牌桌上的人制定规则，桌边的人决定自己看牌，还是打牌。
