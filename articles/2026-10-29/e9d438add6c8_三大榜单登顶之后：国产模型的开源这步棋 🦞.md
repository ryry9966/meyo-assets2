36kr 消息刷屏：一款国产大模型同时拿下三大榜单第一，并宣布年底全面开源。评论区老三样随之赶来，“遥遥领先”“又是刷榜吧”“关我什么事”。作为常年盯榜单的人，我的看法是：榜单第一是结果，不是原因；开源是策略，不是情怀。这篇把三件事讲清楚：分数是怎么来的、开源到底在图什么、普通人该怎么用。

## 先拆题：三个榜单，各在测什么？

“三大榜单第一”听着唬人，但榜单和榜单差别很大，常见分三类：

1. **人类偏好类**（如 LMArena，前身 Chatbot Arena）：两个模型匿名对战、用户盲选，按 Elo 积分排名。优点是贴近真实使用手感，缺点是“说得漂亮”也能加分，偏好不等于正确。
2. **能力基准类**（如 MMLU-Pro、GPQA、AIME）：固定题库测知识与推理。可复现，但有数据污染风险，题目若混进训练集，分数就虚高；而且高分段已经开始饱和。
3. **工程与智能体类**（如 SWE-bench Verified）：让模型修真实 GitHub issue、跑通测试用例，是近几年公认最硬的口径之一。

关键判断：**同时拿下三类第一，含金量远高于单一榜单第一**。三者考察维度互补——一个像高考，一个像奥赛，一个像试用期考核。全都要，才说明不是靠某种“应试技巧”。

## 分数从哪来：模型做对了哪四件事

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/38fa6c02fe12a128.png)

榜单第一从来不是单点魔法，拆开看是四件事的叠加：

- **架构：MoE（混合专家）**。总参数量大、每次推理只激活一小部分。参考同行已公开的配置：DeepSeek-V3 总参 671B、激活约 37B；Kimi K2 总参 1T、激活约 32B。相当于万人公司只叫醒关键岗位，能力上限和推理成本同时拿下。
- **后训练：可验证奖励的强化学习（RLVR）**。数学答案对错、代码测试是否通过，这些信号可自动判卷，适合大规模 RL。它把“会做题”训练成“会解决问题”，正是智能体榜单涨分的主引擎。
- **数据工程**。清洗、去重、合成数据配比，再加上 128K 级长上下文训练，后者是多步工具调用任务的地基。
- **工程底座**。FP8 混合精度、万卡集群稳定性、推理侧优化。训练成本从“玄学”变成可以算账的工程学，DeepSeek-V3 论文报出的约 279 万 GPU 小时就是代表案例。

一句话总结：**架构给上限，数据给下限，RL 给泛化，工程给性价比。**四项全对，才有榜单第一。

## 「年底全面开源」，到底图什么？

先校准概念，“开源”其实分三档：

1. 只放权重（open weights）；
2. 权重 + 推理/部署代码，市面上绝大多数“开源”停在这档；
3. 权重 + 训练代码 + 数据配方——真·全量开源，目前业界极少。

所以“全面开源”具体到哪一档、用什么许可证（Apache 2.0 / MIT / 自定义），年底见真章，现在下结论为时过早。

再说商业账。开源从来不是慈善，本质是把获客成本从广告费换成了 GPU 电费：

- 权重公开 → 开发者下载、试玩、迁移生态 → 企业愿意做私有化部署；
- 真到生产环境，重度流量还是回流官方 API 和云服务——开源是漏斗顶端，推理计费才是收口；
- 参考历史：Llama 系列把“开源权重”变成行业默认选项；DeepSeek-R1 引发全球复现潮；Qwen 的衍生模型数量长期霸榜 Hugging Face。开源已经从“姿态”进化成“获客渠道”。

顺带一个竞争副作用：权重一公开，全行业闭源 API 的定价锚就被往下拉了一格。

## 榜单第一 ≠ 闭眼用：三个冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-29/0d47988a2650790a.png)

最后给三条实操建议，比转发“遥遥领先”有用得多：

1. **看榜单先看口径**：确认测的是哪类任务、哪个模型版本号、是厂商自报还是第三方托管、有没有给出置信区间，Arena 的 Elo 前几名经常在误差范围内咬得很紧。第三方评测 > 自测自报。
2. **用自己业务做 private eval**：攒 20~50 条真实 case，做匿名盲测对比。榜单是别人的考卷，你自己的数据才是你的考卷——这一步的成本可能就一个下午。
3. **看许可证和“开源成色”再上生产**：商用前确认 license 条款（部分自定义许可对用户规模、品牌使用有限制）；同时评估推理成本——MoE 模型分数高，但总参数大、显存不便宜，小团队建议先量化（AWQ/GPTQ）再部署。

榜单会过期，工程能力不会。年底开源那一刻，才是真正比赛的发令枪。
