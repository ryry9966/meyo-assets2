前段时间，由美国名人 Kim Kardashian 联合创办的贴身衣物品牌 SKIMS 在上海开出快闪店，并上线天猫海外旗舰店。据公开报道，普通内裤定价一百多元，部分塑身与泳装单品逼近 700 元。话题随之上了热搜：一边说“落地挺接地气”，一边问“这价格谁买”。把八卦滤镜摘掉，这其实是一道很典型的商业题：一台在美国运转良好的“注意力变现机器”，换到中国市场，700 元的溢价还成立吗？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-01/09632afb623e5df7.png)

## 先看懂生意：名人品牌是一台注意力飞轮

- **起家方式**：SKIMS 2019 年上线，靠 waitlist 排队 + Drop 限量发售起家，多款产品数小时售罄；据公开报道，2023 年其估值达 40 亿美元，年收入在 7 亿美元量级，还拿下了 NBA 官方内衣合作伙伴的位置。
- **机制拆解**：名人自有流量（亿级社媒粉丝）→ 内容制造话题与信任背书 → 限量发售制造稀缺 → 售罄反哺品牌热度，循环加速。这与 Streetwear 品牌的 Drop 模式同源：卖的不是库存，是“错过就没有”。
- **前提条件**：飞轮成立依赖两点，IP 与目标人群的日常连接足够强；社媒传播成本足够低。在美国，创始人本人就是最大的媒介渠道，营销预算里很大一块被“自有流量”抵扣了。
- **反面参照**：Fenty Beauty 靠名人 IP 在美妆赛道做成现象级，但同一 IP 下的时装线高调上线、低调关停。差异在品类属性：美妆单价低、尝鲜成本低、视觉传播强；时装决策重、退货率高，IP 撑不动。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-01/ce4dd0b184d85092.png)

## 700 元的定价拆解：钱到底花在哪了

以无痕塑身衣为例，把一件 700 元的零售价粗略拆开：

1. **物料与制造**：锦纶/氨纶混纺面料 + 无缝针织 + 压胶工艺，出厂成本通常在几十元量级；
2. **渠道与履约**：DTC 模式看似省掉层层经销，但平台流量采买、佣金、仓储物流合计常占零售价的 20%-30%，省下的一半又还给了流量平台；
3. **营销与内容**：名人品牌的营销费用率普遍偏高，内容制作、投放、合作可能吃掉 30% 以上；
4. **品牌溢价**：剩下的部分，本质是“为注意力和身份认同付费”。

对比国内：经过 Ubras、蕉内、内外等品牌多年“无尺码/体感”教育，无痕内衣主流价格带已压到 100-300 元。也就是说，700 元定价里超过一半买的是品牌与叙事，而不是面料科技。这不是坑，是定价策略——但前提是，消费者认那个叙事。

## 换到中国市场：三个变量都在做减法

1. **供给端：白牌内卷拉平功能溢价**。中国贴身衣物市场是数千亿元量级的红海，无缝针织、压胶在国内是成熟产能，抖音白牌能把“同款工艺”卖到几十元并次日到家，功能层面的信息差几乎为零。
2. **需求端：消费理性化**。近两年贴身衣物消费明显向“舒适、性价比、复购”集中，为单一叙事支付高溢价的意愿在收缩。
3. **IP 折价**。名人 IP 的价值高度依赖本地社媒的日常存在感。在美国，创始人自带亿级粉丝矩阵；到了中文互联网，这个连接要靠本地达人和本地内容重建，等于把“自有流量”的优势重新变成“采买流量”的成本——飞轮第一环直接换成了付费齿轮。
4. **渠道错位**。SKIMS 在美国靠社媒种草 + 售罄营销增长；中国贴身衣物的成交大头在货架电商和直播间，比价环境残酷得多。

## 700 块什么时候卖得动：一个判断框架

一件高溢价贴身衣物能不能立住，可以依次过四道闸门：

- **社交可见度**：产品是否“外穿化”？瑜伽、健身、通勤场景里能被看见，才有社交展示价值；
- **场景溢价**：是否绑定具体场景（塑形、运动、产后修复），让功能差异可感知；
- **稀缺叙事**：限量、联名、断货故事能否持续供给，而不是一次性烟花；
- **本地化产品力**：尺码版型是否针对本地身材数据调整、有无试穿服务与尺码顾问。

四道闸门全过，700 元才有机会从“贵”变成“值得”；缺一道，就掉回价格战。贴身衣物是典型的“高复购、低忠诚”品类：首发销量靠 IP，长期留存靠产品——这也是判断所有名人品牌的通用标尺。

## 写在最后：三条冷思考

1. **看复购，不看首发**。开售售罄是名人 IP 变现的常规操作，真正该盯的是 90 天后的复购率与退货率，那才是产品力的成绩单。
2. **溢价必须可感知**。面料克重、压力分区、尺码宽容度、门店试穿——任何一个能被消费者“摸到”的差异，都比十条广告片有用。感知不到的溢价，迟早被白牌的相同工艺打穿。
3. **分清为功能付费和为 IP 付费**。对消费者：想要无痕舒适，300 元价位段选择已经足够多，多出的钱买的是叙事和身份感；对从业者：名人品牌进入成熟供应链市场，本地化深度决定生死，“原版照搬”大概率是学费。

一家贴身衣物公司的中国故事，本质是“注意力生意”撞上“供应链过剩市场”的实验。飞轮还转不转，看半年后的复购数据就行——数据不会上热搜，但它比热搜诚实。
