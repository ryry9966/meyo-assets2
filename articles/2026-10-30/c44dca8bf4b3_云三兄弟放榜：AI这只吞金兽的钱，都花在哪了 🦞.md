最近几家云厂商的财报挨个放榜，评论区画风很分裂：一边是“云业务收入增速回暖”的喜报，一边是资本开支（capex）的数字看得 CFO 手抖。收入在涨、花得更多，这两件看似矛盾的事，恰好拼出了当下 AI 云生意的完整拼图。这篇就把账本摊开，拆一拆“AI 吞金兽”的钱流向了哪里、生意模式变了什么、以及我们该盯哪些指标。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-30/ed8338665ae1b120.png)

## 两个刺眼的数字：收入涨两位数，开支涨得更凶

- **阿里云**：AI 相关产品收入连续多个季度保持三位数同比增速；同时公司宣布未来三年投入约 3800 亿元建设云和 AI 基础设施——这个数字超过了过去十年的总和，等于把“基建先行”写进了财报。
- **腾讯**：资本开支占收入比重从此前的个位数抬升到 10% 以上量级，管理层在电话会里反复强调“AI 是长期投资”，而 AI 对广告、游戏等业务的增益也开始体现在毛利端。
- **百度智能云**：营收同比增速维持在 20% 上下，AI 云收入占比持续提高，重心明显从“卖资源”转向“行业模型 + 解决方案”。
- 放到全球看这不是孤例：北美几大云厂商 2025 年的资本开支指引加起来是三千亿美元量级。

一句话结论：这是一场全球同步的算力基建竞赛，没有玩家敢先停手。

## AI 为什么吞金：拆开一张 GPU 账单

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-30/a63fb336ef314840.png)

很多人对“烧钱”没有数量级概念，这里把成本拆开看：

1. **单点成本**：一张高端训练 GPU 价格以万美元计，一台 8 卡服务器整机是百万人民币级；一个千卡集群，光硬件就数亿起步。
2. **GPU 只是大头，不是全部**：无损高速网络（400G 互联）、并行存储、液冷系统、土建与供配电，这些配套通常占整个数据中心成本的三成以上。一句话总结：买 GPU 是首付，养 GPU 才是房贷。
3. **电力账**：大型训练集群的功率相当于一座小型城镇，电价与供能稳定性直接决定选址——这也是“东数西算”工程被反复提起的原因。
4. **折旧陷阱**：服务器通常按 5~6 年折旧，但 GPU 一年一代（Hopper → Blackwell），如果下一代性价比翻倍，手里的卡就是加速贬值的资产，账面减值压力随时会出现。
5. **历史参照**：2000 年前后电信商疯狂铺设光纤，当时被骂“产能过剩”，后来这些冗余管道成了 4G 和流媒体时代的地基。算力会不会重演这个剧本，是整场竞赛最大的悬念。

## 生意换引擎：从“卖机房”到“卖 token”

- **云 1.0 怎么赚钱**：卖虚拟机、存储、CDN，按资源计费，毛利稳定，但增长高度依赖企业上云率，天花板肉眼可见。
- **云 2.0 的新 KPI 是 token**：模型即服务（MaaS）按调用 token 计费，头部厂商的日均 token 调用量环比动辄翻倍——这个指标正在取代“上云率”，成为新的增长叙事。
- **价格战是主动选择**：过去一年大模型 API 降价数轮，降幅经常到 80%、90%。逻辑不是恶性内卷，而是推理成本确实在指数级下降（架构优化 + 硬件迭代 + 批处理调度）。先降价换生态，等应用繁荣后再靠增值服务变现——和当年 AWS 低价获客、靠数据库与安全服务赚钱，是同一个剧本。
- **飞轮长这样**：低价 → 开发者涌入 → 工具链与数据被锁定 → 微调、评测、向量库、Agent 平台等高毛利服务接力变现。

## 同一个方向，三条路线

- **阿里**：开源模型 + 重资产基建，赌的是“通义生态 → 云上转化”，3800 亿是最激进的表态。
- **腾讯**：把 AI 塞进自家场景（广告投放、游戏、办公协同），云侧重行业解决方案，开支节奏相对克制但在明显提速。
- **百度**：智能云 + 行业纵深，自研芯片搭配行业模型，走“企业级重服务”路线。
- 差异背后是同一个共识：下一轮云市场排位赛，比的是谁先把 token 消耗量做起来。

## 冷思考：吞金兽什么时候回本？

- **变量一：模型迭代速度**。换代太快，存量算力贬值；这是折旧政策激进的公司最大的利润率风险。
- **变量二：推理需求曲线**。训练可以“一波流”，推理必须长期增长——token 量的环比数据，比收入增速更诚实。
- **变量三：能源与供应链**。先进制程产能、电力审批、冷却方案，任何一环卡住，工期和回报测算都会失真。
- **乐观的一面**：历史上推理成本每下降一个数量级，都会冒出一批原来“算不过账”的应用——图像生成、视频生成、Agent 都是这么来的。算力的“暂时过剩”，往往只是“应用还没长出来”。

## 最后三条，建议直接抄

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-30/e77cb43ccd2ea19f.png)

1. **开发者/企业用户**：在应用层做好 API 网关与模型路由的抽象，别和任何单一厂商深度绑定；token 单价大概率继续降，长约别签太死，给自己留切换余地。
2. **看财报别只看收入增速**，盯三个数：capex 占收入比、云业务 EBITA 利润率、token 调用量环比。三个数放一起看，才分得清“真增长”和“烧钱换流水”。
3. **冷思考收尾**：每一轮基建先行都会伴随“过剩论”，但应用总是晚于管道长出来。对个人最划算的策略不是去预测周期，而是先把 AI 工具用成肌肉记忆——管道总会铺好，先学会跑水管的人最占便宜。
