最近一级市场最耐人寻味的一笔交易：据 36kr 等媒体报道，Anthropic 在上市传闻持续升温的当口，收购了一家员工总数为 **1** 的“制药公司”。没有研发团队，没有自建实验室，整家公司就是一位创始人加一整套 AI 工作流——开周会只需要照镜子。听起来像段子，但它其实是一份关于科研组织形态的问卷：**当 AI 把执行环节的成本压到极低，一家公司最少需要几个人？**这笔交易给出的参考答案是：也许比我们习惯的认知少得多。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-30/8792193f4fdd61fb.png)

## 一家“一个人的制药公司”，到底怎么运转？

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-30/b07c4d28e308c800.png)

传统药企的分工表很长：药物化学、生物学、ADMET、临床前、临床、注册事务，随便一个环节都是几十人起步。而“一人药企”的玩法，是把其中大量环节替换成模型和 agent：

- **文献与靶点研究**：过去靠医学情报团队数月精读；现在 LLM agent 能在几天内扫完上万篇论文，提取靶点、通路和相互矛盾的证据。
- **结构预测与分子设计**：AlphaFold、ESM 系列把蛋白质结构预测成本压到接近零（AlphaFold 数据库已公开约 2 亿个结构预测）；生成模型负责分子生成和 ADMET（吸收、分布、代谢、排泄、毒性）打分。
- **流程编排**：Claude 这类 coding agent 把“读文献 → 提假设 → 设计实验 → 写分析代码 → 出报告”串成自动化 pipeline，创始人更多扮演科学总监加审稿人。
- **湿实验外包**：分子合成、活性测试交给 CRO（合同研发组织）和云实验室，像下 API 订单一样排队执行。

几个参照数字：业界常引用一款新药平均耗时 10 年以上、总成本 10~26 亿美元（含失败项目与资本成本摊销）；而 Insilico Medicine 曾披露，AI 驱动下从靶点发现到临床前候选分子只用了约 18 个月、约 260 万美元；Exscientia 为住友制药设计的首个 AI 分子 DSP-1181，设计阶段约 12 个月，而行业平均是 4~5 年。

所以“一个人”的真实含义是：**一个人 + 一群 agent + 一张外包网络**。工序并没有消失，只是被软件化和外部化了。

## Eroom's Law：药物研发为什么越做越慢、越做越贵

- **Eroom's Law**（Moore's Law 倒着写）：Scannell 等人 2012 年的统计显示，1950 年代以来，每 10 亿美元研发投入能产出的新药数量约每 9 年减半。靶点越来越难啃，试错成本越来越高，临床与监管流程刚性。
- **前两波浪潮的天花板**：1990 年代的组合化学 + 高通量筛选、2010 年代的深度学习分子设计，确实加速了“找分子”，但临床阶段占总成本大头、动辄数年，AI 一度只能加速前半程。
- **这一波的不同**：foundation model 能力跃迁 + agent 具备跨环节编排能力 + 云实验室把湿实验“接口化”。AI 从单点加速器变成了流程组织者——这正是“一人公司”成立的必要条件。
- **冷静提醒**：目前周期与成功率的改善仍集中在发现和临床前阶段，临床试验这个最大的黑洞，谁都还没填上。

## Anthropic 的算盘：买的不是药，是“人 + 方法学”

Anthropic 显然不会自己去跑临床试验，这笔交易更接近 **acqui-hire（人才收购）**。标的大致是三层东西：

1. **领域级 eval 与真实反馈**：资深科学家最清楚模型在真实科研里哪里可靠、哪里开始幻觉。这种一手反馈比任何公开 benchmark 都稀缺。
2. **"AI for Science" 的样板间**：科研机构和药企是 Claude 付费能力最强的场景之一，需要一位懂行的内部建造者，而不是外部咨询。
3. **资本市场叙事**：IPO 要讲的不只是聊天机器人的收入曲线，还有“平台深入科学生产力”的想象空间。一笔小额 acqui-hire，性价比极高。

顺带一个观察：Sam Altman 曾预言“会出现一个人的十亿美元公司”，过去这更像口号；这次至少证明，在“被收购”这个出口上，超级个体已经可以被单独定价。

## 别神化一人公司：瓶颈没消失，只是被外包了

- **外包不等于免费**：CRO 合成一个分子要数千到数万美元，动物实验更贵。一人公司的资金链通常全押在融资或合同收入上，容错极低。
- **合规需要组织**：IND 申报、GLP/GCP、质量体系，本质是组织能力而非个人能力。一人药企实际是长在外包与合规生态上的极小节点——单点可以是一个人，系统依然庞大。
- **幸存者偏差**：能被 Anthropic 看上的，大概率是领域内积累了十几年的资深科学家，用 AI 放大既有判断力，而不是“零基础 + AI”的炼金术。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-30/3a9cb2f86a7d1941.png)

1. **对个体**：顺序不能反——先成为某个领域的深度从业者，再用 agent 把自己变成杠杆。AI 放大的是判断力，不是替代判断力。
2. **对创业者**：人数不再是估值的锚。可验证的方法学、能被同行复现的结果，才是小团队第一次拥有的清晰退出路径：被基础模型公司当作“领域插件”收购。
3. **对围观者**：把它当组织形态的风向标，而不是“人人都能制药”的邀请函。真正的瓶颈——临床验证、合规、资金——只是从公司内部搬到了网络外部。

科技史反复证明一件事：工具每便宜一个数量级，组织的最小单元就缩小一个数量级。这一次，轮到科研了。
