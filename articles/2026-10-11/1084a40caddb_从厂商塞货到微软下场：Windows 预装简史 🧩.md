最近一条 36kr 相关话题把一个老问题顶上了热议：Windows 里也有预装软件了，网友调侃“微软跟手机圈学坏了”。严格说，微软不是最近才“学”，而是过去三十年里，“预装”这门生意的主角一直在换人——从 PC 厂商，到应用分发商，再到操作系统厂商亲自下场。这篇把预装从现象、历史、商业和技术几个角度拆开，看看它到底是怎么一步步变成今天这个样子的。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/a661e18fcda93949.png)

## 一、现象：今天的 Windows 有多“满”

- **系统组件级预装**：Copilot 以系统组件身份内置进 Windows 11，不提供常规卸载入口；有用户用命令行卸掉后，随系统更新又装了回来，像极了打地鼠。
- **促销推送**：2024 年微软通过 Windows Update 推送过名为 Start Experiences Package 的组件，随后部分用户开机即遇全屏促销页，推荐 PC Game Pass、Microsoft 365 等订阅服务。
- **界面广告位**：开始菜单的“推荐的项目”会展示应用推广；锁屏的 Windows Spotlight 也在承担内容分发角色。
- **挽留弹窗**：把 Chrome 设为默认浏览器时，Edge 会弹窗劝你“再考虑一下”；2021 年起甚至出现过直接在 Chrome 里弹窗推荐 Bing 的操作。
- **OEM 层照旧**：不少整机出厂依然预装第三方杀毒软件试用版，传统艺能没丢。

一个值得记住的数据结构：微软 2024 财年总营收约 2450 亿美元，Windows 授权相关收入占比约一成；而 Microsoft 365 消费版订阅数已超过 8000 万。钱的来源变了，系统的行为就会变——这是理解整件事的钥匙。

## 二、历史：预装一直存在，主角换了两轮

1. **OEM 塞货时代（1990s～2010s）**：Windows 授权费是 PC 成本大头，硬件毛利薄，厂商就把开机那一刻“卖”出去——浏览器工具栏、游戏试玩、杀毒试用版，按装机量与推广方结算。那时用户的吐槽对象是整机厂商，微软反而是被塞货的一方。
2. **微软当“裁判”的年代**：1998 年美国司法部起诉微软，争议焦点正是 IE 与系统捆绑；2007 年 Opera 向欧盟投诉，2010 年起欧洲版 Windows 出现“浏览器选择屏”。预装与捆绑的边界，最早是由诉讼划出来的。
3. **角色反转（2015 至今）**：Windows 10 免费升级，微软放弃“卖拷贝”的思路，把 Windows 重新定位成服务入口。此后推广自家订阅的动作越来越密，塞的东西也从第三方工具栏，换成了自家全家桶。

## 三、账本：为什么操作系统开始“学手机圈”

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/8c9c24620f5ab873.png)

手机圈的公式早已成熟：硬件毛利薄 → 预装分成 + 应用商店抽成 + 系统内广告 + 云服务 → 用装机量换长期服务收入。应用想进 ROM，按 CPA（每次安装）付费，装机量就是渠道价值。

微软的处境与这套逻辑高度同构：

- Windows 授权收入增长见顶，消费者端几乎不再为系统本身付费；
- 订阅服务的用户生命周期价值（LTV）远高于一次性授权：一年 Microsoft 365 订阅的收入抵得过一次系统授权，而且年年续费；
- 桌面操作系统意味着每天开机即触达的“自有流量池”，获客成本约等于零——这是所有厂商梦寐以求的渠道位。

所以“学坏”这个词并不准确：装机量换服务收入，本来就是 PC 时代 OEM 玩法的延续，只是微软把渠道权从厂商手里收了回来，自己下场做零售。

## 四、技术：预装怎么进系统，能不能拆

- **打包与部署**：新式系统应用多以 MSIX/AppX 打包，通过 Provisioned Package 机制随系统镜像部署；新用户首次登录时会自动重新铺一遍——这就是“删了又回来”的技术原因。
- **权限差异**：部分组件被标记为“系统应用”，不给常规卸载入口，后台还常驻独立进程。
- **通用解法**：winget 卸载、PowerShell 移除 Provisioned 包、社区 debloat 脚本；代价是更新后部分组件可能回归，个别依赖功能会受影响。
- **渠道差异**：LTSC、Enterprise 等企业渠道版本预装内容明显更少，这也是极客圈长期推荐它们的原因。
- **监管差异**：在欧洲经济区（EEA），受《数字市场法案》（DMA）约束，微软已放开 Edge、Bing 等组件的卸载。同一套 Windows，在不同监管环境里能力并不一样。

## 五、边界：哪些预装合理，哪些越线

公允地说，预装不全是恶：

- 对不折腾的多数用户，开箱即有一套可用的基础工具，是有效的引导；
- 平台投入巨额研发，需要商业模式回报，订阅化是全行业选择。

真正越线的是三条线：

1. **不可逆**：卸不掉、删了又自动回来；
2. **误导性**：促销弹窗做成系统提示的样子，关闭入口藏得很深；
3. **干扰性**：已付费用户照样收到同类推送。

## 三条实用建议与一点冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/d9b46a4732d7d03d.png)

1. **新机器开箱先做减法**：关闭开始菜单“推荐”与锁屏推广的开关，卸载用不到的预装，检查默认浏览器和默认应用有没有被重置——十分钟的事，一劳永逸。
2. **要长期干净，选对版本**：企业渠道版本（如 LTSC）预装最少；动手时优先用 winget 和微软官方文档，别用来路不明的“一键精简”工具——这类工具历史上出过后门。
3. **冷思考**：预装之争的本质，是“免费软件靠什么赚钱”。当授权收入消失，用户注意力就成了商品。这条边界不会由厂商自觉划出，也不会由用户单独划出，而是竞争（macOS、Linux、手机跨端）与监管（DMA 类法案）共同作用的结果——历史上每一轮预装乱象的收敛，都是这两股力一起推动的。
