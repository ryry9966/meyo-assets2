同一个季度，AI 圈上演了一出冷热两极的戏：一边是 OpenAI 被曝下调内部营收预期，未来几年的展望也同步缩水；另一边，通用 Agent 创业公司 Manus 据报道完成了约 5 亿美元融资，估值冲上约 50 亿美元。卖模型的巨头在低头算账，做应用的初创在扩编抢人。钱为什么换流向？这篇我们把这背后的产业逻辑拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/8f29e18721daae78.png)

## 一、OpenAI 的账本：一台烧钱机器的数学题

先看收入端。OpenAI 的收入主要来自三块：ChatGPT 订阅、API 调用、企业服务。据 The Information 等媒体报道，其 2025 年营收预期被内部下调，未来两年展望也同步调低——不是业务崩了，而是增速兑现的节奏比资本市场想象的慢。

再看成本端，这里才是重头戏：

- **算力承诺**：与 Oracle、Broadcom、AMD 等签下的算力合作，总规模据报道已达约 1.4 万亿美元量级，这是未来多年的刚性支出；
- **推理成本**：ChatGPT 每周数亿活跃用户，每一次对话都是真金白银的 GPU 时间；
- **人才成本**：顶级研究员的薪酬包，已经和职业体育一个量级。

把两边放一起，就是一道经典数学题：收入按「订阅费 × 用户数」线性增长，成本按算力军备竞赛指数级增长。OpenAI 不是不行，而是「通用大模型」这门生意的变现周期，天然比资本市场的耐心长。

## 二、Manus 凭什么：一个「干活的 AI」的融资逻辑

Manus 是什么？一句话：通用 AI Agent。你给它一个任务——做行业调研、整理报表、写一段代码、策划一条旅行线路——它自己拆解步骤、调用浏览器和工具、跑完整个流程、交付结果。关键在于：它自己不训模型，底层调用的是 Claude、GPT、开源模型等多家供应商的 API。

用发电厂打个比方：

- 模型层是**发电厂**：重资产、长周期、拼规模；
- 应用层是**电器**：贴近场景、回款快、按需求快速迭代。

投资人买 Manus，买的不是模型能力（那部分是租的），而是两样东西：**任务完成率**和**收入曲线**。据报道，它在 2025 年 4 月拿到 Benchmark 领投的 7500 万美元后，付费用户与 ARR（年化经常性收入）增长很快，一年内从零冲到数千万美元量级。应用层公司从 0 到 1 亿美元收入的速度，普遍比模型层快一个身位——这才是 5 亿美元融资背后的算术。

## 三、风向为什么变了：价值正在从模型层向应用层迁移

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/605c82d30e620aee.png)

这不是偶发事件，而是三个机制叠出来的结果：

1. **模型能力趋同**。DeepSeek、Qwen、Kimi 等开源模型把「够用的智能」的价格打了下来，头部闭源模型被迫一次次降价。当核心能力不再稀缺，溢价自然消失——这和当年云计算打价格战是同一个剧本。
2. **推理成本跳水**。主流 API 的单位 token 价格，两年里下降了 1~2 个数量级。靠「我算得便宜」建立的壁垒，保鲜期越来越短。
3. **稀缺性转移**。剩下的难题不在模型侧，而在应用侧：context engineering、多步规划、工具调用的可靠性、长任务的记忆管理。把一个 80 分的模型打磨成 95 分的产品，这层 know-how 成了新的稀缺资源。

还有一层更根本的变化：**计费单位的升级**。传统 SaaS 按席位收费，Agent 可以按任务、甚至按成果收费——软件的对手盘从「IT 预算」变成了「工资单」，市场边界直接大了一个数量级。Anthropic 的 Claude Code 据报道年化收入已破 10 亿美元，Cursor 估值冲向近百亿美元，都是同一条逻辑线上的注脚。

## 四、先别急着上头：应用层的护城河与暗礁

风向变了，不等于应用层躺赢。冷静看，Manus 们的护城河候选只有四条：

- **工作流嵌入**：用户的数据、习惯、历史任务沉淀在产品里，迁移成本高；
- **编排与可靠性**：把多模型、多工具调度的失败率磨到足够低，全是脏活累活；
- **分发与品牌**：流量入口和用户心智，先到先得；
- **垂直 know-how**：法律、医疗、财务这些领域，行业理解比模型聪明值钱。

暗礁同样明显：

1. **上游挤压**：OpenAI、Anthropic 自己也在做 Agent 功能（Operator、Claude Code、ChatGPT Agent）。模型厂商向下打应用，就像渔场自己开餐厅，食材成本直接归零；
2. **毛利率天花板**：应用层赚的是 API 差价，模型降价是红利，也是定价权旁落的信号；
3. **估值透支**：50 亿美元估值对应的是对未来增速的强假设，一旦兑现不及预期，回调会很疼。

一句话判断：应用层的胜负手不在「演示有多惊艳」，而在「失败率有多低、留存有多稳」。

## 五、三条冷思考：怎么把风向变成自己的判断

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/6d8596366746fada.png)

1. **看融资别只看金额，看单位经济模型**。ARR、毛利率、CAC/LTV、留存曲线——Agent 项目的毛利天然被推理成本吃掉一块，数字算清楚了再兴奋也不迟。
2. **评估 Agent 就盯三件事：可靠、可审计、可回退**。采购也好、创业也好，先看任务成功率有没有量化数据，过程能不能回放排查，出错有没有兜底方案。做不到这三点的惊艳 demo，基本等于烟花。
3. **个人视角：岗位价值正在从「会做」转向「会验收」**。把 Agent 当实习生带——会写清楚任务描述和验收标准的人，杠杆最大。这不是危言耸听，而是正在发生的新分工。

风向变了，不是谁的胜利，而是产业分工在细化：发电厂和电器，最后都得接上电。看清自己在链条的哪一环，比追热点重要得多。
