过去两年，大模型推理价格像跳水一样往下砸，可很多团队的月度 AI 账单不降反升。36kr 最近的热议话题把这件事讲得很直白：美国不少 AI 应用团队把预算切成了三层，其中负责"跑量"的那一层，正大量切换到 DeepSeek、Qwen 这类中国开源模型。这不是谁征服了谁，而是一笔很朴素的工程经济学账：单价暴跌反而释放了用量，成本管理的重心，从"买最聪明的模型"变成了"给不同任务接上粗细不同的水管"。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/9889c4d19a0b30b5.png)

## 一、杰文斯悖论：单价降两个数量级，总账单翻倍

- **单价在跳水**：2023 年初 GPT-4 的输入价格是每百万 token 30 美元；一年半后 GPT-4o mini 降到 0.15 美元，价差约 200 倍。a16z 给这个趋势起了名字——LLMflation：单位推理成本大约每年降 10 倍。
- **但用量涨得更快**：一次普通问答约 2000 token；换成 agent 工作流，一个任务会拆成几十次模型调用，再叠加思维链、工具返回和失败重试，轻松吃掉 10 万+ token。
- **150 年前的老剧本**：1865 年经济学家 Jevons 就发现，蒸汽机效率提高后，煤的总消耗不降反升。单价降 10 倍、用量涨 50 倍，账单照样涨。降价从来不是"省钱信号"，而是"用量约束解除"的信号。

## 二、三层预算：饮用水、厨房用水和消防用水

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/d27b09ac50af00c6.png)

成熟团队已经不再"一个模型打天下"，而是像管水一样管 token：

1. **旗舰层**（GPT-4o、Claude Opus、o 系列、Gemini Pro）：攻坚复杂推理、代码和规划。调用量占 10%~20%，却可能吃掉一半预算。
2. **中坚层**（GPT-4o mini、Claude Haiku、Gemini Flash）：日常主力，客服、摘要、文案，是质量与成本的平衡点。
3. **跑量层**：分类、打标、数据清洗、RAG 改写、批量翻译。单价极度敏感、单点容错率高，错一两个无所谓。这一层正被更便宜的开源模型接管。

类比很直白：没有人会用依云水冲马桶。预算分层不是抠门，是用量到了一定规模后的必修课。

## 三、第三层的缺口，为什么正好被中国模型填上

- **开源权重 + 宽松协议**：DeepSeek-R1 用 MIT 协议，Qwen 系列多为 Apache 2.0，可以下载、自部署、微调、蒸馏，没有按 token 计费的"水表"。
- **架构效率**：DeepSeek-V3 是 671B 参数的 MoE 模型，每个 token 只激活约 37B，推理成本天生低；官方论文披露其预训练算力约 278 万 H800 GPU 小时，成本量级远低于同期闭源旗舰的传闻数字。
- **性能"够用"**：R1 在 AIME、MATH-500 等基准上对齐了同期 o1 的水平，Qwen 长期霸榜开源社区下载量。第三层任务要的是 80 分，没必要为最后 10 分付 10 倍价钱。
- **接入成本趋近于零**：OpenAI 兼容 API 改一行 base_url 就能切换；AWS Bedrock、Azure、OpenRouter、NVIDIA NIM 都已上架 R1。

## 四、"投奔"的真相：不是换模型，是装路由器

- **模型级联（model cascade）**是主流打法：默认用便宜模型，置信度不够或任务变难再升级旗舰。业内常见的路由策略会把 70%~80% 的流量导向低价模型，旗舰只处理长尾难题。
- **一批隐藏杠杆**在同步生效：prompt caching 命中后输入价能低一个数量级、Batch API 半价、FP8/INT8 量化、压缩思维链长度——每一项都在把"跑量成本"往下摁。
- **中间多出一层新基建**：LiteLLM、OpenRouter 这类"LLM 网关"按团队、按任务记账，token 变成了和云资源一样需要 FinOps 管理的东西。
- 所以更准确的说法是：预算第三层被全球性价比最高的供给填上了。谁便宜好用就接谁，这叫工程理性，不叫站队。

## 五、便宜不等于免费午餐：三个高频踩坑点

1. **TCO 陷阱**：自部署看似零 API 费，但 GPU 租金、运维和扩容折算下来，调用量不够大反而更贵。中小团队用 Fireworks、Together 这类托管服务通常更划算。
2. **合规与连续性**：医疗、金融要关注数据驻留与出境要求；开源协议要逐条看清；API 端随时可能限流、改价甚至下线模型，关键路径必须留 Plan B。
3. **榜单≠生产**：基准高分不等于在你的脏数据上表现好。切模型前先建自己的评测集，小流量灰度一两周再全量。

## 收尾：三条冷思考

1. **按任务算单位经济账**："每解决一张工单 / 生成一份报告花多少钱"，远比盯着每百万 token 的单价有用。
2. **把"路由 + 降级"当默认架构**：便宜模型打底、旗舰兜底，用抽样人审加 LLM-as-judge 盯住质量漂移。
3. **把抽象层当资产**：统一接口 + 配置化模型列表 + 季度评测，保证随时可换供应商——议价权和迁移能力都握在自己手里。

价格战没有让 AI 变便宜，只是让"贵"变得更精准了。对工程团队来说，先装好水表，才敢真正开闸放水。
