36kr 最近一篇观察里有个很有意思的说法：在亚马逊的橱窗里，智谱和 DeepSeek 活成了“两种模特”。这个词一语双关——model 既是 AI 模型，也是橱窗里的人形模特。同样是 2025 年出海声量最大的两家中国大模型公司，一个像是被各大渠道争相上架的爆款单品，另一个像是自己租下旗舰店、亲自站柜台的品牌方。橱窗只是表象，背后是两条完全不同的分发路线。这篇文章把这两条路线拆开来看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/86b8334dba801bd3.png)

## 一、先分清：这里的“橱窗”其实是两个

- **电商橱窗**：在 amazon.com 搜"DeepSeek"，能翻出大量第三方作者写的使用指南和本地部署教程，2025 年初一度霸榜 AI 类图书畅销品——而这些书没有一本是官方出品。
- **云计算橱窗**：2025 年 1 月底，微软 Azure AI Foundry 与亚马逊 AWS Bedrock 先后官宣上架 DeepSeek-R1。对云厂商来说，这是零采购成本拿到手的热门 SKU。
- **智谱的摆法**：海外品牌 Z.ai 走的是自营路线——自家 API 平台、GLM Coding Plan 订阅、企业私有化部署，同时也在 OpenRouter 这类第三方聚合平台上架 GLM 系列。
- 一句话总结区别：**DeepSeek 的“上架”主要由别人完成，智谱的“上架”主要靠自己完成。**

## 二、DeepSeek：把分发外包给全世界

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/a0efb3394b31cfe9.png)

- **开源权重 + MIT 协议是起点**。2025 年 1 月 20 日 R1 发布，权重可自由商用，任何人——包括亚马逊和微软——都可以把它复制到自己货架上卖推理服务。
- **云厂商有天然的上架动力**。托管开源模型几乎零采购成本，卖出的每个 token 都是 GPU 时长收入，还能顺势对冲闭源模型的定价权。所以开源模型在云端货架上出现的速度，经常比闭源模型还快。
- **结果是病毒式铺货**。1 月 27 日 R1 登顶美区 App Store 免费榜，英伟达单日市值蒸发约 5890 亿美元；几天之内，从 Bedrock、Azure 到 Groq、Together，再到各种“一键部署”镜像，R1 出现在几乎所有主流渠道。
- **代价也很清楚：分发收益大头归渠道**。开发者记住的是“DeepSeek 这个权重”，而不是某个托管平台。DeepSeek 不直接收这波钱，它要的是品牌与生态位。顺带一提，V3 论文口径的 GPU 训练成本约 558 万美元，这个数字常被误读成 R1 的全部成本——传播里的很多“神话”，其实都是口径问题。

## 三、智谱（Z.ai）：自营旗舰店，亲自站柜台

- **组织基因不同**。DeepSeek 背后是幻方量化，算力和资金自给，没有营收 KPI，可以“只发权重、不做销售”；智谱是典型创业公司，股东众多，2025 年下半年科创板 IPO 申请获受理，需要实打实的收入支撑估值。
- **产品定位不同**。智谱押注 Agentic 与编程场景：GLM-4.5/4.6 相继开源（MIT 协议），配合 AutoGLM、Coding Plan（促销价一度低至每月 3 美元）。订阅、工单、版本升级这类持续服务，决定了柜台必须自己站。
- **监管环境不同（此处只陈述事实）**：2025 年 1 月智谱被列入美国实体清单，北美 ToB 直销通道受限，于是更依赖 Z.ai 的开发者品牌与第三方聚合平台间接触达海外用户，开源权重反而成了绕开渠道限制的产品形态。
- **效果参考**：第三方报告口径下，智谱长期位居国内 MaaS API 市场份额前列；GLM 系列在 OpenRouter 公开调用量排行中一度跻身前十。自营模式慢，但客户关系和数据反馈握在自己手里。

## 四、两种打法背后的账本

- **定价锚点被重写**。DeepSeek 把 V3/R1 的 API 价格打到每百万 token 输入约 0.27–0.55 美元、输出 1.10–2.19 美元的量级（还有夜间折扣时段），全行业价格基准被迫下移，靠 API 毛利吃饭的厂商集体承压。
- **同一件事，两本账**。开源权重对云厂商是“免费货架商品”，对模型厂则是“获客成本”：渠道赚算力差价，品牌赚生态位，立场不同，算法完全不同。
- **历史会押韵**。Android 用开源分发换来生态霸权，Google 靠搜索与服务变现；Red Hat 证明“给开源做服务”可以做成上市公司；MySQL 与 Oracle 的分岔走的也是同一条路。开源与否从来不是道德问题，是渠道策略问题。

## 五、冷思考：橱窗之外怎么判断

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/24b5fa3f4121be5d.png)

1. **选模型先问“谁对结果负责”**。用云厂商托管的 open-weight 模型时，确认版本锁定、更新节奏、量化方式和区域可用性——同名权重在不同平台上的吞吐和效果可能差一截。拿自己的业务数据做 benchmark，别只看橱窗里的人设。
2. **创业者想清楚“开源换什么”**。开源权重是分发策略，不是商业模式的完整答案：要么换生态位（工具链、订阅、企业服务），要么换人才与声誉红利。只开源不变现，账是平不平的。
3. **警惕“橱窗效应”**。App 排名、社交声量、上架渠道数量都是曝光指标，不是使用指标。多看 OpenRouter 这类平台的真实调用排行与第三方评测数据，比看橱窗更接近真相。

橱窗里的模特怎么摆，说到底是“让别人替你卖”还是“自己卖”的选择。两条路没有标准答案，唯一确定的是：能算清账的那条，才是走得远的路。
