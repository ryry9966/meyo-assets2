黄仁勋最近放话：**“如果没有 Windows，英伟达根本不会诞生。”** 一家市值一度冲上 3 万亿美元、常被称作“全球最值钱公司”的芯片巨头，公开说自己这条命是别人给的——第一反应像给合作方的场面话。但对照英伟达前十年的历史，这句话更像一份精确的工程报告：Windows 不是锦上添花的盟友，而是这家公司能存在的前置条件。这篇文章把这条因果链拆开看：一个标准化接口如何救活一家濒死的小公司，又如何一步步养出今天的 AI 算力巨头。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/0e7dafd34b8624f4.png)

## 先补历史课：1995 年，英伟达离倒闭只有 30 天

很多人以为英伟达一路高歌猛进，实际上它前五年差点死一次。

- **1993 年**，黄仁勋、Chris Malachowsky、Curtis Priem 在一家 Denny's 餐厅敲定创业方向：给游戏做 3D 图形加速。
- **1995 年**，首款产品 NV1 豪赌“四边形渲染”（quadratic surfaces）路线；同年 Windows 95 发布，微软把行业标准定在“多边形 + DirectX”上。NV1 押错方向，商业惨败。
- **1996 年**，现金流见底，团队从 100 多人裁到 30 多人。黄仁勋后来回忆：当时公司距离倒闭不到 30 天，团队把全部筹码押在下一代产品上。
- **1997 年**，全面转向 Direct3D 标准的 RIVA 128 上市，几个月卖出约 100 万颗，公司被从死亡线上拽了回来。

注意这个细节：救命的并不是什么天才发明，而是**第一时间兼容了 Windows 定下的标准**。

## Windows 到底提供了什么：一个接口 + 一个市场

把那句话翻译成工程语言，Windows 给了两样东西，缺一不可。

**1. 统一的图形接口（DirectX）**

1990 年代初的 PC 图形是“API 战国”：3dfx 有自家的 Glide，各显卡厂推私有接口，开发者要为每种硬件单独适配。微软 1995 年推出 DirectX，等于给所有显卡定了统一“插座标准”：游戏写一次，任何符合标准的显卡都能跑。所有厂商从此在同一条规则下比拼性能、价格和驱动稳定性——这对反应最快、执行力最强的公司最有利。

**2. 规模化的消费市场**

Windows 95 把 PC 从办公工具变成大众游戏平台，数千万台 PC 构成统一市场，显卡有了可预测的出货量基本盘。两件事叠加，转出一个经典飞轮：

- 游戏厂商基于 DirectX 开发，兼容成本降低；
- 玩家为了跑新游戏买新显卡，出货量上升；
- 出货量摊薄研发成本，芯片迭代更快；
- 更强的芯片支撑更炫的游戏，需求继续放大。

英伟达不是飞轮的发明者，但它是飞轮上跑得最快的参赛者。此后的 GeForce 256（1999 年，第一次亮出 "GPU" 这个词）以及之后的每一代游戏卡，都是在这个飞轮里滚出来的。统一插座标准这事听起来不性感，但商业史里最值钱的往往就是插座。

## 游戏市场的现金流，最后变成了 CUDA 的研发弹药

这才是整件事最有意思的地方：Windows 养大的游戏业务，后来“叛变”成了通用计算的起点。

- **2000–2001 年**：微软为造 Xbox 向英伟达下大额订单，前期付款约 2 亿美元——在公司最缺现金的阶段，这是一条救命输血管。
- **2000 年代**：游戏卡业务是稳定的现金流奶牛，支撑英伟达做“不务正业”的实验——让程序员拿显卡的并行单元去算非图形问题。
- **2006 年**：CUDA 发布，GPU 从“画图的”被改造成通用并行计算平台，绕开 Windows 与游戏，直接面向科研和工程界。2012 年 AlexNet 用两块 GTX 580 拿下 ImageNet，深度学习与 CUDA 从此绑定。
- **一个插曲**：初代 Xbox 之后因价格纠纷，微软把 Xbox 360 的订单转给了 ATI。这堂“别把命押在一个客户身上”的课，也解释了英伟达后来为什么死磕 CUDA 自建生态。

看 FY2024 财报：游戏业务年收入约 104 亿美元，数据中心约 475 亿美元，占总收入约 78%。换句话说，**今天大部分收入来自 CUDA 开辟的战场，而 CUDA 的研发账单，是 Windows 游戏市场付的**。

一句话总结这条因果链：Windows 统一接口 → 游戏市场起飞 → 游戏收入养 GPU 研发 → GPU 通用化长出 CUDA → CUDA 接住 AI 时代。抽掉任何一环，今天的英伟达都不是这个样子。

## 这句话该怎么听：一半是历史，一半是商业智慧

冷静点，这句“感谢”要分两层消化。

- **场合**：它出自黄仁勋与微软高管同台的公开活动，向重要合作伙伴致敬，本身含联盟维系的成分，不必逐字当论文审。
- **反事实推演**：没有 DirectX，市场最终也可能由 OpenGL 或某个私有 API 统一，英伟达未必活不下来。但“何时统一、由谁统一、确定性多高”会完全不同。历史没有对照组——Windows 给出的是**确定性**，而确定性在商业里比什么都值钱。
- **可迁移的规律**：技术史上反复出现的一幕是，制定标准的平台，往往比做出最好产品的公司更早决定谁有入场资格。英伟达赢，是因为它最快把命运绑上了正在变大的标准。

## 三条冷思考

1. **评估任何技术公司，先看它踩在哪个平台上。** 接口标准决定产业分工，入场资格常常比技术优劣更早决定生死。看项目、找工作、选技术栈，都先问一句：这个生态在变大还是变小？
2. **依附与独立要有先后时序。** 英伟达前十年靠 Windows 生态输血，后二十年靠 CUDA 自建生态、完成“去平台化”。先借势、再造血——顺序反了，要么饿死在独立之前，要么永远锁死在别人的地基上。
3. **想想你自己的“CUDA”是什么。** 平台红利期全力吃增长，同时有意识积累可迁移的东西：技术、方法论、渠道、声誉。英伟达最聪明的一步不是感谢 Windows，而是让自己有一天可以不必感谢。
