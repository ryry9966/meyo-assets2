最近不少朋友在后台甩给我同一条对照新闻：一边，The Information 报道 OpenAI 下调了 2025 年收入预期；另一边，上线不到一年的 AI Agent 产品 Manus 据报道完成约 5 亿美元新融资，估值冲到约 50 亿美元。全球最大的 AI 公司"预期降温"，一个年轻的应用层公司"融资升温"，两件事撞在同一段时间，并非巧合——AI 赛道的估值逻辑，正在从"堆模型"切换到"卷落地"。这篇文章把两条新闻拆开，讲清楚钱到底流向了哪、风向为什么变、我们该怎么看。

## 先把两条新闻摆到一起看

OpenAI 侧的事实链条大致是：

- 据 The Information 报道，OpenAI 把 2025 年收入预期从约 127 亿美元下调至约 115 亿美元，这是它首次下调年度预期，对 2026 年 Agent 相关收入的判断也更保守；
- 另一面是成本：据《纽约时报》获得的早期财务数据，OpenAI 2024 年收入约 37 亿美元、亏损约 50 亿美元；有报道称其内部测算到 2029 年的累计现金消耗可能超过 1000 亿美元；
- 用户侧其实不差：ChatGPT 周活跃用户已达约 8 亿。问题不是"没人用"，而是"用的人多、赚的钱少"。

Manus 侧的时间线则是：

- 2025 年 3 月上线即爆红，邀请码一度被炒到高价；
- 4 月拿下 Benchmark 领投的约 7500 万美元 B 轮，估值约 5 亿美元；
- 年底据彭博等媒体报道再融约 5 亿美元，估值约 50 亿美元——不到一年估值涨了约 10 倍，商业模式也简单直接：订阅制（39 与 199 美元两档）加积分制，卖的不是"聊天次数"，而是"干完的活"。

## OpenAI 的账本，问题出在结构上

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/5d4b5975d8bd2148.png)

逐条拆它的经济模型，会发现几个结构性错配：

1. **收入是订阅费，成本是按 token 计费的推理账单。** 收入随用户数线性增长，成本随使用量增长，而免费用户每多聊一句都在烧钱——8 亿周活是资产，同时也是全世界最大的固定成本之一。
2. **分成结构拖累毛利。** 据公开报道，OpenAI 需要把约两成收入分给微软；企业大单销售周期长、交付重，短期撑不起增速。
3. **"循环融资"引发质疑。** 英伟达宣布将投资 OpenAI，OpenAI 承诺采购英伟达芯片，又与甲骨文签下巨额算力合同——外界开始追问：这些是天量需求，还是资金闭环？这类疑问直接压低了资本市场对"算力叙事"的容忍度。

一句话总结：OpenAI 的困境不是需求消失，而是单位经济模型（unit economics）转不正——每 1 美元收入背后的推理成本、分成与资本开支加起来，超过了 1 美元本身。

## Manus 押中了什么：从"会聊天"到"会干活"

Agent 的技术本质是一个循环：LLM 负责规划 → 调用工具（浏览器、终端、代码解释器）→ 观察结果 → 修正策略 → 交付成果。Manus 把这个循环产品化：用户丢过去一个任务（做一份竞品分析、爬一批数据、搭一个小站），它在云端虚拟机里自主执行，最后交付文件和结果，而不是一段需要你复制的对话。

几个工程细节值得注意：

- **多 Agent 协作**：规划器与执行器分离，主 Agent 拆任务、子 Agent 干活，上下文互不污染；
- **Context Engineering**：对上下文做压缩与外置存储，兼顾长任务的连续性和 token 成本；
- **异步云端执行**：任务跑在云端沙箱里，人可以下线，结果好了再来取。

商业逻辑上，它把"卖工具"换成了"卖结果"：订阅费对应任务额度，随任务完成率提升，客单价与毛利有上升空间。更关键的是成本端——DeepSeek、Qwen、GPT 小模型把推理价格打了下来，这对模型厂是坏消息，对应用层反而是利好：上游降价，下游毛利升。资本买的正是这个剪刀差。

但要泼一盆冷水：Manus 上游依赖 Claude、GPT 等模型，护城河更多在产品编排与工作流上；模型厂每一次升级，都可能顺手覆盖它的功能。它真正的考验是任务完成率、留存与复购。

## 风向怎么变：资本从"押模型"转向"押落地"

2023–2024 年的主流叙事是 Scaling Law：算力堆上去、智能涨上去，谁先到 AGI 谁通吃，所以头部模型公司按"未来的 OpenAI"给估值，钱如潮水般涌向基础设施。

2025 年，资本开始问三个更"土"的问题：

1. 毛利率多少？
2. 用户留存多少？
3. 每 1 美元收入的推理成本是多少？

答不上来的公司，预期被下调；答得上来的公司，估值被上调。从结构上看，这像极了云计算时代：AWS 们先赚走基础设施的第一波，随后 SaaS 应用赚走更大、更持久的一波——价值正沿着"模型层 → Agent 层 → 行业应用层"迁移。

两点冷思考：

- OpenAI 远没到"失败"：收入仍在增长，Agent 化产品（Operator、Codex 一类）也可能改善它的单位经济。这是预期修正，不是叙事崩塌；
- 融资额是资本投票，不是用户投票。Agent 产品普遍存在"看起来很忙、结果不太行"的可靠性问题，评测（evals）与稳定性才是这个赛道的硬骨头。

## 收尾三盏灯：怎么看、怎么用、怎么避坑

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/3f0876ac27f1a88e.png)

1. **看 AI 公司先看单位经济模型。** 别只盯 DAU 和融资额，问三个数：毛利率、次月留存、单用户推理成本。这三个数健康，估值才有地基——壳再硬，也得看里面的肉值多少。
2. **把 Agent 当"初级同事"，而不是"更聪明的搜索框"。** 先挑低风险、可验收的任务——整理数据、写周报初稿、盯工单、跑测试——跑通一两个流程再放大。Agent 的 ROI 体现在省下的小时数，不在新鲜感。
3. **记住 Agent 时代的护城河公式：模型可以租，独有数据和工作流编排租不到。** 无论创业还是选工具，优先看"谁沉淀了私有数据、谁把结果交付做得最稳"，而不是谁的 demo 最炫。demo 会过时，留存不会说谎。
