最近 36kr 的一篇观察在技术圈刷了屏：同样“站”在亚马逊的云端货架——AWS Marketplace 与 Amazon Bedrock 上，智谱（国际品牌 Z.ai）和 DeepSeek 呈现出截然不同的姿态。一个把柜台布置成自营品牌店，订阅套餐、定价页、企业支持一应俱全；另一个几乎“人不在场”，货却铺满了整条街。这不是运营风格的差异，而是两条大模型商业化底层路线的分野。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/c36573cb2359c884.png)

## 先搞懂：亚马逊的“橱窗”到底是什么

标题里的“模特”是个双关：既指橱窗里的 fashion model，也指 AI model。要读懂这场走秀，得先弄清橱窗本身。

- **AWS Marketplace**：全球最大的云软件商店之一，企业可按订阅购买第三方软件与服务，统一走 AWS 的账单、合同与合规流程。
- **Amazon Bedrock**：AWS 的“模型托管专柜”，Anthropic、Meta、Mistral 等模型以托管 API 形式入驻——AWS 管算力与基础设施，模型方只管模型本身。
- **时间线**：2025 年初，DeepSeek-R1 进入 AWS 生态，随后以托管形式登陆 Bedrock；同年夏天，Z.ai 的 GLM-4.5 上架 Bedrock，并在 AWS Marketplace 开出官方订阅。
- **为什么重要**：对模型公司来说，这相当于直接进入全球企业的采购清单，合规、账单、SLA 一站式解决，是目前出海摩擦最小的通道之一。

## DeepSeek：把自己做成“公共面料”

- **开放权重路线**：R1 权重采用 MIT 许可证，允许商用、也允许蒸馏——其他团队可以拿它生成的数据去训练自己的小模型，影响力进一步外溢。
- **官方几乎不做海外运营**：没有英文商店，没有企业销售团队，官方 API 主要面向国内调用。
- **于是“人不在场、货满全街”**：微软 Azure、OpenRouter、Groq、Together、Perplexity 等第三方各自部署、各自收费。海外开发者用到的 DeepSeek，多半是别人家转售的。36kr 观察到的“缺席”正来自这里——在 Marketplace 搜 DeepSeek，出现的大多是第三方部署方案，而非官方柜台。
- **背后的逻辑**：不追求直接卖 token 的收入，而是把使用量兑换成技术影响力与生态渗透；算力由幻方体系自建集群消化，运营成本靠极小的团队规模压到最低。

## 智谱：把橱窗开成“自营品牌店”

- **完整 GTM（go-to-market）**：以 Z.ai 品牌出海，GLM 系列上架 Bedrock，Marketplace 官方订阅包含按月套餐、定价页、文档与企业支持；据公开报道，其几美元一档的编程订阅曾在开发者社区刷屏。
- **深度绑定云厂商**：AWS 负责算力与服务封装，智谱专注模型迭代，类似“品牌方进驻商场专柜”，可复用对方积累多年的企业客户关系。
- **技术底座**：旗舰 GLM-4.5 采用 MoE 架构（据公开资料，总参数约 355B、激活约 32B），主打编码与 Agentic 任务的性价比。
- **赚“明面上的钱”**：订阅费与 token 费构成可验证收入，模式清晰；代价是必须与 Anthropic、Meta、Mistral 同台竞争，销售与合规成本高，每一步都在烧钱。

## 两条路线背后的经济学

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/e4f05dcea51caff0.png)

- **开源是“飞轮模型”**：权重开放 → 开发者采用 → 工具链完善 → 形成事实标准 → 影响力反哺融资、招聘与下游服务。Android 与 iPhone 都赢了，但赢法完全不同。
- **自营是“零售模型”**：看毛利率、获客成本（CAC）、续费率，本质是经营一家全球化 SaaS 公司。
- **成本结构不同**：DeepSeek 背后是幻方自建算力与极小团队，边际成本低；智谱要同时支撑研发、算力与全球销售体系，重得多。
- **共同点是价格曲线**：两家都把 API 打到“每百万 tokens 几毛到几美元”的量级——竞争的本质是工程效率（MoE、稀疏注意力、低精度训练），而非单纯降价。
- **两条路线并非对立**：Meta 的 Llama 已示范了“开源建生态 + 托管赚收入”的混合打法，这大概率是行业走向成熟的形态。

## 给开发者与企业的判断框架

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-11/4aceab446876eef1.png)

- **原型期**：优先用开放权重自部署或低价 API，试错便宜、随时可换。
- **生产期**：重点看托管渠道的 SLA、合规与账单整合；模型能力只是入场券，稳定性才是复购理由。
- **算账方式**：用“每百万 tokens 单价 × 预估调用量”做预算模型，别只看发布会 benchmark——上下文长度和缓存命中率对账单影响巨大。
- **防风险**：开放权重不等于永远免费，许可证与后续版本策略都可能调整；核心业务至少准备一条 fallback 链路。
- **观察信号**：一家模型公司是否上架主流云、是否提供企业级支持，是判断其商业化成熟度的快捷指标。

## 三条冷思考

1. **橱窗位置 ≠ 销量**。上架 AWS 只是拿到入场券，真正的分水岭是企业客户的复购与续约数据。
2. **开源与自营会合流**。纯开源难以直接变现，纯闭源获客昂贵，“开源获客、托管变现”正在成为主流姿势。
3. **把模型当供应链管理**。记录备选模型、评估许可证条款、定期压测迁移成本——今天选“面料”还是“成衣”，决定了明天改版的自由度。
