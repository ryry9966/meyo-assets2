最近技术圈流传一个新玩法：有人把小米电视的系统应用列表丢给 Claude，AI 直接回了一份带逐行注释的 ADB 命令清单，开机广告、屏保广告、桌面推荐位十分钟清干净。帖子火了，评论区一片“原来还能这么干”的现场。有意思的是，这套操作里没有任何新知识——用 ADB 卸载广告包的教程，几年前就在论坛和 GitHub 上流传。变的不是知识，是门槛。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/e0bb82786568293a.png)

## 一、先搞清楚：广告是怎么长进电视里的

- **商业结构**：电视硬件长期低毛利。小米 2018 年公开承诺“硬件综合净利率永远不超过 5%”，大屏硬件经常贴着成本卖。钱从哪里补？操作系统侧：开机广告、屏保广告、桌面推荐位、应用商店分发、内容会员。
- **为什么盯上电视**：它是“客厅流量入口”。开机那一屏的曝光率接近 100%，比手机 App 的日活确定性强得多，广告主愿意为此付预算。
- **一个背景节点**：2019 年，江苏省消保委就开机广告无法一键关闭约谈多家电视厂商，此后“一键关闭”成为行业底线。注意措辞——是“可以关”，不是“没有”。
- **结论**：广告不是系统的 bug，而是商业模式本身。你想删的不是几行代码，是别人收入结构的一根支柱。

## 二、知识一直免费，贵的是“最后一公里”

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/62f8cdc55ed83f60.png)

社区早就把路趟平了，常见三条路线：

1. **ADB 路线**：电视进入开发者模式，`adb connect <电视IP>` 连上后，用 `pm list packages` 列出全部应用，挑出名字带 ad、push、shop、recommend 的包，`pm uninstall --user 0 <包名>` 逐个移除。
2. **DNS 路线**：路由器上跑 AdGuard Home 或 Pi-hole，加载社区维护的域名屏蔽列表，让广告请求在解析阶段就失败。
3. **设置路线**：最温和——关闭屏保推荐、退出“个性化推荐”，能去掉一部分。

方法五分钟就能搜到，但真实的操作链条长得多：找帖子 → 确认机型和系统版本对得上 → 对着命令猜风险 → 报错了回去翻几百楼。每一个环节都在筛人，最后留下的只有动手能力强的少数派。

AI 改变的是这条链路的形状：

- **翻译**：把论坛黑话翻译成针对你机型的具体步骤，逐行解释这条命令在动什么；
- **排错**：`adb: device offline`？贴给 Claude，它提示你重新授权 USB 调试；
- **风险标注**：哪个包删了会丢账号登录，哪个只是推荐位，删了没副作用。

本质上，LLM 把“读十篇帖子 + 交叉验证”压缩成一场对话。知识没有变多，获取知识的成本降了一个量级——这才是这条热搜真正值得记的东西。

## 三、动手之前，把这几件事刻进脑子

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/4932f9e51313510b.png)

AI 是好副驾，但它会幻觉，而且不为你的电视负责——责任这种东西，目前还没有 API。

1. **优先选可恢复的操作**。`pm uninstall --user 0` 只是对当前用户卸载，系统分区原封未动，想恢复时 `cmd package install-existing <包名>` 一条命令请回来。凡是涉及 root、刷分区、改系统文件的选项，先停手。
2. **关键命令交叉验证**。AI 给的包名可能是编的。正确姿势是先让它分析你跑出来的 `pm list packages` 真实输出，而不是直接要一份“通用清单”。动手前把原始列表存档。
3. **DNS 屏蔽别一刀切**。把厂商域名全拦掉，广告是没了，账号登录、OTA 系统更新可能也一起没了。让 AI 帮你区分“广告域”和“功能域”，宁可多留几个。
4. **预期管理**。系统 OTA 更新大概率会把广告包请回来。这是一场持久战，不是一次性手术。

## 四、如果人人都屏蔽成功，行业会怎样

- **对抗升级**：厂商可能把广告逻辑挪进核心服务进程，提高屏蔽代价，或者默认收紧开发者模式、检测 ADB 状态。
- **商业迁移**：广告换会员。“无广告会员”并没有消灭那笔钱，只是收钱对象从广告主换成了用户。逻辑没变，付钱的人变了。
- **也有正向可能**：当“系统干净程度”变成选购参数，厂商会开始比谁预装少、谁的广告克制——就像当年手机行业比拼预装软件。竞争压力有时比什么都好使。
- **一个参照系**：浏览器广告拦截插件和网站的猫鼠游戏跑了十几年，结局是共存——网站学乖了，用户也习惯了为好内容付费。

## 最后，三条冷思考

1. **AI 这次真正的价值，不是“帮谁干了活”，而是把原本属于极客的知识交还给普通人。** 电视广告只是开始，往下一步可能是家电去云化、设备本地化控制。稀缺的不再是教程，是会提问的人。
2. **屏蔽广告是止痛药，不是解药。** 根源在于“硬件贴钱卖、软件赚回来”的模型。长期解法只有两个：定价诚实，或者用户持续用钱包为干净的系统投票。
3. **能力升级了，责任也要升级。** AI 既降低了动手的门槛，也降低了搞坏东西的门槛——`--user 0` 和 root 之间隔着的，就是“能恢复”和“变砖”的距离。
