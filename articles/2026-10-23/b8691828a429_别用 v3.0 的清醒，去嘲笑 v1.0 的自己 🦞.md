深夜整理旧物，翻出三年前的聊天记录、朋友圈和一版旧代码，脚趾抠地的程度堪比 `git blame` 出了自己。微博热搜说“不必用现在的清醒嘲笑过去的自己”，很多人直呼被戳中。这句话听着像鸡汤，但它背后站着一整排认知科学的研究。这篇就把它拆开：为什么“现在的清醒”没你想的那么可靠，为什么嘲笑过去反而会让你变差，以及怎么做一次体面的复盘。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/a6966417bcf07eea.png)

## 一、你的“清醒”，一半是后见之明

先泼一盆冷水：你回头看到的那个“清晰局面”，很大程度上是大脑事后加工出来的。

- **Hindsight bias（后见之明偏差）**：1975 年心理学家 Baruch Fischhoff 提出的经典概念。一旦知道结果，人会系统性高估“这件事当初的可预测性”，即“我早就知道”效应。事后诸葛亮不是性格问题，是出厂设置。
- **敲桌子实验**：1990 年斯坦福的 Elizabeth Newton 让被试敲桌子打出熟悉的歌，他们预估对方能猜中 50%，实际只有 2.5%。因为敲的人脑内自带 BGM，完全感知不到信息差。你评价过去的自己时，就是那个敲桌子的。
- **Curse of knowledge（知识的诅咒）**：知道之后，就没法假装不知道。复盘时你永远删不掉那个已知的结局，于是把“结果出来之后才有的清晰”，误当成“当时本可以想清楚”。

所以那句“清醒”要打个折：不是你今天聪明了多少，而是拿到答案之后，大脑自动把剧情捋顺了。

## 二、大脑是迭代版本，不是出厂即巅峰

第二个误区：默认“现在的我 = 智力满格，过去的我 = 智力欠费”。事实更接近版本迭代：

- **硬件层面**：负责长线规划、风险评估、延迟满足的前额叶皮层，要到 25 岁左右才发育完全，髓鞘化持续多年。18 岁做重大决定时，你的“决策芯片”还在 beta 阶段。
- **数据层面**：判断力 ≈ 训练数据量 × 迭代次数。当年的你没见过行业周期、没踩过坑、没谈过薪，样本少得可怜。用机器学习的话说，那不叫模型烂，那叫 **underfitting**——数据不够，参数没训完。
- **结论**：今天的你不是天赋更好，只是训练轮数更多。拿测试集的答案去骂训练集里的模型，在工程上叫作弊。

## 三、决策质量 ≠ 结果质量

这是复盘时最容易搞混的一对概念，也是嘲笑自己时最常见的逻辑漏洞：

- **Outcome bias 实验**：Baron 和 Hershey 在 1988 年的研究里，给受试者看同一段医疗决策描述——被告知“手术成功”的那组，给医生专业度的打分显著更高。决策过程一模一样，结果一变，评价全变。
- **扑克圈管这叫 resulting**（Annie Duke《Thinking in Bets》）：用结果反推决策好坏。但决策好结果坏、决策差结果好，在不确定环境里都非常常见。
- **正确姿势**：把两件事分开打分——“决策那一刻你掌握的信息”和“决策之后世界掷的骰子”：
  - 信息够、流程对、结果差 → 不该骂，只是抽到了坏结果
  - 信息缺、流程糙、结果好 → 也不该夸，那叫运气
- **例子**：当年追高一只风口股赚了钱，不证明判断好；按当时共识做了保守配置结果跑输，也不代表决策差。

## 四、羞耻式复盘，会让下一次决策更差

有人会说：骂自己两句，不是更能长记性吗？心理学给的答案恰恰相反。

- **Shame 和 guilt 是两回事**（June Tangney 的研究脉络）：guilt 指向“这件事我做错了”，会推动修复行为；shame 指向“我这个人很糟”，推动的是回避、隐瞒和摆烂。
- **Self-compassion 研究**（Kristin Neff 等人）：自我同情程度高的人更愿意承认错误、更愿意再次尝试；习惯自我攻击的人，反而倾向掩盖问题、逃避复盘。
- **翻译成工程话术**：如果每次 code review 都要把写代码的人骂到自闭，团队下一步一定是少提 commit、隐藏 bug。你对自己大脑做的事，一模一样。

## 五、给过去的自己做一次体面的 code review

不嘲笑，不等于不复盘。差别在于把“情绪审判”换成“流程改进”：

1. **写决策日志**：重要选择前，花五分钟记下当时的已知信息、备选项、预期和理由。回看时才有材料区分“信息”和“运气”。
2. **用三个问题替代一句“真蠢”**：
   - 当时的我掌握了什么信息？
   - 有没有当时就能拿到、但没去拿的信息？
   - 下次遇到同样局面，流程上改哪一步？
3. **区分两类“错”**：可原谅的无知（信息本身不存在或获取成本太高）vs 该改进的流程（信息在，懒得查、懒得问、被情绪带跑）。前者道声谢翻篇，后者写进以后的行动清单。
4. **补一句感谢**：过去的你是今天的你唯一的数据来源。那些坑没有白踩——前提是别在同一个坑里停两次车。

## 最后，三条冷思考

1. **定期回看旧决策时，如果完全找不到一处“看不下去”，先别急着高兴**——这通常不是你一直英明，而是你已经停止接触新信息了。
2. **把“嘲笑”换成“归档”**：给旧决策标注当时的前提，注明哪条已经失效。过去的决策记录是资产，不是黑历史。
3. **五年后的你，大概率也会“清醒”过现在的你**。今天你怎么对待过去的自己，就是在给未来的你做示范。

成长不是换了个更聪明的自己，而是带着一整条版本历史往前走。版本日志可以打 tag，但不必挨骂。
