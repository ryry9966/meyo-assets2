过去一年，"个人智能体"（Personal Agent）从 demo 走上了发布台：替你订机票的、操作浏览器填表的、在手机上代点外卖的，一个接一个上线。演示视频里它们行云流水，可真派它去干活，你就会发现：绝大多数 App 的门，根本没给它开。这不是某个产品的 bug，而是一场围绕接口、流量和定价的产业博弈。今天把它拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/5955540501423b19.png)

## 智能体干活的三条路，条条有收费站

智能体要"替你操作"，技术上只有三条路径：

1. **API 直连**：最稳、最便宜，但前提是对方开放接口。现实是，绝大多数消费级 App 根本没有公开 API，有的大多也只开放读取，不开放写入和下单。
2. **浏览器 / 屏幕操作（GUI Agent）**：用视觉模型"看"界面、模拟点击，像人一样用 App，比如 Anthropic 的 Computer Use、OpenAI 的 Operator。代价是慢、贵、脆——页面一改版就可能失灵。在 WebArena 这类公开评测里，早期顶尖 agent 的任务完成率长期只有 15%~30%，和 demo 里的丝滑是两回事。
3. **系统级自动化**：Android 无障碍接口、手机厂商的 agent 协议。权限收紧、机型适配成本高，走不远。

再算一笔数学账：一次订机票约 30 步操作，就算每步 95% 正确，整单成功率只剩 0.95³⁰ ≈ 21%。agent 的可靠性不是线性叠加的，是指数衰减的。

## App 不开门，其实是三本账在打架

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/048c4c0f867be65e.png)

**第一本：广告账。** 多数消费 App 靠广告和用户时长赚钱。agent 替你"直达结果"，意味着不刷信息流、不看开屏广告、不为推荐系统的冲动点击买单——平台变现漏斗被从中间抽走了一节。

**第二本：数据账。** 你用得越少、agent 用得越多，App 就从"产品"退化成"管道"，用户关系被 agent 平台截走：你以后只记得你的助手，不记得哪家 App 帮你订的票。

**第三本：风控账。** 平台花十年修的反爬体系——验证码、设备指纹、行为风控——本来防的是黄牛和爬虫。一个合法 agent 发出的请求，在服务端和恶意脚本长得几乎一样。验证码对人类是考验，对 agent 是劝退；门开得越大，坏人进得越顺手。

历史也早有剧本：淘宝多轮封停第三方接口、微博几度收缩 API、Twitter/X 把 API 改成高价订阅。龙虾壳硬，不是讨厌外面的世界，是真有东西想吃它；App 门关得紧，是同一个道理。

## 协议在补课：MCP 解决"怎么连"，不解决"愿不愿意连"

- 2024 年底 Anthropic 开源 **MCP（Model Context Protocol）**，让模型用统一协议连接工具和数据源，OpenAI、Google 相继跟进，工具生态肉眼可见地长了出来。
- 围绕 agent 的授权机制也在推进：OAuth 的委托授权、作用域限定的 token、操作日志与审计，都在回答"机器拿着你的权限办事"如何可控、可撤销、可追责。
- 但协议解决的是接口语言，解决不了动机。就像有了通用插头，不代表每家都愿意给你供电——插头问题靠工程，供电问题靠商业。

## 哪些门会先开？看钱的流向就知道了

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/e5865bc1ee9f28d7.png)

判断一个 App 愿不愿意接 agent，先看它怎么赚钱：

1. **交易抽佣型**（旅行、电商、本地生活）：agent 带来真实订单，平台赚佣金还能拿到归因数据，最愿意开门。关键词是"带归因"——得让平台知道这单是谁带来的。
2. **订阅工具型**（日历、邮件、办公套件）：没有广告冲突，agent 用得越多，产品价值越高，续费意愿反而上涨。这类门会最先大方打开。
3. **广告变现型**（信息流、内容平台）：agent 是天敌，短期最不情愿开门。

还有一个信号可看"谁在主动修门"：平台自己发布官方 agent、开放带计费标准的接口，说明它想通了分成模型；只做 agent 不开 API 的，多半是想把流量和心智留在自家围墙里。

## 收尾三条冷思考

1. **给普通用户**：现阶段把 agent 当"副驾驶"而非"代驾"。支付、确认、删除这类高危动作留在人工环节（human-in-the-loop）；授权一律走官方 OAuth 流程，别把账号密码抄给任何第三方。
2. **给开发者**：别赌"人人都会开放 API"。优先选有佣金体系、有官方接口的场景；同时给"接口不通"准备降级路径——浏览器模拟只能是过渡方案，不是终局。
3. **给观察者**：评估 agent 生态别看发布会，看两个硬指标——可调用接口覆盖率、真实任务完成率。至于那些关着的门，别急着骂：门不会因为技术进步自动打开，只会因为利益对齐慢慢打开。
