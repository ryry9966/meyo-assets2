前沿模型公司最爱讲"差异化"的故事，Anthropic 尤其如此：安全文化、工程师气质、不追消费级热点，一度是它的标签。但 2025 年，Claude 一口气补上了联网搜索、深度研究（Research）、跨对话记忆、工具集成——把三家的产品摆在一起，普通用户已经很难一眼认出谁是谁。36kr 把这件事概括为"Claude 终于忍不住抄作业了"。这篇我们就认真聊聊：Claude 抄了什么，为什么全行业都在抄，以及"抄作业"背后真正值得你关注的信号。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/10e430a94ac71d69.png)

## 先对答案：Claude 补了哪几门课

把时间线排开，这份"作业"大致有这几门：

- **联网搜索**：2025 年 3 月 Claude 支持实时 web search。而 ChatGPT search 在 2024 年 10 月已全面开放，Perplexity 更早把"会查资料的助手"变成了默认体验。
- **深度研究**：Google Gemini 的 Deep Research 于 2024 年 12 月上线，OpenAI 跟进于 2025 年 2 月，Claude 的 Research 随后推出。技术思路几乎一致：任务分解 → 多轮检索 → 汇总成带引用来源的报告。
- **记忆与个性化**：ChatGPT 的 memory 2024 年初上线；Claude 随后跟进，能跨对话记住项目背景与偏好。
- **工具集成**：接入 Google Workspace 等连接器，对标 ChatGPT 的 connectors 生态。

但要说句公道话：Claude 不是只抄不写的差生。artifacts、Claude Code、以及 2024 年 11 月开源的 MCP（Model Context Protocol），都是它先交的卷子——其中 MCP 后来被 OpenAI、Google 相继兼容，属于"自己被全班抄"的少数派。

## 为什么全行业都在抄：三股推力

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/b05957a2ca5a3767.png)

"抄作业"听起来不体面，但拆开看，它是竞争结构决定的必然：

1. **用户预期被锚定**。ChatGPT 定义了"AI 助手"的默认形态。用户不会分别背三家的功能清单，只会拿最强的那位当基准线——你缺一项，留存和转化数据立刻说话。
2. **技术是公开的，能力是收敛的**。主流模型同源于 Transformer 架构与 RLHF 一类公开训练方法；深度研究类功能的技术栈——查询分解、迭代检索、引用合成——没有黑魔法，别人做出来之后的跟进窗口期通常只有几个月。
3. **商业模式倒逼功能清单**。订阅制要证明 20 美元/月这一档的合理性，企业客户要搜索、要合规、要接入自家数据。于是"标配清单"越拉越长，留给"人无我有"的空间越来越窄。

所以更准确的说法是：全班面对同一张考卷，题目（用户需求）一样，教材（公开技术）一样，答案自然趋同。参考答案就摆在同一间教室里，还免费。

## 抄什么、不抄什么，才是真问题

Anthropic 抄的是"形"，守的是"位"：

- **主战场仍在开发者与编程**：Claude Code 和 API 侧的编码能力是它的招牌，多方报道显示其收入高度依赖编程与 API 场景，而非消费级聊天。
- **用开放标准换生态位**：MCP 开源，相当于主动把作业本借给全班抄，换来的是工具生态的事实标准地位——类似当年 Android 的打法。
- **安全与对齐当品牌**：在 computer use 这类 agent 能力上步伐并不慢，但宣传口径明显更克制。

反过来，OpenAI 也在"抄"Anthropic：agent 化、兼容开放协议。整个行业处在追赶—反超—再追赶的循环里。功能趋同之后，竞争重心转移到分发、生态和信任——这三样，抄不来。

## 普通用户和开发者的判断框架

- **用户视角**：功能打平意味着"全家桶比价时代"来了。选品逻辑从"谁功能多"切换成"谁在我的工作流里稳定、谁的数据政策我放心"。
- **开发者视角**：默认"平台半年内会补齐通用能力"。没有私有数据、分发渠道或深度工作流绑定的薄壳应用，护城河会持续变浅。
- **一个低成本动作**：把同一个真实任务——例如"读完三份 PDF、联网核对关键数据、输出结构化报告"——同时投给两三家模型，看结果，而不是看发布会。

## 冷思考：三条建议

1. **别用"有没有"评估产品，用"好不好"评估。** 功能清单趋同后，同一功能的质量差距（引用准确率、任务完成率）才是真正的区分度。攒一个自己的小型评测集，比追十场发布会有用。
2. **把趋同当作技术成熟度信号。** 当头部玩家集体补同一门课，说明该能力已从"亮点"降级为"标配"——这往往是采购和迁移的好时点：价格更卷，服务更好谈。
3. **想清楚你手里"抄不走"的东西。** 对企业与个人都一样：数据资产、沉淀的工作流、验证过的评测方法——模型换代的浪打过来时，这些才保得住。

全班答案一样，不代表考试结束，只说明这道题不再给分。真正的分差，在下一道大题。
