最近一条 36kr 热搜把 Anthropic 顶上了风口：一贯以“克制”“只管把模型做好”形象示人的 Claude，密集上线了文件生成、记忆、联网搜索等一揽子功能——而这些几乎全是 ChatGPT 玩了两年的“老作业”。网友调侃“Claude 终于忍不住抄作业了”。热闹之外，有个更值得聊的问题：为什么所有 AI 助手最后都长得越来越像？“抄作业”背后到底是偷懒、跟风，还是行业规律？这篇拆给你看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/a772876470f7412f.png)

## 先对时间线：Claude 到底补了哪些课

把功能清单拉出来，“趋同”的痕迹非常明显：

1. **联网搜索**：2025 年 3 月开放，比 ChatGPT 的联网浏览晚了大约一年半；
2. **记忆（Memory）**：跨对话记住用户偏好与项目背景，ChatGPT 早在 2024 年就已上线；
3. **文件创建**：2025 年 9 月推出，能在沙箱里直接产出带公式的 Excel、排好版的 PPT 和 Word——这正是 ChatGPT“数据分析 + 文件导出”的核心场景；
4. **更早的 Artifacts（对标 Canvas）、Projects（对标自定义 GPT）**：交互形态也高度相似；
5. 连订阅定价都整齐对齐在了“每月 20 美元”这一档。

单看每一项都算不上首创，但一次性补齐，说明 Anthropic 的产品策略确实变了：从“模型即产品”转向“体验即产品”。这家以安全研究立身、靠 API 和企业客户起家的公司，开始正面进入消费级体验竞争。

## “抄作业”的技术底细：没有魔法，全是工程

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/363c11cd297cc33a.png)

先泼一盆冷水：这些功能没有一个涉及未公开的黑科技。

- **联网搜索的本质是 RAG（检索增强生成）**：把你的问题改写成检索 query → 调用搜索引擎 API → 对网页去重、重排 → 拼进模型上下文 → 生成附引用的答案。任何一家都能做，差距在检索排序质量与引用准确率。
- **记忆是分层存储**：短期靠上下文窗口，长期靠摘要压缩加向量检索——把“你告诉过它的事”存成条目，下次对话前按相关性注入 prompt。难点不在“存”，而在“该记什么、何时忘、如何避免张冠李戴”。
- **文件生成靠代码执行**：模型并不直接吐出一个 .xlsx，而是在沙箱环境里跑 Python（openpyxl、python-pptx 这类库），先算数据再生成文件，出错还能自检重跑。

一句话总结：这些功能 = 模型 + tool use + 系统工程。论文、开源实现、最佳实践全是公开的，题库就摆在桌上，“抄得像”丝毫不奇怪——毕竟科技圈的作业本向来是公开传阅的。

## 为什么 AI 产品必然越长越像

- **需求收敛**：全球用户想要的东西高度一致——帮我查、帮我算、帮我记住、帮我交付一份能直接用的文件。需求相同，答案自然趋同。
- **技术收敛**：RAG、tool use、memory 是行业通用件，没有专利墙，开源社区甚至有现成轮子。
- **商业压力**：ChatGPT 周活跃用户已达数亿量级，跑通了“海量用户 → 订阅收入 + 数据飞轮 → 摊薄推理成本”的循环；Anthropic 此前重心在 API 与企业客户，C 端是明显短板。推理是烧钱生意，没有高频 C 端场景，账单很难看。
- **历史参照**：浏览器大战、智能手机的全面屏与快充，最后都是“你有我有全都有”。

所以，功能趋同是品类成熟期的常态，不是抄袭判决书。真正的分野从来不在“有没有这个功能”，而在实现质量。

## 抄作业容易，对答案难：真正的护城河在哪

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-23/e2afb29a44d3cce4.png)

- **模型底子**：代码能力、长上下文、指令遵循的硬差距。Claude Code 能在开发者圈立足，靠的是模型实力和工程质量，不是功能清单长度。
- **工程细节**：同一个 RAG，检索质量差 20%，体验就是“能用”与“没法用”的区别；表格公式的正确率、文档排版的审美，处处见功力。
- **场景纵深**：MCP 协议、企业系统集成、办公生态对接，是功能列表之外的第二战场，也是 Anthropic 原本最强的地盘。

给普通用户一个判断框架——别问“有没有”，问三件事：

1. **准确率与幻觉率**：拿你专业领域最刁钻的 5 个问题实测，看谁错得少、错得诚实；
2. **交付物质量**：生成的表格、文档能否直接拿去用，还是总要返工；
3. **数据政策**：对话是否默认用于训练、记忆能否关闭、企业数据是否隔离。

## 最后三条冷思考

1. **给用户**：AI 功能会持续趋同，别为单个功能换订阅。用自己的 10 个真实任务当 benchmark，跑完再决定钱包投给谁。
2. **给从业者**：凡是“模型 + 通用工具”就能实现的功能，默认会被所有大厂补齐。创业要么在垂直数据和私有工作流上做深，要么把“被下一代模型更新覆盖”写进风险清单。
3. **给观察者**：AI 竞争已经从“单点功能创新”进入“工程化整合”阶段。值得盯的是推理成本曲线、agent 任务完成率和安全评估数据，而不是发布会上的功能数量。

抄不抄作业其实不重要，重要的是——谁先把答案做对。
