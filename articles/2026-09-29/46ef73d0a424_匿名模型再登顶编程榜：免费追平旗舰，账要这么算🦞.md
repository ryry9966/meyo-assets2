每隔几个月，编程模型榜单上就会冒出一个没有名字、没有白皮书、没有官宣的"神秘选手"：匿名上线、免费开放，分数一路爬到与顶级旗舰平起平坐，然后全网考古队连夜开工，猜它背后是谁。这次的主角剧本照旧——匿名、免费、编程能力追平 GPT-6 Astra。比起"它到底是谁"，更值得聊的是三个问题：匿名上分是怎么操作的？免费怎么算得过账？榜单分数又能信几分？

## 匿名上分，其实是一套成熟打法

匿名测试不是新鲜事，它早就成了头部实验室的标准流程，2024 年神秘出现的 gpt2-chatbot（后被证实是 GPT-4o 的前身测试）就是经典开局，此后各家都沿用至今。背后的逻辑大致有四条：

- **盲测去光环**：一旦评测者知道模型出自哪家，打分难免带上品牌滤镜。匿名之后，人类盲测的 Elo 分数更接近真实偏好，这对研发迭代是高价值信号。
- **真实流量压测**：内部 benchmark 再全面，也模拟不了互联网用户的千奇百怪。上线前用匿名身份接真实流量，是最便宜的 infra 压测，顺手还能收集长尾 bad case。
- **握住发布主动权**：匿名账号可以随时改名、换权重、悄悄下线，不触发"官宣跳票"的公关成本，节奏完全自己掌握。
- **顺手的营销**："猜猜我是谁"本身就是免费广告，正式发布前两周，社区讨论度已经拉满。

所以"匿名"不是遮掩，而是一套刻意设计的测试 + 发布组合拳。

## 免费追平旗舰，商业账怎么算？

上一代旗舰级的能力，如今能以免费层放出来，背后是两条曲线和几副算盘：

- **推理价格雪崩**：过去两年，同等能力的推理价格大约每 9~12 个月降一个数量级。一年前还烧钱的旗舰能力，今天的边际成本已经低到可以"撒"给开发者。
- **免费的几副算盘**：
  1. **数据飞轮**——真实的 coding 工作流（报错、修复、agent 轨迹）是最稀缺的训练数据，用免费额度换遥测与反馈，划算；
  2. **抢生态位**——开发者先用免费模型把 prompt、工具链、CI 集成搭好，迁移成本自然把人留住；
  3. **削峰填谷**——夜间闲置 GPU 跑免费流量，边际成本没有想象中高。

但要划一个重点：追平的是"榜单分"，不一定追平生产体验。长上下文的稳定性、tool calling 的可靠性、并发与 rate limit，都可能是免费版的缩水项。分数是平均数，你的任务是分布里的某一个点。

## 编程榜单的含金量，要打个几折？

"追平 Astra"这句话的信息量，取决于榜单测的是什么：

- **人类盲测类**（如聊天竞技场）：pairwise 对比 + Elo/Bradley-Terry 算分，优点是贴近人类偏好，缺点是偏"讨好型"回答，代码正确性靠人眼在有限时间内判断，容易失真。
- **竞赛题类**（如 LiveCodeBench）：从竞赛平台按时间窗口抽新题，训练时没见过，是近年相对硬的防污染指标。
- **真实 issue 修复类**（如 SWE-bench Verified）：丢给模型一个真实仓库加一个 GitHub issue，考的是 agentic 全流程。同一个模型换一套 agent 脚手架，分数能差 10 个点以上——你测的其实是"模型 + 框架"的组合。

常见的阅读陷阱还有三个：pass@1 和 pass@k 是两回事，别混着比；"能过测试用例"不等于"写对了"，测试覆盖不全时尤其如此；题面泄漏进训练数据（contamination）的模型，分数会虚高。正确的读法是：在某个评测组合、某个脚手架下，平均分接近——它不等于在你的任务上两者一样好。

## 把榜单分数，翻译成自己的结论

与其围观排名，不如花一个下午做三件事：

1. **拿真实任务复测**：从自己的 repo 里挑 10~20 个典型任务——一个 bug 修复、一次重构、一段迁移脚本——用统一口径跑一遍。这比看任何榜单都有用。
2. **读清免费条款**：免费层的数据会不会用于训练？rate limit 给多少？匿名期转正后会不会涨价砍配额？答案在 ToS 里，不在热搜里。
3. **别急着换栈，先跑影子流量**：把匿名模型当"备胎"，与现役模型双跑一周，对比一次通过率和返工次数，再决定要不要迁。

一句话：把榜单当筛选器，把真实任务当判决书。

## 三条冷思考

1. **榜单是筛选器，不是判决书**。它只回答"值不值得测"，不回答"值不值得用"。分数平价化的时代，拉开体验差距的是上下文工程和工具链，而不是 0.5 分的 Elo。
2. **免费是策略，不是慈善**。你省下的 API 费用，可能以数据、迁移成本或生态锁定的形式付回去。算总账，别只看单价。
3. **能力平价化是大趋势**。前沿模型的领先窗口越缩越短，护城河正从"模型更聪明"转向"工程整合更快"。对开发者这是好消息：上游卷得越凶，你手里的杠杆越便宜。等神秘选手揭面那天，先看正式定价和条款，再决定要不要追。
