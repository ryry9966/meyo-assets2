一份被媒体曝光的 Anthropic 招股文件，最近在科技圈刷了屏：营收 46 亿美元、亏损 420 亿、算力承诺 5180 亿、估值 2 万亿。第一眼像乱码——亏损是营收的九倍，估值是营收的四百多倍。这账显然不是用 Excel 算出来的，是用预期乘以斜率算出来的。下面把四个数字挨个拆开，看它们各自躺在财报的哪个位置、为什么长成这样（具体口径以最终披露为准，这里拆的是逻辑）。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/a97e98304cf2f863.png)

## 先把四个数字放上四条时间轴

这四个数最容易被塞进同一个标题，其实分属完全不同的时间轴和会计科目：

- **46 亿营收（过去式）**：Anthropic 的收入基本盘是 Claude 的 API 调用与企业订阅。注意两个口径的区别——媒体常把某个月收入乘以 12 得到的 annualized run-rate，和会计上确认的营收混着说，前者好看，后者才算数。
- **420 亿亏损（损益表结果）**：到底是年度亏损还是累计亏损，各路报道口径不一，但量级本身就是信息。AI 实验室的亏损构成通常是三块：算力租用与训练成本、研发折旧摊销、巨额股权激励（SBC）。SBC 不流出现金，算力账单可是真金白银，得分开看。
- **5180 亿算力承诺（将来时）**：这不是"已经花掉的钱"，而是与云厂签下的多年期采购合同，未来若干年必须履行，性质接近 take-or-pay。
- **2 万亿估值（对未来的折现）**：传统 SaaS 上市普遍按 10~20 倍市销率定价，这里直接给到四百多倍，市场定价的不是利润，是那条指数增长曲线。

一句话：把四条时间轴不同的数字塞进同一个标题，冲击力就有了，可比性未必有。

## 为什么"越卖越亏"：成本结构写死的剧本

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/a09854a10d722bb9.png)

- **训练是入场券**。一次前沿模型的训练 run，公开测算普遍在数亿到数十亿美元量级，而且每换一代模型都要重新交一遍学费。
- **推理是永不停表的电费**。模型训完才是花钱的开始：每一次 API 调用都占用 GPU 时间，token 卖得越多烧得越快，收入与成本是同步上扬的两条曲线，差距全看效率。
- **毛利取决于利用率**。卖 token 的价格，减去算力成本和折旧，才是真毛利。GPU 集群闲着也照样折旧，利用率上不去，毛利就是负的。
- **云厂交易的结构性绑定**。Amazon 累计投资 80 亿美元、Google 多轮注资，再加上 Microsoft 与 NVIDIA 参与的 Azure 算力大单，资本以"股权投资 + 算力采购承诺"的组合进场。钱从股东手里进来，又以算力账单的形式流回云厂——市场对这类"循环交易"的质疑从未停过。

所以"亏损 420 亿"不等于"烧掉 420 亿现金"，但它确实说明：在现有收入结构下，这门生意的单位经济性（unit economics）还没跑正。

## 5180 亿算力承诺：签下的是"未来的固定成本"

- **Take-or-pay 的本质**：不用也得付。和航空公司在油价低位锁定十年燃油、芯片厂提前锁定产能是同一个逻辑——用确定性换价格。
- **为什么敢签**：算力是当下最硬的稀缺品，锁量能拿到供应优先级和折扣价；对云厂来说，这也是把大客户长期绑在自己机架上的办法，双方各取所需。
- **风险藏在折旧曲线里**：H100 级别的加速卡，会计上通常按 3~6 年折旧，技术上的有效寿命可能更短。下一代模型一旦改变硬件需求，手里的卡就可能"账面有值、市场上没价"。
- **一个判断式**：算力承诺是资产还是负债，取决于"利用率 × 单位经济性"。满载运转是护城河，空转就是堰塞湖。

## 2 万亿估值：市场在给"斜率"定价，不是给"利润"

- **估值数学很粗暴**：假设营收几年内从 46 亿冲到 300~500 亿美元并守住 50% 以上的毛利率，2 万亿大致对应 40~60 倍远期市销率——听起来就没那么离谱了，但这根前提链条的每一环都不能断。
- **敏感性极高**：增长率从 100% 掉到 50%，收入拐点后移两年，估值模型就会塌方式下修；反过来，一款爆品也能让斜率陡起来。估值的波动，本质是对斜率的投票。
- **历史给过两种结局**：Amazon 亏损近二十年，把亏损换成了物流网络和 AWS 的飞轮；也有大量公司倒在现金流断档的前夜。区别从来不在"亏不亏"，而在亏损买到的是可复用资产，还是纯消耗性费用。
- **一个参照系**：这轮周期里最确定的利润，目前更多被 NVIDIA 这类"卖铲子的"赚走。模型公司的账本，反而是全产业最激进的那一本。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/99ae53e1f5a19b1e.png)

1. **看 AI 公司先看三个数**：毛利率、算力承诺/年营收比、现金及等价物还能撑几个月。这三个数比"估值多少"能多透露十倍的信息量。
2. **对数字保持时间感**：分清"已发生的、本年度的、多年累计的"三种口径。很多惊悚标题的手法，就是把十年的算力承诺压缩成"一年亏掉的钱"来讲。
3. **建立算力周期思维**：任何以"算力 = 资产"为前提的估值，都值得追问一句——三年后这批 GPU 跑的是什么模型、按什么价格折旧、还能不能满载。

账可以算得很大，但真正决定谁能游到终点的，往往是单位经济性这种小账。虾米虽小，也是"单位"。
