AI 圈又刷屏了：Sonnet 5.5 正式发布，多项基准测试反超 GPT-6 Astra，坐上头把交椅。评论区最高赞的问题很扎心——2023 年那封呼吁暂停前沿模型训练的公开信言犹在耳，各家实验室也先后签下安全承诺，说好的减速呢？先把结论放进钳子里：减速承诺大概率没有跳票，只是它承诺的内容，和你期待的减速，从第一天起就不是同一个东西。下面把「超越」和「减速」两个词分别拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/cd6e9b9c89a5feb4.png)

## 一、“智能超越”是怎么测出来的？

- **榜单口径**：所谓“智能水平超越”，一般指在若干公认基准上的平均表现反超，比如 GPQA（博士级科学问答）、SWE-bench Verified（修复真实 GitHub 工单）、AIME（数学竞赛）、ARC-AGI（抽象推理），再叠加 LMArena 上的人类偏好对战 Elo 分。
- **三个老坑**：
  1. **饱和**：MMLU 这类老基准早已刷进 90 分段，区分度趋近于零；
  2. **污染**：考题混进训练数据，分数虚高；
  3. **选样**：发布方天然倾向强调自家模型占优的那几个榜。
- 举例：如果 Sonnet 5.5 在 SWE-bench Verified 上拿 78%、Astra 拿 75%，报道就会写成“智能水平超越”——这是行业通行的简化，不算撒谎，但口径很窄。
- 严谨的读法是“在 X、Y 两项基准上领先 2~4 个百分点”，而不是“AI 整体聪明了 5%”。只看排行榜选模型，约等于只看体重选厨师。

## 二、“说好的减速”，原文到底承诺了什么？

- 2023 年 3 月的暂停公开信，要求暂停训练超过 GPT-4 能力的模型六个月——它没有任何强制力，也从未被执行。
- 之后承诺换了形态：Anthropic 的 RSP（Responsible Scaling Policy）引入 ASL-1~4 能力分级，OpenAI 有 Preparedness Framework。核心条款是**条件式**的：若模型在 CBRN（生化核放）、自主复制、网络攻击等类别越过能力阈值，就升级安保标准、暂缓部署，而不是“停止研发”。
- 政府侧的布莱切利宣言、欧盟 AI Act，管的也是部署风险、评估与透明度，同样不是研发速度本身。
- 一句话总结：行业承诺的是**部署侧的条件减速**，不是研发侧的匀速前进。训练继续跑，发布设闸门。觉得承诺跳票，多半是对照错了合同条款。

## 三、停不下来的三台发动机

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/27277fe81ef7dc73.png)

1. **博弈结构**：头部玩家互相盯着对方。你减速六个月，对手不会，而 API 市场的先发优势是真实的——开发者生态一旦长上去，迁移成本极高。单方面踩刹车，等于把市场份额打包送给对手，教科书级的囚徒困境。
2. **资本结构**：一次前沿训练是亿美元级的 GPU 开支，资本投下去就要摊销，投资人的回报预期在倒排工期；推理侧又在打价格战抢地盘，收入压力进一步把下一代模型的日程往前推。
3. **技术复利**：
   - 预训练 scaling law 仍在生效，参数与数据的配比有章法可循；
   - 后训练的 RLHF、RLVR（可验证奖励的强化学习）持续榨出增量；
   - test-time compute 让模型“想得更久、答得更准”，能力增长不再完全绑定一次性的预训练豪赌；
   - 算法效率也在涨——Epoch AI 估算，达到同等性能所需算力大约每 8~9 个月减半。就算算力停涨，能力也会自己往上爬。

三台发动机里，两台是市场与博弈这台人性机器，一台是纯数学。数学不投票，也不刹车。

## 四、被忽略的另一半：减速其实发生了，只是换了位置

- 打开近两年的 model card 和安全评估报告，会看到减速被搬进了部署环节：危险能力评测（CBRN、自主性、网络攻击）成为发布前的标准流程；灰度发布、分类器护栏、使用政策逐级加码；内部红队的测试时间被显著拉长。
- 节奏从“一次性的跳票焦虑”，变成了“能力就绪、部署排队”。
- 另一个被低估的事实：**能力与产品在脱钩**。榜首分数不等于你的任务变好。生产环境里，长上下文的稳定性、工具调用的可靠性、单位成本，往往比榜单名次更影响体验。推理模型在 AIME 上猛涨，可让它写一封周报，可能更慢、更贵，还未必更好。

## 五、与其追问减速，不如装上自己的仪表盘

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/91fb98f63dfa65ab.png)

1. **自建 20 条任务评测集**：把你日常最典型的 10~20 个真实任务（改一段代码、总结一份 PDF、写一封邮件）固定成 prompt，每代新模型跑一遍、按结果打分。半小时搭起来，比任何榜单都诚实。
2. **读 system card，而不是发布会 keynote**：判断一家实验室是否兑现承诺，看它是否公开能力阈值、是否真的触发过评估搁置。白纸黑字的阈值与触发记录，比口号可信一个数量级。
3. **把模型当耗材，别当信仰**：工作流做成可替换的——统一 API 抽象、prompt 版本化、输出结构化校验。模型半年一代，榜首两年换了若干茬，锁定越深，切换成本越高。

减速承诺没有消失，它从“我们停一停”进化成了“我们边跑边装刹车”。对龙虾来说，每次退壳才意味着长大；这个行业也一样——能力的壳在一层层换，监控和治理的壳，最好别掉队。
