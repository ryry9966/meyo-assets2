最近刷科技资讯，大概率撞见过一个神秘缩写——"Jev"。有人喊"Jev 显灵"，有人把杰文斯的画像当头像供起来，仿佛拜的是赛博锦鲤。一个 160 年前的英国经济学家，凭什么在 AI 时代一夜封神？这事不只是一个梗：背后是一条被反复验证过的经济学规律，也有它当下被过度神化的部分。这篇把它拆开看清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/f5c64d1e1b69bfbd.png)

## "Jev"不是网红，是 1865 年的经济学家

先对齐信息。所谓 Jev，指的是 **Jevons Paradox（杰文斯悖论）**，提出者是英国经济学家、逻辑学家 William Stanley Jevons（威廉·斯坦利·杰文斯）。

- 1865 年，他出版《煤炭问题》（*The Coal Question*），研究英国工业的能源命脉。彼时煤就是工业时代的"算力"。
- 当时蒸汽机技术不断改良，烧煤效率持续提升。按直觉，效率提升该让煤越烧越省。杰文斯翻遍统计数据后发现相反的结论：**英国的煤炭总消耗不降反升**。
- 他的原话大意是：认为节约使用燃料等于减少消费，是完全的观念混淆；蒸汽机的每一次改进，都让煤炭消费以新的速度增长。
- 后人把这类现象概括为：**技术进步提高了资源使用效率，总消费量反而上升**。

所以"Jev"的走红第一步就很魔幻：网友把一个 160 年前的学术概念拟人化，变成了可以拜的"显灵体"。

## 底层机制：为什么"省"反而换来"多"

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/e7c76c2e24b98de1.png)

用现代语言说，这是 rebound effect（回弹效应）的极端形态。传导链条有三段：

1. **单位成本下降**。效率提升 → 做同样的事消耗更少资源 → 单位价格跟着降。
2. **被压抑的需求被价格激活**。原本"用不起""舍不得用"的人和场景，因为便宜而入场，用量开始上升。
3. **新场景解锁**。成本跌破某个临界点后，会出现此前根本不存在的用途。这部分增量，经常吃掉甚至超过省下来的份额。

举几个跨时代的例子：

- **照明**：LED 比白炽灯省电 80% 以上，但全球照明总耗电量并没有按比例下降——灯更亮、亮得更久、景观照明这种"新物种"冒了出来。
- **蒸汽机**：改良让运输成本骤降，铁路网扩张，钢铁和煤炭全线起飞。
- **算力**：过去几十年单位计算成本指数级下降，结果不是算力过剩，而是大数据、深度学习这些"以前算不动"的问题全部涌现。

学术上的判断条件是：当**需求价格弹性大、该项成本占总支出比重高、存在大量未开发场景**三者叠加时，回弹率可能超过 100%，即所谓 backfire——省得越多，烧得越多。

## 它凭什么在 2025 年翻红

导火索是 2025 年初的 DeepSeek 时刻。当时微软 CEO Satya Nadella 在 X 上引用了杰文斯悖论："随着 AI 变得更高效、更易得，使用量将暴涨，最终变成我们离不开的商品。"这条推文被广泛解读为对"算力过剩论"的正面回击，也在中文互联网点燃了"Jev 显灵"的梗文化。

- 每当有模型公司把 API 价格打下来，评论区就有人刷"Jev 又赢了"。
- 从产业侧看，这个逻辑目前有数据支撑：主流大模型 API 的每百万 token 价格，两年间下降了不止一个数量级；但头部应用的 token 消耗量以更陡的曲线增长。
- 推理模型（reasoning model）兴起后更是火上浇油："想得越深、烧得越多"，单次任务的消耗从几千 token 涨到几万甚至几十万。
- 于是"降价 → 用量暴涨 → 总算力需求上升"这条链，在 AI 上暂时走得通。这也是"Jev 神教"能持续圈粉的底气。

## 冷静点：Jev 不是万有引力定律

热归热，得泼半盆冷水。悖论不是铁律，它成立有前提。

- **需求会饱和**。家用冰箱能效提升了好几倍，但没人会因此一天开二十次冰箱门，总耗电量确实降了。需求接近上限时，回弹会衰减甚至归零。
- **约束会换地方**。AI 场景里，就算 token 打到地板价，瓶颈可能转移到电力供应、高端 GPU 产能、数据合规，或者人类每天能分给 AI 的注意力——注意力总量是有硬上限的。
- **预言者本人也翻过车**。杰文斯当年忧心英国煤炭枯竭将动摇国本，但石油和天然气的登场直接改写了前提。机制判断对了，长期结论未必对——这是对"拜先知"行为最直接的提醒。
- 单向推理"效率↑ ⇒ 算力需求∞↑"，跳过了需求侧弹性与供给侧约束，属于把一条"观察到的规律"错当成"必然的物理定律"。

## 收尾：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/2e0dc55e92ddf3b6.png)

给做技术、做产品、做投资判断的朋友三条可操作的：

1. **效率提升 ≠ 支出下降**。做成本预算时，盯住"总消耗量"而不是"单位价格"。便宜 90%、用量涨 20 倍，账单照样翻倍——把需求弹性纳入测算，而不是拍脑袋假设"省了就是赚了"。
2. **找瓶颈要找"当前最硬的约束"**。token、电力、显存、人力审核……约束会迁移。今天的瓶颈被打下去，明天的瓶颈在别处冒头，资源规划要动态跟着约束走。
3. **警惕一切先知式叙事**。无论"Jev 保佑"还是"算力过剩"，先问三个问题：需求弹性有多大？约束在哪？这个价格解锁了哪些新场景？三问答完，比转发一句梗更能帮你做决策。

杰文斯真正留下的遗产，不是一句可供膜拜的口号，而是一套思考方式：**技术进步改变的是价格，而价格如何改写人类行为，永远要具体问题具体分析**。下次再看到"Jev 显灵"，你可以会心一笑，然后把上面三问问回去。
