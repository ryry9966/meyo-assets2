最近据 36 氪等媒体报道，字节跳动的豆包 App 正在内测“打车”功能：用户在对话里说出出发地和目的地，就能叫车、比价、完成支付，全程不用跳去别的 App。更有意思的是，豆包自己不碰运力，走的是聚合模式，接的是第三方出行服务商。一边是国内用户规模最大的 AI 原生应用之一，一边是出行市场深耕十几年的老大哥——一个“聊天框”，凭什么敢去切“方向盘”的蛋糕？这篇文章把生意逻辑和技术逻辑拆开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/465bba6aca4cf1d9.png)

## 从“陪聊”到“办事”：豆包为什么盯上打车

先看豆包的处境。公开数据显示，豆包月活跃用户早已过亿，是国内体量最大的 AI 助手类应用。但问题在于：纯聊天不太赚钱。大模型每多聊一句，就多一份 GPU 推理成本，对话本身是“烧钱换留存”，总得找到把流量变成现金的出口。

打车恰好是教科书级的好场景：

- **高频**：通勤、接送机、聚会返程，一周多次，复购天然高；
- **标准化**：A 点到 B 点、价格透明、履约结果确定，AI 理解起来几乎零歧义；
- **决策链路短**：用户几秒内就要做决定，谁能第一句话接住需求，谁就拿到订单。

再结合字节的一贯打法：抖音切本地生活、番茄切网文阅读，套路都是“流量在手，服务外包，自己收撮合佣金和广告费”。豆包做打车，本质上就是这套打法的 AI 版——只是入口从“点图标”变成了“说人话”。

## 聚合模式：不养一辆车，也能分一杯羹

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-29/2fb8c62e242b1866.png)

这不是什么新发明。2017 年高德地图上线聚合打车，2019 年美团跟进，玩法一致：平台自己不养车不雇司机，接入多家出行服务商，按撮合订单抽佣。正是这套轻资产模式，把滴滴的市场份额从早年的绝对垄断，磨到了如今行业估算的七成上下——入口的力量，可见一斑。

豆包等于照抄了这套成熟方案。技术上看，就是一次标准的 Tool Use / API 编排流程：

1. 大模型解析对话意图（起点、终点、时间、偏好）；
2. 并发拉取多家供应商的报价、预估等待时长；
3. 在对话里做推荐或让用户选择；
4. 回传订单状态、司机信息、行程跟踪。

商业上的妙处很清楚：轻资产、无车辆折旧、无司机管理成本，扩张几乎不随单量线性烧钱。代价同样明显：品控和运力调度握在别人手里，出了纠纷，用户第一个骂的还是入口。这是所有聚合平台的老毛病。

## 滴滴的护城河与软肋，各在哪一环

先说护城河，重点在**供给端**：数百万量级的活跃司机网络、秒级派单的调度算法、多年堆出来的安全合规体系（行程录音、紧急联系人、司乘纠纷处理机制）。这些是重运营、慢功夫，任何聚合平台短期都复制不了。

再说软肋，恰恰在**需求端入口**。打车是典型的工具型需求——用户要的是“三分钟来车、价格合适”，而不是“我一定要用滴滴”。这类需求的忠诚度天然稀薄，谁排在最前面就用谁。

一个类比：航空业。航司掌握着全部运力，但当订票入口被 OTA 掌握之后，用户关系和比价权就旁移了。滴滴真正该担心的，从来不是有人抢司机，而是有人抢下“用户开口说的第一句话”。

## AI Agent 时代，这场仗和以前的入口战不一样

过去切蛋糕靠补贴和买量，是真金白银砸出来的；AI 入口的竞争逻辑变了三点：

- **切换成本极低**：一个大模型接谁的 API 都行，随着 MCP 这类工具协议成熟，“换一家供应商”几乎只是改几行配置的事；
- **意图捕获前移**：未来用户可能直接说“帮我叫个最便宜的”，比价发生在对话里，App 品牌被压扁成一个看不见的后端服务；
- **交易变现升级**：从“注意力换广告”变成“成交抽佣”，单位流量的变现效率更高。

但也别高估短期。语音和对话下单在效率上未必赢得过两下点击；网约车平台牌照、各城市监管细则、安全责任划分，每一条都是硬门槛。聊天量不等于订单量，豆包能不能把留存变成高频复购，最终还是要看履约体验。

## 三条冷思考

1. **给产品人**：入口之战的本质是“意图捕获权”。如果你的产品只被当成后端 API 调用，利润就会被前端抽走。先想清楚一件事——你到底是入口，还是供给。
2. **给行业观察者**：盯住两个指标就够了——聚合模式在整个网约车盘子里的接单份额，以及豆包打车的复购率。前者看趋势是否加速，后者验证“AI 入口叫车”到底是不是真需求，还是尝鲜。
3. **给普通用户**：聚合叫车记得核对承运方和实际来车信息；大模型推荐的“最便宜”未必真便宜，“一口价”和“实时计价”的差异要自己看清。工具越方便，越值得多看一眼。
