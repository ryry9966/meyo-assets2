前不久，「大模型六小虎」中率先登陆二级市场的 MiniMax 在港交所挂牌。招股书里的成绩单并不难看：2023 年收入约 3.4 亿元，2024 年冲到约 18.3 亿元，同比增速超过 400%，海螺 AI、星野、Talkie 等产品也都有可观的用户盘子。但挂牌之后，股价一度跌破发行价，也就是俗称的「破发」。收入曲线向上，价格曲线向下，两条线为什么打架？这篇文章把它拆成三层来看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/6ce0dcf99ac3df73.png)

## 先把「破发」这个词拆开看

- **破发的定义**：股价跌破发行价。发行价不是公司拍脑袋定的「目标市值」，而是投行拿着路演材料向机构投资者询价、按认购热度「谈」出来的成交价。
- **误区一：破发 ≠ 公司不行。** 它只说明在上市这个时点，公开市场愿意付的价格，低于一级市场谈出来的价格。
- **误区二：不破发 ≠ 公司优秀。** 港股新股首日表现受大盘情绪、流通盘结构、基石投资者配置影响很大，短线资金博弈的噪音不少。
- **港股机制小知识**：没有涨跌停板、支持当日回转交易，定价偏差会在极短时间内被市场「纠错」——情绪来了暴涨，预期落空暴跌，都来得比 A 股更直接。

一句话：破发是「定价与预期的偏差信号」，不是公司质量的判决书。

## 收入涨 400%，为什么不等于「值钱」

资本市场为一个「收入」付钱，中间要过好几道折算：

1. **基数问题**。从 3.4 亿涨到 18.3 亿是 400%+，但绝对额还比不上很多互联网公司一个季度的广告收入。增速漂亮、底盘尚小，抗风险能力有限。
2. **质量问题**。C 端订阅（星野、Talkie、海螺 AI）要扣掉应用商店分成与买量成本，AI 陪伴类产品的留存和付费深度仍需长期验证；B 端 API 则卷在价格战里，2024 年以来国产大模型 API 价格一轮轮下探，「增收不增利」是行业普遍现象。
3. **成本结构问题**。大模型是「研发与算力前置、收入后置」的生意：训练集群、推理 GPU、研究员薪酬都先花钱，收入慢慢爬。招股书口径下 MiniMax 至今未盈利，亏损随投入同步放大，市场自然会问：增长的每一块钱，背后烧了多少块钱？

这不是 MiniMax 一家的问题，而是整个模型层的共性：收入在涨，但单位经济模型（unit economics）还没完全跑通。就像跑 benchmark，跑通 demo 只是及格线，跑赢基线才有性能分。

## 一二级市场的估值落差：破发的核心机制

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/d1d40be2e8d3c04d.png)

这是整件事最关键的一环，可以拆成四个机制：

- **一级市场定价逻辑**：私募轮看稀缺性、赛道叙事和「下一轮有没有人接盘」。大模型是过去两年最热的叙事，MiniMax 上市前的融资估值已按数十亿美元计，老股东自然不愿折价退出。
- **二级市场定价逻辑**：公开市场看可比公司、流动性和已披露的财务数据。港股对 AI 公司的定价一向谨慎，此前已有 AI 新股上市后跌破发行价的先例。
- **「price in」效应**：机构询价时，早就把「未来两年收入高增长」打进发行价了。上市后想让股价上涨，需要的不是「兑现高增长」，而是「超出已经打进价格里的那部分预期」。用工程师的话说，发行价是一次多方谈判后合并的 commit，破发只说明市场这个 main 分支暂时不买账。
- **供需关系**：如果发行规模与流通安排让短期供给偏多，又缺乏存量持仓者「护盘」，抛压就容易集中释放。

所以更准确的表述是：不是「收入涨了还破发」，而是「涨 400% 这件事，在询价阶段已是共识——共识本身不值钱」。

## 大模型赛道的三重压力测试

即便抛开 IPO 技术细节，市场对模型层公司还有三重系统性担心：

1. **技术迭代风险**。开源模型把能力基线快速拉高，闭源模型的差异化窗口期越来越短，今天的领先可能一个版本周期就被追平。
2. **巨头挤压**。字节豆包、阿里通义千问背靠云业务和自有算力，可以用低价 API 换生态份额；创业公司在客户端、渠道、资金上都不占优。
3. **资本开支黑洞**。训练一代前沿模型的开销以十亿元计，推理成本随用户量线性增长，而订阅涨价空间有限。市场会持续怀疑：收入曲线的斜率，追得上成本曲线的斜率吗？

MiniMax 的应对是多线布局——模型层（文本、多模态、视频生成）＋应用层（陪伴、视频、生产力工具）＋海外市场（Talkie）。好处是收入来源分散，代价是每条线都在和不同量级的对手作战，资源始终紧绷。

## 破发 ≠ 判死刑：该跟踪什么

格雷厄姆那句老话在这里很适用：市场短期是投票机，长期是称重机。对这类公司，比首日涨跌更值得盯的是：

- **收入增速与毛利率能否同向向上**：判断增长是不是「越涨越贵」；
- **销售费用率的变化**：C 端收入若靠买量堆出来、费用降不下来，增长质量就要打问号；
- **经营性现金流与账上现金**：决定它能否撑到单位经济模型跑通那天；
- **新版本模型的行业口碑**：模型层的估值溢价，最终要靠技术叙事续命。

上市本身对 MiniMax 并非坏事：融资通道打开、财务透明度被监管倒逼、员工期权有了公开定价——对一家仍在烧钱换规模的公司，这些都是实打实的弹药。

## 写在最后：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/0a0675db73cc949e.png)

1. **看增长，先看每一块钱收入的成本**。增速斜率只讲了一半故事，毛利率、获客成本、现金流缺口才是另一半。这个标准不挑行业。
2. **分清「叙事定价」与「现金流定价」**。早期公司按故事和稀缺性定价（看增速、看 PS），成熟公司按利润定价（看 PE、看自由现金流）。用错尺子，就会得出「涨 400% 还破发真奇怪」的错觉。
3. **别把破发当捡漏信号**。破发不等于便宜，也可能继续跌；首日大涨也不等于安全。打新前至少看三样：发行估值与可比公司的对比、募资用途、基石投资者的成色。

股价会吵很久，但生意的标准一直很清楚：收入质量、成本结构、现金续航。这一课不只属于 MiniMax，属于每一个在「高增长」叙事里冲锋的公司。
