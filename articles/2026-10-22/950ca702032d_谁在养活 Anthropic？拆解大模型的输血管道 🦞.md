最近，36kr 一篇讨论「谁在养活 Anthropic」的文章引发热议。这家做出 Claude 的公司，收入增速是 AI 创业公司里的优等生——据公开报道，年化收入从 2024 年初的约 1 亿美元，涨到 2025 年下半年的 50~70 亿美元量级。但另一面是：据 The Information 披露的融资材料，它预计要到 2028 年前后才可能盈亏平衡，在此之前每年要烧掉数十亿美元。客户付的钱不够花，那到底是谁在给它续命？这篇文章把背后的输血管一根根拆开。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/8c28756ed5b53ca0.png)

## 先看账本：收入狂奔，亏损也在狂奔

- **收入侧**：2024 年底年化收入突破 10 亿美元；2025 年据多家媒体报道，年化 run rate 达到 50~70 亿美元量级。构成主要是 API 调用、企业版订阅（Claude for Work）和个人订阅（Pro / Max）。
- **成本侧**：训练一次旗舰模型要数亿美元起步，而更大的开支是推理——全球用户每一次提问，都在消耗 GPU / TPU 时间。行业估算显示，头部模型公司的算力开支长期大于收入。
- **缺口**：融资材料显示，管理层认为需要在 2028 年前后做到约 200 亿美元年收入才能打平。

一家公司同时拥有「史上最快的收入增长」和「巨额亏损」，在大模型行业这不是 bug，是当前商业模式的出厂设置。理解了这一点，才能看懂下面三根管子。

## 管子一：云巨头的战略投资——钱和算力绑在一起

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/89fc3a3cbf976f61.png)

这是 Anthropic 最大的外部资本来源，特点是「投资即采购」：

- **Amazon**：累计投入 80 亿美元（2023 年首笔 12.5 亿，此后多次加注），AWS 成为 Anthropic 的主要云供应商；作为交换，Amazon 得到了自家 Trainium 芯片的大客户。
- **Google**：早期约 3 亿美元入股，累计投资约 30 亿美元；2025 年 10 月双方签下大单，Anthropic 将使用最多 100 万颗 TPU，金额达数百亿美元级。
- **Microsoft + NVIDIA**：2025 年 11 月披露的三方交易，微软投 50 亿、英伟达投最高 100 亿美元，Anthropic 承诺在 Azure 采购 300 亿美元算力。

看清这个结构的本质：云巨头投出去的是钱，收回来的是算力订单——资金从股东口袋出发，途经 Anthropic，再以采购款的形式回到自家账上。对 Anthropic 来说，等于先锁定算力，再用对方的钱付账单；对云巨头来说，一笔投资同时买到了股东回报、算力消耗和生态绑定，三重收益。

## 管子二：真金白银的企业客户与开发者

这是唯一「非循环」的钱，也是最被投资人看重的部分：

- **写代码是最强现金牛**。Claude Code 以及 Cursor 等编程工具大量调用 Claude 模型，第三方分析显示，代码相关收入一度占其总收入的近三成。2025 年的 vibe coding 浪潮，等于给 Anthropic 装了增压器。
- **企业 API 客户**。Notion、Zoom 等产品把 Claude 接进自家功能；Anthropic 自创立起主打「安全优先」路线（Constitutional AI），契合企业客户对合规与稳定的偏好。第三方调研（Menlo Ventures）显示，其企业级模型市场份额一度位居第一，约三成。
- **个人订阅**。Pro 每月 20 美元，Max 每月 100~200 美元，重度用户贡献的毛利远好于普通聊天场景。

隐患同样明显：收入集中度偏高，头部客户与大额代码类合同占比过大。一旦 DeepSeek、Llama、Qwen 等开源模型在代码任务上追平，API 定价会被快速拉低，毛利随之承压。

## 管子三：风投、可转债与「拿未来借今天」

- 2025 年 3 月，Lightspeed 领投 35 亿美元，投后估值 615 亿；9 月，ICONIQ 领投 130 亿美元，估值 1830 亿；年底又有按 3500 亿美元估值洽谈新一轮的报道。
- 股权之外还出现了新工具：据媒体报道，Anthropic 正洽谈以未来收入和算力合同为抵押的债务融资，规模达百亿美元级——本质是把 2027 年的钱提前到今天花。

估值两年从 40 亿涨到千亿美元以上，靠的不是市盈率，而是收入增速乘以资本市场对 AGI 的信仰系数。

## 循环交易的争议：输血，还是左手倒右手？

把三根管子合起来，会看到一个微妙的图形：**Anthropic 的最大股东，同时是它最大的供应商。** 商业史上有过类似剧本——2000 年电信泡沫期，设备商朗讯、北电向运营商放贷，让对方买自己的设备，报表收入光鲜，最终客户破产、应收账款变成坏账，史称 vendor financing（供应商融资）。

辩护方的逻辑是：云巨头的订单对应真实算力消耗，Anthropic 的收入来自真实终端用户，循环只是降低了各方的现金流压力，与当年「借钱买设备、设备闲置」有本质区别。质疑方的逻辑是：一旦 AI 应用的收入增长不及预期，「投资—采购—收入—再融资」这个飞轮的任何一环失速，都会连环传导。两条路线谁对，市场大概会在 2027 年前后给出答案。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/b2468ecbc2cf3dba.png)

1. **看 AI 公司，先问钱是谁出的。** 区分终端客户收入与战略股东收入：前者是需求，后者本质是融资。如果一家公司的「收入」大量来自大股东的关联采购，估值逻辑要完全另算。
2. **盯单位经济模型，别只看总收入。** 同等能力的 token 价格每年下降常超过一半，但模型能力上限也在抬高算力需求。谁能把「单次调用毛利」做正，谁才有资格谈规模。
3. **开发者的实操建议：别急着锁价。** 模型 API 价格仍在快速下探，核心业务保留多模型切换能力（Claude / GPT / Gemini / 开源自部署）——供应商锁定的隐性成本，往往两年后才显现。

养活 Anthropic 的，短期看是云巨头和风投，长期看只有一件事：有没有足够多的人，愿意为模型的产出持续付钱。这根管子接不通，前面三根都只是延长赛。
