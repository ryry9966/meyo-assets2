MiniMax 上市了。招股书里的收入曲线一路陡峭，结果二级市场开门就给了一根阴线，股价跌破发行价。评论区瞬间分裂：一派喊"AI 泡沫要破了"，一派喊"市场不识货"。RY哥先把情绪放到一边——"收入快速增长"和"上市破发"根本不是同一套计分系统，它们完全可以同时成立。这篇就拆开讲：钱进来了，为什么价格反而往下走。

## 一、破发的机制：一级市场是撮合，二级市场是投票

- IPO 定价走的是询价 + 簿记建档（book-building）：投行收集机构投资者的报价区间，撮合出一个发行价。这个价格要同时照顾三方诉求——公司想多募资，投行想顺利交付，基石投资者想要折扣。
- 行业里长期存在"IPO 折价"惯例：发行价通常定得比机构心理价位略低，保证首日有肉吃，投行下次发单才有人捧场。行情热时折价表现为暴涨，行情冷时折扣给不到位，就直接破发。
- 上市首日的价格由边际资金投票决定：流通盘大小、解禁时间表、当天大盘和板块情绪，权重不比基本面小。承销商手里那点"绿鞋机制"（超额配售选择权）只能熨平小波动，托不住大趋势。
- 还有解禁这把悬着的剑：Pre-IPO 投资者和基石通常有 6~12 个月锁定期，解禁前流通盘小、波动大，而市场会提前把预期计价——所以有时破发不是"当天的事"，而是"倒计时的事"。
- 历史参考：2019 年 Uber 顶着上百亿美元年收入上市即破发；近几年 AI 公司上市后深度回撤的先例也不少。破发不新鲜，它只是发行定价与二级市场共识之间常见的裂缝。

## 二、收入增长快，但 AI 公司的收入要拆开看成色

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/bc9e3aa5cc4031cf.png)

先交代背景：MiniMax 是靠海螺 AI、Talkie 等产品出圈的国产大模型公司，覆盖文本、语音、视频生成多条产品线，收入主要来自 API 调用、To C 订阅和 To B 合作。这三类收入的"成色"完全不同：

1. **API 调用收入**：按 token 计费，增长快，但每一笔收入背后都对应真实的 GPU 折旧和电费，毛利率被推理成本死死压住；
2. **To C 订阅**：付费意愿波动大，留存曲线抖，收入可预测性一般；
3. **To B 定制与合作**：金额大、一次性、难复制，在估值体系里折价最狠。

再算一笔粗糙的账：假设 API 收入 10 亿元，毛利率 50%，毛利 5 亿元；研发加算力投入 12 亿元，净亏 7 亿元。收入翻倍到 20 亿元，毛利率不变，毛利 10 亿元——但为了撑住更大的训练和推理盘子，投入也涨到 18 亿元，净亏反而扩大到 8 亿元。收入翻倍，亏损更大，这在数学上完全自洽。工程师式翻译：收入的一阶导数为正，自由现金流持续为负。

这就是 AI 行业典型的 growth at a cost（花钱买增长）：规模效应要等毛利率爬升或投入增速放缓才兑现。在那之前，收入增速和盈不盈利，基本是两条平行线。

## 三、估值锚点错位：一级市场按叙事定价，二级市场按数字定价

- **一级市场的逻辑**：稀缺性 + 故事 + 下一轮融资预期。头部模型公司的估值讨论大多是叙事驱动，市销率（P/S）给得慷慨，参照物是"未来可能的平台型公司"。
- **二级市场的逻辑**：机构资金要向出资人交代，锚点通常对标成熟 SaaS——但成熟 SaaS 毛利率普遍在 70%~80%，而大模型 API 的毛利率结构完全不同。用 SaaS 的估值模板去套模型公司，算出来的数字自然难看。
- **结果就是**：发行价若延续一级市场的倍数，二级市场用更严格的锚重新称重，中间的差额就以破发的形式"找零"。
- **还有一层行业背景**：这几年模型层的巨额算力资本开支（capex）大头由云厂商承担，独立模型公司必须在"追前沿"和"活下去"之间反复权衡，这种不确定性本身就是折价因子。叠加这两年新股供给多、打新情绪偏谨慎，个体故事再好也得排队上秤。

## 四、市场真正在担心什么：三个变量

1. **开源冲击定价权。** DeepSeek、Qwen 等开源模型把 API 价格打了下来，闭源 API 的溢价空间被压缩，模型能力的领先窗口期以月为单位计算，护城河得靠产品工程和生态去补。
2. **算力成本与 unit economics。** 高端 GPU 供应紧张是公开事实，推理成本随 token 消耗同步上涨，"每一单到底赚不赚钱"还需要几个季度的财报来验证。
3. **变现场景的斜率。** C 端 AI 应用付费留存波动大，B 端客户预算审批周期长，收入曲线的斜率能否维持，才是多头和空头真正的分歧点。

## 五、冷思考：过三张过滤网，再下判断

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/f8a4f457619fac70.png)

1. **先看收入质量三件套**：毛利率、净收入留存（NDR）、经营性现金流。收入增速本身只值半张票——增速 100% 但毛利率为负的生意，未必好过增速 50%、毛利率 70% 的生意。
2. **破发不是基本面死刑，首日暴涨也不是基本面认证。** 短期价格一半是流通盘、锁定期、板块贝塔的机械结果。真正的判决通常出现在解禁窗口前后，再加上两三份完整财报之后。
3. **别用两个价格互相倒推。** 一级市场的估值是谈判产物，二级市场的短期价格是投票机，长期才是称重机。用融资估值证明"它值钱"，和用首日跌幅证明"它不行"，是同一种错误，只是方向相反。

一句话收束：收入曲线讲的是公司已经做了什么，股价讲的是市场认为它接下来能做什么。两条线异步更新，别硬对齐。
