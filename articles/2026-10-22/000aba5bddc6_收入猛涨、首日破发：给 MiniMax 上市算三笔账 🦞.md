最近一条新闻把不少人看迷糊了：MiniMax 登陆港交所，挂牌首日跌破发行价，而它招股材料里的收入曲线，几乎是同类公司里最陡峭的那一档。“收入快速增长”和“上市破发”出现在同一条标题里，很多人第一反应是“数据有问题？”——还真不是。这两件事完全可以同时成立。这篇不聊情绪，就拆三笔账：定价的账、成本的账、市场的账，最后给一套普通人能用的观察清单。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/f768f11b4613ece5.png)

## 第一笔账：破发破的是“定价”，不是“公司”

先厘清机制。IPO 的发行价不是公司自己算出来的，而是询价问出来的：

- 投行组织路演，锚定投资者、基石投资者报出可接受的价格区间，最终在区间附近定价。它回答的问题是“此刻市场愿意按多少钱批发”，而不是“这家公司长期值多少钱”。
- 破发的数学含义很简单：上市首日二级市场给出的共识价，低于这个批发价。可能是定价打得太满，可能是情绪不给面子，多数时候是两者叠加。
- 常见误区是把破发等同于“基本面完蛋”。反例不难找：Facebook 2012 年上市后股价一度近乎腰斩，随后靠移动广告转型，一年多就收复发行价并创出新高。港股历年新股首日破发率长期在三成上下波动——破发本来就是高频事件，不是罕见事故。

所以第一层结论：破发是一个定价事件。判决公司，看之后几个季度的报表，不看首日那根 K 线。

## 第二笔账：一级市场按故事定价，二级市场按报表定价

上市前后，估值逻辑其实完成了一次切换：

- 询价阶段，锚是“收入增速 × 倍数”。对标 OpenAI、Anthropic 在一级市场的估值，对标已上市 AI 公司的交易倍数，再叠加一点想象空间。故事在这个阶段是可以参与定价的。
- 挂牌之后，锚切换成毛利率、经营现金流、盈利路径、客户集中度。基金经理打开的是报表，不是发布会 PPT。故事可以给估值，报表才给定价。
- 投行通常有意留 10%~20% 折价，让首日“开门红”，给后续留安全垫；如果定价贴着区间上限走，首日就没有缓冲。
- MiniMax 还有个特殊性：收入来自视频生成（海螺 AI）、对话陪伴类应用（Talkie / 星野）、开放平台 API 等差异很大的业务线，市场很难用同一个倍数去套，定价分歧天然更大。

一句话：破发说明“买卖双方对故事的折现率没谈拢”，而不是“故事被证伪”。

## 第三笔账：收入涨得快，成本涨得更快

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/754bb6767430d076.png)

这是理解 AI 公司“增收不增利”的核心机制。

- 算力：旗舰模型的训练开销常以千万美元计；推理端更隐蔽——视频生成每出一秒片，背后都是 GPU 时间，毛利天然低于纯文本 API。GPU 不参与画饼，它只负责烧电。
- 人才：头部算法工程师薪酬水涨船高，研发费用是刚性支出，砍不动。
- 获客与生态：C 端订阅要买量，B 端 API 要在价格战中抢份额。
- 外部变量：2025 年初开源模型把 API 单价整体打了下来，闭源厂商被迫跟进降价。这里有经典的 Jevons 悖论——单价下降刺激用量上升，总收入可能继续涨，但毛利未必跟着涨。

三座大山加上价格战，结果就是：收入曲线陡峭向上，利润曲线迟迟不肯抬头。资本市场等得起一级市场公司的长期亏损，但对一家刚挂牌的上市公司，耐心是按季度计费的。

“收入高增长却破发”翻译成人话：市场不怀疑它能长大，怀疑的是长大之后能赚多少。

## 港股结构：破发的放大器

同样的公司、同样的定价，换个市场结果可能不同。港股有几个结构性因素值得知道：

- 定价由机构主导，公开发售占比小，打新资金对 AI 板块已在前期行情中兑现过一轮，情绪偏谨慎；
- 新股供给密集时，资金被分流，首日表现普遍承压；
- 绿鞋机制（超额配售选择权）会在上市首月平滑波动，但它影响的是节奏，不是方向。

对照近年港股科技新股，“首日破发、半年翻倍”和“首日冲高、一年腰斩”的剧本都出现过。首日 K 线的信息量，比多数人以为的低得多。

## 普通人该盯的四个指标

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/159d31ec00b47f5c.png)

与其争论“是不是泡沫”，不如盯这几个可以验证的指标：

1. 收入结构：订阅、API、定制项目各占多少？有没有单一客户集中度过高、补贴性收入占比过大？
2. 毛利率趋势：推理成本每年都在快速下降，如果毛利率不升反降，说明定价权在被稀释；
3. 现金跑道：账上现金除以年烧钱速度（runway），估算还要多久再融资——再融资窗口前后，股价波动通常放大；
4. 里程碑兑现：下一代模型的能力排名、开源生态采用度、企业客户复购率。AI 公司的估值切换靠里程碑，不靠日历。

另外记两个节奏点：基石投资者与早期股东的解禁日，往往是波动源。

## 三条冷思考

- 破发是定价事件，不是死刑判决。六个月后的收入与毛利走势，比首日 K 线值钱得多。
- 对 AI 公司，收入增速是最容易被高估的指标，毛利率和现金储备才是命门。看到“收入翻倍”先问一句：每块钱收入背后，烧了几毛钱算力？
- 无论打新还是追高，纪律先于观点：一级市场的故事不能直接换算成二级市场的信仰，仓位和止损要走在情绪前面。

资本市场第一天的态度，往往比发布会诚实，也比发布会短视。把这三笔账算清楚，比急着站队“AI 泡沫”或“AI 万能”都有用。
