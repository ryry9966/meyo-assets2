DeepSeek 开源周收官那天，随代码一起放出的还有一份 V3/R1 推理系统概览，把自家"印钞机"的内部构造亮了个底朝天。社区里最兴奋的不是某段 kernel，而是有人拿着披露的吞吐数据和租赁成本算了笔账：按 API 白天定价满负荷开卖，这门"卖 token"的生意毛利约 82%。一个推理框架，怎么就把 AI 的利润表照亮了？这篇把算法、口径和水分一次讲清。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/ead5c96753ca6566.png)

## 82% 不是拍脑袋，是一道可复现的算术题

- **官方口径**：论文设定 4K 张 H800、按 R1 白天 API 定价满负荷运行，理论日均收入约 56 万元，GPU 租赁成本约 8.8 万元/天，官方称之为"成本利润率 545%"。
- **毛利怎么算**：毛利 =（收入 − 成本）/ 收入。545% 有两种读法——若收入约为成本的 5.45 倍，毛利 = 1 − 1/5.45 ≈ 82%；若按"利润是成本的 5.45 倍"理解，毛利约 84%。社区流传的 82% 取的是前一种。
- **单价视角**：R1 输出 token 标价 ¥16/百万。把上面的账折到单价，硬成本只占标价两成不到——每卖 1 元 token，卡租加电费不超过 2 角。
- **吞吐参照**：论文披露单节点 prefill 约 7.3 万 tokens/s、decode 约 1.5 万 tokens/s，这是整笔账的物理基础。

注意：这是理论满负荷 + 白天价格的口径。论文自己也承认，夜间折扣时段大量请求按低价计费、部分故障的恢复机制尚未上线，实际收入要打折。先把"怎么算"摁明白，再谈"能不能信"。

## 利润不在模型里，在工程里：这套框架优化了什么

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/73112e3a51269bb5.png)

开源周放出的 FlashMLA、DeepEP、DeepGEMM、DualPipe、3FS 等组件，加上论文里的系统设计，核心就一句话：**把每一张卡的每一秒都喂饱**。

- **大规模专家并行（EP）**：MoE 架构把专家拆到多节点，激活参数远小于总参数，batch 拉大后，单 token 摊薄的算力成本骤降；
- **Prefill–Decode 分离**：prefill 是算力密集，decode 是显存带宽密集，物理分开部署、各自用满资源，整机利用率直接上一档；
- **冗余专家**：MoE 各专家负载天然不均，总有一批"网红专家"被挤爆。给高负载专家多复制几份，木桶短板被补掉；
- **计算–通信重叠**：DualPipe 把跨卡通信藏进计算里，减少流水线空转；
- **削峰填谷**：夜里的卡闲着也是烧钱，折扣定价把需求引到谷底，等于把一天跑成两天。

一句话总结：82% 不是模型聪明，是调度聪明。推理是门工程活，毛利是调优调出来的。

## 和谁比：卖 token 的单位经济学

- **参照系**：传统 SaaS 毛利 70%~80%，云计算 IaaS 约 30%~50%。"推理毛利 82%"意味着，卖 token 有机会是一门**软件级毛利**的生意，而不是重资产苦役；
- **对照组**：据 The Information 等媒体援引的报道，OpenAI 的推理毛利一度只有约 50%，部分产品线更低。同样是卖 token，成本结构差异巨大——自建机房、非 MoE 架构、更贵的卡，账完全是另一本；
- **但这串数字至少要挤四遍水**：
  1. **毛利 ≠ 净利**：研发人力、数据、渠道分成、折旧都不在这道算术里；
  2. **理论 ≠ 实际**：夜间折扣、故障停机、需求波动都会压低真实毛利率；
  3. **满负荷假设**：需求不足时空转的卡照样烧钱，毛利率对利用率极其敏感；
  4. **可复制性存疑**：同样的账，换一支团队用同样的卡未必算得出来——这套成本来自模型架构与硬件的深度协同设计，属于"少数人的成本曲线"。

## 82% 是终点还是起点：价格锚与杰文斯悖论

- **成本锚效应**：成本结构被公开，等于给全行业挂了一块定价参照物，API 价格战只会更卷；
- **杰文斯悖论（Jevons Paradox）**：历史经验是，单位成本下降不会减少总支出。GPT-4 级能力的推理成本两年降了一个数量级以上，用量涨得更快——蒸汽机越高效，煤烧得越多；
- **下一阶段的变量是 Agent**：多步推理、长上下文、工具调用，会让单任务 token 消耗乘性增长。o1/R1 这类"多想几步"的推理时计算，本质上是把成本曲线和收入曲线同时抬高了一截；
- **毛利是快照，不是护城河**。真正稀缺的，是持续压低单位成本的组织能力。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/a8e748c979e2e181.png)

1. **看毛利先问口径**：什么价格时段？是否满负荷？含不含折旧和人力？理论值与财务报表之间，隔着一整个运营团队；
2. **采购与应用，用"单位成本"说话**：对比 ¥/百万 tokens、缓存命中折扣、夜间折扣、Batch 接口；做 Agent 还要估算输出 token 占比——输出比输入贵好几倍，架构里省下的那点输入费，可能不够多吐几轮输出费；
3. **别用今天的成本否定明天的产品**：底层成本曲线在陡降，应用层的价值判断要跟着重算。降本释放出来的预算，最后会流向把 token 用得最聪明的那批人。

82% 的意义不在数字本身，而在于第一次有人把"黑盒生意"的账本摊开在阳光下。对整个行业来说，这比多卷出一个 benchmark 有用得多。
