2 月底的一周里，DeepSeek 连续开源了 FlashMLA、DeepEP、DeepGEMM 等一批推理系统核心组件，随后又公开了 V3/R1 推理系统的架构与成本数据。很快，第三方机构 SemiAnalysis 算出一笔账：按 API 牌价计费，其推理服务的毛利率约为 82%。这是「AI 推理到底赚不赚钱」第一次变成一个可以动手验算的数字。这篇文章把这 82% 拆开看：它是怎么算出来的、靠什么撑起来、又有哪些口径上的水分。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/1d368d2b8ba8be9a.png)

## 先拆开看：开源的不是"框架"，是印钞机的零件

2 月 24 日到 28 日的"开源周"，DeepSeek 每天放出一组仓库，五天五连发：

- **FlashMLA**：面向 Hopper 架构（H800）的 MLA 解码 kernel，官方数据内存吞吐可达 3000 GB/s——决定注意力计算这一步有多快。
- **DeepEP**：首个开源的专家并行（Expert Parallelism）通信库，处理 MoE 模型跨节点的 all-to-all 通信，兼顾预填充的吞吐模式和解码的低延迟模式。
- **DeepGEMM**：FP8 矩阵乘法库，支持细粒度缩放，官方称在 H800 上可达 1350 TFLOPS 量级。
- **DualPipe / EPLB**：双向流水线并行与专家负载均衡，让计算和通信重叠起来，GPU 不空转。
- **3FS / Smallpond**：高性能并行文件系统与数据处理框架，官方给出 6.6 TiB/s 的聚合读吞吐，用来喂 KV cache 和海量数据。

严格说，这不是一个开箱即用的推理框架，而是一整套系统的关键零件：计算 kernel、通信、并行策略、存储。打个比方：别人卖整车，DeepSeek 把发动机、变速箱和悬挂的图纸全公开了。这些零件共同决定一个核心指标——**一块 GPU 一小时能吐出多少有效 token**。推理服务的成本基本就是「GPU 小时数 × 单价」，吞吐翻倍，单位成本近乎减半。

## 82% 是怎么算出来的

先明确口径：毛利 = 收入 − 直接服务成本（GPU 折旧或租金、电力、带宽、机房运维），不含研发费用，也不含训练投入的摊销。

- **官方披露的理论账**：以 2 月 27 日为例，全天输入约 6080 亿 token（其中约 56% 命中缓存），输出约 1500 亿 token。若全部按 API 牌价计费，理论日收入约 56.2 万美元；按 H800 每小时 2 美元的租金假设，理论日成本约 8.7 万美元。成本收入比约 1:5.45，折算毛利率约 84.5%。
- **第三方测算**：SemiAnalysis 基于硬件规模、batch 大小、利用率的独立假设建模，得出约 82%。两个数字口径不同，但指向同一件事：**API 推理的直接成本，大约只占牌价的 15%~18%**。
- **体感对照**：以 R1 为例，输出 token 牌价约 2.19 美元/百万 token，而把 GPU、电力、运维摊到每个 token 上，只是这个价格的零头。

值得注意的是，第三方之所以"能算"，恰恰因为 DeepSeek 把架构、组件、定价全部公开了——开源的副产品是**可审计性**，这在闭源时代不可想象。

## 高毛利的来源：稀疏、压缩、并行

82% 不是靠定价虚高撑起来的，而是一套工程组合拳：

1. **MoE 稀疏激活**：模型总参数 671B，但每个 token 只激活约 37B。相当于一栋 18 层的楼，每次只点亮一层的灯，算力和电费全省下来。
2. **MLA 压缩 KV cache**：把推理时最占显存的"记忆"大幅压缩，省下的显存塞进更大的 batch——batch 越大，GPU 越接近满负荷。
3. **PD 分离 + 专家并行**：预填充（prefill）和解码（decode）拆到不同集群，各跑各的最优配置；DeepEP 让专家权重分散在不同机器上也能高效协作。
4. **MTP 投机解码**：一次前向计算多吐 token，官方披露可让解码吞吐接近翻倍。
5. **缓存与错峰**：输入缓存命中只收约十分之一的价格，既让利又省算力；夜间错峰折扣把闲时算力卖出去，减少空转。

一句话总结：GPU 每小时的成本是固定的，推理本质是**「把固定成本摊到尽量多的 token 上」**的生意，吞吐就是一切。

## 82% 不等于躺赚：口径里的水分

- **理论满载 ≠ 现实运转**：夜间低谷、流量波动、缓存命中、折扣促销都会拉低实际收入。命中缓存的部分只收十分之一价格，命中率越高，收入缩水越明显。
- **免费流量不在账上**：App 端大量免费用户消耗真实算力，却不产生 API 收入，这部分一直在摊薄真实毛利。
- **毛利 ≠ 净利**：V3 预训练就烧掉约 279 万 H800 GPU 小时，训练集群的折旧、团队薪酬、后续研发，全都不在这 82% 里。
- **横向对照**：传统 SaaS 毛利率 70%~80% 很常见，而单纯卖 GPU 算力的租赁生意毛利通常薄得多。AI API 目前更像「软件定价、硬件成本」，吃到的是高吞吐工程叠加供不应求的窗口期红利——前提是价格战别把牌价打穿。

## 把"印钞机图纸"公开，图什么

- **生态卡位**：开源周仓库上线几天内，vLLM、SGLang 等主流推理引擎就宣布集成。全行业推理效率上台阶、单位成本整体下探，API 价格的天花板被压低——对走「低价换规模」路线的 DeepSeek 是顺势加杠杆。
- **技术招牌**：能把推理系统做到这个效率的团队，开源就是最硬的简历。对顶尖系统工程师来说，「我的 kernel 被全球开发者调用」比任何招聘广告都管用。
- **对使用者的直接好处**：照着公开组件自建推理服务，同样的硬件能跑出更高吞吐，「自托管还是买 API」的天平开始向自托管倾斜，API 的溢价空间被压缩。
- **历史参照**：Android 之于智能手机、PyTorch 之于深度学习——开源基础设施不直接收费，但会定义整个行业的默认技术栈。

## 冷思考：看懂这类数字的三个习惯

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/607d829548fecbf6.png)

1. **先问口径再下结论**：这是"理论满载模型"还是真实报表？算的是 API 收入还是全公司收入？「82% 毛利」和「公司盈利」之间，还隔着训练摊销、研发薪酬这条巨大的鸿沟。
2. **盯单位成本，别只盯降价**：token 牌价会一路向下，真正值得跟踪的是「每 token 综合成本」的下降斜率。缓存命中、错峰折扣、自托管，都是你自己业务里的"毛利率"杠杆。
3. **成本曲线决定价值迁移**：推理成本每几个月就下一个台阶，模型层正越来越像"电力"。价值会持续向用得起、用得巧的应用层转移——与其纠结谁家毛利更高，不如盘点自己的业务里哪些环节能吃到这波成本红利。
