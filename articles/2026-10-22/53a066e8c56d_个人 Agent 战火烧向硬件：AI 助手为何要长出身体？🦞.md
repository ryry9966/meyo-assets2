过去两年，AI Agent 的主战场一直在对话框里：比谁的推理强、谁的工具调用稳、谁的订阅便宜。但风向变了——OpenAI 花约 65 亿美元把 Jony Ive 的硬件团队 io 收入囊中，Meta 的智能眼镜销量悄悄迈过 200 万副，国内 AI 眼镜、AI 耳机、AI 玩具也扎堆发布。Personal Agent 这场仗，正从软件烧向硬件。为什么纯软件的 Agent 不够用？硬件到底补上了什么？哪些是机会、哪些是坑？这期把棋盘摊开讲清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/01e5f6df5c36afbc.png)

## 一、Agent 为什么要“长出身体”？

先对齐概念：Personal Agent 不只是聊天机器人，而是能理解意图、拆解任务、替你调用工具干活的数字助手——订机票、比价下单、排日程、回邮件都算。

纯软件形态的 Agent 撞在三堵墙上：

1. **上下文太薄**。Agent 要干活，得知道“你现在看到什么、听到什么、在哪、在做什么”。藏在 App 里，它只能拿到应用内的数据；而一副眼镜、一台耳机、一块手表，天生自带摄像头、麦克风、IMU、心率计，能持续采集第一手多模态信号。
2. **入口受制于人**。移动互联网时代，应用商店是总闸门；Agent 如果只活在别人的手机里，分发权永远不在自己手上。硬件是重排入口座次的机会。
3. **商业模式太被动**。做应用要被平台抽成，做订阅要和同行卷价格，“硬件 + 订阅”的组合拳能拿回一部分定价权。

一句话：Agent 要从“你去找它”变成“它常在你身边”，物理载体几乎是必经之路。

## 二、前车之鉴：两台“先烈”教了什么？

硬件圈的老规矩：发布会负责梦想，发货负责现实。2024 年两台标志性设备几乎把坑踩了个遍：

- **Humane AI Pin**：别在胸口的激光投影“无屏终端”，699 美元外加每月 24 美元订阅。上市后评测一边倒：发热、识别慢、答非所问。最后 HP 以约 1.16 亿美元买走其资产——而这家公司巅峰估值超过 8 亿美元。
- **Rabbit R1**：199 美元的橙色小方块，靠“大动作模型（LAM）”讲了个好故事，但实测大量功能用手机 App 就能完成，被普遍评价为“发布时还没准备好”。

拆开看，失败有明显的共性：

1. **杀手场景不成立**——“替代手机”本身不是场景，用户只认“手机做不到的事”；
2. **没有生态**——没有开发者、没有第三方服务，单机智能的上限极低；
3. **交互学习成本高**——让用户放弃触摸屏，需要十倍于屏幕的体验补偿。

对照组是 Meta 的 Ray-Ban 智能眼镜：它没有发明新品类，而是在一副本来就有人买的墨镜上叠加 AI 能力（第一视角拍摄、语音助手、实时翻译），累计销量突破 200 万副。结论很直白：现阶段，**旧品类 + AI 增量，远比“全新 AI 设备”走得稳。**

## 三、巨头们的三种下注姿势

把牌桌上的玩家分分类，目前是三条路线：

1. **新物种派**：OpenAI 收购 io 后，据公开报道方向是一款无屏、可环境感知的随身设备，团队里汇集了当年打造 iPhone 的核心成员；国内也有不少创业公司在做独立的 AI 伴侣、AI 挂件。赌的是“AI 时代的 iPhone”，风险是先烈名单就在眼前。
2. **旧品类 AI 化派**：眼镜、耳机、手表、玩具、学习机——在供应链成熟、用户习惯现成的品类上叠加 Agent。Meta 和国内眼镜阵营都走这条路，确定性最高。
3. **存量设备派**：苹果依托自家 20 多亿台活跃设备的生态，把 Apple Intelligence 当系统能力逐步下发；手机厂商则把系统级 Agent 做进 OS，先守住入口再说。硬件是“结果”，不是“起点”。

三条路线拼的资源完全不同：新物种拼设计与叙事，旧品类拼供应链与渠道，存量派拼用户基数。短期看第三条护城河最深，中期看第二条渗透最快，第一条变数最大、想象力也最大。

## 四、技术底座：端云协同，“小脑 + 大脑”

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/526a1029e6ad27b2.png)

Agent 真要常驻设备，靠的不是单项黑科技，而是一套端云协同的分工体系：

1. **端侧小模型当“小脑”**：负责唤醒、语音识别、意图初筛这类高频低复杂度任务，延迟低、数据不出设备。这几年旗舰手机 NPU 算力从个位数 TOPS 涨到几十 TOPS，内存普遍 16GB 起步，跑 3B~7B 参数的模型已经不吃力。
2. **云端大模型当“大脑”**：复杂规划、多步推理、跨服务调用，回传云端完成，结果再下发到端侧执行。
3. **多模态传感器喂上下文**：VLA（视觉—语言—动作）类模型的成熟，让“看到→理解→执行”第一次闭环。手机 Agent 能帮你订机票，但眼镜 Agent 能“看见”你正盯着货架犹豫——这是本质区别。
4. **数据飞轮**：在合规前提下，设备越贴合用户，个性化数据越丰富，Agent 越懂你，正循环就此成立。这也是为什么隐私设计从第一天起就是产品问题，而不是法务问题。

这套架构决定了：纯端侧和纯云端都不是终局，**“端云一体”才是 Agent 硬件的地基**。判断一台 AI 硬件靠不靠谱，可以先看它有没有把这条链路讲清楚。

## 五、三条冷思考：上船前先看这三点

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-22/b1dfc022925b773c.png)

1. **只看增量场景，不看参数表。**问一个狠问题：这台设备做了什么“手机做不到”的事？第一视角拍摄、免手持交互、全天候常驻算增量；把聊天框搬进眼镜不算。没有增量场景的设备，本质是个形态新颖的周边。
2. **对初代产品的“半成品税”保持警惕。**AI 硬件的价值高度依赖模型迭代和生态填充，首发往往只是“能跑”。不急的话，等第二代，或者直接买“成熟品类 + AI 功能”的稳妥组合，试错成本低得多。
3. **把隐私条款当产品规格看。**常驻麦克风和摄像头意味着你要重新划信任边界：数据是否本地处理、有没有物理断连开关、录音录像存在哪、能否一键删除——这些指标的重要程度不亚于续航和算力。

Agent 走向硬件不是概念炒作，但也不等于“随手再造一个 iPhone”。更现实的图景是：模型能力决定上限，硬件形态决定场景，而两者都成熟之前，最先赚到钱的往往是卖眼镜、耳机这些“旧船票”的商家。潮水方向是对的，上船的顺序，值得每个人自己掂量。
