2025 年 1 月，DeepSeek R1 发布后，微软 CEO 纳德拉在 X 上引用了 Jevons paradox（杰文斯悖论），一句话把 160 年前的经济学观察重新送回行业视野。喧嚣过后，一个更技术的问题浮出水面：当推理需求因为“便宜”而暴涨，**每一次推理花多少钱、等多少秒**，就成了全行业最核心的变量。最近 36kr 等媒体报道，国内多家团队把研究重心转向 AI 的“直觉层”——让模型少写草稿、多“直接会”。这篇文章把这件事拆开讲清楚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-04/4622211d07f70242.png)

## 先补课：Jevons 悖论为什么重要

- **出处**：1865 年，英国经济学家 William Stanley Jevons 在《煤炭问题》中发现一个反直觉现象——蒸汽机效率越高，煤的消耗不降反升。因为煤变便宜了，用得起的人和使用场景暴增。
- **AI 版演绎**：纳德拉引用它回应“DeepSeek 会不会减少算力需求”：模型每 token 成本暴跌 ≠ 算力需求下降，而是需求曲线整体右移。
- **逻辑链条**：单位成本下降 → 原本“不划算”的场景变得划算（全量文档阅读、视频理解、Agent 多轮循环、代码批量重构）→ 总消耗反而上升。
- **对行业的推论**：推理成本是需求弹性的“闸门”。谁能持续压低「每次推理的成本 × 延迟」，谁就吃到下一波增长。

但压成本不能只靠堆显卡和打价格战——于是有人换了个思路：**减少“思考”本身的开销**。这就是“直觉层”的由来。

## “直觉层”是什么：把卡尼曼装进模型

心理学家卡尼曼在《思考，快与慢》里把人类思维分成两套系统：

- **System 1**：快、自动、便宜，也就是直觉；
- **System 2**：慢、费力、昂贵，也就是深思。

现在的 reasoning 模型（OpenAI o 系列、DeepSeek R1 等）是标准的 System 2：先在输出里写几百上千个 token 的 chain-of-thought，再给答案。简单说，以前模型靠“打草稿”显得聪明，现在行业想让它学会“心算”。

代价肉眼可见：

1. **延迟**：语音助手让用户等 10 秒是不可接受的；
2. **成本**：大量 token 花在“让我再检查一遍”式的自我怀疑上；
3. **过度思考（overthinking）**：已有多项研究统计，部分推理模型在简单题目上生成的思维链里，相当比例是冗余的重复验证。

所谓“直觉层”，就是让模型把这些显式草稿**内化**成隐藏层里的快速计算——少产出 token，多在向量空间里一步到位。

## 四条主流技术路线

1. **潜空间推理（latent reasoning）**：代表作是 Meta 2024 年底的 COCONUT（Chain of Continuous Thought），让模型不把中间步骤解码成文字，直接在连续隐向量里“想”。省掉“解码成语言—再编码回去”的开销，也绕开了自然语言对推理结构的约束。国内团队在类似的“连续思考”方向上已有跟进。
2. **CoT 内化 / 蒸馏**：把大模型的思维链蒸馏进小模型的权重，让“深思熟虑”变成“条件反射”。R1 的蒸馏系列、各家“轻量思考”版本，本质上都是这条路。
3. **自适应思考（adaptive reasoning）**：给模型设“思考预算”（thinking budget），简单问题直接答，难题才展开 CoT；或者在系统层做 router，按难度分流到不同规格的模型。
4. **RL 去冗余 + 推理工程**：用强化学习的长度惩罚压掉思维链里的废话；再配合 MLA、MoE、KV cache 压缩、speculative decoding 这些推理侧优化，把「每 token 单价」和「token 数量」两头一起压。

一句话总结：直觉层不是玄学，是**压缩**——把冗长的显式推理，压成更短、更靠近内部的计算。

## 为什么中国团队在这里卷得凶

客观说，“让模型少想一点”是全球共同方向，OpenAI 和 Google 也在推轻量推理版本。但国内团队投入密度更高，原因主要在市场结构：

- **价格战把利润压到地板**：2024 年起国内大模型 API 价格多轮跳水，部分模型每百万 token 已被打到几毛到几块钱量级。推理成本每降 10%，毛利率可能翻倍式改善——显卡烧的不是电，是毛利率。
- **应用密度高**：语音硬件、智能客服、Agent 工作流这些对延迟和成本极度敏感的场景，在国内落地速度快，需求倒逼技术演进。
- **效率工程的路径依赖**：从 DeepSeek 的 MLA、细粒度 MoE、FP8 训练开始，国内头部团队已经验证了“把工程效率做成核心竞争力”这条路走得通。深挖直觉层，是同一套方法论的自然延续。

## 对从业者意味着什么：三层影响

- **调 API 的应用层**：把「每解决一个任务的成本」（cost per solved task）当作北极星指标，而不是每 token 单价。直觉层成熟后，同一个任务的账单结构会彻底变样。
- **做产品的**：延迟预算开始成为一等公民。语音、Agent 循环、实时协作里，“等模型想完”的体验税正在被取消，可以重新设计交互节奏。
- **做模型和评测的**：评价口径在变——准确率之外，tokens-per-solved-problem（解出一题花多少 token）、简单题零思考通过率，会是新的比较维度。

## 收尾冷思考：三条建议

1. **别把直觉神化，它有失效模式**。直觉是压缩，压缩有损。显式 CoT 的价值之一是可审计——错误步骤看得见、能定位；内化之后，模型可能“自信地错”。关键业务场景要保留“展开思考”的开关，并保留抽查机制。
2. **自己先做 router，别等模型替你做**。应用层完全可以先上“小模型直答 + 低置信度升级到大模型 CoT”的两级方案，成本收益立刻可量化；等直觉层技术成熟，无缝替换即可，架构不用推倒重来。
3. **盯住需求弹性，而不是单次成本**。Jevons 悖论提醒我们：成本下降不会让你少花钱，只会让你多做以前不做的事。做预算规划时，假设用量随降价同比例甚至超比例增长，比假设“能省下一笔钱”更接近现实。
