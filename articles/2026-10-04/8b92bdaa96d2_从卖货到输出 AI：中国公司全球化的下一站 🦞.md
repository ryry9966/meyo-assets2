这周的 36kr「中国公司全球化周报」里有两条新闻，放在一起看很有意思：一边是速卖通（AliExpress）的智能经营 AI Agent 全面上线，一边是百度海外版 AI 应用 Kooko 用户突破 1000 万。一个把 AI 卖给跨境卖家，一个把 AI 产品直接推给海外用户。看似不相干，其实指向同一件事：中国公司的全球化，正在从"输出商品"切换到"输出能力"。这篇拆开讲讲。

## 速卖通的 AI Agent，到底是个什么东西

先说结论：它不是一个"更聪明的客服机器人"，而是一个会自己干活的运营员工。

- **以前的平台工具**：本质是单点功能——标题优化工具、广告出价工具、翻译插件。你点一下，它做一步，决策权始终在你手里。
- **现在的 Agent**：LLM + 工具调用（function calling）+ 平台数据 + 任务目标。你给它一个目标，比如"把这款产品在巴西站点的转化率提上去"，它自己拆任务、自己执行、自己看结果再调整。
- **具体能干什么**：多语言 listing 生成（标题、卖点、详情页一次到位）、结合竞品和库存动态调价、夜间自动回复买家咨询、广告预算在不同国家之间自动调配。

举个例子：义乌一个小卖家，200 个 SKU，想同时铺英、法、葡、西语等多个市场。按老办法，他得雇一个会多门外语的运营团队——这不现实。现在 Agent 一晚上能把 listing 全部本地化，凌晨三点巴西买家提问，它秒回。运营门槛被直接打掉了一截。

## 为什么是现在？三个条件刚好凑齐

Agent 不是新概念，强化学习时代就有雏形，但商业化落地卡了很多年，最近才跑通，因为三件事同时成熟：

1. **模型能力过了线**。多语言、多模态（能看图）、function calling 这些关键能力，基本是 2023–2024 年补齐的。没有 function calling，Agent 就只是个聊天框。
2. **推理成本降了一个数量级以上**。公开测算普遍显示，同等能力的调用成本两年间下降超过 90%。Agent 是高频调用型应用——一个卖家一天可能触发几百次——成本降不下来，商业模型就不成立。
3. **平台有闭环数据**。这是电商平台做 Agent 最狠的优势：交易、物流、客服、退货数据全在自己手里，Agent 的每一次调价建议都能用真实成交结果来反馈校准。独立做 Agent 的创业公司最缺的就是这个。

## Kooko 破千万：另一条出海路线的注脚

如果说速卖通是把 AI 卖给卖家（B 端工具路线），Kooko 就是把 AI 体验直接推给海外消费者（C 端产品路线）。

放回历史坐标里看，中国互联网出海大致有三波：

- **第一波（约 2012–2016）**：工具类应用出海，浏览器、清理、壁纸，靠应用商店的自然流量。
- **第二波（2017–2022）**：内容和电商出海，TikTok、Shein、Temu 把"推荐算法 + 供应链"打包输出，规模做到世界级。
- **第三波（现在）**：AI 原生应用出海，产品核心体验本身就是 AI 能力，Kooko 属于这一波的早期样本。

关于"用户破千万"这个数字，泼一点冷水：下载量或注册用户，和产品成功之间隔着留存、时长、付费三座大山。C 端 AI 应用常见的曲线是前期靠新鲜感冲量，30 日留存能不能站住一个健康的水平，才决定它是现象还是烟花。千万用户是入场券，不是终点线。

## 两条路线，同一个底层逻辑

把两件事放一起看，逻辑是共通的：**把"运营知识"和"产品能力"编码成软件，然后卖出去。**

- 速卖通的 Agent，本质是把顶级卖家的运营经验（怎么写标题、怎么定价、怎么投广告）编码成模型可执行的策略，然后平权地发给所有中小卖家。卖家门槛降低 → 供给变多 → 平台 GMV 变大。AI 在这里不是卖点，是供给侧基础设施。
- Kooko 的逻辑类似，只是把服务对象从卖家换成了全球消费者：把模型能力包装成日常可用的产品体验。

两代全球化的对比：

| 维度 | 全球化 1.0 | 全球化 2.0 |
|---|---|---|
| 卖的东西 | 商品 | 商品 + AI 能力 |
| 运营方式 | 人力堆运营 | Agent 承担日常运营 |
| 竞争壁垒 | 供应链 + 流量 | 供应链 + 数据闭环 + 模型迭代 |

## 冷水时刻：Agent 出海不是自动赢

- **合规是硬成本**。欧盟 GDPR 与 AI Act 对用户数据、模型透明度都有明确要求，数据出境、内容审核、隐私政策，每一项都是真金白银的投入。
- **翻译不等于本地化**。语种覆盖了，但支付习惯、退货预期、促销节奏（黑五和大促的时间差）都得重做。
- **幻觉在商业场景里是亏钱**。通用聊天里模型胡说八道顶多尴尬，电商 Agent 报错价格、对买家做出错误承诺，是直接的资损。所以商业 Agent 必须有护栏（guardrails）和人工兜底，涉及钱的全自动，现阶段是个伪命题。
- **对手不弱**。OpenAI、Google、Meta 都在往 Agent 方向压，本地玩家的本地化能力也是天然优势。窗口期有，但不宽。

## 写在最后：三条冷思考

1. **判断 Agent 产品，看任务成功率，不看 demo**。演示视频永远丝滑，真正该问的是：任务自动完成率多少？人工兜底占多少成本？这两个数字决定它是一门生意，还是一场发布会。
2. **中小卖家把 Agent 当"初级员工"管理**。给它清晰的目标、边界和复核点——定价上下限、敏感类目不碰、每周抽查一次决策记录。当全自动印钞机用的，最后大概率交学费。
3. **出海预算里给合规留位置**。法务、本地化、数据合规这些"不产出"的项，建议按总预算 15%–25% 预留。平时看是成本，出事时是生死线。

全球化这件事，上一轮比的是谁货便宜、谁投放狠；这一轮比的是谁把 AI 塞进业务流程塞得更深。船票还是那张船票，但船上装的东西变了。
