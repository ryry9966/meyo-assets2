最近商业航天圈刷屏的一条消息：据36氪报道，「瑞启深空」三个月内连续完成两轮融资，天使+轮金额超亿元人民币，方向是把遥感数据卖成“情报”。很多人的第一反应是：卫星在天上拍照，怎么就值一个亿了？这篇文章不讲故事，只拆三件事：遥感产业链的钱怎么分、“数据”变成“情报”中间隔着什么、以及投资人为什么敢在这么早的阶段下重注。

## 一、商业遥感到底在卖什么：从“像素”说起

- 遥感（remote sensing），指不接触目标、从远距离获取信息。载体主要是搭载传感器的卫星：光学相机负责可见光与多光谱成像；SAR（合成孔径雷达）靠微波成像，能穿云透雾、昼夜工作；红外载荷则捕捉温度异常，比如火点与热泄漏。
- 衡量能力的两个硬指标：**空间分辨率**——0.3～0.5 米级已经能看清车辆轮廓；**重访周期**——同一地点隔多久被“再看一眼”，从数天到一天不等。后者决定了你只能看“快照”，还是能持续追踪“变化”。
- 产业链大致四层：卫星制造与发射 → 星座运营（卖原始影像）→ 数据增值处理 → 行业应用。越往上越重资产，越往下越接近钱。
- 参照系：美国 Planet 用约两百颗小卫星实现了陆地每日成像；国内“吉林一号”星座在轨卫星已过百颗。结论很简单：影像本身正在变得不稀缺，稀缺的是“从影像里读出什么”。

## 二、“数据”与“情报”之间，隔着一条加工流水线

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/417989128dc79663.png)

- 所谓“情报”，可以理解成：数据 + 时效 + 结论 + 可执行。一张原始卫星图到一份情报，典型链路是：
  1. **预处理**：辐射校正、几何校正、正射拼接，把“照片”变成“可测量的图”；
  2. **AI 解译**：目标检测（识别飞机、船舶、油罐）、变化检测（这里多了或少了什么）、语义分割（把耕地、水体、建筑自动分类）；
  3. **情报化**：把结果结构化成结论、预警或 API 接口，直接嵌进客户的决策流程。
- 价值规律很朴素：原始像素越来越便宜，结论越来越贵。粗略地说，信息量 ≈ 数据量 × 处理能力 × 行业知识。
- 三个被反复引用的案例：
  - 对冲基金用卫星数零售商停车场里的汽车密度，提前一个季度估算营收走势；
  - Orbital Insight 通过测量油罐浮顶阴影的变化，估算全球原油库存；
  - 保险公司在台风过境后用影像批量定损，把理赔周期从数周压缩到几天。
- 所以“卖情报”的本质，是把一次性图像交易升级为订阅制的决策服务——这也是资本愿意给高估值的核心叙事。

## 三、天使+轮超亿元：钱为什么敢这么早进来

- 先解释名词：**天使+轮**介于天使轮和 Pre-A 之间，一般出现在项目进展快于预期、老股东抢先加注的阶段。三个月连融两轮，本身就是市场信号。
- **供给端**：可回收火箭持续压低发射成本，小卫星走标准化、批量化路线，组网门槛大幅下降。数据供给在变多，解读能力成为瓶颈。
- **需求端**：农业估产、大宗商品监控、物流追踪、金融风控、灾害应急，这些行业天然需要“上帝视角”，而且预算相对成熟。
- **政策端**：商业航天连续被写入政府工作报告，被定位为新增长引擎，各地配套了产业园与专项基金，行业叙事有确定性。
- 一个类比：十年前的云计算，卖硬盘和带宽不值钱，卖 SaaS 服务才值钱。遥感行业正处在“卖数据”切向“卖服务”的节点，早期重注押的就是这个拐点。按行业惯例，能在天使阶段拿到亿元量级的公司，通常在团队拼图（卫星、算法、行业资源）或初步订单上已有可验证的东西。

## 四、护城河与坑：这门生意没有看上去那么轻

- 护城河大致三条：
  1. **数据获取能力**：自有星座或独家数据源，重访频率、分辨率、SAR 与光学组合形成差异化；
  2. **行业模型**：特定领域的标注数据和解译算法积累，通用大模型短期难以替代；
  3. **流程绑定**：以 API 和订阅嵌入客户日常决策，切换成本随使用时间上升。
- 坑同样清晰：
  - **重资产属性**：一颗商业卫星造价从数千万元到上亿元，还要面对轨道衰减、频谱协调与更新换代；
  - **合规约束**：遥感数据在国内有资质与分级管理要求，跨境交付另有规则，商业模式必须前置设计；
  - **客户教育成本**：许多传统行业并不知道自己能用遥感，销售周期以年计；
  - **公益数据竞争**：高分专项等国家级数据长期低价或免费发放，纯“卖图”没有生存空间。

## 五、冷思考：三条判断清单

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/379792a06bda2033.png)

1. **盯住“结论收入”占比**。如果主要收入仍是原始影像或数据处理外包，“情报”叙事就要打折；订阅与 API 收入的续费率，比融资新闻可靠得多。
2. **追问行业 know-how**。一个有效的问题：它的模型在目标行业数据上的表现，比“通用大模型 + 公开影像”的组合强多少？强不出量级，就没有护城河。
3. **别把融资速度当成验证**。卫星从立项、发射到正向现金流，周期以年计；三个月两轮说明资本认可叙事，但叙事与商业闭环之间，还隔着发射节奏、客户续约和模型迭代的漫长考验。热闹可以围观，下注需要耐心。
