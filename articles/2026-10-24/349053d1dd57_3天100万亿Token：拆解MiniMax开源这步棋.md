10月底的这波消息密度有点高：MiniMax 把新旗舰 M2 的模型权重直接放到开源社区，华为昇腾随即官宣将完成接入适配，官方口径称 API 上线三天处理了超过 100 万亿 token。三个信息点放在一起，其实指向同一件事——模型能力、国产算力、推理需求这三块齿轮，开始咬合转动了。这篇把每个数字拆开，算一算背后的账。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/e7fe9f6d9f0596f6.png)

## M2 是个什么模型：先把参数看明白

- **架构**：M2 采用 MoE（Mixture of Experts，混合专家）架构，总参数量约 230B，但每个 token 只激活约 10B。打个比方：公司养了两千名专家，每来一个需求只点名十位值班专家干活——能力来自“专家库”的广度，省钱省在“当班人数”上。
- **定位**：明确押注 coding agent 与工具调用场景，特点是“边想边干活”——在两次工具调用之间穿插推理（interleaved thinking），让模型自主跑完多步任务，而不是一问一答。
- **成绩**：公开评测中 SWE-bench Verified 约 69%，处在开源模型第一梯队；上下文支持 20 万 token 量级。
- **路线**：上一代 M1（总参 456B、激活 45.9B）就在押线性注意力（lightning attention）做长上下文，M2 把筹码换到了 agent 场景的极致性价比上。两条路其实是同一条：单位算力的产出最大化。

## 100 万亿 Token 怎么理解：算三笔账

1. **算力账**：100 万亿即 10^14。假设单卡推理速度 100 token/s，一张卡不眠不休要跑约 3.2 万年。说明这不是单点性能，而是大规模推理集群在并行吞吐。
2. **对照账**：Llama 3 预训练语料约 15T token，三天推理量约等于把它全量读六七遍。当推理消耗在数量级上压过训练消耗，说明行业重心正在从“造模型”滑向“用模型”。
3. **结构账**：普通对话一轮几千 token，而一次 agent 编程任务动辄几十万甚至上百万 token——每一步工具调用都带着全部上下文往返。token 暴涨的主力不是“人变多了”，而是“任务变长了，模型开始自己干活”。

一个必要的口径提醒：100 万亿是官方披露的吞吐数字，可以当行业热度指标看，但不必当审计数据用。

## 昇腾接入：开源模型与国产算力的飞轮

- **背景**：过去几年，大模型推理默认绑定英伟达的 CUDA 生态，迁移的最大成本在算子库和推理框架。
- **开源改变了什么**：权重和架构公开之后，芯片侧才有可能做针对性优化——算子移植、量化方案、MoE 的专家并行调度。DeepSeek、Qwen 系列此前走过同样的路径，vLLM-Ascend 这类推理栈也在逐步成熟。
- **飞轮两端**：模型厂拿到 GPU 之外的第二条供给曲线，不被单一货源卡住；芯片厂拿到真实的高强度负载，反过来打磨自家工具链。
- **对企业的意义**：私有化部署、数据不出域、供应链多元化——这三个采购理由，往往比榜单分数更接近决策现场。

## 为什么要开源：这其实是一笔商业账

- **经典打法**：Commoditize your complement——把“模型”这一层商品化，繁荣应用和 agent 生态，利润沉淀在 API 服务、企业版和云上。
- **抢开发者心智**：主流 agent 编排工具普遍兼容 OpenAI / Anthropic 协议，开源模型一旦被框架“零成本接入”，分发就变成社区自发行为，营销费用全省。
- **护城河没有消失**：开源的是权重，不开源的是训练数据、RL 环境、infra 和调参手艺。相当于乐高说明书公开了，但模具和产线还在自己手里。

## 三条冷思考：给开发者和选型团队

1. **看“每百万 token 的钱”，不只看榜单**：agent 场景的 token 消耗是聊天的几十倍，同一分数档里成本差一倍，月底账单可能差十倍。同时确认协议兼容性和工具链成熟度，这三件套缺一不可。
2. **芯片适配要看“时间差”**：官宣接入到生产级稳定之间，通常隔着多个版本迭代。PoC 阶段重点测三件事：MoE 算子覆盖率、量化后的精度损失、长上下文 KV cache 的显存与延迟表现。
3. **把 token 当电费管理**：设预算上限、开缓存（prompt caching / KV 复用）、做模型路由——分类摘要交给小模型，复杂决策留给大模型。尤其要监控 agent 循环里的无效重试：agent 最贵的 bug 是死循环。

开源、低价、国产芯，三条线在这条新闻里拧成了一股绳。2025 年底的大模型竞争，比拼的已经不只是“谁更聪明”，还有“谁更便宜、谁的电更省”——而对真正要干活的人来说，后者往往才是那个决定性的变量。
