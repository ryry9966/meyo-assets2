最近开发者圈子里刷屏的一件事：有用户发现，同样花 $20 订的 Claude Pro，你和别人的可用额度居然不一样——有人在 5 小时窗口里能发几十条消息，有人十几条就"熄火"了。36kr 等媒体跟进报道，称 Anthropic 正在小范围秘密测试不同的订阅套餐与额度组合。这事乍听离谱，拆开看其实是 AI 商业模式里一个绕不开的冲突点：订阅制的"一口价"，撞上了算力成本的"按量烧"。今天把这层窗户纸捅破。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/f68e60b2a6609486.png)

## 先把事实捋清楚：到底发生了什么

- **现象**：多位用户在 Reddit 和 X 上晒出截图，同为 Pro 订阅，消息条数上限、5 小时滚动窗口内的可用量并不一致。
- **报道**：据媒体报道，Anthropic 被曝在灰度测试不同的订阅额度与档位，官方没有给出完整解释。
- **背景**：Claude 目前的档位是 Pro $20/月，Max $100（约 5 倍用量）与 $200（约 20 倍用量）；今年 8 月底起，连 Max 用户也被叠加了每周用量上限——"花更多钱"也不等于"无限用"。
- **横向看**：这不是一家的事。OpenAI 的 ChatGPT Plus 长期有速率限制，$200 档的 Pro，Altman 公开说过平均下来是亏钱的。

一句话总结：不是 Anthropic 特别"黑"，而是所有 AI 订阅厂商都在偷偷做同一道数学题。

## 为什么 AI 订阅不敢"无限畅吃"：一条 token 一度电

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/9449ed02c0e431ca.png)

核心差异在于边际成本。传统订阅的边际成本约等于零，AI 订阅的边际成本是实打实的 GPU 电费：

- **Netflix 模式**：多一个用户看片，成本几乎不变，内容成本是固定的，所以敢卖"无限"。
- **健身房模式**：按 100% 容量卖卡，赌大多数人办了不练。
- **AI 订阅模式**：每次对话都要真烧算力，重度用户一天的消耗，可能超过一个月的订阅费。

再把推理成本的细节摊开看：

1. 模型每生成一个 token 都是一次前向计算；长上下文加上长输出，消耗近似线性甚至平方级增长。
2. 模型档位之间差价巨大。以 API 单价计，Opus 的输出 token 约 $75/百万，Sonnet 约 $15/百万，差 5 倍。你随手一句"用 Opus 帮我写篇长文"，单次成本可能是普通闲聊的几十倍。
3. 所以额度的存在，与其说是"防你薅羊毛"，不如说是防极少数重度用户把整个算力池子烧穿——剩下的轻度用户体验会先崩。

这就决定了：AI 订阅天然是**限额商品**。真正值得讨论的从来不是"有没有限额"，而是"限额怎么定、告不告诉你"。

## 灰度测试不新鲜，"同价不同量"才是雷区

灰度实验（A/B test）是互联网行业的标准操作：随机把用户分成几组，试不同的价格、额度、文案，对比留存、消耗、退款率，成本低、结论快。你每天看到的 App 改版，十有八九都是灰度出来的。

但测按钮颜色和测价格，是两回事：

- **前者**：不改变你拿到东西的"量"，属于体验优化，用户基本无感。
- **后者**：同样的钱拿到不一样的商品，经济学上踩进了版本划分（versioning）与价格歧视的灰色地带；落到用户感知上，就是三个字——被区别对待。

还有一笔信任账：用户可以接受"明码标价的贵"，Max $200 摆在官网上没人骂结构，大家骂的是贵；但很难接受"暗中缩水的等"。一次被截图曝光，抵消得掉一百次产品优化。

用工程师的话说：A/B 测试第一定律——永远假设你的 B 组截图会被发到网上。

## 普通用户怎么应对：三个可操作动作

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/b91d897b98390702.png)

1. **看懂额度的计量单位**。别只盯着月费，去看限制到底按什么算：消息条数、token 数、5 小时窗口，还是每周总量？同样叫"$20 档"，计量方式不同，实际可用量可能差出几倍。
2. **模型分层使用**。日常问答、改错别字用 Sonnet 级别的模型，硬骨头再手动切 Opus。很多人额度不够用，一半是被默认调用的旗舰模型悄悄吃掉的，切回去，额度立刻耐用一截。
3. **订阅和 API 算一笔账**。用量大且稳定的话，API 按量付费配上 prompt caching（重复前缀的成本能降一个数量级）反而更划算；用量轻且不固定，订阅才便宜。每月花十分钟导出自己的用量记录，比对着额度条焦虑有用得多。

再加一条习惯：额度页截图存档。规则哪天变了，你有据可查。

## 三条冷思考

1. **AI 订阅本质是"算力预售"**。你付的是固定价，厂商扛的是变动成本，中间的缓冲垫就是限额。只要 GPU 还是稀缺品，"无限"就永远只是营销词。
2. **灰度是工具，透明度决定它是优化还是背刺**。同样一组实验数据，"我们正在测试新档位"和"什么都不说"，沟通成本几乎一样，结局完全不同。
3. **用户真正在乎的不是价格，是公平感**。同价必须同量；涨价可以商量，暗改没法原谅。这条对现在和未来所有做订阅制的 AI 公司，都成立。
