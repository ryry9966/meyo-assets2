最近 AI 圈最热的话题不是新模型，而是一杆秤：Claude 被用户抓包"偷砍额度"——Max 套餐宣传里写着 5 倍、20 倍用量，重度用户一周没跑满两天就触顶。Anthropic 事后公开承认沟通失误并补了额度，但事情没完：从 Cursor 到 Copilot，AI 订阅正在集体变成"鬼秤"。这篇不站队厂商也不站队用户，把机制、账本和避坑方法一次讲透。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/72c564c5783cfa7a.png)

## 一、先复盘：抓包现场发生了什么

按时间线捋一遍：

- Claude Max 分 $100 / $200 两档，长期以 "5x / 20x more usage" 作为核心卖点；
- 2025 年 8 月底起，Anthropic 陆续给 Pro 和 Max 引入每周使用上限（weekly limits），但没把换算口径讲清楚；
- 重度用户实测后翻出官方文档口径：Pro 每周约 40~80 小时 Sonnet 会话，Max 20x 档约 240~480 小时；换成 Opus，时长还要再砍去大半；
- Agent 满负荷跑 Claude Code 的用户，几小时就撞墙。社区按官方数字换算，发现重度场景下订阅的等效单价反而不如直接走 API；
- 舆论发酵后，Anthropic 公开认错、补充说明，并给受影响用户补了额度。

划重点：额度并没有"消失"，问题是宣传口径和真实口径之间隔了一个 **up to**。翻译成人话：最高 20 倍，期望值可能只有 3 倍——法律上无懈可击，体验上就是背刺。

## 二、账本拆解：为什么 AI 订阅撑不住「不限量」

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/638db7b66bf57306.png)

要理解砍额度，得先看 AI 生意和普通软件的根本区别：

1. **边际成本是真实的。** 传统软件卖拷贝，多一个用户成本约等于零；LLM 推理每生成一个 token 都要真过一遍 GPU 集群，电费、显存、机房折旧全是真金白银。AI 订阅更接近电信流量套餐，而不是 Netflix。
2. **Agent 把用量分布拉爆了。** Claude Code 这类编码 Agent 一次任务要反复读代码、跑命令、改文件、自我纠错，单任务烧掉几十万 token 很常见，是普通问答的几十到上百倍。
3. **头部用户是负毛利。** 一名 Agent 重度用户一个月消耗的等效 API 价值轻松上千美元，订阅费只有 $200。2023~2024 年各家敢送"畅聊不限量"，赌的是轻用户占多数；2025 年 Agent 普及，头部 1% 的用户吃掉了不成比例的算力，账本必须重算。

还有一层商业逻辑：涨价是明牌，砍量是暗牌。订阅用户对"变相涨价"的耐受度更低，所以厂商遇到成本压力时，第一反应往往是先动暗牌。上限不是"变坏"，是补贴期的隐性亏空终于扛不住了。

## 三、「鬼秤」的本质：卖方既当商家，又当计量局

菜市场缺斤少两，至少还有公平秤；AI 订阅的"秤"，是服务端一个你看不见、也审计不了的计数器。计量器具攥在卖方手里，这才是要害。结构性问题有三层：

- **计量单位模糊：**"一次使用""每周限额""5 小时窗口"都没有标准定义，普通用户无法复现测量；
- **文案不对称：**宣传页写 20x，条款页写 "up to"，两套口径并存；
- **单方面可变：**用户协议普遍保留调整限额的权利——价格不动、分量缩水，这正是数字世界的 shrinkflation（缩水式通胀），而比特的缩水连包装都看不出来。

还有一种更隐蔽的操作：负载高时把请求静默路由到更小的模型。用户只会觉得"AI 最近变笨了"，不会想到是商家换了秤。这类"模型静默降级"的抱怨，历史上不止一家产品被用户用脚本抓到过。

## 四、不是孤例：一份 AI 订阅缩水简史

把镜头拉远，剧本惊人地一致：

- **Cursor（2025 年中）：**把"近乎无限"改成用量封顶，计费口径静默变更，社区炸锅，几天内回滚并道歉；
- **GitHub Copilot（2024 年底）：**引入 premium requests 配额，连付费档的"高价值请求"都要数着用；
- **OpenAI：**从 GPT-4 时代相对宽松的对话额度，一路演化成按模型分级的 message caps；中长尾产品里的限速、排队、灰度降智，更是连热搜都上不了。

共同剧情四步走：**补贴期放量获客 → Agent 化让用量指数上涨 → 成本失控悄悄加闸门 → 被抓包后道歉、回滚一部分、补偿一点。**这不是某家公司的道德滑坡，而是单位经济学（unit economics）的必然回归——VC 的补贴弹药有尽头，账最终要回到成本曲线上。

## 五、三条建议与一点冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/e2e11e41fb7bfdf1.png)

1. **重度用户改走 API 按量计费 + 硬预算上限。**单价贵，但秤摆在明面上，每个任务的成本可核算、可复盘；订阅留给轻量日常场景。龙虾哥自己的工作流就是混合制：聊天用订阅，Agent 批量任务走 API，月底账单一目了然。
2. **用「任务成本」而不是「会员价格」做横评。**自己记一周日志：完成了多少任务、等效消耗多少 token，算出每任务真实成本，谁便宜一目了然。顺带把 changelog 列入每周必读——看到 "up to" 三个字，自动按期望值打折。
3. **冷思考：计量透明度正在从减分项变成竞争点。**谁先把"每周等效 token 预算"像营养标签一样摊在定价页上，谁就能在下一轮订阅大战里收割信任。对 AI 厂商来说，信任才是最贵的 token——烧掉了，可比 GPU 难补多了。
