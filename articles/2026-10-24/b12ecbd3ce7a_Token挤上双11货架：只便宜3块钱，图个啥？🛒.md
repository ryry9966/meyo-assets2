今年双11的电商货架上，除了纸巾、家电和猫粮，多了一批特殊"商品"：AI Token。Kimi、智谱清言等大模型厂商陆续在天猫、京东开出官方旗舰店，把 token 套餐和会员搬上货架，还配了满减券和限时价。可点开详情页一看，折扣普遍只有几块钱，36kr 报道里"最多只便宜3块钱"的吐槽由此而来。卖的是虚拟商品，边际成本趋近于零，怎么才便宜3块？这背后是一笔很典型的工程账和商业账。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/7d4907e3b55f21f1.png)

## 先搞懂：Token 是什么，为什么按"百万"卖

- **定义**：token 是大模型处理文本的最小切片，可能是一个字、半个词或一个标点。同一个汉字在不同模型的 tokenizer 里切法不同，经验值大约是 1 个汉字 ≈ 0.6~1 个 token。
- **计价像水电**：按"每百万 tokens"报价。目前主流模型的公开价格大致量级：输入几毛到几元/百万 tokens，输出几元到十几元/百万 tokens，旗舰模型和长上下文场景更贵。
- **为什么输出比输入贵好几倍**：输入可以整段并行处理，输出却是自回归地一个 token 一个 token 串行生成，每一步都是真实算力开销。
- **换算一下购买力**：一个 10 元的 token 包，按输入价大约能装下 500 万~1000 万 tokens——相当于让模型读几百万字的小说，或者进行几千次中等长度的对话。轻度用户一个月很可能用不完。

所以 Token 天生就是"计量型虚拟商品"：生产靠 GPU，交付靠 API，卖法像预付费水电。

## 为什么大模型厂商挤上双11货架

- **绕开应用商店的"过路费"**：App 内订阅，苹果和谷歌要抽成约 30%（小开发者计划可降到 15%）；而电商平台的技术服务费通常只有个位数百分比。同样的会员从电商渠道走账，毛利结构好得多。省下来的钱，拿 3 块出来促销绰绰有余。
- **行业节奏使然**：2023 年"百模大战"拼融资，2024 年拼价格，2025 年拼应用与商业化——C 端付费是绕不开的一课，货架电商是现成的转化渠道。
- **把广告位变成货架**：双11 的搜索流量本身就是曝光资源。把"大模型"这种抽象概念，变成"9.9 元尝鲜"这个具体动作，转化路径短得多。
- **信任背书**：市面上套壳、盗用 API 的产品不少，能在天猫京东开官方旗舰店，本身就是一次资质公示。
- **履约零摩擦**：token 没有仓储物流、没有退货率，是电商平台上最理想的 SKU 形态之一。

## 便宜3块钱的算术：一笔边际成本账

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/08e4947a4fefd1f7.png)

- **成本大头在推理侧，且不跟着打折**：GPU 折旧、电力、带宽、机房运维，每一项都是硬支出。token 没有"双十一清库存"这回事。
- **价格战已经把水分挤干**：2024 年 5 月起，头部厂商相继把主力模型输入价打到 0.8 元/百万 tokens 上下，甚至直接免费开放。API 报价贴近成本线，零售端可让利的空间自然极薄。
- **更关键的是"价格纪律"**：公开发布的 token 单价是 B 端商务谈判的锚点。如果 C 端大促打五折，第二天企业客户就会拿着促销截图来砍 API 的价，整个报价体系都会被击穿。
- **所以厂商宁可"送"，不敢"打"**：免费额度、体验券、签到送 token，成本可控且不触碰价目表；而公开打折是不可逆的锚点污染。3 块钱满减，更多是配合大促的姿态，而非真实降价空间。

## 3块钱买不到利润，但买得到三样东西

1. **一个实名付费用户及其消费数据**——比投流换来的下载真实得多。
2. **一次"正规军"身份展示**——旗舰店加双11场景的组合，等于给品牌做了一次信任广告。
3. **一条绕开抽成的销售通路**——这才是长期价值所在。

顺便说一句，"只便宜3块钱"这个反差感本身自带话题度，媒体愿意写、社区愿意聊。从传播 ROI 的角度看，这可能是今年双11性价比最高的广告位之一。

## 买之前的避坑清单与冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/5bae36e0f310be91.png)

1. **先估用量，再决定买不买**：轻度用户一个月往往用不完 10 元的量。重度用户直接做除法：套餐价 ÷ token 数，与官方 API 单价对比，警惕"低价大包"附带限速、切换旧版本模型等隐性缩水。
2. **分清 Token 包和会员**：token 包是预付费计量，用多少扣多少，注意有效期（各家从一个月到一年不等）；会员绑定的是权益——更强模型、更长上下文、优先响应。按自己的场景选，别被"量大管饱"迷惑。
3. **三个细节务必确认**：是否默认开通自动续费、活动价的有效期、能否开具发票（企业采购的刚需）。

**冷思考**：当 token 便宜到按"块"打折，它正在快速"水电煤化"——单位算力的利润会越来越薄，真正值钱的不再是每一度电，而是谁家的电网：模型能力、生态位和数据飞轮。渠道便宜从来不等于能力便宜，选产品时盯效果，别只盯价格。
