最近 36kr 一篇报道把 AI 漫剧行业的账本摊开了：团队熬夜肝出来的爆款，收入扣掉算力账单后所剩无几，老板们自嘲“在给算力打工”。这不是个别现象的矫情，而是当下 AIGC 内容创业的普遍结构问题——创意离钱最近的地方，往往离利润最远。这篇文章把这件事拆开看：钱花在哪、为什么降不下来、场上的人怎么破局。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/c507d85ae99d9722.png)

## 先看产线：一集 AI 漫剧是怎么“算”出来的

AI 漫剧的产线大致五步：

1. **编剧**：用 LLM 辅助生成和润色剧本，拆成分镜表；
2. **出图**：文生图模型（SD 系、即梦、Midjourney 等）逐镜头生成画面；
3. **动起来**：图生视频模型（可灵、Vidu、Runway 一类）把静态画面变成 3~10 秒动态镜头；
4. **后期**：TTS 配音、字幕、剪辑、音效；
5. **分发**：投放到短视频平台，吃播放分成、广告或付费解锁。

看起来是“AI 替人干活”，但每一环背后都对应一次模型推理，也就是一次 GPU 时间。人的活儿变成了“指挥 AI”，而指挥本身是按次数计费的。

## 钱花在哪：抽卡经济学

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/ae10d62aec09384e.png)

成本大头不在“生成一次”有多贵，而在“要生成多少次才能用”：

- **抽卡损耗**：扩散模型的生成本质是从噪声出发的随机采样，同一个提示词跑两次结果都不同。为了让主角在近百个镜头里长同一张脸，团队普遍要反复抽卡。按从业者口径，单张“可用率”在 10%~30% 算正常——等于为一张能用的图，付了三到十张的钱。扩散模型不保证出片，只保证扣费。
- **角色一致性的隐性成本**：为了压抽卡次数，团队会上 LoRA 微调、参考图控制（IP-Adapter / InstantID 一类方案），这又引入训练算力和调试成本。
- **图生视频的算力密度**：视频生成要保证时序一致性，单条消耗的 GPU 时间远高于静态图。按条计费下，一条 5 秒视频的 API 报价通常在几毛到几元，可用率同样要打折。
- **单集账本（量级估算，因模型与批次而异）**：一集 90 秒的漫剧约 70~120 个分镜，图 + 视频 + 修补的算力开销大致几百元；一部 80~100 集的剧，仅算力就可能到数万元，且随产量线性增长。

于是出现一条拧巴的曲线：**收入随爆款波动，算力成本却随产量刚性增长**。产量越大、爆款越多，喂给 GPU 的钱越多——这就是“给算力打工”的字面含义。

## 为什么成本降不下来：三个结构性原因

1. **不确定性写在原理里**。扩散模型逐级去噪，输出天然带随机性；想“一次就对”需要更强的可控生成能力，而控制能力本身也是算力。
2. **定价权不在内容方手里**。模型迭代快，API 定价、可用率、效果上限都由上游决定，内容工作室是纯粹的价格接受者，没有议价筹码。
3. **同质化把毛利压薄**。门槛低、套路易复制，收入端被平台算法和同行竞争摊薄，成本端却降不下来，两头挤压。

那为什么还有人做？平台在生态建设期的流量扶持、赌一个爆款回本、以及“先占位再谈钱”的卡位逻辑——都是理由，但都改变不了租金刚性的事实。

## 历史在押韵：从给带宽打工到给算力打工

这个结构并不新鲜：

- **2010 年代的视频网站**：带宽和版权成本吃掉大部分收入，全行业亏损多年；
- **手游时代**：研发商给渠道五五分成，利润被渠道抽走一半；
- **直播与电商**：商家给流量成本打工，投流费吞掉毛利；
- **矿圈**：矿工给矿机厂商和电费打工。

规律很清楚：**当生产要素被少数上游掌握、而内容端高度分散时，价值分配必然向上游集中**。淘金热里赚钱的是卖铲子的，这一次铲子叫 GPU。

## 破局思路与三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-24/c40a51e3e4955894.png)

给还在场上和想进场的团队三条建议：

1. **把“单位可用素材成本”当第一 KPI**。别只盯播放量，先算清“每秒可用视频、每张可用图的平均算力开销”，沉淀自己的提示词资产库、LoRA 角色库和抽卡工作流。可用率从 20% 提到 40%，等于成本直接砍半——这比到处找便宜模型更可持续。
2. **利润别押在“搬运模型能力”上**。模型会越来越便宜也越来越强，单纯靠 API 拼画面的能力溢价终将归零。护城河在 AI 拿不走的地方：选题嗅觉、人设 IP、连载运营、用户数据反馈闭环。算力是租金，内容资产才是产权。
3. **可以赌成本曲线，但要先活到降价那天**。推理价格战确实在打，过去一年主流模型 API 价格经历多轮下调，视频生成效率也在提升，“今天算不过来的账，半年后未必算不过来”。但降价节奏是上游定的，现金流是自己的——控制产量、小步验证，把爆款赚到的钱变成内容资产，而不是更多次抽卡。

算力是新时代的地租，谁都得交。区别在于：有人交完租只剩账单，有人用交租换来了属于自己的地。
