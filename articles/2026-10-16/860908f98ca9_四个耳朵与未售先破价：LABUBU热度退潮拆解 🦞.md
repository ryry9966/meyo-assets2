几个月前还得靠抽签、靠排队、靠黄牛加价才能抱回家的 LABUBU，最近行情急转直下：新品图曝光后，有网友发现它的耳朵在视觉上变成了四个，评论区齐刷 "AI缝合怪"；更要命的是，货还没正式发售，二级市场报价已经跌破了官方发售价，而上一代产品还曾溢价数倍、一娃难求。一只玩偶的耳朵数量和它的价格曲线，怎么就扯上关系了？这篇文章不讲八卦，只拆机制：顶流 IP 是怎么被 "制造" 出来的，又是怎么降温的。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-16/2e5ad9d219a8b319.png)

## 一、先对齐事实：这几天到底发生了什么

- **来历**：LABUBU 是香港出生、荷兰长大的艺术家龙家升在 2015 年绘本《精灵三部曲》里画出的角色，原型来自北欧民间传说中的小精灵，2019 年起成为泡泡玛特的独家 IP。
- **爆红路径**：2024 年，Blackpink 成员 Lisa 多次在社交媒体晒出 LABUBU，先带火东南亚，再传导全球。2025 年上半年，LABUBU 所在的 THE MONSTERS 系列收入约 48 亿元，同比增长约 668%；一只初代薄荷色大娃更是拍出过 108 万元。
- **最近的拐点**：新一代产品曝光后，部分网友指出造型里耳朵的数量 "看起来是四个"，被调侃为 "AI 缝合怪"——这个网络词原本指把各种特征硬拼在一起、缺乏整体感的设计；与此同时，新品在得物等平台的预售报价已跌破发售价。
- **一个关键细节**：老粉鉴定 LABUBU 真伪的土办法之一是数牙——正版是九颗牙。耳朵、牙齿这类设定细节，恰恰是 IP 的核心资产，这也解释了为什么 "四个耳朵" 能掀起这么大的风波。

## 二、顶流飞轮：热度是如何被 "制造" 出来的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-16/1361ccb3debad95f.png)

1. **IP 本体提供辨识度**：丑萌（ugly-cute）定位，尖耳、圆眼、九颗牙，情绪价值拉满，天然适合做挂件、适合出片。
2. **稀缺机制制造欲望**：盲盒 + 隐藏款（概率常在 1/72 到 1/144）+ 限量发售 + 抽签排队，人为把 "想要" 升级成 "抢"。
3. **社交货币放大声量**：挂在包上等于免费的行走广告，小红书、Instagram 的晒单形成二次传播。
4. **黄牛与脚本完成价格发现**：Bot 抢购、二级平台实时报价，把 "喜欢" 翻译成 "价格"，而溢价本身又成了新的传播素材，越涨越有人晒，越晒越有人抢。
5. **官方运营控制奏**：稳定上新、跨界联名、大娃拍卖，持续给飞轮补充能量。

这套 "注意力 → 稀缺 → 转售溢价 → 更多注意力" 的飞轮，本质是把一款消费品临时金融化：玩具还是那个玩具，但边际买家已经从 "喜欢它的人"，换成了 "相信下一个人会出更高价的人"。飞轮转多快，决定涨多猛；飞轮靠什么停，决定跌多狠。

## 三、价格掉头的机制：投机性需求有多脆弱

- **价格公式变了**：二级市场价格 = 真实需求 + 预期收益。当共识从 "必涨" 松动为 "可能跌"，投机盘会第一时间离场，而它们的离场本身就是下跌。
- **供给端在放量**：补货频率上升、系列越出越多、海外门店铺开，稀缺性被自己稀释。IP 方要的是营收曲线，不是维持二手溢价，两者的目标函数并不一致。
- **边际买家结构恶化**：圈外人占比越高，需求越不稳定。涨势一旦停滞，"止损抛售 → 价格更低 → 更没人接盘" 的负反馈立刻启动。
- **设计争议是催化剂，不是病根**：先不论 "四个耳朵" 是渲染角度造成的视觉误会，还是设计本身的失误，它的杀伤力在于动摇了收藏逻辑的根基，设定一致性（canon）。收藏品溢价很大程度上来自 "原作感"，一旦用户开始怀疑 "这玩意是不是 AI 拼的"，情绪价值先打折，溢价逻辑跟着松动。
- **历史对照**：1990 年代的 Beanie Babies 毛绒玩具走的是同一条路，可爱 + 限量 + 二级市场报价，1999 年崩盘后价格跌去九成以上。剧本高度相似：飞轮加速有多快，刹车就有多突然。

## 四、"AI 缝合怪" 这个差评，为什么值得单独拎出来讲

- **大众的 "AI 雷达" 变得极其灵敏**：2025 年的消费心理出现一个微妙转向，对 "看起来是 AI 生成的" 给折价，对 "有人的意图和手艺" 给溢价。这在潮玩这种强设计驱动的品类里尤其明显。
- **IP 角色本质是品牌资产**：和可口可乐的曲线瓶一个道理，耳朵数量、牙齿数量、五官比例都是 hard constraint，会写进 style guide。偏离设定，轻则被吐槽，重则触发轻量版的恐怖谷（uncanny valley）效应。
- **客观说一句**：被吐槽的新品未必真用了 AI 生成，"AI 缝合怪" 更多是一个情绪标签。但标签比事实更有信息量，它说明用户信任已经出现损耗，大家开始用最挑剔的眼光找茬。
- **一句话总结**：设计失误是伤口，信任损耗才是出血点。

## 五、一个判断框架：怎么给潮玩估价

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-16/c9b69100c1017923.png)

把二手价格拆成三层，逐层验收：

1. **情绪价值（底价层）**：剔除一切炒作后，你个人愿意为它付多少钱。这是唯一完全由自己说了算的部分，也是价格的地基。
2. **社交价值（中间层）**：它还能不能持续产出 "值得晒" 的内容？社区在认真聊设计，还是只聊涨跌？只聊涨跌，说明盘子已被博弈资金主导。
3. **金融价值（泡沫层）**：溢价是集中在隐藏款，还是全线溢价？全线溢价通常是纯炒作信号；同时盯紧补货频率和放量节奏，供给端一松口，泡沫层最先归零。
4. **反向指标**：当身边从不玩潮玩的人开始问 "怎么买能赚钱"，一般离顶部就不远了。

## 最后，三条冷思考

1. **给普通玩家**：用消费品心态买，别用金融心态接。按 "我喜欢它的程度" 定价，把可能的溢价当彩蛋，而不是买入理由。为爱付费不丢人，为涨付费要小心。
2. **给 IP 运营方**：稀缺是运营出来的，信任是设计出来的。角色设定一致性之于潮玩 IP，就像 API 兼容性之于软件生态，破坏它省下的力气，远不够支付修复它的成本；供给节奏则决定生命周期，赚快钱和做长线，上新表上就得二选一。
3. **给围观群众**：单次破价不等于 "IP 死亡"，昔日溢价也不等于 "永动机"。二手报价只是注意力曲线的镜像，波动是常态；真正值得跟踪的是复购率、老用户留存这些慢变量。至于那只多出两只耳朵的 LABUBU，它至少证明了一件事：老粉是真的在数牙。
