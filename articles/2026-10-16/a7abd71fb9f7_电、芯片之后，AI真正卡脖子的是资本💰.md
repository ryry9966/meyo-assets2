2023 年，全行业在抢 H100，显卡被抢成了理财产品；2024 年，大家发现芯片买得到、电不够用，微软干脆签约重启三里岛核电站给数据中心供电；到了 2025 年，市场把目光移向更上游的报表：四大云厂商一年资本开支加总超过 3000 亿美元，而 AI 业务本身的收入远追不上这笔投入。正如 36kr 那个判断——AI 最大的瓶颈不是电，不是芯片，而是钱。这篇文章拆一下：“缺钱”到底缺在哪一层，以及普通人该盯什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-16/ceac37f9353acea5.png)

## 一、瓶颈迁移史：显卡 → 电网 → 资产负债表

- **2023，缺芯片。** H100 一卡难求，交付周期以月计，真正的卡点是台积电 CoWoS 先进封装和 HBM 显存产能。“算力就是权力”在那一年不是段子。
- **2024，缺电力。** AI 机柜功率从十几千瓦冲到上百千瓦，数据中心排队等并网，美国大项目动辄要等数年；变压器、大型燃气轮机的交付周期普遍拉长。微软与核电运营商签 20 年协议重启三里岛，就是那个阶段的标志性事件。
- **2025，缺钱。** 芯片和电本质都是“花钱能买到”的资源，于是所有讨论最终汇到同一张表上：微软 2025 财年资本开支约 800 亿美元，谷歌把全年指引上调到 900 亿以上，亚马逊冲上千亿量级，Meta 也在 600~700 亿区间；OpenAI 牵头的 Stargate 项目更是放话四年 5000 亿美元。

瓶颈没有消失，只是沿着产业链向上游移动——走到头，就是“谁出钱、钱能不能转回来”这个终极问题。

## 二、“钱”到底卡在哪：拆开这台烧钱机器

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-16/5c573f520d3f6f0d.png)

把大模型的商业闭环拆开，钱至少在四个地方漏水：

1. **收入追不上投入。** 几千亿美元级别的年资本开支，对应模型层与应用层的直接收入，公开估算只有几百亿美元量级，中间差着一个数量级。GPU 会计折旧年限 5~6 年，但产品代际约两年一换，经济寿命可能更短——投资人 Michael Burry 就公开质疑头部云厂商拉长折旧年限、低估当期成本，这笔账市场正在重算。
2. **推理是真金白银的边际成本。** 每次对话背后都是实打实的 GPU 时间。好消息是 token 单价在暴跌，按 a16z 的测算，同等能力模型的价格一年降约一个数量级；坏消息是单价降得越快，模型厂毛利率越承压——先上量，利润在后头。
3. **循环交易让资金链互相咬合。** 英伟达宣布最多向 OpenAI 投资千亿美元，OpenAI 拿这笔钱采购芯片；OpenAI 与 AMD 的 6GW 大单附带认股权证；据媒体报道它还与甲骨文签了约 3000 亿美元、为期数年的云合同；Meta 则把部分数据中心项目装进合资载体、引入私募信贷，并发行了三百亿美元公司债。买家、卖家、投资人互相转账，各方报表一起变胖，“资金空转”的质疑声也随之变大。
4. **终局考验只有一个词：闭环。** 资本市场可以容忍巨额亏损，但前提是“能力提升 → 用户付费 → 收入增速跑赢折旧增速”这条链持续成立。链条哪一环断了，前面的投入都会变成资产负债表上的减值。

一句话总结：芯片和电是能用钱解决的问题，而钱的问题，是钱要能自己转回来。

## 三、历史对照：光纤泡沫早就演过一遍

1. **1840 年代英国铁路狂热。** 资本蜂拥入股铁路公司，高峰期议会一年批准的里程超过此前几十年的总和；泡沫破裂后大批公司清盘，股东血本无归——但铁轨铺下去了，成了此后百年英国经济的底座。
2. **1990 年代末光纤泡沫。** 电信运营商加杠杆狂铺骨干网，2001 年后批量破产重组，带宽价格暴跌一个数量级以上。结果呢？2005 年前后 YouTube 这类“烧带宽”的产品才做得起来，云计算的红利正是踩在过剩的光纤上。
3. **共同教训：** 资本过热往往超额完成基础设施铺设，泡沫破裂不等于技术失败；但对场内玩家来说，估值重置与杠杆出清是真实的淘汰赛。
4. **这次更狠的一点：** 光纤能躺二十几年慢慢变现，GPU 三五年就可能被下一代反超。资产周转越快，留给“烧钱换时间”的窗口越短，回报验证来得越急。

## 四、接下来看什么：一套可操作的判断框架

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-16/c6a27f5448a4df66.png)

与其猜泡沫何时破，不如盯这几个先行指标：

1. **闭环进度**：AI 直接收入（订阅 + API + 云推理）对比全行业年折旧额，看比值趋势向上还是向下；
2. **折旧政策**：哪家又在延长 GPU 折旧年限，哪家悄悄缩回去（亚马逊已把服务器年限调回 5 年）——会计政策是最诚实的焦虑信号；
3. **循环交易占比**：收入里有多少是“股东或供应商转一手”的钱，剔除后还剩多少真实需求；
4. **价格曲线**：GPU 租赁价、token 单价是否持续下探。下探对使用者是红利，对重资产持有者是警报；
5. **融资结构**：股权 → 债券 → 私募信贷 → SPV，资金来源越往信用市场下沉，对回报确定性的要求就越高，容错越小。

给从业者的两条避坑提示：采购算力别在价格高位锁死超长合约，token 成本在跌，弹性比折扣值钱；做产品则要主动押注成本下降曲线——今天贵到没人用的功能，明年可能就是白菜价。

## 收尾：三条冷思考

1. **看现金流闭环，别只看参数榜单。** 判断任何 AI 叙事的健康度，先问一句：收入什么时候能覆盖折旧加运营成本？答不上来的，故事再大，本质也是负债。
2. **成本曲线比排行榜更值得盯。** 过去两年 token 价格的下降速度远超多数人预测，好生意是站在成本下降曲线上做事，而不是赌某一家永远维持高价。
3. **泡沫破裂不等于技术终结。** 铁路和光纤都验证过：基础设施会留下来，但玩家名单会重写。无论投资还是创业，控制固定成本敞口，别把身家押在“永远高增长”的假设上。

芯片可以扩产，电网可以增容，唯独“钱要赚得回来”这件事没有捷径。GPU 可以三班倒加班生产，投资人的耐心没法三班倒——它才是这场马拉松里唯一不可扩产的资源。
