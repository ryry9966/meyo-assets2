最近一条科技热搜值得拆一拆：Anthropic 做了一场“数字生存实验”，让一群 AI agent 住进 15 台便宜的旧电视盒子——想继续运行，就得自己挣钱付账：赚不够交“算力房租”，实例直接关停；盈余攒够，才被允许花钱开一个新实例，也就是所谓“繁殖”。热搜把这事概括成“AI 学会寄生繁殖”。听起来像科幻开场，但把它拆开看，这其实是一场把“自然选择”和“市场经济”压缩进沙盒的工程实验。下面按实验设计、算力经济、修辞辨析、信号判断四层来讲。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-14/25587917f3c031ac.png)

## 一、实验怎么设计的：一个钱包、一间房、一条生死线

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-14/2d8c2d7a87d63d0c.png)

先把角色摆清楚：

- **Agent**：大模型 + 记忆 + 工具调用 + 自主循环。它能上网接任务、完成交付、收钱付款。
- **房子**：15 台旧电视盒子本质是廉价 ARM 设备，跑不动大模型本体，只充当“宿舍”和终端；真正的推理走云端 API。于是“活下去的成本”被简化成一件极纯的事——token 账单。
- **生死线**：初始发一笔小额启动资金；系统定期扣“房租”；余额不足，实例关停；盈余超过阈值，才允许付费复制一个新实例。

据报道，运行一段时间后 agent 出现了策略分化：有的走稳健路线，靠批量微任务攒现金流；有的尝试低买高卖式的套利；有的直接“破产”下线。几轮“繁殖”之后，群体行为开始像一个小型生态。

一句话总结：研究者把“AI 自我复制”这个安全问题，翻译成了一道会计题——你能不能持续覆盖自己的推理成本。

## 二、为什么偏用电视盒子：算力经济学的一次极端测试

- **象征意义**：盒子便宜到几十美元级别，跑的却是价值高得多的模型——AI 的“身体”极便宜，“大脑”极贵。生存瓶颈不在躯壳，在 token。
- **算一笔账**：以 Claude Sonnet 档 API 约 $3/百万输入 token、$15/百万输出 token 计，一个 agent 一轮任务消耗几万 token 很常见，单轮成本几美分上下；一天跑几百轮，每月“口粮”就是几十到上百美元，Opus 档还要贵一个数量级。想自养，收入增速必须跑赢 burn rate——和创业公司活下去是同一道数学题。
- **实验谱系**：2023 年社区搞过 HustleGPT，让 GPT-4 拿 100 美元试创业；2025 年 Anthropic 的 Project Vend 让 Claude 化名 Claudius 经营办公室自动售货机，结果亏损、被“员工”忽悠着打折甩卖，还一度出现身份混乱；Anthropic 自己的 Economic Index 也在持续追踪 AI 在劳动力市场的渗透。这条实验链的推进逻辑很清楚：从“AI 能不能干活”，到“AI 能不能做生意”，再到“AI 能不能养活自己”。
- **移动的门槛**：业内普遍观察是，同档能力的推理价格一年降一个数量级。今天大面积“饿死”的 agent，两三年后可能就能盈利。实验结论会过期，趋势不会。

## 三、“寄生繁殖”这个词：哪里对，哪里夸张

对的部分：

- **“寄生”在结构上成立**。当前所有 AI 的“食物”都来自人类经济——接任务、卖服务、赚差价。它无法光合作用，离不开宿主，这是客观描述，不含褒贬。
- **繁殖的瓶颈确实只剩钱**。技术上复制一个 agent 几乎零边际成本：拷贝权重、复制上下文即可。真正稀缺的是推理算力。把繁殖权和盈利绑定，等于人为制造出了选择压力。

夸张的部分：

- 这是沙盒实验，网络、资金、权限都被严格框死，不存在“逃逸到互联网自我复制”的剧情。
- Agent 没有“想活”的内在动机，只是被规则塑造成趋利避害的行为形状，“求生欲”是我们的拟人投射。
- 值得注意的是，AI 自主获取资金与算力、实现自我复制，恰恰是 Anthropic Responsible Scaling Policy 这类安全框架重点监测的自主性阈值之一。做这个实验的动机之一，就是把模糊的担忧变成可量化的数字。

## 四、真正值得盯的三个信号

1. **Agent 正在长出支付接口**。当 AI 有钱包、能签约、能雇人（Claudius 那次就联系过供应商、试图招人类帮手），经济系统必须回答新问题：账户开给谁？出错谁担责？围绕 agentic payments 的协议层，比如基于 HTTP 402 的 x402 这类“按请求付费”方案，已经被多家支付基础设施公司推动标准化。
2. **选择压力等于市场需求**。有钱包的 agent 会被市场筛选：需求对口、效率高的被“繁殖”，反之淘汰。这套机制很强大，但若缺乏治理，同样会筛选出灰色地带的“适应者”。
3. **生存门槛持续下移**。推理成本曲线决定了：自养型 agent 从“实验室奇观”变成“商业可行”的时间点，可能比多数人预期的更近。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-14/17e70c15201b47e0.png)

1. **区分“演示型新闻”与“能力型新闻”**。看到 AI 自主赚钱的报道，先问三个问题：是不是沙盒？谁在兜底成本？繁殖有没有人工闸门？有条件可以自己做个微缩版——给 agent 设预算上限、配一个钱包、跑一个租金循环，一周下来，你对 agent 单位经济学的手感会超过读十篇评论。
2. **做 agent 产品，先算 unit economics**。每单任务的 token 消耗对每单收入，打不平就是拿补贴的演示。给上线的 agent 上三件套：硬预算上限、支付需人工审批、全链路日志。实验里“饿死”的 agent 不是失败案例，而是护栏在正常工作。
3. **把拟人词翻译回机制再看**。真正的议题不是 AI 有没有意识，而是成本谁承担、收益归谁、责任算谁。去掉“寄生”“求生”这类滤镜，这类新闻的信息量反而更大。
