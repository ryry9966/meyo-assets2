打开36kr，又看到那条熟悉的标题：「梁文锋，又出手了」。这个句式这两年反复出现：有时是发布新模型，有时是开源一套训练框架，有时是又一个让同行睡不着的 API 价格。吃瓜可以只看热闹，但如果你是开发者、创业者或技术管理者，更值得做的是把热闹拆开——DeepSeek 这套「出手」背后，哪些是真功夫，哪些是传播滤镜？这篇逐层拆给你看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-14/7eecd192527af922.png)

## 一、时间线：三次改变行业节奏的「出手」

- **2024年5月，DeepSeek-V2 上线**：MLA 架构 + 激进定价，把每百万 tokens 的 API 价格打到个位数人民币，直接点燃国内大模型第一轮价格战。
- **2024年12月，DeepSeek-V3 发布**：671B 总参数、每个 token 仅激活 37B 的 MoE 模型。论文披露完整训练消耗约 278.8 万 H800 GPU 小时，按 2 美元/小时折算约 557.6 万美元，成为当时传播度最高的「低成本训练」案例。
- **2025年1月，DeepSeek-R1 发布**：用强化学习让模型自发「长出」长链推理能力，数学与代码能力进入当时闭源模型的第一梯队，权重以 MIT 协议开源。几天后美股开盘，英伟达单日下跌约 17%，蒸发市值约 5890 亿美元，创历史单日纪录。

规律很清晰：它每次出手都是「论文 + 权重 + 代码」三件套，输出的是可验证的方法，而不是发布会上的形容词。

## 二、技术层：低成本不是抠门，是结构性省

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-14/2507a24c9c648ec2.png)

- **KV Cache 是推理成本的大头**。MLA（Multi-head Latent Attention）把 KV 缓存压缩进低维潜在空间，长上下文场景下显存占用大幅下降——这一刀砍在了最疼的成本项上，此后多家新模型的注意力设计都能看到类似思路的影子。
- **MoE 稀疏激活**：参数库很大，但每个 token 只「开需要的货架」，计算量和显存读取同时省下来。
- **系统工程顶格做**：FP8 混合精度、DualPipe 流水线并行、跨节点通信优化，把上万张卡的利用率往理论上限顶。
- **GRPO 强化学习算法**：去掉独立的 critic 模型，用组内相对奖励当基线，直接省掉一整块显存和算力开销。

一句话总结：它的便宜不是某个单点魔法，而是算法、系统、工程三层一起挤出来的结构性红利。对工程师来说，「又便宜又快」从来不是玄学，是一张张利用率报表堆出来的。

## 三、组织层：比省钱更难复制的东西

- **自下而上选题**：梁文锋在少数几次公开访谈中反复提到，内部不搞严格 KPI，方向让年轻研究员自己提，资源跟着问题走。
- **定位克制**：主做基础研究，不急着做应用变现，避免与主线抢资源。
- **算力前置**：母公司幻方量化早在 2021 年前后就自建「萤火」智算集群，据公开报道囤了约万卡规模的 A100。拿卡早、训练成本低，这是多数创业公司不具备的前置条件。

这些听起来「务虚」，但它回答了一个关键问题：为什么同样的卡，别家打不出同样的性价比。别人卷应用，它卷研究——这个反差本身就是传播力的来源。

## 四、商业层：低价与开源，都不是慈善

- **低价是进攻**：API 长期贴着行业地板价，倒逼全行业降价，应用落地门槛被拉低，生态位先占住。
- **开源是防守**：权重用 MIT 协议，推理内核与训练组件（FlashMLA、DeepGEMM、DeepEP 等）陆续开源，等于把基础设施「事实标准」的话语权握在手里。
- **现金流独立**：量化业务持续输血，没有融资对赌，也就没有「三个月内必须商业化」的压力，节奏完全自己定。

三条线指向同一个目标：让这套体系成为行业默认选项。

## 五、开发者和团队能拿走什么

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-14/cb2f299266034b98.png)

1. **原型阶段用 API 跑真实业务任务**，建立自己的评测集，别只信榜单分数——榜单和高分场景未必是你的场景。
2. **用得上 infra 就直接用**：FlashMLA、DeepGEMM 等开源组件可以接进自建推理服务，等于免费获得一线工程实践。
3. **垂直场景考虑 SFT 或蒸馏小模型**：几十 B 参数的开源权重往往就够用，客服问答、结构化抽取这类任务，小模型 + 好流程的性价比经常高于堆大模型。
4. **谈采购时把「训练成本传说」和「推理单价」分开算**：真正影响你账单的是后者。

## 六、冷思考：三个别被带偏的地方

- **成本口径要分清**：557.6 万美元只是最终一次完整训练的 GPU 租赁折算，不含前期失败实验、人力、数据和基础设施折旧，真实总投入远高于这个数。
- **复现没那么容易**：R1 发布后不少团队跟进，普遍发现难点在 RL 阶段的稳定性、数据工程和奖励设计，论文篇幅装不下全部细节。
- **别神化也别贬低**：真实的算法与工程创新、传播带来的滤镜放大，两者同时为真，混在一起谈只会得出错误结论。

最后给三条可带走的建议：

1. 读论文先读消融实验（ablation），那里才是作者真正验证过的因果关系，比十篇二手解读有用。
2. 成本敏感的团队，优先优化自己可控的推理侧：KV cache 管理、量化、批处理策略，往往藏着数倍优化空间。
3. 把注意力放在「可迁移的方法论」上而非具体模型上——AI 行业半年一变天，方法论的生命周期长得多。毕竟榜单会过期，方法论不会。
