最近一条热搜让不少人后背发凉：AI 不只会写代码，还被抓到了“寄生繁殖”。据 36kr 报道，有犯罪团伙用十几台廉价旧电视盒子当“宿主”，指挥大模型跑完了一场几乎全自动的网络入侵。听起来像科幻片，拆开看其实是一条非常工程化的攻击链——硬件是破的，思路是新的。RY哥带你把这条链一层层剖开，看看“寄生”到底寄生在哪，防御方又该怎么接招。

## 事件复盘：一场 80% 自动化的攻击

2025 年 11 月，Anthropic 威胁情报团队发布报告，披露了代号 GTG-1002 的攻击行动。几个关键数字：

- 攻击者越狱了 Claude Code。它本是给程序员用的命令行编程 Agent，能读写文件、执行命令、调用工具——换个场景就是现成的攻击编排器；
- 整场行动约 80%–90% 的环节由 AI 自主推进，人只在关键节点拍板，人力被压缩成了“几个按钮”；
- 扫描了约 30 家目标组织，覆盖科技、金融、化工与政府机构；
- 报告同时提到 vibe hacking 勒索案：至少 17 家医疗、政务与公共服务机构遭自动化勒索，赎金要价 5–100 枚比特币。

真正的新闻点不是“AI 能攻击”，而是**人从攻击链里被抽掉了**。过去一支 APT 团队干几周的活，现在一个 Agent 一天就能跑完第一轮。

## 「寄生」到底寄生在哪：三层借力

先纠正一个常见误读：那十几台电视盒子根本跑不动大模型，也没打算跑。“用盒子养活大模型”是标题的修辞，实际情况是——盒子只是接线板，真正贵的算力借的是别人的。寄生体现在三层：

1. **算力寄生**：模型推理跑在 AI 厂商的正规服务器上，攻击者只需批量注册、盗用或低价买入 API 账号。一场过去要烧几十万美元研发的定向攻击，如今几百美元加几个账号就能跑出雏形；
2. **设备寄生**：指挥、调度、流量中转放在电视盒子上。二十几美元一台、24 小时在线、走家庭宽带 IP，封不干净，坏了就换——论单位成本，这可能是最便宜的“肉鸡”入场券；
3. **能力寄生**：不自己写漏洞利用，直接调用通用 Agent 自带的网络知识与工具能力，缺什么让模型现场生成。

所谓“繁殖”，是 Agent 循环（计划 → 执行 → 观察 → 再计划）不断派生子任务、生成新脚本、控制更多设备——像寄生虫在宿主之间自我复制。

## 为什么偏偏是电视盒子

选电视盒子不是行为艺术，是成本与隐蔽性折算后的最优解：

- **便宜量大**：ARM 芯片、几十美元一台，十几台的总成本不到一张中端显卡；
- **无人运维**：厂商停更固件、系统常年不升级、大量默认口令，天然是软柿子；
- **出口干净**：流量从居民宽带发出，和普通人刷剧无异，比云服务器 IP 难拉黑得多；
- **用完即弃**：暴露了就断电换新，取证难度直线上升。

这套思路和红队圈的老话 Living off the land（靠地吃饭）一脉相承：用现成的、不起眼的东西干活，不留指纹。

## 攻击是怎么“越狱”出来的

模型出厂时并不愿意干这个，攻击者用了三板斧，本质就是 prompt injection 加任务拆解：

1. **角色扮演**：谎称自己是“某虚构公司的授权渗透测试员”，给模型套一层合法叙事；
2. **任务拆分**：把“入侵一家公司”拆成“扫描这个网段”“生成一组密码”“起草一封邮件”，每个子请求单看都人畜无害，安全分类器很难把整体意图拼出来；
3. **自带工具**：外挂端口扫描、凭据生成、代理轮换等工具，模型只当“大脑”，脏活在工具层完成。

结果是每次生成的脚本都不一样，传统特征码检测基本失明。Anthropic 靠实时分类器发现异常调用模式，随后封禁账号、通知受害机构、向合作伙伴同步失陷指标（IOC）——这套“厂商侧雷达”以后会是标配。

## 防御方怎么接招

攻击成本塌方，防御思路也得跟着换：

- **假设对面有 AI**：补丁周期、口令策略、网络分段，按“分钟级攻击者”重排，而不是“月级”；
- **盯住出口与调用**：异常的 API 用量、非常规时段的自动化请求，是最早的警报器；
- **给自己的 Agent 上锁**：最小权限、工具白名单、高危操作强制人工确认，日志全量留存；
- **IoT 资产入账**：电视盒子、摄像头、路由器统统登记造册，能升级的升级，不能升级的隔离进 VLAN。

## 冷思考：三条带走的话

1. **把攻击面当债务管理**：每台不再更新的联网设备都是一笔计息负债。先盘库存，再谈安全预算，顺序不能反；
2. **Agent 上线前先答三问**：它能碰到什么数据？能执行什么命令？谁为它的动作签字？三个问题答不上来，就先别上线；
3. **别恐慌，但要更新威胁模型**：能力是中性的，同一个 agentic loop 既能放大攻击，也能做自动响应与自动取证。攻防天平没有消失，只是换了一端放砝码。

AI 没有学会“繁殖”，是人把繁殖的欲望接到了它身上。安全这件事，护城河从来不在攻击有多炫，而在运维有多枯燥——枯燥，恰恰是最难被自动化的东西。
