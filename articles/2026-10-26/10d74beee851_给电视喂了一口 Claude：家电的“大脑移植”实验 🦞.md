最近，一位海外开发者干了场“小手术”：把 Claude 的 API 接进自家电视，让这台老家电“服用”了大模型。据他晒出的效果，电视从一台“频道格子播放器”，变成了能听懂自然语言、会跨应用找片、还能回答“刚才出场这人是谁”的对话终端。围观群众看到的是好玩，工程师看到的是另一个问题：这次“大脑移植”，到底改了系统的哪一层？这篇文章把手术台拆开看看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-26/a2ff030015f39ed4.png)

## 一、变化的不是硬件，是“意图解释器”这一层

先泼一盆技术冷水：Claude 并不在电视里运行。一台电视 SoC 的算力，连中等参数量的模型都跑不动，更别说前沿大模型——所有推理都发生在云端，电视本地只是终端。

真正被替换的，是“用户意图 → 系统操作”的翻译层：

- 过去：意图要手动编译成按键序列——按 HOME → 找应用 → 进搜索 → 方向键在虚拟键盘上逐字母爬；
- 现在：LLM 直接在自然语言和系统 API 之间架桥，“编译器”变成了模型本身。

落到体验上是三类质变：

1. **语义级跨应用搜索**：“找一部适合孩子看、又不太吵的动画”。传统搜索只能关键词匹配，LLM 能理解“适合孩子”“不吵”这类语义约束，再跨内容库筛选。
2. **上下文问答**：“刚才那个人演过什么？”电视结合当前播放内容调用信息接口作答，这是格子界面做不到的。
3. **多步任务合并**：“把这个系列加进收藏，然后打开体育频道”——一句话触发一串系统调用。

打个比方：发动机没换，但车装上了自动驾驶。硬件参数一条没动，使用方式全变了。

## 二、技术拆解：Claude 是怎么“钻进”电视的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-26/20587701ae65cc00.png)

关键机制是 function calling（工具调用）：模型并不直接“控制”电视，它只能输出结构化 JSON，由本地程序映射成系统操作。完整链路是：

1. 麦克风拾音 → ASR 语音转文字；
2. 云端 LLM 理解语义、规划步骤；
3. 模型输出工具调用，例如 `{"action":"open_app","app_id":"sports"}`；
4. 电视端常驻的小代理程序校验参数，调用系统 API 执行；
5. 执行结果回传，LLM 组织成口语 → TTS 播报。

这套架构里，电视端只需要三样东西：**耳朵**（麦克风+ASR）、**手**（能调系统接口的本地代理）、**嘴**（TTS）。大脑完全在云上。开发者真正写代码的部分，是把换台、搜片、调音量、开应用注册成一份“工具清单”，模型自己决定调哪个、传什么参数。这类玩法如今还在标准化，比如 Anthropic 开源的 MCP 协议，本质就是把“挂工具”的接法统一了。

两笔账要算清：

- **延迟**：一次完整往返约 2–4 秒。ASR 不到 1 秒，LLM 首 token 约 1–2 秒，工具执行几百毫秒。靠流式 TTS 边生成边播，体验才能勉强“像对话”。
- **成本**：每轮对话几千 token，按主流模型定价约 0.01–0.03 美元/轮。个人玩票无所谓，做成产品就是每月固定账单，还要乘以用户量。

## 三、为什么值得围观：从“格子世界”到“意图直达”

遥控器可能是人类效率最低的输入设备之一：40 个按键、层层菜单，输入一个片名要用方向键爬半天虚拟键盘。智能电视迭代了十年，格子越来越密，输入效率几乎原地踏步。

智能音箱曾试图用语音救场，但它们本质是“有限意图识别”：听得懂“播放周杰伦”，听不懂“找一部和某科幻片气质类似但更轻松的”。LLM 把语音交互从“命令匹配”升级为“语义理解 + 多步规划”，这是量级差异，不是音质升级。

电视的位置也很特殊：家里最大、最共享、使用频率却偏低的屏幕。它不缺显示能力，缺的恰好是输入与理解能力——正是 LLM 的强项。

这也是 2023–2024 一批 AI 硬件的对照组：Rabbit R1（199 美元）、Humane AI Pin（699 美元起）都想造一台“替代手机”的新设备，双双遇冷，后者最终在 2025 年以约 1.16 亿美元出售了资产；而“老设备 + 云大脑”的改造思路不推翻任何东西，只补上缺的那一层。形态上保守，范式上激进。

## 四、冷水时间：三个绕不开的现实问题

1. **幻觉会变成误操作**。模型在聊天里说错话是尴尬，在设备里做错事是事故——没确认就打开付费点播、删错收藏夹。工具调用必须分级：只读操作直通，不可逆操作强制二次确认。
2. **隐私账单**。常开麦克风 + 云端推理，意味着客厅里的话会变成 token 流出家庭网络。本地唤醒词、传输脱敏、数据可删除，一项都不能省。
3. **商业结构冲突**。电视厂商的收入大头是开机广告、应用分发和内容抽成，而一个够聪明的助手天然会绕开推荐位直达内容。谁给电视装大脑，谁就在动电视的商业模式——这也解释了为什么厂商倾向做封闭的自研助手，而“魔改”只发生在开发者自己家里。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-26/20d4a7e254c9c7a8.png)

1. **Demo 与产品之间隔着三张表**：p95 延迟表、月度 token 成本表、失败率表。演示的惊艳只是分子，稳定性与成本才是分母——评估任何 AI 硬件项目，先看分母。
2. **想动手复刻？权限最小化是底线**。先只给只读权限跑通全链路，付款、删除、订阅类操作一律加人工确认；永远不要把系统级万能钥匙直接交给模型。
3. **判断“AI+硬件”值不值得买单，只看一个问题**：它提升的是输入效率（一句话替代十次按键），还是只多了一个聊天框？前者在改范式，后者在贴皮。

那台电视唯一没变的，大概是开机广告——商业模式这块，大模型暂时也治不了。
