打开任意一家大模型厂商的定价页，你会看到一个反直觉的现象：新发布的模型更强了，价格反而更低了。GPT-4 当年每百万 token 几十美元的“天价”记忆还没散去，如今同级能力的模型已经打到了几块钱人民币。36kr 这个热议话题问得很实在：更强更便宜的背后，到底发生了什么？答案可以拆成三本账：厂商的成本账、生意账，以及你自己的账。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-28/4031b9e1cc95b3b4.png)

## 价格战简史：从天价到白菜价，只用了两年

- 2023 年 3 月，GPT-4 发布，输入 $30 / 百万 token，输出 $60。当时开发者一边喊贵，一边乖乖充值。
- 2024 年 5 月，DeepSeek-V2 把 API 价格打到输入 1 元/百万 token 量级，直接点燃国内价格战；随后字节豆包主力模型标出 0.8 元/百万，宣称比行业均价低 99%。
- 2024 年底到 2025 年，DeepSeek-V3/R1 接力，推理价格约为同级海外旗舰的几十分之一；OpenAI 也连续多轮降价，GPT-4o 比 GPT-4 Turbo 便宜一半。
- 打法还在升级：夜间错峰半价、prompt caching 缓存命中一折计费、蒸馏小模型开源免费。

两年时间，同一档能力的单价跌了不止一个数量级。这不是慈善，是成本端真的降了。

## 第一本账：成本账——推理成本为什么能一降再降

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-28/6e60ef4292d44ce3.png)

价格战的底气来自推理成本的持续下降，主要靠四件事：

1. **模型架构**：MoE（Mixture of Experts）稀疏激活是关键。DeepSeek-V3 总参数 671B，但每个 token 只激活约 37B——相当于从“全员到岗”改成“按需排班”，计算量骤降。
2. **低精度化**：FP8 训练与推理取代 FP16，显存占用和带宽需求直接砍半，同样的卡能跑更大的 batch。
3. **系统工程**：continuous batching、prefill/decode 分离部署、投机解码、KV cache 复用，把 GPU 利用率从三成拉到七成以上。推理拼的早就不只是模型，是整套 serving 系统。
4. **能力下放**：大模型蒸馏小模型，长尾任务用 7B 级别就能解决，边际成本接近白送。

芯片迭代（H100 → B200）再往上叠一层。Epoch AI 的估算显示，同等能力水平的推理价格大约以每年一个数量级的速度下探。换句话说：你今年觉得便宜的模型，明年只配给新模型打下手。

## 第二本账：生意账——为什么明知烧钱也要降

- **获客逻辑**：API 是开发者生态的入口，切换成本会随时间累积。先用低价把你锁进来，类似云厂商的 land-and-expand 打法。
- **引流品逻辑**：对大厂来说，模型本身可以不赚钱，它负责给云业务和企业服务导流，赚的是后面的 GPU 租赁、存储和解决方案的钱。
- **规模效应**：机房、电力、研发团队都是固定成本，token 才是边际成本。调用量越大，单位成本越低——降价反而可能改善毛利结构。
- **份额优先**：这套剧本互联网人太熟了，网约车、外卖、社区团购都是亏损换市场，只是这次补贴对象从 C 端用户换成了 B 端开发者。

所以“更便宜”不等于“亏本甩卖”，更像一场算过 ROI 的抢滩登陆。

## 第三本账：你的账——单价降了，总账未必降

这里有个反直觉的经济学现象：杰文斯悖论（Jevons Paradox）。19 世纪蒸汽机效率提升后，煤的消耗不降反升——因为用得起了，用量暴涨。LED 灯比白炽灯省电 80%，但城市照明总耗电几乎没降，因为灯变多了。

AI 完全复刻了这个曲线：

- Agent 工作流一次任务要几十次调用、长上下文反复投喂，单任务 token 消耗比单轮问答高出 10~100 倍；
- 思考型模型的 reasoning tokens 也计费，“想得越久，账单越长”；
- 输入输出差价、缓存未命中、工具调用的中间 token，都是标价页上看不到的隐藏项。

单价降一个数量级，总账单可能不降反升。便宜的是 token，不便宜的是你的用量。

## 终局推演：价格会一直降下去吗

大概率是分层，而不是一路降到底：

1. **前沿能力维持溢价**：最新推理模型、超长上下文，供给稀缺，价格坚硬；
2. **成熟能力商品化**：两三年前的“旗舰级”能力，会像云主机和电力一样，趋近边际成本定价；
3. **变量**在算力供给与需求曲线两端：算力供需紧张托底价格，Agent 时代的需求爆发推高总消耗——两端拉扯，中间的商品化区间才是价格战主战场。

参考云计算的历史：AWS 降价降了十几年，但企业云支出总额年年暴涨。单价下降和盘子变大，从来不矛盾。

## 冷思考：给开发者和企业的三条建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-28/ea4c987ac9d44b6f.png)

1. **别把架构押在单一模型上**。做一层 provider 抽象（LiteLLM、OpenRouter 这类思路），让模型可热切换——切换自由度是你面对价格战最强的议价权。
2. **算“有效成本”，别只看标价**。提高缓存命中率、做模型路由（简单任务走小模型、难题升级大模型）、控制输出长度，这三板斧比盯着单价省得多。
3. **红利期攒资产，别只顾省钱**。价格战是使用者的窗口期：趁机把数据 pipeline、自己的 eval 评测集、工作流沉淀下来。API 费是暂时的，这些资产才是护城河。

龙虾钳再硬，也砍不动 token 单价；但好的架构设计，可以让价格战替你打工。这波“更强更便宜”，看得懂账本的人，才是真正的赢家。
