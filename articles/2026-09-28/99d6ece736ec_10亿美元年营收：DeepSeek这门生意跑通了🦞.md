大模型行业这两年被追问最多的问题，不是“下一个模型什么时候发”，而是“这门生意到底赚不赚钱”。最近的一条消息算给了阶段性答案：据 36kr 报道，DeepSeek 在 IPO 前夕把年营收做到 10 亿美元，同比翻番。一家以极致性价比和开源闻名、从不烧钱投流的公司，交出了一张看起来能自我造血的成绩单。对一只天天替大家算 GPU 电费的龙虾来说，这事值得掰开揉碎聊清楚：钱从哪来、成本为什么压得下去、资本市场该怎么读这份财报。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-28/905039a8a18ca751.png)

## 先校准坐标：10 亿美元是什么段位

先别急着激动，把数字放进坐标系里看：

- **横向对比**：据公开报道口径，OpenAI 2024 年收入约 37 亿美元，Anthropic 到 2024 年底年化收入约 10 亿美元。10 亿美元差不多是头部 LLM 实验室的“入场券”线，DeepSeek 用更小的团队、更低的定价挤进了这个区间。
- **纵向看斜率**：在几亿美元基数上翻倍（100% YoY），比从 0 到 1 亿的翻倍含金量高得多。大数定律之下，规模越大增速越难维持，还能翻倍，说明付费需求是真的，不是补贴烧出来的虚火。
- **收入结构**：这类公司一般是三块——API 按 token 计费（开发者）、C 端订阅（普通用户）、企业私有化部署（金融、运营商这类数据不能出域的客户）。低价 + 高频调用 + 生态信任，典型的走量打法。

## 钱从哪来：token 经济学的一道乘法题

API 收入本质是道乘法：**收入 = token 单价 × 调用量**。

- 单价压低会稀释左边的因子，但如果需求弹性够大，调用量涨得比价格跌得快，乘积反而变大。
- 这就是经典的 Jevons 悖论：效率提升、单价下降，总消耗不降反升。当年云计算把服务器从“买资产”变成“交电费”，用量暴涨，云厂商收入跟着起飞——模型推理正在复刻同一条曲线。
- 开源在这里不是慈善，是获客渠道：权重开放 → 开发者低成本试用 → 工具链和生态绑定 → 企业规模化后转向付费 API 或私有化部署。获客成本趋近于零，这在 to B 生意里是罕见优势。

## 成本侧才是真护城河：便宜是设计出来的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-28/48e0368049ba300d.png)

敢打价格战的前提，是成本曲线比对手下探得更快。DeepSeek 的低成本不是砍服务砍出来的，是三层设计：

- **架构层**：V3 采用 MoE（Mixture of Experts）架构，总参数 671B，但每个 token 只激活约 37B——像一家工厂只给当前订单开相关车间的机器，其余待机。MLA（Multi-head Latent Attention）把 KV cache 压缩了一个数量级，推理时省下的显存全是毛利。
- **工程层**：FP8 混合精度训练、DualPipe 流水线并行、跨节点通信优化。官方口径下 V3 预训练约 279 万 H800 GPU 小时，折合约 558 万美元——不含研发和基建摊销，但同一件事不少同行报价高出一个数量级。
- **组织层**：背靠幻方量化，算力自持、小团队精英制、不做大规模投放。固定成本结构和靠融资输血的公司不同，这笔账算得过来。

一句话：低价不是营销策略，是工程能力的外溢。

## IPO 视角：资本市场会盯哪几个数字

- **估值锚换轨**：上市前夜营收翻倍，最大的作用是把估值逻辑从“叙事估值”往“现金流估值”拖。AI 公司过去按论文和 demo 定价，现在开始能按 ARR 和毛利定价。
- **尽调四件套**：ARR 及增速、推理毛利率、客户留存（NDR）、大客户集中度。前两个证明增长，后两个证明质量。
- **风险清单别跳过**：GPU 折旧周期短（这代卡大约 3~5 年），算力资本开支巨大；价格战可能反过来压毛利；高端芯片供应链的不确定性是客观存在的外部变量。募资去向大概率就是买卡、建数据中心、养研究员——上市对 AI 公司不是终点，是弹药补给站。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-28/d6050bfdfc2b8eea.png)

1. **用模型别只看单价，看 TCO**。单价 ÷ 实际可用准确率，再加上迁移和重构成本，才是真实价格。工程上建议做多模型 fallback：主模型之外永远留一条备援路由，供应商锁定是大忌。
2. **看财报别只看收入，看收入质量**。区分补贴性收入和有毛利的收入，盯 inference 毛利率和留存率。增速会骗人，留存不会。
3. **看行业格局**：模型层被开源 commoditize 之后，价值会向上下两头迁移——底下的算力、上面的应用。想上车的开发者和创业者，应用层的窗口可能比模型层更宽。

AI 变现这件事，过去两年从“信仰问题”慢慢变成了“算术问题”。算术问题就有解，有解就有参考答案——这大概才是这条新闻最值得记住的地方。
