2023 年 AutoGPT 刮过一阵风，又很快凉下去——它证明了"让 AI 自己干活"很酷，也证明了"没有边界的自主"等于死循环加 token 火葬场。两年多过去，Agent 赛道卷土重来，这次的关键词变成了 Super Agent：不光能接需求、调工具、跑长任务，更重要的是开始有"分寸感"——该出手时主动出手，该闭嘴时绝不刷屏。36kr 这篇之所以值得展开，是因为"主动干活"和"适时沉默"恰好对应 Agent 技术栈里最硬的两块骨头：自动化架构与人机交互设计。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-02/73c694fd68343e6b.png)

## 从"有问必答"到"主动干活"：Agent 的三级跳

- **第一级：对话式 AI。** 你问它答，一问一答，会话结束关系归零。所有动作由人发起，AI 本质上是一支更聪明的"笔"。
- **第二级：工具型 Agent。** 大模型套上执行循环：ReAct 范式（Reason + Act）让它"想一步、做一步、看结果、再修正"，配合 function calling 调用搜索、代码执行、浏览器。代表是各类代码助手和浏览器操作智能体。局限是仍要人下指令，属于"随叫随到的外包"。
- **第三级：Super Agent。** 在第二级之上加三个关键件：**触发器**（不等指令，事件、时间、状态变化自动开工）、**记忆**（知道你是谁、你的偏好和历史）、**校准**（知道什么能自己拍板、什么必须请示）。它从"外包"变成了"不用盯着的同事"。

历史注脚：AutoGPT 当年的失败恰恰说明，自主性不是越多越好。这一代 Super Agent 的进步，本质上是把"自主性"从一个开关，变成了一个可调的旋钮。

## "主动干活"的四个技术底座

- **触发器（Trigger）**：定时任务（cron）、事件订阅（webhook）、状态监测（库存低于阈值、收件箱出现某类邮件）。传统 AI 是"拉模式"——人拉一下才动；Super Agent 是"推模式"——世界一变，它先动。
- **规划器（Planner）**：把大目标拆解成任务图，处理依赖关系和失败重试。关键不是"一次生成完美计划"，而是"执行—观察—修正"的在线规划。
- **记忆系统（Memory）**：三层结构——当前任务的短期上下文、跨会话的长期向量库、用户偏好档案。偏好档案是主动性的前提：不知道你的习惯，"主动"就等于"打扰"。
- **工具与沙箱（Tools & Sandbox）**：代码执行环境、浏览器控制、API 调用。可逆操作先在沙箱里试跑，产出确认后再落地到真实世界。

## "更懂何时闭嘴"：一门打断成本的经济学

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-02/7839d71603cb29a1.png)

这是 Super Agent 最容易被忽视、却最决定体验的部分。

- **打断成本**：Agent 每问一次"要不要继续"，都在消耗用户的注意力预算。问上十次，价值归零——你还不如自己干。
- **出错成本**：擅自动了不该动的事，信任一次性清零，用户从此不敢放手。
- 好的校准策略长这样：
  1. **可逆 + 高置信** → 直接做，事后批量汇报（整理文件、写初稿、跑测试）；
  2. **可逆 + 低置信** → 也做，但明确标注"这是我的猜测，可一键回滚"；
  3. **不可逆**（发邮件、转账、删除）→ 无论置信度多高，必须停下请示；
  4. **关键歧义**（两个选项都合理）→ 把问题打包一次问清，而不是挤牙膏式连环追问。
- 一个贴切的类比是自动驾驶分级：L2 时时刻刻要人盯着（其实最累），L4 在限定区域内才能真放手。Agent 的自主性同理——不该是开关，该是分级的旋钮。
- "闭嘴"还有另一层含义：过程不刷屏。只在关键节点同步，失败时才呼叫人类。这和 SRE 告警设计的原则一致：好的告警宁可少，也不能把 on-call 疲劳化。

## 落地场景与泼冷水时间

已经在发生的场景：

- **编程**：Agent 模式的 IDE 自动跑测试、修 lint、提交 PR，人只负责 review。这是目前 ROI 最高的落地，因为代码环境天然可逆——有 Git 兜底。
- **个人助理**：邮件分诊、日程协调、订阅管理、票据归档。
- **企业流程**：异常巡检、报表生成、工单预分类。

但约束同样真实：

- **错误级联**：多步任务的失败率会相乘。每步成功率 95%，十步下来整体只剩约 60%（0.95¹⁰ ≈ 0.60）。"看起来会做"和"稳定做对"之间，隔着一整个工程化的太平洋。
- **成本**：主动意味着随时在跑，token 账单和算力都是真金白银。
- **安全**：权限给足的 Agent 就是新的攻击面，提示注入（prompt injection）可以让它"被人借刀"。
- **评测难**：SWE-bench 这类基准在快速进步，但"主动性"和"分寸感"目前几乎没有公认的量化标准。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-02/9772bf4476e8c068.png)

1. **用"可逆性"给任务分类，别用"重不重要"。** 重要但可逆的事（写文档、改配置）尽管放给 Agent；不重要但不可逆的事（群发消息）也要攥在自己手里。可逆性才是授权的第一变量。
2. **给 Agent 写一份授权清单。** 什么能自动做、什么必须问、什么绝不碰，写清楚——就像给新员工的 onboarding 文档。没有这份清单的 Agent，不叫聪明，叫冒险。
3. **警惕"伪主动"。** 判断标准很简单：它是替你减少了决策，还是制造了更多等你确认的红点？前者是 Super Agent，后者只是个更吵的通知系统。

Super Agent 的终局不是"更全能的 AI"，而是"更懂边界的产品"。技术把能力推到哪儿是一回事，产品敢让能力走到哪儿、用户敢放手到哪儿，是另一回事——而后者，恰恰是当下真正的胜负手。
