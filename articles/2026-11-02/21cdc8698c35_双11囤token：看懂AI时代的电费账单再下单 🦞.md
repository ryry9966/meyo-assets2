## Token 是什么：大模型的“字数计价单位”

先补基础课，三个要点：

- **Token 是分词器切出来的最小单元。** 大模型并不直接“读字”，它读的是 tokenizer（分词器，主流方案是 BPE，Byte Pair Encoding）切出来的 token。这也是为什么计费单位是 token 而不是“字”——模型的真实成本和 token 数成正比，和字数只是近似相关。
- **换算有个经验公式。** 英文大约 1 token ≈ 0.75 个单词；中文一个汉字约 0.6~1 个 token，各家分词器略有差异。一本 10 万字的小说，粗略对应 7 万~10 万 tokens。
- **输入和输出分开计价。** 你发给模型的是 input，模型回给你的是 output，输出单价通常是输入的 3~5 倍，行业通行单位是“元/百万 tokens”。过去两年大模型 API 打了一轮价格战，轻量模型的百万 tokens 输入已经进入“元级”，但旗舰模型的长输出依然不便宜。

还有两个容易被忽略的“消耗放大器”：

1. **长上下文。** 128K tokens 的上下文窗口如今是标配，一次塞进一整份代码库或长文档，单次请求就能吃掉几万 tokens。
2. **多轮对话的平方级增长。** 每一轮对话，历史记录都会被重新发送一遍，n 轮对话的输入消耗接近 O(n²)。Agent 更狠：一次任务循环调用几十次，账单厚度翻着跟头涨。

## 为什么双11开始卖 token：收费模式的三次进化

把时间轴拉长看，软件行业的收费方式经历了三次跃迁：

- **卖拷贝（License）时代：** 一次买断，装完拉倒，厂商和用户的关系在收银台就结束了。
- **卖订阅（SaaS）时代：** 按月按年付费，厂商靠续费率活着，开始关心你到底用不用。
- **卖消耗（Usage-based）时代：** 按 token 计费，用多少付多少。AI 的成本天然随用量线性增长，这是第一次，厂商的收入和你敲了多少字直接挂钩。

Token 之所以能上架电商，逻辑和当年的话费充值、网盘会员、游戏点卡一模一样：它是标准化的数字消耗品，单价清晰、可充值、可叠加。厂商的动机也很直白：

1. **预收现金流**——储值用户比月活用户“稳”得多；
2. **借大促拉新锁客**——折扣买来的用户，至少会用到额度花完；
3. **电商旗舰店成了新的获客渠道**，获客成本比自己投广告低。

需求侧同样在膨胀：写论文、改简历、写代码、生图的重度个人用户，月消耗轻松到百万 tokens 量级；开发者和创业团队把 API 成本计入毛利，折扣直接改善现金流；再加上视频生成、Agent 自动化这些“吃 token 大户”，供需两头一拍即合，双11只是把两条曲线的交点变成了促销节点。

## 下单之前，先算清这笔账

囤货本质上是一道数学题，五步走：

1. **拉账单。** 导出最近 90 天的消耗记录，算出日均 tokens，乘以有效期天数，再乘 1.2 倍余量——这是合理囤货上限，而不是“看起来划算”就囤。
2. **算盈亏平衡点。** 举个例子：你月均消耗 500 万 tokens，某 90 天包打 7 折，只有当折后单价低于你后付费均价 15% 以上时才真正划算，否则不如继续后付费，灵活性白送。
3. **看有效期。** Token 不像纸巾会受潮，但像酸奶一样会过期。常见有效期 30 天、90 天、一年，囤一年只用三个月，等于给厂商发了笔无息贷款。
4. **读条款。** 是否绑定特定模型？换成新模型作废吗？有没有限速（rate limit）？能开发票吗？支持退款吗？这些细节比折扣数字重要得多。
5. **分身份。** 轻度个人用户，包月订阅（会员含额度）通常比 token 包划算；开发者和重度用户，“token 包打底 + 后付费兜底”的组合更稳，既吃到折扣又不怕爆量。

还有一条很多人栽过：**只在官方渠道买。** 第三方转卖的“低价额度包”可能绑定来路不明的账号，轻则用不了，重则连自己的主账号一起搭进去。

## 三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-11-02/6fcef870e1115948.png)

**第一，token 是贬值资产。** 模型迭代的速度摆在这里：今天按折扣囤的额度，明年同样的价格能买到强得多的模型。囤太多，等于把自己锁死在旧的智能水平上。囤 1~3 个月的量是弹性，囤一年的量是负债。

**第二，单价下跌是大势，别为 9 折焦虑。** 价格战打了两年还没停，今天的促销价很可能是明天的日常价。Jevons 悖论正在 AI 行业上演——19 世纪的经济学家发现煤价下降后，煤的消耗不降反升；放在 AI 上同样成立：单价越便宜，用量涨得越猛，你省下的单价大概率会被涨上来的用量吃掉。

**第三，省钱靠工程，不靠囤货。** 上下文缓存（prompt caching）、精简 system prompt、按任务难度做模型路由、定期清理冗余的对话历史——这些手段省下来的钱，经常比大促折扣还多。把 AI 支出当水电费管理：每月看账单、设预算告警，比蹲守一天折扣有用得多。

购物车能囤住 token，但囤不住智能的价格曲线。理性囤货，把省下来的预算留给下一次模型升级。
