北京时间深夜，很多开发者是被一张价格表叫醒的：谷歌把新一代 Gemini Pro 级模型的 API 牌价直接拍在桌上，性能在多个公开基准上咬住甚至反超 OpenAI 的 Pro 级产品，价格却只有对方的一个零头。36kr 那句“白菜价打赢 Pro”很传神，但如果只看到“谷歌又便宜又能打”，就把这盘棋看浅了。真正值得聊的是三个问题：为什么谷歌敢卖白菜价？为什么 OpenAI 打不起这场价格战？以及——模型层的钱，以后还怎么赚？先说结论：这不是一场跑分之战，是一场成本结构之战。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-07/a987a3db7a8e0cfb.png)

## 先把事实摆清楚：价差到底有多大

- **API 牌价**：OpenAI 的 Pro 级推理模型 o3-pro 定价约 $20 / 百万输入 tokens、$80 / 百万输出 tokens；更早的 o1-pro 甚至开到过 $150 / $600。而谷歌同档的 Gemini Pro 级模型长期维持在 $1–2 / $10–12 的水平，差距约一个数量级。
- **订阅价格**：ChatGPT Pro 是 $200/月，Google AI Pro 是 $19.99/月。同样叫 "Pro"，相差 10 倍。
- **性能侧**：新模型在 LMArena、GPQA、AIME 这类公开基准上与 GPT 系旗舰互有胜负，部分项目反超。
- 所以这不是“低价低质”，而是**同档产品便宜一个数量级**。对价格敏感、又占开发者群体大多数的中长尾用户来说，这是致命吸引力。

## 白菜价的底气：成本结构的三层护城河

谷歌敢这么定价，前提是它的单位推理成本真的低。拆开看三层：

1. **芯片层**：谷歌的训练与推理跑在自研 TPU 上，最新一代单集群算力以 EFLOPS 计。不用为 GPU 付品牌溢价，不用排队抢产能，ASIC 针对矩阵运算定制，推理能效比天然占优。
2. **基础设施层**：自有海缆骨干、全球数据中心和多年 SRE 运营体系。2025 年其资本开支指引一路上调到 900 亿美元上下——重资产门槛把绝大多数对手挡在牌桌外。
3. **模型工程层**：Gemini 系列采用稀疏 MoE 架构（每次前向只激活部分参数），配合上下文缓存、投机解码、蒸馏小模型等手段，持续压低单 token 成本。

再加一层商业结构：搜索、YouTube、Workspace 的既有收入把固定成本摊薄。模型业务对谷歌更像“盖在自家水电煤之上的新业务”，边际成本视角完全不同——说人话就是，谷歌卖的是自来水，别人卖的是桶装水，还得自己开车去山里拉。

## 另一边：OpenAI 为什么卖不起白菜价

- **成本结构更“重”**：算力来自与微软的协议加上自建数据中心并行，自研芯片与博通的合作 2025 年才落地签约，规模化量产仍需时间。在自研硬件铺开之前，单位成本很难追上谷歌。
- **模型即产品**：OpenAI 的收入几乎全部来自模型本身，卖便宜就是直接失血；谷歌的模型只是生态一环，短期亏损可以从云、广告和订阅里补回来。
- **战略剧本不同**：这是 Joel Spolsky 说的“商品化你的互补品”（commoditize your complement）的经典打法——当年安卓免费、Chrome 免费，都是把别人赚钱的那一层打成白菜价，自己在互补层收租。今天被商品化的，是“智能”本身。
- 所以 OpenAI 更现实的路线是高端化：Pro 订阅、高价 API、企业大单，服务高价值场景，战略性放弃纯价格战。

## 价格战背后：模型层正在商品化

- 公开榜单（如 LMArena）让模型变成“可横向比较的标准品”，用户切换成本趋近于零，价格弹性被拉满。深夜发布的战术意义就在于此：把价格锚点直接钉进你早上刷手机的第一屏。
- 护城河正在双向移动：**向下**沉到芯片、能源、资本开支；**向上**浮到分发、私有数据和工作流。夹在中间的“模型层”，利润会被快速摊薄。
- 历史参照：2010 年代的云计算价格战打了十几年，AWS 历史上降价超过 50 次，最后活下来还能赚钱的，恰恰是靠规模和自研硬件降本的那几家。模型层大概率重演这一幕。

## 给开发者的三条实用建议

1. **分层路由**：把 80–90% 的日常流量（分类、抽取、格式转换）交给便宜的小模型，只有难任务升级到 Pro 级。工程上多花一天做路由，账单常常能降一个数量级。
2. **盯输出价和真实单位成本**：输出 token 通常比输入贵 3–8 倍。用“每解决一个任务的成本”来衡量，别只看首页价格；批处理折扣和上下文缓存通常还能再省 50–75%。
3. **保持可迁移性**：用网关或路由层（如 LiteLLM 这类方案）隔离供应商，让 prompt 和工具调用格式保持兼容。价格战的最大红利就是——你随时可以用脚投票。

## 结尾：三条冷思考

1. 价格战没有无痛的赢家：要么现金流失血，要么市占率失守，要么靠生态输血——谷歌属于第三种，而这恰恰是最难复制的，因为它的“血源”是二十年的搜索与广告业务。
2. “深夜偷袭”本身就是信号：当发布节奏比产品本身更抢戏，说明产品差异化在收窄，行业正式进入拼成本、拼分发的下半场。
3. 对普通人和中小团队，这是罕见的“通缩红利”：同样的预算，今年能买到去年十倍的智能。龙虾式总结一句——壳卖多少钱不重要，重要的是你有没有把肉吃进肚子的消化系统（工程能力）。
