北京时间 11 月中旬的一个凌晨，Google 把 Gemini 3 直接推进了公众视野——距离 OpenAI DevDay 和 GPT-5.1 的发布刚过去两周。真正让开发者炸锅的不是跑分，而是价签：Gemini 3 Pro 的 API 卖 $2/百万输入 token、$12/百万输出，而 OpenAI 主打高强度推理的 GPT-5 Pro 定价 $15/$120，差出一个数量级。能力互有胜负、价格倒挂，这篇就拆一拆：谷歌凭什么敢这么定价，这场"白菜价"价格战对行业和普通开发者到底意味着什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-07/a21f047ef9b20b2d.png)

## 一、复盘现场：一次教科书级的节奏卡位

先看时间线：

- 11 月 3 日，OpenAI DevDay，发布 AgentKit 与 Apps 生态，并开放 GPT-5 Pro API；
- 11 月 12 日，GPT-5.1 上线，主打更自然的对话与自适应推理档位；
- 11 月 18 日，Google 发布 Gemini 3，正面截住热度，连 OpenAI CEO 都公开称赞对手。

硬指标同样能打：

- LMArena 竞技场首发冲上约 1500 Elo，登顶榜首；
- SWE-bench Verified 76.2%、GPQA Diamond 91.9%、ARC-AGI-2 45.1%，多数关键基准反超 GPT-5.1 系；
- 1M token 上下文（GPT-5.1 API 为 400K），且 day one 就进 Search AI Mode、Gemini App 和新 IDE Antigravity，消费者免费可用。

然后是关键的那张价签（每百万 token，输入/输出）：

| 模型 | 输入 | 输出 |
| --- | --- | --- |
| Gemini 3 Pro | $2 | $12 |
| GPT-5.1 | $1.25 | $10 |
| GPT-5 Pro | $15 | $120 |

注意 OpenAI 的操作：把"高算力推理"单拎成 Pro 档，价格抬到 8~10 倍；Google 把同档能力直接卖平价。"白菜价打赢 Pro"不是修辞，是字面意思。

## 二、"白菜价"的底气：谷歌的成本结构不一样

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-07/36906e95ede78046.png)

同样是大模型，谷歌凭什么敢定这个价？三个结构性原因：

1. **芯片垂直整合**。Gemini 从训练到推理大量跑在自研 TPU 上（第七代 Ironwood 已在 2025 年规模交付），绕开 GPU 整机链条的多重溢价，单位有效算力成本显著更低。这不是一代产品的运气，是近十年押注的复利。
2. **基础设施摊销**。全球自建数据中心网络，电力、散热、网络与调度系统沉淀几十年；MoE 架构、推测解码、激进量化、分离式 serving，把"每 token 成本"压到行业第一梯队。
3. **商业模式根本不同**，这是最关键的一条。OpenAI 收入几乎全靠模型订阅与 API，模型必须自己养活自己；谷歌的模型则是集团级"杠杆"：Search AI Mode 提升广告变现，Cloud 与 Workspace 借模型拉新，Android 靠它守入口。模型部门可以不赚钱甚至贴钱，账在集团层面算——教科书级的交叉补贴。

反观 OpenAI：天量推理支出、与微软的分润结构，Pro 档本身吃算力，外界普遍推算其高强度推理的单位查询毛利极薄。让它跟进降价，等于往自己的现金流上动刀。

## 三、不是第一场价格战：模型正在变成大宗商品

把镜头拉远，剧本其实眼熟：

- 2024 年国内大模型降价潮，豆包把入门价打到"厘"级，DeepSeek 用 V2/V3 证明工程优化（MLA、MoE、FP8）可以让 frontier 能力不绑定天价算力；
- 2025 年初 DeepSeek R1 以极低价格提供强推理，把"推理价格锚"砸穿，英伟达单日近 17% 的巨震与随后的 Jevons 悖论大讨论，就是市场给这个逻辑的定价。

经济学上这叫商品化（commoditization）：当头部模型差距缩小到"跑分互有胜负"，价格就成了主要竞争变量。而降价又会触发 Jevons 悖论——token 越便宜，总消耗量越大，蛋糕反而被共同做大。短期看是价格战，长期看是在扩张整个 token 市场。

## 四、开发者视角：便宜 ≠ 省钱，学会算"单位任务成本"

直接给 API 用户几条实操判断：

1. **别只盯着 $/M token**。推理模型的"思考过程"计入输出计费：同一任务，模型 A 烧 8K reasoning token 才给出 2K 答案，模型 B 直接 2K 答案——后者单价贵一倍，总花费可能反而更低。选型要按"单任务平均成本"建模。
2. **工程手段往往比换模型更省钱**。prompt caching（缓存命中的输入约一折）、Batch API（约五折）、压缩历史对话、给臃肿的 system prompt 瘦身——组合拳常常省下一半。省钱这件事上，工程师的直觉永远是先看看自己的 prompt 有多肥。
3. **做多供应商路由**。统一接口抽象 + 质量分流，让"换模型"变成改一行配置；价格战期也是议价窗口，迁移补贴和免费额度都可以谈。
4. **警惕首发红利陷阱**。新模型上线初期常见限流、回退与调价，核心链路等一个月，非核心链路再尝鲜。

## 五、冷思考：当模型成为大宗商品，护城河往哪搬

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-07/a87e0dcad0726fd0.png)

这场价格战值得记住的不是"谁赢了"，而是它暴露的行业走向：

- **算力与能源是长期定价权**。谁的单位 token 成本低、电力供给稳，谁就敢持续压价；自研芯片与数据中心是重资产慢功夫，短期烧钱追不上。
- **分发入口的价值被放大**。能力相近时，Search、Android、Workspace 这些"默认入口"能把旗舰模型直接变成日活亿级的公共服务，这是纯模型公司最难复制的部分。
- **数据飞轮在跑分之外**。真实用户的高频使用持续产生 post-training 反馈，这种复利不会出现在任何 leaderboard 上。

最后，三条带走就能用的建议：

1. 给自己的业务建一套小型 eval 集（50~200 个真实任务），用"质量 × 单位任务成本"双维度定期横评，不追首发跑分；
2. 架构上坚持模型无关：统一网关、路由层，并记录每任务 token 消耗日志，把切换成本压到最低；
3. 盯成本曲线而非价格牌：API 价格会涨会跌，但自研芯片、缓存策略、开源权重模型（DeepSeek、Qwen、Llama 系）这些确定性降本路径，才是穿越价格战的船票。
