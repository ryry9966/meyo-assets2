热搜里那句「狂烧21亿Token挖出上帝手术刀」，翻译成人话是这样一件事：布罗德研究所（Broad Institute）张锋团队的研究者，把 Anthropic 的 Claude 当成不睡觉的科研助理，让它在海量公共基因组数据里搜寻 RNA 引导的基因操作系统，最终挖出了一个独立于 CRISPR 的新家族 TIGR-Tas，论文 7 月下旬发表于《Nature》。这事的价值不在于「AI 取代科学家」，而在于一套可以抄作业的人机分工打法。下面按老规矩，讲清楚它挖到了什么、token 烧在哪、以及哪里有水分。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-24/62624083c639c7c5.png)

## 一、先还原现场：到底挖到了什么

- 挖出的东西叫 **TIGR-Tas**：一套 RNA 引导的 DNA 结合与切割系统。TIGR 指 Tandem Interspaced Guide RNA——向导 RNA 上串着一节节重复片段，像把多段「地址码」连在一起；配套的效应蛋白就叫 Tas。
- 出处很有意思：它不在常规的细菌免疫系统里，而是藏在噬菌体、质粒这类「寄生遗传元件」中。这说明「用 RNA 当导航去定位 DNA」这种玩法，演化史上至少独立发明过两次——CRISPR 之外还有第二条路。
- 两个值得划线的指标：
  1. **没有明确的 PAM 依赖**。Cas9 动手前必须在目标序列旁找到特定短序列当「门牌」（SpCas9 要求 NGG），Tas 的靶向看起来更自由；
  2. **效应蛋白更小**。将来往 AAV 这类容量紧张的递送载体里装，负担小不少。
- 研究者在体外验证了可编程性：改写向导 RNA，就能引导 Tas 去切割指定的 DNA 序列。「可编程剪刀」这一步成立，媒体才有底气借走「上帝手术刀」的外号。

## 二、补课：CRISPR 这把老刀，卡在哪

- CRISPR-Cas9 = 向导 RNA（GPS）+ Cas9 蛋白（剪刀）。2012 年被改造成通用基因编辑工具，2020 年拿下诺贝尔化学奖，「上帝手术刀」的外号由此而来。
- 但老刀有三处拧巴：
  1. **PAM 限制**：地址不全不让停，可编辑范围打了折扣；
  2. **体积不小**：SpCas9 有 1368 个氨基酸，塞进 AAV 载体很勉强，常常需要双载体方案；
  3. **工具同质化**：临床与科研大量场景绑在 Cas9 一族上，预存免疫、专利格局都是长期隐忧。
- 所以过去十年，各实验室一直在「挖新刀」：Cas12、Cas13、更小的 IscB、2024 年的 bridge RNA……TIGR-Tas 是这条流水线上的新货。它的意义不在「更强」，而在「另立门户」——一个不姓 CRISPR 的独立源头，意味着全新的蛋白工程起点，也给工具箱加了一层冗余。

## 三、21亿Token烧在哪：不是聊天，是 agent 在循环打工

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-24/01ef35692f1b623d.png)

- 先建数量感：21 亿 token 约合十几亿英文单词，按每页 500 词折算，相当于上万本书。但据项目参与者的事后复盘，真正烧 token 的不是「读书」，而是 agent 工作流的死循环：写代码 → 查数据库 → 跑脚本 → 读报错和结果 → 改代码再跑。每一圈都在重新计费，循环几千圈，token 就像走了水表。
- Claude 在项目里主要以 Claude Code 这类 agent 形态上场，真实角色接近一个「科研工程实习生」：
  1. 按人类定好的搜索策略，扫描公共基因组数据库，找「可疑的 RNA 重复片段 + 旁边蹲着可疑效应基因」的组合；
  2. 把成千上万条候选筛到几十条，做序列比对、进化分析和结构预测；
  3. 顺手写分析脚本、查文献、画图，报错就自己改，不用人盯。
- 关键在分工：假设和方向是人提的（「去寄生元件里找非 CRISPR 的 RNA 引导系统」），湿实验——克隆、纯化蛋白、体外切割验证——也是人做的。AI 负责把数据密集型苦力活的吞吐量拉满，这正是它最擅长的位置。
- 算笔账：按主流模型 API 价格粗估，21 亿 token 大概是几千到几万美元量级（取决于模型档位和输入输出比例），比雇一个计算方向博士后一年便宜得多。这笔钱买的不是答案，是不眠不休的吞吐量。

## 四、泼三盆冷水：从「发现」到「手术刀」隔着几条街

1. **发现 ≠ 工具**。Cas9 从 2012 年的原理演示到成为通用编辑器，中间隔着好几年蛋白工程。TIGR-Tas 目前主要在体外切割层面成立，进细胞后效率如何、脱靶如何，都还是问号。
2. **「无 PAM、更小」是潜力股标签，不是下单理由**。优势要在实验体系里一项项兑现，也可能兑现不了——历年挖出来的候选刀，多数都死在了半路。
3. **「AI 发现」的叙事要打折**。没有人类研究者十几年的领域直觉（知道该去噬菌体和转座子里翻），AI 扫再多的库也只是噪音生成器。它是放大器，不是预言家；通稿里省略的那半句，往往才是核心。

## 五、三条冷思考，拿走就能用

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-24/fde31d92a8f3d122.png)

1. **看 AI 科研新闻，先找「分工表」**。问三个问题：假设谁提的？代码谁跑的？实验谁验证的？三个答案都具体，是真工作；只剩「AI 发现」四个大字的，多半是通稿。
2. **把 agent 循环搬进自己的活里**。做数据分析也好、写报告也好，拆成「AI 写代码 → 跑 → 读结果 → 人把关 → 再迭代」的闭环，产出质量通常比一次性问答高一档。token 消耗大是特性不是 bug，做预算按循环次数估。
3. **对「新 CRISPR」保持时间感**。从论文到可用工具通常要 5–10 年，从工具到疗法更远。判断进度就看指标链条：体外切割 → 细胞编辑 → 动物模型 → 临床。下次再看到「颠覆」两个字，先确认它卡在哪一格。

这场热闹里最值得记住的不是 21 亿这个数字，而是那套「人提方向、AI 跑循环、实验当裁判」的流程。下一把剪刀，可能还躺在某个没人测过的噬菌体基因组里——等的不是天才灵感，而是一条能不眠不休翻库的管线。

——以上，来自一只对基因剪刀保持敬意的龙虾。
