最近 36kr 一篇题为《A社O社，坐不住了》的文章在技术圈刷屏。"A社"是 Anthropic，"O社"是 OpenAI——硅谷大模型双雄。让它们“坐不住”的不是某篇新论文，而是一组市场信号：榜单易主、价格跳水、对手的用户盘子在变大。在 AI 行业，“坐不住”其实是个准技术术语，意思是 roadmap 整体提前、迭代周期压缩。这篇文章拆三件事：它们到底看到了什么，背后的机制是什么，以及对我们这些“用模型干活的人”意味着什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-24/fccc7a34920ea0e9.png)

## 一、最直观的信号：发版从“年更”变成“月更”

节奏变化是最容易量化的一条：

- OpenAI：GPT-5（2025 年 8 月）到 GPT-5.1（2025 年 11 月）只隔了约三个月，中间还有 Codex 系列的多次滚动更新；
- Anthropic：Claude 在 2025 年内从 4 系列一路迭代到 Opus 4.5，几乎每个季度都有旗舰级更新；
- Google：Gemini 3 发布后迅速登顶 LMArena 等竞技场榜单，给前两名造成直接压力；
- 开源侧：DeepSeek、Qwen、Llama 等以月为单位，把“上一代旗舰”的能力下放进开源权重。

做个历史对比：GPT-4（2023 年 3 月）到 GPT-4o（2024 年 5 月）隔了 14 个月。如今旗舰模型的“保鲜期”按月计算——领先优势从“年级差”缩到“月级差”。当追赶者的冲刺速度跟你的迭代速度一样快，“先发”就不再是资产，而是一笔需要不断续费的负债。

## 二、机制拆解：三条护城河同时变浅

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-24/1ef69b0419818261.png)

“坐不住”的本质，是三道曾经很深的护城河正在被填平：

1. **能力差距在收敛。** 一篇新论文、一套 RL 训练配方公开后，几个月内各家基本都能复现；蒸馏技术又让小模型快速继承大模型能力。结果是基准分数集体水涨船高：MMLU 这类老基准早已被普遍刷到 90% 以上、失去区分度；SWE-bench Verified 上，头部模型一年前还在 50% 附近徘徊，如今已集体冲到 77%~80%。分数越高，能说明的差距越小。
2. **分发存在天然不对称。** Google 把 Gemini 内嵌进搜索、Android、Workspace，公开口径月活已达 6.5 亿量级，还向学生等群体送出整年免费权益——典型的“以量补价”换生态。独立模型公司主要靠订阅和 API 向“愿意付费的人”收费，规模天花板肉眼可见。
3. **成本曲线两头挤压。** 训练端，前沿模型单次训练成本公开估算已进入数亿美元量级；推理端倒是好消息——有机构测算，同等能力的推理价格大约每年下降 10 倍。但推理变便宜是全行业一起便宜：你降，对手也降，省不出护城河。

再叠加开源的价格冲击——DeepSeek-V3 官方口径的训练 GPU 成本约 560 万美元（仅预训练部分），发布后各家 API 价格应声下调——“按 token 卖智能”这门生意的毛利逻辑，被整体重新定价了一遍。

## 三、竞争维度迁移：从“谁的模型更聪明”到“谁的生态更好用”

技术视角看，纯模型层的领先越来越难维持：

- 预训练数据接近极限，Scaling Law 的边际收益放缓，前沿竞争转向 test-time compute 与强化学习——而这条新赛道的配方扩散得更快；
- 基准污染（benchmark contamination）让公开跑分失真，竞技场式评测又偏向“聊得舒服”，与真实工程任务存在系统性偏差；
- Agent 时代的新 KPI 变成了：完成一个任务的成功率、耗时和总成本，而不是单轮回答漂不漂亮。

于是三家给出的答案明显分化：

- O社：C 端 SuperApp 化，浏览器、社交功能、广告模式陆续试点，先把用户和时长攥在手里；
- A社：押注开发者与企业市场，Claude Code 年化收入据报道已达 10 亿美元量级，同时力推 MCP 开放协议，把“AI 接工具”的标准握在手上；
- Google：用免费额度和全家桶绑定，赌的是“默认选项”的力量。

一句话总结：模型本身在商品化（commoditization），价值正在向工作流、工具链和分发渠道转移。这才是“坐不住”的深层原因——不是模型不行了，而是光有模型不够了。

## 四、冷思考：给用模型的人三条建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-24/8a2410f8787313d7.png)

1. **别把业务焊死在单一模型上。** 在接口层做抽象：统一走 OpenAI 兼容格式，或用 LiteLLM、MCP 这类适配层，保留随时切换的能力。今年的榜单第一，明年可能只是第二，你的架构要允许这件事无痛发生。
2. **用“单位任务成本 + 可靠性”评估，而不是跑分。** 从自己业务里挑 30~50 条真实 case 搭一个最小 eval 集，每季度重测。比如客服摘要这类任务，便宜模型加一条打磨过的 prompt，成本可能只有旗舰模型的十分之一——这种结论只有自己的 eval 能告诉你。
3. **选模型也是在选生态。** 看它背后的 IDE 集成、agent 框架、上下文管理和协议开放度，这些决定了半年后你的迁移成本，而不是今天谁多考了两分。

“坐不住”不是坏消息，它意味着牌桌上的人都在拼命出牌。行业卷的是模型，我们要卷的只是“换模型的成本”——把这个成本做低，无论 A 社 O 社怎么坐不住，你都坐得稳。
