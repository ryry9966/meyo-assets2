这两年大模型行业的竞争叙事，正在从"谁更聪明"悄悄切换成"谁更便宜"。GPT-6 一口气上线两个版本——Sol 和 Luna，定价直接击穿行业心理防线，36kr 那句"打折比梁文锋还狠"，等于公开承认：连定义 frontier 的公司，也开始用 DeepSeek 式的价格打法抢市场了。价格跳水从来不是做慈善，背后是一整套推理工程 + 商业算计。这篇文章把它拆开看清楚：Token 凭什么这么便宜，大厂图什么，开发者怎么接住这波红利。

## Sol 与 Luna：一对"日月双星"的产品逻辑

从命名就能读出定位：Sol（太阳）大概率对应旗舰档——高算力、深度推理、贵但聪明；Luna（月亮）对应轻量档——低延迟、便宜、够用。官方未必把话说死，但行业剧本基本就这么写的，而且早有先例：

- OpenAI 自己：o1（重推理）配 o-mini（轻快便宜）
- Google：Gemini Pro 配 Flash
- DeepSeek：R1 之外放出一整套蒸馏小模型

双模型真正的意义不是"发两个型号"，而是给模型级联（model cascade）铺路：日常流量走 Luna，疑难杂症升级 Sol，成本曲线立刻由陡变缓。对厂商来说还有个隐藏好处——流量分流这件事，让用户自己在调用时完成，产品复杂度为零。

## 价格简史：Token 单价怎么两年跌没一个数量级

先把锚点摆出来（单位：每百万 token）：

1. 2023 年 3 月，GPT-4 发布：输入 $30 / 输出 $60
2. 2023 年 11 月，GPT-4 Turbo：$10 / $30
3. 2024 年，GPT-4o 一年内降到 $2.5 / $10；GPT-4o-mini 把入门款干到 $0.15 / $0.60
4. 2024 年 12 月，DeepSeek V3：输入 $0.27（缓存命中仅 $0.07）、输出 $1.10，直接把全行业锚点砸穿
5. 同期国内价格战更卷，豆包等把主力模型打到"厘/千 tokens"量级，降幅号称 99%

结论很清晰：同等能力档位的单价，两年掉了 10 倍以上。"打折比梁文锋还狠"不是修辞，是两条价格曲线真的交汇甚至交叉了。

## 便宜的物理学：推理成本到底怎么压下来的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-23/f4fa84d33d9c96d6.png)

降价能持续，靠的是硬工程，每一项都值得单独写一篇：

1. **MoE 稀疏激活**：DeepSeek V3 总参数 671B，但每个 token 只激活约 37B——算力按需点菜，而不是每次全员上岗。
2. **KV Cache 工程化**：PagedAttention（vLLM）把显存当操作系统页表来管理；prefix caching 让相同的 system prompt 不必每次重算，缓存命中价差能到 50%~90%。
3. **量化**：FP8/INT4 推理，显存占用和带宽压力砍半再砍半。
4. **蒸馏**：Luna 这类小模型大概率是 Sol 蒸馏出来的——用大模型的输出教小模型，能力留下，算力账单扔掉。
5. **推理调度**：continuous batching、speculative decoding，把 GPU 利用率从"三成干活、七成吃灰"往六成以上推，等于白捡半个机房。
6. **规模摊薄**：训练是固定成本，token 消耗越大，摊到每个 token 上的折旧越薄。

代价是经济学里著名的 Jevons 悖论：效率越高、单价越低，总消耗反而暴涨——你现在一个月烧的 token，很可能是两年前一年的量。

## 主动打折的三层商业算盘

1. **能力同质化**：头部 benchmark 快被挤成牙膏，顶级模型差距缩到个位数百分点，价格和延迟成为新的差异点。
2. **生态抢滩**：API 是有迁移成本的，业务管线焊死在谁家 SDK 上，后面推 Agent、推企业版才有故事。降价本质是获客成本，不是让利。
3. **开源封顶**：Llama、Qwen、DeepSeek 的开源权重，把私有 API 的价格上限压到"接近自建成本"。不想被开源按在地上摩擦，就只能自己把价格打下去。

## 开发者怎么接住这波降价

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-23/92887787b9c5013b.png)

给一套可执行的三步框架：

1. **用"每任务成本"替代"每 token 成本"**：拿自己业务的真实 case 跑 eval，算清解决一个工单、生成一篇文案的真实花费。便宜 10 倍但幻觉翻倍的模型，总账大概率是负优化。
2. **架构上留活口**：做 provider 抽象层 + 级联路由——80% 流量走 Luna 档，置信度不够再升级 Sol；换模型应该是改一行配置，而不是重构整条管线。
3. **吃满缓存红利**：把 system prompt、few-shot 示例、长文档这些稳定上下文设计成可缓存前缀，命中价差 50%~90%，这是最容易被白送的折扣。

## 写在最后：三条冷思考

1. **单价会跌，账单未必**：Jevons 悖论 + Agent 自动化会成倍放大消耗。先给 API 加预算告警，别等月底账单来教育你。
2. **警惕静默更新**：模型行为漂移不会发公告，核心链路要自建回归测试集，每次版本切换跑一遍再上线。
3. **补贴窗口不会永远开着**：价格打得越狠，越要问一句毛利从哪来。把业务建立在"永久地板价"的假设上，和建立在"模型永远不更新"上一样危险。

价格战对用户是短期红利，对行业是长期洗牌。Token 越来越便宜之后，真正昂贵的资源只剩两样：判断力，以及知道该问什么问题的能力。
