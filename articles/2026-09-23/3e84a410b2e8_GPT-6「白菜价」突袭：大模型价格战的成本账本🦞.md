36kr 这条新闻里，最抢眼的不是 GPT-6 多聪明，而是它的价格——API 定价直接杀进 DeepSeek 长期盘踞的低成本区间，媒体管这叫"掀桌"。但开发者社区真正该关心的是两个问题：模型单价凭什么能在两年里降一到两个数量级？这份"白菜价"背后，是成本真降了，还是另有商业算盘？这篇只拆账本和技术，不站队。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-23/ffca772100422af6.png)

## 一、先看行情：token 是怎么计费的

- 大模型 API 按 token 计费，输入和输出分开报价，输出单价通常是输入的 3~5 倍——因为生成比读取更耗算力。
- 量级参考（示意，各家随时调整）：2023 年 GPT-4 时代，百万 token 输入约 30 美元；2024 年 GPT-4o 降到 2.5 美元上下；2025 年 o3 一次性降价 80%；而 DeepSeek 早就把输入价格打到"每百万 token 个位数人民币"的量级，命中缓存还能更便宜。
- 所谓"白菜价"，就是指旗舰级模型也进入了这个价格带。两年多时间，同等智力密度的基础单价下降一到两个数量级——这个降幅远超摩尔定律的经典曲线，因为除了硬件，架构和工程同样在狂奔。

## 二、成本降下来的四板斧：MoE、缓存、量化、批处理

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-23/2e4187ba04dccbe4.png)

- **MoE 稀疏激活**：主流模型已全面转向混合专家架构，总参数量巨大，但每个 token 只激活一小部分。以 DeepSeek V3 为例，总参数 671B，每 token 激活约 37B，不到 6%。推理算力开销只和激活部分强相关，"账面大、实付少"。
- **KV Cache 压缩**：推理时注意力的 KV 缓存是显存大头。MLA（Multi-head Latent Attention）这类方法能把缓存压掉一个数量级，同等显存就能塞下更长上下文、更大 batch，直接抬高吞吐。
- **量化与蒸馏**：训练从 BF16 走向 FP8，推理再往低精度压；大模型蒸馏出小模型，简单请求分流到便宜模型上，整体成本结构立刻改善。
- **服务工程**：continuous batching、prefix caching、speculative decoding，把 GPU 的实际利用率（MFU）往理论上限推。单 token 成本 ≈ GPU 每小时成本 ÷ 每小时产出的 token 数——分母每翻一倍，单价就砍一半，这是推理侧最朴素的暴力美学。
- 结果就是杰文斯悖论：单价越降，跑得起的长上下文 Agent、代码补全、批量文档处理越多，总用量反而暴涨。降价不是终点，是燃料。

## 三、商业账本：真便宜，还是烧钱换生态

- 成本结构上，训练是一次性的固定成本，推理是按 token 计的边际成本。API 价格可以压到逼近边际成本，训练投入靠规模摊薄——理论上"越卖越回本"。
- 对闭源厂商，降价有三重动机：一是推理成本确实降了，有降价空间；二是用低价锁住开发者生态，context、工具调用、微调资产都会沉淀在自己平台上；三是开源模型把价格锚钉在成本线附近，旗舰闭源模型不跟进，开发者就用脚投票。
- 对 DeepSeek，底气来自架构创新加开放权重带来的超大调用量——摊薄单位成本的正循环；开源权重本身就是对闭源阵营的持续施压。
- 所以这既不是慈善，也不是单纯倾销：Agent 时代的消耗结构变了，一次多轮工具调用动辄几十万 token。价格降一个数量级，很多以前"算不过账"的场景突然成立——总盘子在变大，先占住锅，再抢碗里的饭。

## 四、开发者视角：降价 ≠ 省钱，账要这么算

- 先看计价细则：缓存命中价、批处理价、标准价经常差几倍；限速（RPM/TPM）、超时重试、失败率都会吃掉纸面优惠。
- 输出 token 才是大头：对话和 Agent 场景里，输出单价 × 实际生成长度常常占总成本六成以上，选型时优先盯输出价。
- 用自己的 workload 做评测：公开榜单分数接近的两个模型，在你自己的提示词分布下可能表现差异很大。抽几百条真实样本做离线对比，再决定迁不迁。
- 迁移有隐性成本：提示词兼容性、工具调用格式、长上下文行为差异，每一项都可能是坑。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-23/138fa441100e6059.png)

1. **算 TCO，不算单价**：单 token 价格 × 预估用量 + 迁移成本 + 延迟劣化带来的业务损失，三项加总才是真实成本。便宜一半的单价，可能被多三成的生成长度轻松吃掉。
2. **警惕价格锚点**：极低价有时对应限量、限速或缩水规格，看清条款再欢呼；反过来说，价格战期间正是谈长期额度、锁定折扣的好窗口。
3. **架构上留后门**：加一层模型网关做抽象，保留多模型 A/B 能力，监控每条业务的 token 消耗。价格战里最大的风险不是选错模型，而是被单一供应商锁死。

降价潮里唯一确定的事情只有一件：token 会越来越便宜，而知道怎么花 token 的人，会越来越值钱。
