最近 36 氪一篇报道把一个正在发生的趋势摆上了台面：不少大模型公司开始组建“解决方案团队”，派工程师驻场到客户那边，做需求调研、数据清洗、微调训练、私有化部署——翻译成人话：卖模型的公司，干起了咨询公司和系统集成商的活。乍一听有点魔幻，仿佛米其林大厨下场帮人包了食堂，但扒开看底层逻辑，其实相当扎实。这篇咱们掰开揉碎聊聊：为什么会这样、这门生意长什么样、钱怎么算，以及企业和从业者该怎么看。

## 一、模型层卷不动了：同质化 + 价格战

第一推动力来自上游，模型本身不赚钱了：

- **能力差距在收窄**。2023 年各家旗舰模型的 benchmark 还能拉开明显身位，到 2024~2025 年，头部模型通用能力互相咬得很紧，“换一家模型、指标涨 20 分”的叙事越来越难讲，客户自然也就不缺“非它不可”的理由。
- **价格战打穿地板**。2024 年国内头部云厂商集体降价，部分主力模型 API 降幅超过 90%，轻量模型直接打到“厘/千 token”级别；海外主流模型同样在发布后一路砍价。推理收入的毛利被迅速压薄。
- **开源进一步摊薄溢价**。Llama、Qwen 等开源权重模型把“能用”的门槛拉得很低，闭源模型只能靠“好用得多”吃饭，而“好得多”越来越难证明。

结论很朴素：当卖水的不赚钱，就得往下游走，去卖“水管道工程”。这是所有商品化行业的老剧本，轮到模型层上演而已。

## 二、企业客户要的不是模型，是“能用的系统”

第二推动力来自下游。Gartner 曾给出过一个扎心的预测：大量生成式 AI 项目会死在 PoC（概念验证）之后，原因是数据质量差、成本失控、业务价值说不清。真实落地场景里，企业买完 API 通常会发现四件事：

1. **私有数据不在模型里**。得做 RAG（检索增强生成）、搭知识库、先治理数据——很多客户的数据甚至还是一堆没人维护的 Word 和扫描件。
2. **通用模型不懂行业黑话**。金融的风控口径、医疗的病历术语、制造业的工艺参数，都要靠行业语料和微调喂出来。
3. **合规红线过不去**。数据不能出内网，就得私有化部署，模型厂得派人拎着工具箱进机房。
4. **业务流程要重构**。光给个对话窗口没用，得把能力接进 CRM、ERP、工单系统，还得重排人的工作流。

这四件事，没有一件是“调个 API”能解决的——全是咨询公司和集成商的传统地盘。模型厂为了把货真正卖出去，只能自己下场干脏活累活。

## 三、这门生意的三种形态，一档比一档重

- **定制微调 + 私有化部署**：最重的一档，典型客户是政务、金融、大型制造，交付周期以季度计，本质上是传统集成商的项目制。
- **Forward Deployed Engineer（前驻工程师）**：Palantir 炒火的模式——工程师直接坐进客户业务团队，边聊需求边写代码。OpenAI 近年也在扩招类似岗位，国内头部厂商普遍组建了成建制的交付与解决方案团队。
- **行业解决方案包**：把重复项目沉淀成半标准产品，比如智能客服、合同审查、代码助手，按席位或按量收费。这是三档里唯一有点“产品相”的，也是模型厂真正想要的终点。

三种形态对应一个共同动作：从“卖燃料”变成“帮客户把发动机装进车里”。

## 四、算一笔账：Token 计费 vs 人天计费

这大概是整件事最拧巴的地方，咱们摆几个数字：

- 纯软件 / SaaS 业务的毛利率通常在 70%~90%，而服务、咨询类业务大多只有 30%~50%，还要承担人力爬坡和回款风险。
- 资本市场给软件公司的估值倍数普遍高于服务公司，所以“越像咨询公司，估值就越像咨询公司”——这是模型厂最不想听到的一句话。
- 但另一面：光卖 API 在当前价格体系下确实撑不起收入目标，服务收入虽然毛利低，却是当下最确定的现金流，还能顺手锁住客户关系。

所以合理的打法是一个组合拳：**用服务收入撑报表，同时把交付过程沉淀成可复用资产，慢慢把毛利往回捞**。判断一家模型厂这门生意健不健康，关键就看一个指标——交付项目里可复用资产的比例。比例持续走高，说明在从咨询爬向产品；一直靠堆人头，那就是披着 AI 外衣的传统外包。

## 五、有意思的是，咨询公司也在反向“AI 化”

故事还有另一面。麦肯锡早已上线自己的内部 AI 知识助手，埃森哲披露的生成式 AI 相关订单达到数十亿美元量级，四大也在重写自家交付方法论。也就是说：

- 模型公司往下走：从模型到方案；
- 咨询公司往上走：从方案到“内置 AI 的方案”。
- 两拨人在“企业智能化改造”这条价值带正面会师。

未来几年的看点只有一个：谁先把对方的价值环节吃掉。模型厂能不能把驻场交付沉淀成产品，咨询公司能不能把 AI 变成自己的交付杠杆、用更少的人干更多单——这两条曲线的斜率，决定了五年后行业格局。

## 收尾：三条冷思考

1. **对企业买家**：评估方案商别只看 demo 炫不炫，重点问一句“这个方案里多少是标准产品、多少是现场堆人天”。纯人天的项目，明年续费时预算会被砍得最狠；而 demos 好看、生产环境翻车，恰恰是 PoC 阶段最常见的坑，评测体系和数据治理才是该盯的地方。
2. **对从业者**：“AI 解决方案工程师 / 交付架构师”可能是未来几年需求涨得最快的岗位之一。既懂模型的能力边界、又懂业务流程的人才极度稀缺，这类岗位建立的经验壁垒，未必比卷模型微调技术低。
3. **对整个行业**：服务重不等于不健康，“重服务 + 零复用”才是陷阱。真正的问题不是该不该干咨询的活，而是干完之后能不能把人天变成资产、把项目变成产品。Palantir 和埃森哲的历史都证明了这条路走得通——也证明了它有多难走。大模型公司现在踩进去的，正是这段最难的路。
