最近科技圈一条不太起眼但分量很重的消息：据报道，Anthropic 在旧金山悄悄搭了一间自动化生物实验室——不是演示用的展厅，而是配备移液机器人、微孔板和检测仪器的真实湿实验室（wet lab）。分工很明确：Claude 负责"动脑"，读文献、设计实验、分析数据；机械臂负责"动手"，加样、培养、读数。这意味着 AI for Science 正在从"出主意的军师"，变成能亲自跑完验证环节的"研究合伙人"。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-23/a010fa685f5ab400.png)

## 为什么要给大模型配一间实验室

过去五年，AI 在科学里的角色基本停留在 in silico（纯计算）层面：

- AlphaFold 把蛋白质结构预测做到了原子级精度，覆盖超过 2 亿个蛋白，但它给的是"预测结果"，后续的湿实验验证仍要靠人；
- 大语言模型擅长读文献、提假设、写综述，可假设再多，人工实验排队动辄几个月，科研吞吐量的瓶颈不在"想"，而在"做"。

科学发现的真实引擎是一个闭环：**假设 → 实验 → 数据 → 修正假设**。这个循环转得越快，发现越快。AI 只参与第一环，等于拧螺丝只拧一半。让模型直接驱动实验，还有一层更深的意图：实验产生的高质量一手数据会反过来喂给模型，形成数据飞轮——这是爬互联网文本永远得不到的东西。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-23/e8dfbba82aafdfc6.png)

## 这间实验室实际怎么运转

从公开信息和同类系统推演，一条典型的流水线长这样：

1. **任务拆解**：生物学家给出研究目标，Claude 以 agent 形式读文献、设计实验方案，包括对照组、浓度梯度、重复次数；
2. **协议翻译**：方案被转写成自动化设备能执行的指令——哪块微孔板、加多少微升、什么温度孵育多久，相当于给机器人下"工单"；
3. **硬件执行**：移液工作站、培养与检测仪器完成物理操作，产出原始读数；
4. **分析与迭代**：Claude 解读数据、修正假设，进入下一轮循环，关键节点始终有生物学家人工审核。

这套思路并非 Anthropic 首创。2023 年 CMU 团队的 Coscientist 在 Nature 上展示了 GPT-4 自主规划并完成化学合成；伯克利的 A-Lab 也跑通过无机材料的自主合成。Anthropic 做的，是把"AI 科学家"从论文 demo 推向产品化、常态化运行。

## Anthropic 的商业算盘

这步棋放在行业棋局里看并不突然：

- **竞争压力**：Google DeepMind 背后有 AlphaFold 和分拆出的 Isomorphic Labs（2025 年完成 6 亿美元融资）；Google 推出了多智能体"AI co-scientist"；FutureHouse 的 agent 已报告发现候选药物。各家都在抢"AI scientist"这个高地。
- **数据资产**：Anthropic 没有 DeepMind 式的科学数据积累，自建实验室等于自建数据管道，一手实验数据是最深的护城河。
- **客户对齐**：药企和生物科技公司是典型的高客单价客户，与 Anthropic 的 to B 商业模式天然契合。
- **agent 试炼场**：长周期任务、多工具调用、低容错环境——实验室是检验 agentic AI 极限能力的最好考场。

## 生物安全这根弦，比能力本身更受关注

"前沿模型 + 自动化湿实验"的组合，天然带着双重用途属性：同一套系统能加速药物筛选，理论上也存在被滥用于危险剂型优化的可能，这是绕不开的客观事实。

Anthropic 在这个方向上有现成的框架：其 Responsible Scaling Policy 的 ASL-3 档位专门针对 CBRN（化学、生物、放射、核）能力设置了评估门槛，据报道该实验室也配套了访问控制、用例限制和人类审核机制。客观地说，当前这类系统的通量和复杂度还很有限，离所谓"自主造出危险物"有相当距离；但正因为能力在快速爬坡，安全基建必须与实验能力同步升级——这大概是这间实验室里最不能省的"设备"。

## 三条冷思考，给不同的你

1. **看门道，别看热闹**：评估任何 "AI scientist" 项目，别被"AI 会做实验了"这种表述带偏，真正要问的是闭环速度——假设到验证的周期从几个月压缩到几天了吗？样本量和可复现性如何？速度和可靠性才是硬指标。
2. **对工程师**：这类系统的难点不在模型多聪明，而在 agent 与硬件的集成质量——指令翻译、异常处理、失败重试。实验室自动化的坑（耗材批次差异、仪器校准、边缘 case）比调 prompt 深得多，是典型的"最后一公里"工程。
3. **对从业者**：生物 + agent 编排的交叉人才极度稀缺。懂实验 protocol 的人往往不懂 API 和 workflow 编排，反之亦然。主动补上另一边的知识结构，未来五年的稀缺性会兑现成溢价。

从"会聊天的模型"到"能验证假设的系统"，AI for Science 这一步跨得不小。至于能不能真正跑出科学发现——下一个五年，看循环速度。
