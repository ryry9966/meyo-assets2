最近 36kr 有篇文章讨论了一个有意思的错位：智谱的 GLM 系列模型在海外开发者圈口碑相当能打，但国内大众的心智，基本被 DeepSeek 和豆包占满了。同一家公司的同一批模型，为什么在两个市场拿到的"分数"差这么多？这不是谁在数据造假，而是两边压根用的不是同一把尺子。这篇拆开讲：海外好评是怎么攒出来的，大众心智是怎么被占领的，以及这个错位对行业意味着什么。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/85b631785b2707ea.png)

## 一、先摆事实：GLM 的海外口碑不是玄学

- **家底**：智谱 2019 年从清华 KEG 实验室的技术转化起家，是国内最早一批投入大模型研发的公司。
- **起点很高**：2023 年 3 月开源的 ChatGLM-6B，是国内最早可本地部署的中英双语对话模型之一，在 HuggingFace 和 GitHub 上攒下大量开发者，一度催生数百个衍生模型。
- **近作能打**：2025 年 7 月的 GLM-4.5 采用 MIT 许可证开源，355B 总参数的 MoE 架构（激活约 32B），官方口径在多项 agentic 综合评测中位居全球前列，海外社区的独立反馈大体对得上；10 月的 GLM-4.6 把上下文拉到 200K，代码能力继续加强。
- **真正出圈的杀手锏是价格**：GLM Coding Plan 月费低到 3 美元量级，大量海外开发者把它接进 Claude Code、Cline 这类编程工具当"平替"，相关评测视频在 YouTube 上热度可观。
- **注意一个共性**：这些好评几乎全部来自开发者视角——benchmark 成绩、许可证宽松度、API 价格、代码与智能体能力。

## 二、国内大众用的，是另一套评价体系

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/a74e27eded6c0813.png)

大众用户不下载模型权重，他们接触 AI 的入口是应用商店和短视频信息流。这条赛道上，口碑 ≈ **渠道 × 场景 × 话题性**：

- **DeepSeek 靠"技术奇观"破圈**：2025 年 1 月 R1 发布，推理能力对标顶级闭源模型、MIT 开源、把训练成本打到极低，App 半个月内冲上包括美国区在内的多个应用商店免费榜第一，完成了一次罕见的大众级冷启动。
- **豆包靠"渠道碾压"破圈**：字节把抖音流量、预装和广告投放全部用上，再配上免费语音、拍照解题、日常闲聊这类低门槛场景。第三方机构口径下，豆包月活从 2024 年底的约 6000 万，涨到 2025 年的亿级量级，长期坐稳国内 AI 原生应用头把交椅。
- **而智谱的 C 端产品"智谱清言"，存在感一直偏弱**。不是产品不能用，而是它没出现在大众注意力聚集的地方。

用 benchmark 的尺子去量应用商店排名，就像用游标卡尺量火锅底料：工具没错，对象错了。两个战场甚至不在同一个物理空间——一个在 HuggingFace，一个在抖音信息流。

## 三、错位的根源：不是传播失误，是战略取舍

把结论停在"智谱不会营销"就太浅了，更合理的解释是资源投向的选择：

1. **主力押在 toB 与开发者生态**：MaaS 平台、API 服务、政企私有化部署。toB 是项目制生意，成交靠销售和案例库，天然不产生大众话题。
2. **开源在两个市场的"汇率"不同**：海外开发者看重 MIT 许可证和 self-host 的自由度，开源是强加分项；但在国内大众眼里，"开源了"约等于什么都没发生。
3. **C 端打爆点需要持续烧钱换量**：豆包背后是字节的渠道成本转嫁能力，DeepSeek 赌赢了一次技术奇观。智谱没做同等级的 C 端投入，自然也没有等量的 C 端回报——投入和回报在这个市场基本守恒。

## 四、品牌叙事：名字太多，故事太少

- 智谱的对外称谓有点复杂：智谱AI、GLM、智谱清言、AutoGLM、Z.ai……大众记不住超过一个名字。
- 对比之下，DeepSeek 是"一个名字一条故事线"：低成本、高推理、让硅谷重新审视开源。豆包名字亲切，自带抖音场景。
- 海外技术社区的叙事由 Hacker News、YouTube 评测和竞技场榜单驱动；国内大众叙事由热搜和应用商店榜单驱动。评价权握在不同的人手里，结论自然不同。

## 五、错位是坏事吗？得算两本账

大众认知度低，不等于商业失败：

- 企业客户选型恰恰看 benchmark、私有化能力和稳定性，"大众认不认识"在采购决策里几乎不重要。智谱的 API 收入和政企订单长期位居国内第一梯队，2025 年上半年还率先启动了上市辅导。
- 海外开发者口碑本身就是资产：订阅收入、API 出海，以及"国际基准背书"反过来支撑 toB 报价。
- 硬币另一面：C 端品牌意味着数据飞轮和下一代用户的默认选项，彻底放弃 C 端的长期代价，现在还看不清。

## 六、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/bd82f461be4764d2.png)

1. **评价模型先问"用哪把尺子"**：benchmark、真实任务表现（写代码、整理文档）、单 token 成本是工程师视角；App 排名是大众视角。两把尺子都合法，但别混着用。
2. **技术品牌要做大众传播，需要"一个名字 + 一个可感知的爆点"**，缺一个都出不了圈。选择不做，就得接受"隐形冠军"的定位，不必羡慕流量。
3. **对普通用户：模型强和你用得上是两回事**。选工具看场景——日常问答看体验，写代码看 agentic 能力，语音陪伴看产品设计。热度只是成本最低的参考项，虾壳好看的部分，不一定是肉。
