最近 36kr 等媒体曝出 OpenAI 正酝酿一笔巨额融资，同时与 Anthropic 在争夺同一批机构金主。先给结论：这类新闻里，融资额、估值、算力承诺三个口径经常被混为一谈，所以这笔“2000 亿”值得关注的不是数字本身，而是它折射出大模型行业已经变成一门什么样的生意。下面把账本摊开看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/bd356110f64d68d4.png)

## 先分清三个“亿”：融资额、估值、算力承诺

读科技财经新闻的第一课，是搞清楚数字到底是哪个口径：

- **融资额**：这一轮实际打进公司账上的现金。OpenAI 2025 年 3 月由软银领投的那轮约 400 亿美元，是近年一级市场最大单笔之一。
- **投后估值**：公司整体作价。随后员工股转让传闻把 OpenAI 估值推到约 5000 亿美元；Anthropic 在 2025 年 9 月完成约 130 亿美元 F 轮，投后约 1830 亿美元。
- **算力承诺**：多年期采购与建设合同，比如 Stargate 计划传出 5000 亿美元规模、Oracle 云合同传闻 5 年约 3000 亿美元。这是“未来要花的钱”，不是“今天融到的钱”。

“急融 2000 亿”具体指哪个口径，各家报道并不统一。所以第一反应应该是：问口径，再看数。

## 钱烧在哪：一门电网级的“重工业”生意

大模型公司的成本结构，和传统互联网公司完全是两个物种：

1. **训练**：一次前沿模型训练需要数万到数十万张 GPU 组成的集群，单次训练成本据估算在数亿美元量级，还没算数据中心土建、供电、液冷和高速互联网络（IB/以太网）。
2. **推理**：每个用户每次对话背后都是 GPU 时间。用户量 × 人均调用量，成本是线性堆上去的。
3. **长期算力合同**：近半年 OpenAI 与 NVIDIA、AMD、Broadcom、Oracle 签下多份总计数十吉瓦（GW）级别的算力协议。GW 是什么概念？一座大型核电机组约 1GW。这已经不是软件公司的开销，是电网级别的规划。
4. **人才**：顶级研究员的薪酬包以千万美元计，且需要用期权持续锁定。

所以巨额融资的真正用途，往往不是“研发更好模型”这么轻巧，而是提前锁定未来数年的电力、土地和芯片产能——在算力供不应求的市场里，钱本质上是排队的筹码。

## “抢金主”抢的是什么：稀缺的耐心资本

- **金主池本来就小**：能消化十亿美元级支票的机构不多——主权基金、大型养老金、头部 PE、战略投资人。OpenAI 和 Anthropic 的名单高度重叠，软银、Coatue 等名字两边都出现过，抢的是同一批长期资金的额度。
- **收入量级**：据报道 OpenAI 年化收入已超百亿美元，Anthropic 约 50~70 亿美元且增速更快。但相对估值，市销率仍是几十倍——投资人买的不是现金流，是“如果下一代产品出现”的期权。
- **差异化筹码**：OpenAI 胜在用户规模与品牌（ChatGPT 周活跃用户据称已达数亿），Anthropic 胜在企业 API 与代码场景（Claude Code 带动的企业订单口碑）。金主做的其实是组合配置题。

## 循环交易争议：左手投资、右手买卡

有媒体统计，OpenAI 近期公布的算力安排里，交易对手同时也是它的投资人：NVIDIA 承诺投资、OpenAI 买芯片；AMD 给认股权证、OpenAI 下 6GW 订单。这种“供应商入股客户”结构并不新鲜，航空业、光伏产业都有长单加股权绑定的先例。风险点在于杠杆的循环放大：投资推高估值 → 增强下单能力 → 订单又反哺供应商营收。历史参照是 2000 年通信泡沫期的 vendor financing——朗讯、北电借钱给运营商买自家设备，泡沫破裂时坏账集中爆发。当然也有不同：今天的云厂商 capex 背后有真实的 AI 收入增长在支撑。这不是阴谋，是金融工程；但金融工程的尾部风险，从来值得盯紧。

## 冷思考：三条给普通人的读法

1. **看到巨额数字先做口径拆分**：融资额、估值、合同承诺额三者差着量级，混用会得出荒谬结论。这是最低成本的信息素养训练。
2. **关注单位经济性而非宏大叙事**：模型推理的 token 单价近两年以每年约 90% 的速度下降，模型层毛利改善的同时，价值可能向应用层转移——从业者与其围观头部融资，不如关注推理成本下降打开的应用窗口。
3. **一级市场新闻不等于二级市场逻辑**：这类融资流动性差、周期长，“大公司抢着投”不能直接翻译成“明天该买什么”。看得懂账本，比追得上热搜更有用。

一句话收尾：这一行最贵的资产是算力，最稀缺的资源是耐心，最容易贬值的，是热搜上的数字。
