最近 36kr 那篇《梁文锋把赚钱的秘密开源了》又刷了一遍屏。一家公司把模型权重、训练细节、基础设施代码全部摊在桌面上，对手照着抄就能省下大把算力钱——听起来像把祖传秘方贴在大门口。这是理想主义，还是精明算计？拆完技术细节和商业逻辑你会发现：都是，而且这套打法的闭环相当漂亮。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/37b08a4e2153b64a.png)

## 先对齐认知：他到底开源了什么

先纠正一个常见误解：开源不等于把家底全捐了。DeepSeek 的开放是**有边界、成体系**的：

- **模型权重**：DeepSeek-V3（671B 总参数的 MoE 架构，每个 token 仅激活 37B）和推理模型 DeepSeek-R1，均以 MIT 许可证发布，商用无门槛。
- **技术论文**：V3 论文公开了 MLA、MTP 等架构设计、训练超参数和 FP8 混合精度细节；R1 论文把强化学习配方（GRPO、规则化奖励）写得相当细。
- **基础设施代码**：2025 年 2 月的 Open Source Week，连续放出 FlashMLA、DeepEP、DualPipe、3FS 等核心仓库。
- **蒸馏成品**：直接给出把 R1 蒸馏到 Qwen/Llama 1.5B–70B 的全套小模型，小团队拿来就能跑。

没公开的也很明确：原始训练数据、完整数据清洗管线、在研的前沿模型。一句话总结：**开放的是方法论，保留的是前沿**。

## 秘方的技术内核：省钱是一层层省出来的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/3c4dea1057c502f4.png)

所谓"赚钱的秘密"，技术上更接近"省钱的秘密"。V3 预训练消耗约 278.8 万 H800 GPU 小时，按每卡时 2 美元租金估算约 557.6 万美元——不含前期研究、消融实验和推理成本，但仍比同期闭源模型低一个量级。钱是这样一层层省的：

1. **MLA（Multi-head Latent Attention）**：把 KV Cache 压缩进潜空间，显存占用大幅下降，推理时能开更大的 batch，单位算力产出更多 token。
2. **MoE 稀疏激活**：671B 总参数只激活 37B，模型容量大、单次计算便宜，容量和成本两头占。
3. **FP8 混合精度训练**：在这个参数规模上稳定跑通 FP8 本身就是工程壮举，显存和带宽开销直接砍掉近半。
4. **DualPipe 流水线并行**：把计算与通信重叠调度，拉高 GPU 有效利用率（MFU）。
5. **GRPO 强化学习**：砍掉独立的 critic 网络，用组内相对优势做基线；奖励用可验证的规则（答案对错、格式正确）而非神经网络 reward model，规避 reward hacking。

这五件事没有一件是单点黑科技，全是系统工程上的复利。省钱省到这个份上，已经不是抠门，是物理学：**当算力受限，效率本身就是护城河**。

## 商业算盘：为什么送出去反而更值钱

只看模型，开源像做慈善；往下一层看，账就通了。

- **商品化互补品**：模型一旦成为 commodity，价值就向上游（算力、数据）和下游（应用、交付）转移。谁先把"智能"打成白菜价，谁就更接近生态入口。
- **人才磁铁**：梁文锋在访谈里提过，团队以国内顶尖高校的年轻人为主，给足算力和自由度，不设短期 KPI。对顶尖研究者来说，"我的论文被全球复现"比年终奖性感得多。
- **标准与分发**：MIT 许可证加蒸馏进 Qwen/Llama 生态，等于让全球开发者替你测试、适配、布道。R1 发布后各家云平台火速上线，相当于一次免费的全球部署。
- **定价权冲击**：R1 以极低 API 价格对齐 o1 级别的表现，直接引发行业价格战，品牌资产却在同步升值——连 Sam Altman 都罕见公开称赞其性价比。
- **资本结构从容**：DeepSeek 背后是量化基金幻方的利润，不依赖 VC 融资，不必靠"闭源护城河"向投资人讲故事，打法自然更长期。

对照历史这不是新剧本：Android 开源换移动生态，PyTorch 开源换研究社区，Meta 放出 LLaMA 换开发者心智。开源从来是进攻动作，不是慈善行为。

## 冷知识区：开源的边界与易错点

- **开源不等于免费跑**：671B 权重随便下载，但部署它需要的显存、推理优化和运维成本一分不少。一句话：权重免费，机柜自费。
- **数据飞轮仍在手里**：方法公开了，数据积累和迭代速度没公开。开源商品化的是"今天的模型"，前沿实验室永远领先复现者一个身位。
- **蒸馏的灰色地带**：各家大厂其实都在互相蒸馏，差别只在许可证与合规边界；"用别家 API 输出训练模型是否违约"至今是行业争议题。
- **复现有隐性成本**：论文里的 557 万美元不含消融实验和失败尝试，照图纸复刻前沿模型，真实预算通常是数倍。

## 收尾：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/d2a0cebde19b3d94.png)

1. **开发者**：把论文当图纸，别当答案。先跑 R1 蒸馏小模型验证 pipeline，确认许可证、算力和数据前提后，再决定是否上全量训练。
2. **选型者**：许可证比参数量重要。MIT 与各种 "open weight" 附加条款的商用差异，可能直接决定产品能不能上线；同时关注 vLLM、SGLang 等推理框架的支持成熟度。
3. **做产品的**：护城河别押在"别人没有模型"上，这堵墙正在被开源潮拆除；押在数据、场景理解和工程交付上的业务，反而更稳。

开源是策略，不是信仰。看懂"为什么开"，比盯着"开了什么"更重要。
