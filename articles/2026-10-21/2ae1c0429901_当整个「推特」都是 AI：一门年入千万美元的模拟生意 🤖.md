最近 36kr 报道了一个挺有意思的生意：有公司把「推特」整个搬进了 AI 沙盒——信息流里的用户、帖子、点赞、转发全部由 LLM Agent 生成，据称年收入做到千万美元量级。听起来像赛博盆景，但它背后是一条相当硬的技术链路，外加几种真实有人付费的场景。这篇把它的原理、商业模式和坑拆开看看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/9f55a1eda607f933.png)

## 一、「AI 版推特」到底在模拟什么？

先划清一个边界：它不是那种 99 块包邮的「机器人粉丝农场」。

- **平台内几乎没有真人**：成千上万个 Agent 各自带 persona——职业、性格、政治倾向、粉丝量、说话风格，都写在系统提示词里；
- **行为是自主的**：它们自己决定何时发帖、给谁点赞、关注谁、跟谁吵架，而不是按脚本定时发模板；
- **行为有涌现性（emergence）**：单个 Agent 的规则很简单，但群体互动会冒出没人显式编程过的现象。

学术源头绕不开 Stanford 2023 年的论文 *Generative Agents*（Park et al.）：25 个 Agent 住进虚拟小镇 Smallville，结果它们自发组织了情人节派对、互相传播八卦、还模仿起了竞选人拉票——这就是「AI 社会」第一次让人觉得像真的。

商业侧，Chirper（纯 AI 社交网络）、Butterflies（AI 角色发帖）等产品已经跑了一段时间；36kr 报道的这类公司则更进一步，把模拟环境做成了**可出售的社会实验场**。

## 二、技术拆解：一个「会发帖的居民」是怎么造出来的？

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/57debbd30cb019cc.png)

一个典型的模拟社区居民，由五层结构组成：

1. **Persona prompt**：定义身份。职业、价值观、语言风格，甚至「今天心情不好，说话冲一点」。
2. **Memory stream**：短期上下文之外，长期记忆写入 vector database，按 **recency / importance / relevance** 三个因子加权检索——这是 Stanford 论文的核心机制，决定了 Agent「记得什么、翻谁的旧账」。
3. **Planning & Reflection**：Agent 会定期「反思」，把零散记忆蒸馏成更高层的信念（比如「我觉得降息话题很无聊」），再反向影响后续发帖倾向。
4. **Tool use + 调度器**：发帖、评论、点赞都是 function call；orchestrator 按事件循环推进整个社区的「时间线」。
5. **成本控制**：日常寒暄用小模型，热搜事件、大 V 发言等关键节点才切换大模型。token 开销能压低一个量级——这是这类产品能盈利的工程前提，不是玄学。

补一句历史背景：agent-based modeling（ABM）并不新鲜，1971 年 Schelling 用一个棋盘模型就模拟出了群体隔离现象，NetLogo 也跑了几十年。LLM 的真正贡献，是给每个 Agent 塞进了自然语言的丰富行为——让模拟从「粒子对撞」升级成「有人味儿的街坊」。

## 三、钱从哪来：四种真实付费场景

千万美元收入不是从天上掉的，买单方大概分四类：

- **娱乐与注意力**：纯 AI 社交网络本身就是内容产品。用户围观 AI 互怼、AI 造梗，订阅费、创作者工具、广告位，本质还是注意力生意，只是演员换成了模型。
- **营销预演**：新品上线前，把 5000 个模拟用户分成四组跑 A/B test，看哪句文案能被 Agent 主动转发扩散。传统 focus group 单场报价常在数千到数万美元，模拟实验按 token 计费，成本差 1–2 个数量级，而且能反复改参数重跑。
- **科研与舆情推演**：谣言传播、信息扩散、政策反应这类社会实验，过去受伦理和成本限制很难做，现在可以 in silico 批量跑参数，卖给研究机构和咨询公司。
- **数据与模型服务**：合成数据（synthetic data）用来训练推荐算法和对话模型；Agent 之间的互动日志本身，也是一份可反复出售的数据资产。

注意一个共同点：除娱乐外，其余三类的客户买的都不是「内容」，而是**对真实世界的近似模拟能力**。

## 四、为什么是现在？三股力量叠加

1. **推理成本雪崩**：同等能力水平的模型，每百万 token 的价格两年间跌了一个数量级以上，「养一万个虚拟居民」从烧钱行为变成可控成本。
2. **记忆与检索基建成熟**：vector DB、RAG、长上下文把「千人千面」从玄学变成了工程题。
3. **真人注意力市场见顶**：信息流的增量卷不动了，Dead Internet Theory 那句调侃（互联网大部分内容已是机器生成）反而成了商业叙事——与其在真人海里捞流量，不如自建一个可编程、可复制的社会。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/a0216fcf4e9bdd94.png)

想入场或者只是想理解这门生意，记住三条：

1. **模拟 ≠ 预测**。Agent 的行为分布继承自训练语料的偏差，用来做趋势感知、文案初筛是靠谱的；拿它直接给真实投票率、销量下结论，一定会翻车。正确姿势是：先用小样本真人实验校准，再放大到模拟规模。
2. **算清 unit economics**。长期运行上万个 Agent，API 成本、存储、调度复杂度都是线性往上爬的；如果收入端不能复用（同一套模拟环境卖给多个客户、跑多次实验），很容易做成慈善项目。
3. **合规红线提前踩**。EU AI Act 等法规已经要求 AI 生成内容与机器人身份可识别；拿模拟流量冒充真实用户数据卖给客户，是商业欺诈级别的雷。技术上诚实，这门生意才走得远。

说到底，这门生意的本质，是把「社会」变成一套可运行、可复制、可测量的 API。至于模拟出来的点赞算不算真爱——那是产品经理该失眠的事，工程师只管把 token 账单压下来。
