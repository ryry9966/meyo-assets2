36kr 最近给大模型圈算了笔账：若按一级市场估值折算，DeepSeek 创始人梁文锋的账面身家，可能比 OpenAI 的 Sam Altman 和 Anthropic 的 Dario Amodei 加起来还多。听起来反常识——毕竟前两位常年占据 AI 新闻头条，一个统领 ChatGPT，一个掌管最被看好的“OpenAI 挑战者”。但这笔账背后，藏着一套很有意思的工程与商业逻辑。今天把它拆开看看：钱从哪来、算力怎么攒、“隐形”二字意味着什么。

## 一笔“账面首富”是怎么算出来的

先看三个人的“资产结构”，差异比想象中大得多：

- **Sam Altman**：OpenAI 采用“非营利母体 + capped-profit（利润上限）”结构，据多方报道，他本人不持有 OpenAI 股份。其公开财富主要来自 YC 时期股权、Reddit、Helion 等早期投资，外界估算在 10~20 亿美元量级。
- **Dario Amodei**：Anthropic 是私有公司，2025 年 3 月融资后估值约 615 亿美元，但联创个人持股通常只有个位数百分比，折算下来同样是“十亿美元”级。
- **梁文锋**：DeepSeek 2023 年由幻方体系孵化成立，据公开工商信息与 36kr 拆解，梁通过宁波程信、宁波程恩等持股平台合计控制约 84% 权益，且官方确认从未接受外部融资。

于是推演开始：哪怕只给 DeepSeek 一个 Anthropic 一半量级的估值，乘上 84% 的权益，账面数字也远超前两者之和。必须强调，这是“纸面推演”——没有融资轮次，就没有经过市场检验的公允价格。但方向是明确的：**不稀释股权，本身就是一种财富策略。**

## 从量化交易到万卡集群：钱和算力是怎么攒出来的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/b7ea67c39dd35a6b.png)

梁文锋的起点不是大厂，而是量化交易：

1. 2008 年金融危机期间，还在浙大读研的他就带队用机器学习做股价预测；
2. 2015 年创立幻方量化，靠 AI 驱动的量化策略做到国内头部，管理规模一度突破千亿人民币；
3. 2019 年自建 AI 超算“萤火一号”；2021 年投入约 10 亿元建成“萤火二号”，搭载 1 万张 A100——那时大模型热还没开始；
4. 2023 年成立 DeepSeek；2024 年底 V3 用 2048 张 H800、278.8 万 GPU 小时完成训练，官方口径成本约 557.6 万美元（不含前期研究与失败实验）；2025 年 1 月 R1 发布并按 MIT 协议开源，App 登顶美区 App Store 免费榜，随后英伟达股价单日下跌约 17%，市值蒸发近 5890 亿美元，创下美股历史纪录。

这里有条容易被忽略的因果链：量化基金赚到的现金流 → 提前囤积的 GPU → 大模型时代来临时的算力现货。别人在融资买卡时，幻方机房里已经躺着上万张卡。别人囤房，他们囤卡——而且囤的是生产资料。这本质上是一场持续十年的“资产前置”：先囤工具，再等风口，而不是风口来了才开始攒钱。

## 工程降本的“抠”：成本不是省出来的，是设计出来的

H800 是 A100 的“阉割版”，互连带宽被大幅削减。按理说是绝境，DeepSeek 却把它逼成了架构创新的催化剂：

- **MLA（Multi-head Latent Attention）**：把推理时的 KV Cache 压缩九成以上，显存和推理成本直接降一个量级；
- **细粒度 MoE + 无辅助损失的负载均衡**：每个 token 只激活一小部分专家，用 bias 调节代替辅助损失来均衡负载，训练更稳也更省；
- **FP8 混合精度 + DualPipe 流水线并行**：计算与跨节点通信几乎完全重叠，把“带宽被砍”的损失磨平；
- **GRPO**：做强化学习时砍掉 PPO 里的价值网络，用组内相对奖励当 baseline，等于少养一整个大模型。

对比更直观：GPT-4 级别模型的训练成本，公开说法普遍在 1 亿美元上下；V3 的 557.6 万美元虽然口径偏窄，但数量级差异是真实的。所以当 V2 把 API 输入价格打到“1 元/百万 tokens”时，业内叫它“AI 界拼多多”——那不是低价倾销，是成本曲线真的低。

## 不融资、不路演、只开源：一套反常识的商业操作系统

DeepSeek 的“隐形”，一半是股权结构造成的，另一半是主动选择：

1. **不融资**：没有 VC，就没有披露义务、没有对赌、没有上市倒计时，节奏完全自己定；
2. **只开源核心**：R1 按 MIT 协议放出权重，把“复制门槛”降到零，换来开发者生态和事实标准的位置——随后大量产品接入其蒸馏模型；
3. **API 卖推理**：权重免费、服务收费，用 MLA 压出来的低推理成本赚钱，是教科书级的开源商业模式；
4. **组织极简**：核心成员多为本土应届或毕业一两年的年轻人，研究自下而上立项，没有层层加码的 KPI。

梁文锋在 2023 年接受《暗涌》采访时说过一句流传很广的话：中国 AI 不可能永远处于跟随的位置。开源不是情怀，是他选定的竞争位。

## 冷思考：账面首富 ≠ 现金首富

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-21/0654e1e7600f78c7.png)

最后给三条带走就能用的思考：

1. **估值 ≠ 存折**。DeepSeek 没有融资轮次，“千亿估值”只是参照系。评估任何公司或机会时，先问钱从哪来、能不能落袋，账面数字永远排第二；Altman 不持股却握有生态影响力，影响力同样是资产。
2. **生产资料要前置囤**。梁文锋真正押对的是“算力会升值”这个判断。映射到个人：你所在领域的"GPU"是什么——数据、作品集、稀缺技能？趁便宜的时候多囤一点。
3. **把成本曲线当产品设计**。无论调 API 还是做项目，先算清单位边际成本（每 token、每小时、每人天），然后优化最贵的那个变量——MLA 和 GRPO 的本质，就是找到了各自链条里最贵的一环。

财富的“隐形”，往往是逻辑的显形。
