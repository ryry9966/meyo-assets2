最近，Rabbit 创始人吕骋的一句话被顶上热搜：人不该为 Agent 改变思考方式。说白了就是：如果一个 AI 助手需要你先背口诀、学咒语、把需求掰开揉碎成它爱听的样子才能干活，那问题多半不在你，而在产品设计。这话听着像产品宣言，其实戳中了人机交互领域吵了半个世纪的老问题——到底该人迁就机器，还是机器迁就人？这篇就把这层窗户纸捅开，算一算背后的技术账本，最后给几条普通人的应对姿势。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-05/7c18d99cbfd5d509.png)

## 一、先看现状：用 Agent，你在交一笔“适配税”

理想中的 Agent 是：你说人话，它办成事。现实中的体验往往是这样的：

- 写 prompt 像填表：角色设定、背景资料、输出格式、禁忌事项，缺一项结果就跑偏；
- 同一个意图换个措辞，输出质量天差地别，用着用着你就开始“猜机器爱听什么”；
- 复杂任务得手动拆步骤，还得盯着它执行、随时纠偏——体验类似带一个聪明但记性不好的实习生：话要说全，锅还得你背；
- 记忆、权限、工具开关，样样要自己配置。

业内把这叫 intent gap（意图鸿沟）：用户脑中的目标，和机器能执行的指令之间，存在一层翻译损耗。这层翻译工作本该由产品承担，现在被外包给了用户。吕骋那句话的矛头，指向的就是这笔隐性税。2023 年“提示词工程”一度被捧成新职业，某种意义上，正是这笔税被制度化的标志。

## 二、历史在押韵：谁迁就谁，吵了五十年

这不是新问题。回看几十年的人机交互史，每一次范式转移，本质都是在重新分配“翻译成本”：

- 命令行时代：人学机器的语法。命令、参数、大小写，错一个字符就报错，学习曲线陡峭；
- 1970 年代施乐 PARC 到 1984 年 Macintosh：图形界面把“直接操纵”（direct manipulation）变成主流理念，人机交互第一次明确写下“机器适应人”这个方向；
- 搜索引擎是个耐人寻味的反例：我们主动放弃说完整句子，学会了敲关键词。因为快、便宜、结果可预测，这笔适配税交得心甘情愿；
- 语音助手卡在中间：宣传里是自然语言，实操中你得说“暗号”才能稳定触发功能，换个说法它就装傻。

规律很清楚：人迁就机器，学习昂贵但运行便宜；机器迁就人，学习近零但运行昂贵。范式往哪边倒，从来不是价值观问题，而是当时工程能力与成本结构的产物。

## 三、那 Agent 为什么还做不到“完全迁就人”？三座大山

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-05/d5758e8818beca45.png)

- 歧义性：自然语言是高熵输入。“帮我订个餐厅”，没说时间、人数、预算——系统要么追问，要么硬猜，猜错就是真金白银的事故；
- 可靠性：自动化领域有条经典悖论——系统接管得越顺手，人越放松警惕。Agent 执行的是发邮件、下单、改文档这类真实操作，演示时 90 分和日常 99.9% 可用之间，隔着一条鸿沟；
- 状态缺失：LLM 本身没有长期记忆，Agent 得靠外挂上下文、工具调用、权限管理来补课，每多一分自由度，就多一分出错面。

所以“迁就”不是设计者傲慢，而是成本转嫁：让机器适应人，贵不在生成，而在验证。用户多写一句 prompt，机器就少猜一次；用户多拆一步，系统就少错一步。Rabbit 自己的 R1 也印证了这点——官方口径首销数月售出约十万台，但媒体实测暴露过响应慢、执行不稳的问题。愿景很性感，账单很诚实。

## 四、吕骋在赌什么：把适配从用户侧挪到机器侧

理解了成本结构，就知道这句话不是情怀，而是一场技术下注：

- Rabbit 的路线是 LAM（Large Action Model）加 teach mode：用户演示一遍操作，机器学会，之后直接说人话下指令——把学习成本从用户搬进模型；
- 学界对应的方向叫 learning from demonstration，是机器人学的老课题；协议层的 function calling、MCP，也在把适配工作从用户界面下沉到基础设施；
- 换成一张简化的对比：人迁就机器，上手贵、运行便宜、结果可预测；机器迁就人，上手近零、运行贵、结果概率性。产品能否成立，取决于你的用户更痛恨“学习”，还是更痛恨“验证”。

话说回来，愿景声明和已交付的现实之间，往往隔着几个版本迭代。这句话真正的价值，是把判断标准摆上了桌：衡量一个 Agent 好不好，别看演示有多惊艳，先看它替你消化了多少翻译工作。

## 五、给普通人的三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-05/ef8f36be2f29bcfe.png)

1. 别当“提示词民工”，当带实习生的人。交代清楚目标、约束、验收标准这三件套，是通用管理能力，换任何工具都不贬值；背口诀式的技巧才会过期。
2. 把验证成本当回事。Agent 越自动，越要主动设抽查点：关键操作要求确认，重要产出人工复核。全自动且静默失败的工具，比笨但可预测的工具危险得多。
3. 选产品看“首次成功率”，不看 demo 观感。一个逼你背术语的产品，和一个会主动追问澄清的产品，后者才真的在朝“机器迁就人”走。

一句话收尾：语言可以自然，代价不会消失，只会转移。好的 Agent，是把这笔账从你的脑子里，挪到它的算力里。
