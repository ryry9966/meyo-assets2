过去十年，BI（Business Intelligence，商业智能）大概是被"唱衰"次数最多的企业软件品类：先有人说"Excel 就够了"，后又有"仪表盘已死"的论断满天飞。但最近行业里出现了一个反直觉的判断——BI 真正的生意才刚开始。这不是给老行业打气，而是三股力量同时到位后的自然结果：数据基础设施成熟了、大模型改变了交互方式、商业模式开始重写。这篇文章拆解三件事：过去为什么尴尬、转折为什么发生在现在、接下来钱怎么赚。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-05/9d50029fbf8f18bc.png)

## 一、前传：一门"叫好不叫座"的生意

先补一点背景。BI 这个词由 Gartner 分析师 Howard Dresner 在上世纪 90 年代推广开来，第一代产品是 SAP BO、Cognos、MicroStrategy 这类重型报表平台，服务对象是 IT 部门；2010 年代 Tableau、Power BI 掀起自助式分析浪潮，业务分析师终于可以自己拖拽出图。工具越来越顺，但这门生意的账一直不好看：

1. **使用率长期偏低**。行业里反复被引用的观察是：大型企业中定期打开 BI 工具的员工常年只有两三成，大量看板建成当天即是访问量巅峰，随后进入"看板坟场"。
2. **人力瓶颈卡死产能**。数据分析师 70% 以上的时间花在找数、洗数、对口径上，真正产生洞察的时间被挤压；业务周一提需求，图表下周才到，黄花菜都凉了。
3. **洞察与行动断层**。看板回答"发生了什么"，但"为什么发生、下一步怎么办"仍靠人肉补课——软件只卖了个开头，最贵的后半段留给了人力。
4. **商业模式天花板明显**。按席位收费，而席位只覆盖少数分析师，收入随人涨不动。于是行业走向整合：Salesforce 以约 157 亿美元收购 Tableau，Google 以约 26 亿美元买下 Looker，一度被解读为"这生意到头了"。

Gartner 在 2019 年其实给过一个预言："到 2021 年，增强分析（augmented analytics）将成为 BI 与数据分析平台新增采购的主导驱动力。"当时听像愿景，现在看像剧本。

## 二、转折点：AI 拆掉的不是界面，而是人力瓶颈

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-05/b7d804732b7817cf.png)

很多人把这一轮变化理解为"加了个聊天框"，那是低估了。真正被拆掉的是 BI 二十多年的死结——**会分析的人不够用**。三个层面同时起作用：

1. **交互层：NL2SQL 把门槛从"会用工具"降到"会说话"**。大模型让业务人员用自然语言直接问数："上周华东区 GMV 为什么下滑？"潜在用户从全公司的 10% 变成 100%，市场分母直接放大一个数量级。
2. **分析层：从问答到 agentic analytics**。AI agent 能做多步推理——拆解问题、取数、建立假设、交叉验证、产出结论和图表。BI 第一次从"描述过去"走向"回答为什么、建议下一步"。
3. **基础设施层：AI 终于有了干净的操场**。云数仓（Snowflake、BigQuery、Databricks）+ 建模工具（dbt）+ 语义层（semantic layer）的普及，让指标口径统一、查询成本下降。没有这一层，大模型只会把垃圾结论生成得更快。

一句话总结机制：**BI 过去卖不动，不是图表不好看，而是服务对象的"分母"太小；大模型把分母变成了全体员工，同时把"分析师的时间"从瓶颈变成了杠杆。**

## 三、生意怎么变：从卖座位，到卖决策

1. **计价方式重写**：按席位 → 按查询量、按洞察、甚至按"被采纳并执行的分析"收费。软件价值第一次有机会和业务结果直接挂钩。
2. **纵深化**：通用 BI 很难差异化，但"懂零售补货逻辑"或"懂制造业良率归因"的行业 agent，壁垒在领域知识 + 指标体系，不在渲染图表的像素。
3. **从"报给人看"到"报给机器执行"**：headless BI 是个值得盯的方向——语义层直接驱动自动补货、动态定价、预算调拨。当 BI 成为决策执行链路的一环，而不是一堆静态看板，收入模型就从"工具订阅"升级成"决策基础设施"。
4. **资本已经在投票**：海外 ThoughtSpot、Sigma Computing 等持续获得大额融资；Databricks、Snowflake 把分析能力往自家生态里收。竞争焦点清一色指向 AI-native 分析。

## 四、冷思考：四个最容易踩的坑

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-05/9a56a0df002ea8f6.png)

1. **数据地基决定上限**。大模型会"编数"，而在 BI 场景里，幻觉是零容忍事故——错一个数，业务就用脚投票。没有统一指标口径和高质量数仓，AI BI 只是更快地生产错误结论。
2. **自然语言 ≠ 可信答案**。产品必须保留查询可追溯：能看到底层 SQL、能下钻验证、有数据血缘。否则业务敢拿 AI 的结论去开季度复盘会吗？
3. **成本结构要提前算清**。每次提问都调一次大模型并不便宜，语义缓存、指标预计算这些"无聊工程"恰恰是产品力的一部分。
4. **不是每家公司都需要**。十几个人、三张看板的团队，Excel 依然是最优解。判断标准不是"新不新"，而是：数据量 × 决策频次 × 分析人力缺口。

## 五、写在最后：三条实用建议

1. **给企业**：预算上 AI BI 之前，先做数据地基审计——指标口径统一了吗、数据质量过关吗、语义层建了吗？评估 ROI 用"采用率 × 行动率"，而不是买了几块酷炫大屏。
2. **给从业者**：分析师不会被替代，但角色会上移——从"写 SQL 的人"变成"定义指标、校验结论、编排 agent 的人"。补齐业务域知识，比多学一个可视化工具值钱得多。
3. **给创业者**：别做"第 101 个 dashboard"。差异化在垂直深度、工作流嵌入和结论可信度，图表渲染早就不是战场了。

BI 被唱衰了十年，恰恰说明它的核心矛盾从没被真正解决过。现在矛盾松动了——这门生意的下半场，才刚开灯。
