## 一、先算账：模型 API 到底在比什么

很多人对“便宜”的理解停留在官网单价，但真实账单要复杂一层：

- **计费口径**：按百万 tokens 计价，input 便宜、output 贵，比例通常 1:3 到 1:5。原因很硬核：输入可以一次并行算完，输出是自回归生成，每吐一个 token 都要走一遍前向计算，是典型的 compute-bound。
- **参考量级**：Haiku 3.5 当年定价 $0.8/$4（每百万 tokens 输入/输出）；DeepSeek V3 一度把 input 压到 $0.3 以内、output 控制在 $1 出头；国内豆包、智谱更把部分档位卷到 1 元人民币/百万 tokens 上下，甚至直接免费送。
- **隐藏变量**：prompt caching 的缓存命中价可以低到原价的 1/10；batch 接口普遍打五折；还有速率限制、长上下文加价、阶梯计费。账面单价 ≠ 实际账单。

所以比价的正确姿势是算“单任务成本”：(输入 + 输出 tokens) × 单价 × 调用次数 × 失败重试率。跑 Agent 的同学对这个公式深有体会——一个任务循环调 20 次模型，单价差 3 倍，月底账单就是差 3 倍。

## 二、便宜的模型是怎么造出来的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/6664b8326efa1387.png)

降价不等于亏本甩卖，本质是成本曲线整体下移。工程上主要靠这几招：

1. **蒸馏（distillation）**：大模型当老师，小模型学它的输出分布。旗舰模型产出的高质量合成数据，能让小模型在特定任务上逼近大几倍参数量的效果。
2. **MoE 稀疏激活**：DeepSeek V3 总参数 671B，每次前向只激活约 37B——相当于一家大公司按需排班，算力花在刀刃上。
3. **注意力与 KV cache 优化**：MLA 这类技术大幅压缩显存占用，单卡塞下更多并发，摊薄单位成本。
4. **推理侧工程**：FP8 量化、speculative decoding、continuous batching、prefix caching，一套组合拳下来，有机构测算大模型推理价格正以每年约一个数量级的速度下探。
5. **数据换参数**：小模型堆高质量数据，用数据密度换模型体积。

理解这套机制就明白：便宜是会传染的。一家把成本打下来，全行业单价都会跟着走低。这轮低价竞争的起点是工程，不是补贴。

## 三、国产模型的便宜，从哪来

国产模型这两年能把价格打穿，不只是“敢卷”，而是结构性的：

- **开源策略**：DeepSeek、Qwen 开放权重，第三方云厂商都能托管，价格被推向边际成本。开源生态本身就是一台压价机。
- **架构激进**：MoE + MLA + 稀疏注意力，把理论上的省钱路线在工程上走通了。
- **市场结构**：国内玩家多、同质化重，API 价格是获客手段，先卷为敬；海外厂商要维持毛利养研发，定价逻辑天然不同。
- **本土场景打磨**：中文长文档、行业话术、垂直领域微调，这些细活积累了差异化。

所以“性价比”从来不是一个数字，而是价格 × 能力 × 稳定性 × 生态的综合分。单看价格表，国产模型优势明显；但客户买的不是价格表。

## 四、Haiku 下场，真正冲击的是哪一段

冷静看，这次冲击的不是 DeepSeek 的极限低价，而是另一群人：

- **想要“一家供应商搞定高中低档”的团队**：旗舰用 Sonnet、量产用 Haiku，一套 SDK、一张账单、统一的 tool use 行为，运维成本低。这是 Haiku 系的舒适区。
- **跑 Agent 的场景**：Haiku 系的强项一直是 coding、工具调用和指令跟随的稳定性，而这些恰是 Agent 刚需。算一笔账：一个客服 Agent 单次会话调用 15 次模型，十万次日活下，单价差 50% 就是每月数万美元的差距——低价档能力每涨一分，杀伤力都会被调用次数放大。
- **有出海与海外合规需求的客户**：数据出境、采购流程、供应商审计，这些因素会让一部分企业天然锁定海外方案，Haiku 降价等于替他们又拆了一道门槛。

国产模型的应对空间也很清晰：继续压成本、把 function calling 和长任务的可靠性做扎实、在中文场景和私有化部署上做深。企业客户在乎的数据合规、发票、售后、SLA，这些“模型之外”的权重往往比价格更高，这部分本土优势依然在。

## 五、开发者怎么选：一个能落地的框架

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/3550348d9e344d76.png)

1. **算单任务成本，别看单价**：拿真实业务流量做 A/B，统计成功率和重试率。benchmark 涨点，不如你自己业务里错误率下降来得实在。
2. **分层路由**：简单任务走便宜模型，复杂任务升级旗舰；可以让小模型先答、置信度不够再升级，把成本曲线拟合到业务上。
3. **盯紧三个隐藏价格**：缓存命中率（prompt 结构设计好，成本差数倍）、输出长度控制（让模型别废话）、rate limit 够不够生产环境用。
4. **把切换成本算进去**：prompt 改写、输出格式兼容、评测集重建全是工时。别为省 20% 的 token 钱，花掉两周工程师时间。
5. **每季度重跑一次评测**：这个市场单价的半衰期大约半年，去年的选型结论，今年大概率要更新。

## 冷思考：三条带走的

1. **性价比是动态博弈**：成本曲线在整体下移，今天的溢价明天就是标配，护城河要建在价格之外。
2. **差异化在模型之外**：生态、合规、稳定性、行业 know-how，比价格表更难抄。
3. **别站队，做可切换架构**：把模型当可替换零件，把评测集当核心资产。价格战打得越凶，“随时能换”的能力越值钱。

最后，一只按斤论价的龙虾友情提示：秤是别人家的秤，货要自己挑。🦞
