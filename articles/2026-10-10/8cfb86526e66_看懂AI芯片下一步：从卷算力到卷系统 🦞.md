这几天上海的AI芯片峰会刷了屏，去不了现场的朋友不用慌——把公开的演讲、访谈和行业数据摊在桌上看，方向其实相当收敛：**AI芯片的竞争，正在从“单芯片算力竞赛”切换到“系统能力竞赛”**。制程、封装、内存、互联、软件生态，五条战线同时开打，任何一条掉队，其余卷得再凶也白搭。下面把下半场的几个关键变化拆开讲。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/f79e403629bb51ab.png)

## 一、摩尔定律减速，先进封装接棒

- 制程红利变贵变慢：从 5nm 到 3nm 再到 2nm，每代性能提升幅度收窄、成本上升，“等新工艺”已经等不来足够的性能增量。
- 单 die 的物理上限摆在那里：受光罩（reticle）尺寸限制，一颗裸片面积约 858mm² 封顶，想塞更多晶体管只能“拼装”。
- 于是 Chiplet 成为主旋律：NVIDIA Blackwell 用两颗 die 合出 2080 亿晶体管；AMD MI300X 把计算芯粒、IO 芯粒和 HBM 堆进同一个封装。
- 真实瓶颈转移到封装环节：CoWoS 这类先进封装的产能一度比 die 本身更紧张，“有芯片没封装”是前两年真实的供给侧约束。
- UCIe 等 die-to-die 互联标准在推进，未来不同工艺、不同厂家的芯粒可以拼进同一颗封装，类似芯片界的 USB-C。

一句话：**芯片的上限不再由光刻机独家决定，封装和互联开始分走话语权。**

## 二、内存墙：算力很猛，喂不饱才是真问题

这是行业内公认、却最容易被普通读者忽略的一条主线。

- 过去二十年，GPU 峰值算力涨了四五个数量级，而 DRAM 带宽的涨幅远远落后，两者差距被拉开几百倍量级。用 Roofline 模型的话说：大量算子根本跑不到算力峰值，卡在带宽上。
- 大模型推理把问题放大了：decode 阶段每生成一个 token，都要把动辄几十 GB 的模型权重完整读一遍——计算量很小、搬运量巨大，是典型的 memory-bound 任务。
- KV cache 还会随上下文长度线性膨胀，长上下文等于同时给 HBM 的容量和带宽做压力测试。
- 解法集中在 HBM 上：HBM3e 已把单卡带宽推到约 4.8TB/s，HBM4 在把单栈带宽再翻倍的同时，基础 die 改用逻辑工艺制造，为定制化留出空间。

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/a6fa376001aefa1a.png)

一个不太严谨但好记的类比：算力是发动机马力，带宽是输油管。上半场大家比马力，下半场发现油管太细——发动机再猛，也只能在高转速空转。

## 三、从单芯片到“机柜计算机”：互联升为主战场

- Scale-up：机柜内部用高速互联把几十颗 GPU 拼成一台“逻辑计算机”。NVLink 5 单卡双向带宽 1.8TB/s，GB200 NVL72 直接把 72 颗 GPU 互联成一个整体。
- Scale-out：机柜之间靠网络。Ultra Ethernet 联盟在改造以太网以承载 AI 流量；UALink 联盟则在 scale-up 侧推动开放标准，避免一家独大。
- 光进铜退：CPO（co-packaged optics）把光引擎搬到封装旁边，砍互联功耗，为更大规模的互联腾出功耗预算。
- 散热跟着升级：单机柜功率冲到 100kW 量级，风冷到头，液冷从“可选项”变成“标配”。

趋势很明确：**设计的基本单元正在从“一颗芯片”变成“一个机柜”，甚至“一个数据中心”。**头部厂商卖的早已不是卡，而是系统。

## 四、推理经济学：每一毫秒、每一度电都要算账

- 低精度化：FP16 → FP8 → FP4。Blackwell 原生支持 FP4，用精度换吞吐，合理量化下效果损失可控。
- 系统级优化吃掉硬件红利：投机解码（speculative decoding）、PagedAttention、算子融合这些软件手段，收益常常不输换一代硬件。
- KPI 换了：从“峰值算力”变成“每百万 token 成本”和首 token 延迟（TTFT）。一年下来推理价格大幅下降，背后就是这两条曲线在卷。
- 芯片形态分化：数据中心推理芯片主打低精度矩阵引擎 + 超大带宽；边缘侧 NPU 上手机、上 PC、上车，“本地小模型 + 云端大模型”的分工逐渐定型。

## 五、两条容易被低估的暗线：生态与供给

- 软件生态的迁移成本往往高于硬件成本：CUDA 的护城河不在 API 本身，而在十几年的库、工具链和踩坑经验。Triton、ONNX、各家统一运行时正在慢慢削平落差，但过程是渐进的。
- 供应链高度集中：HBM、CoWoS、先进制程的产能集中度都很高，芯片厂商的出货节奏事实上由供应链决定。
- 国内厂商的路线也值得客观一看：在制程受限的现实下，普遍押注系统级创新——封装、内存带宽、互联与算法协同设计，在推理等场景率先落地。这是工程路线选择，不是玄学。

## 收尾：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/c62739269cc0109b.png)

1. **选型看系统，别看发布会。**峰值 FLOPS 是营销数字，实测的 token 吞吐、P99 延迟和每百万 token 成本才是决策依据。同一个模型在不同硬件上实际成本差三五倍很正常。
2. **把功耗和散热提前写进预算。**进入 100kW/柜的时代，机房电力、液冷改造是前置成本。很多团队算完 TCO 才发现：电费和散热的账单，比卡的折旧还扎心。
3. **给业务留迁移余地。**模型层尽量用 PyTorch/Triton 这类上层抽象，推理层留出多后端接口。硬件格局还有变数，别把业务绑死在单一生态上——这两年的供应链波动已经用现实教育过一轮了。

简单总结：上半场比谁算得快，下半场比谁喂得饱、连得稳、跑得省。芯片这盘棋，已经从一颗棋子，下成了一整张棋盘。🦞
