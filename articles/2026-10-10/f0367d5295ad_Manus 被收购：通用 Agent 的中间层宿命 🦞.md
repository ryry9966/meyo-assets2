2025 年 3 月，Manus 一夜爆红：邀请码在二手平台被炒到数万元，服务器被挤爆，朋友圈里人人都在转发"AI 替你干活"的演示视频。9 个月后，剧情走向了另一个方向——据多家媒体报道，Meta 以约 20 亿美元将其收入囊中（官方口径为"多数股权投资"），团队并入，产品继续运营。从顶流到被并购只用了不到一年。这不是 Manus 一家的故事，而是"模型之上创业"这个物种的通用剧本。这篇文章拆三件事：Manus 为什么红、为什么难、为什么大概率逃不出巨头的掌心。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/5c10df6c8a0d58d8.png)

## 一、爆红剧本：GAIA 榜单、邀请码与"数字打工人"

Manus 的产品逻辑一句话能讲清：你给目标，它自己拆任务、开浏览器、写代码、处理文件，最后交付结果。它背后的蝴蝶效应团队此前做过 Monica 浏览器助手，对 C 端流量并不陌生。2025 年 3 月发布时，几个因素叠成了完美风暴：

- **基准背书**：官方宣布在 GAIA（General AI Assistants benchmark）上取得 SOTA。有意思的是，GAIA 这个基准正是 Meta AI 与 Hugging Face 的研究者提出的，专门衡量通用助手完成真实任务的能力——后来 Meta 收 Manus，多少有点"自己许的愿自己来圆"的意味。
- **饥饿营销**：邀请码制 + 内测资格，稀缺性本身就是传播素材。
- **演示震撼**：筛简历、做报告这类"看着像真人在干活"的视频，天然适合社交媒体裂变。当然，Agent 界通病是预告片效应——演示是预告片，实测是正片，正片往往没有预告片好看。
- **情绪价值**：打工人对"数字分身"的想象，让 Manus 承担了远超产品本身的叙事重量。

热度退去后，实测落差、任务成功率、推理成本陆续被讨论。但 Manus 至少验证了一件事：大众市场对"能交付结果的 Agent"有真实且巨大的需求——这一点连质疑者也不否认。

## 二、夹缝里的中间层：结构性的三面挤压

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/4b7e7784b01b3ac1.png)

问题不在产品，在生态位。把 AI 产业竖着切一刀，大致是三层结构：

1. **模型层**：OpenAI、Anthropic、Google，掌握基础模型与算力，是整个生态的"地质运动"发源地。
2. **编排层**：Manus 所在的位置——把模型、浏览器、代码执行、工具调用串起来，做成端到端体验。
3. **应用层**：扎进具体行业场景的软件，靠垂直数据、合规和交付闭环吃饭。

编排层被夹在正中间，挤压来自三个方向：

- **能力下沉**：模型厂商把 Agent 能力做成原生功能。OpenAI 从 Operator、Deep Research 一路做到 ChatGPT Agent；Anthropic 有 computer use 和 Claude Code；Google 有 Project Mariner。你精心调了几个月的编排逻辑，上游一次版本更新就能覆盖大半。
- **护城河是租的**：编排层的核心资产——prompt 工程、任务规划、工具链整合——全部建立在别人的模型 API 之上。用工程师的话说：护城河是租来的，房东随时可以自己装修。
- **成本结构倒挂**：多步 Agent 的 token 消耗是普通对话的几十倍，有分析测算 Manus 早期单个复杂任务的成本在几美元量级。订阅制收入很难覆盖"用户每点一次火，烧的都是真金白银"的模式。

三面挤压的终点只有一条路：要么往深里做（自研模型），要么往宽里做（生态+数据），要么——被一个有算力、有分发、有资金的巨头收编。

## 三、巨头的游戏：AI 创业反复上演的三种结局

创业公司的出口传统上是三条：IPO、独立长大、被并购。对 AI 公司来说，前两条的门槛被算力成本抬到了天上：

- **IPO**：需要稳定盈利和独立估值逻辑，而全行业目前大多还在烧钱换规模。
- **独立长大**：意味着自研模型 + 自建算力 + 自建分发。头部公司每年的 capex 以百亿美元计，后来者基本没有上桌资格。
- **被并购 / 人才收编**：近年最拥挤的出口。2024 年 Inflection 团队并入微软、Character.AI 以约 27 亿美元"授权 + 人才"的方式与谷歌绑定、Adept 团队进亚马逊；2025 年 Meta 先以约 143 亿美元拿下 Scale AI 近半股权，年底再收 Manus——打法一以贯之。

对巨头来说这买卖划算：约 20 亿美元买到一个被市场验证过的 Agent 产品、一支完整跑通过端到端任务的团队，远比内部从零孵化快。Meta AI 缺的恰恰是"帮你把事办了"的执行能力，而 GAIA 这个靶子本来就是 Meta 研究者立的。

对创业者和投资人来说，被收购并不丢人，它甚至是中间层这个生态位上最理性的退出设计。只是"改变世界"的叙事，让位给了"进入体系"的现实。

## 四、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/be3b1f38f80ad788.png)

1. **在模型之上创业，先问"上游愿不愿意做、能不能做快"。** 垂直行业的私有数据、合规要求、交付闭环、线下环节，是模型厂商短期不想碰的硬骨头，也是编排层与应用层仅存的高地。选场景时，先画一张"上游能力地图"，再决定往哪站。
2. **把"编排经验"当能力，别当资产。** Prompt、工作流、工具链都会过期，但任务拆解、成本优化、失败重试这套工程方法论可以迁移。对个人从业者同理：追着热点工具跑，不如沉淀可复用的方法论。
3. **对产品热度保持"三个月回看"的习惯。** 邀请码炒到五位数的产品，三个月后看三件事：留存还剩多少、成本能否打平、上游有没有"顺便做掉它"。这三个问题的答案，比热搜更能预测结局。

Manus 没能逃出巨头的游戏，但也很难说它输了——20 亿美元和一张巨头牌桌的门票，是很多团队求之不得的结局。真正值得记住的是这个生态的规则：模型层赢家通吃，离模型越近，就越活在别人的地质运动里。创业如此，个人职业选择，其实也一样。
