上海这场峰会把"AI芯片的下一步"又顶上了热搜。台上的 PPT 我替你翻不了，但行业的技术主线是公开的、也是相当收敛的。这篇不背概念名词，直接拆五个已经确认的方向：为什么是这个方向、跟去年比变了什么、对选型和投入意味着什么。一口虾肉一句干货，放心食用。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/c7e3b1d6c8e1ad6b.png)

## 一、先看大盘：瓶颈从"晶体管"挪到了"系统"

- **需求侧**：主流实验室的训练算力需求大约每年增长 4~10 倍（Epoch AI 的统计口径）；推理侧随着 Agent 和多模态应用上线，token 产量也在指数级攀升。
- **供给侧**：先进制程从两年一档拖到三年开外，单 die 晶体管密度的红利见顶，单纯堆频率又撞上功耗墙。
- 结果是三条硬约束浮出水面：**数据搬运速度、功耗与散热、互联规模**。

一句话总结：AI 芯片的竞争，已经从"制程竞赛"升级成"系统工程竞赛"。

## 二、封装与 Chiplet：从"整块雕"到"拼乐高"

- 把单颗 die 做大的经济学崩了：die 面积翻一倍，良率掉得比这更狠，成本立刻失控。行业答案是 **Chiplet**——把大芯片切成小 die，再在封装层拼回来。
- 代表作是英伟达 Blackwell：两颗计算 die 通过台积电 CoWoS-L 封装"合体"成一颗逻辑 GPU；HBM 则用 TSV 技术把 8~12 层 DRAM 像盖楼一样垂直堆叠，直接贴在计算 die 旁边。
- 当前全行业的紧瓶颈不在光刻机，而在**先进封装产能**：台积电 CoWoS 翻着倍扩产，订单照样排满。
- 启示：评估一家芯片公司，先问它的封装伙伴和 HBM 供应锁定了多少——参数表可以美颜，产能不能。

## 三、内存墙：推理时代，带宽比峰值算力值钱

- 用 Roofline 模型看：当负载的"算术强度"低于机器平衡点时，算力单元大部分时间在空转等数据。
- 大模型解码是逐 token 生成的：每吐一个 token，都要把几百 GB 的权重从显存过一遍，再叠加随上下文长度线性膨胀的 KV Cache——典型的 **memory-bound** 场景。
- 于是 HBM 成了主战场：带宽从 H100 的 3.35TB/s，到 H200 的 4.8TB/s，再到 B200 的 8TB/s；单卡容量从 80GB 卷到 192GB。
- 落到实践：长上下文和 Agent 负载下，**显存容量 + 带宽**几乎决定一切，看"每百万 token 成本"比看峰值 TFLOPS 靠谱得多。

## 四、精度下探与专用化：FP8、FP4 和 ASIC 大军

- 精度每下探一位（FP16→FP8→FP4），大约省一半的存储、带宽和功耗。训练端 FP8 已经普及，FP4 正在推理侧落地。
- 架构配合：MoE 让"每次激活的参数"远小于"总参数"（671B 总量、单次激活 37B 量级的模型已是现实），芯片必须为稀疏计算和专家并行做专门设计。
- 云厂商自研 ASIC 成建制推进：TPU、Trainium、Maia、MTIA——目标不是跑分超越旗舰 GPU，而是在自家负载上把单位 token 成本打下来。
- 另一条激进路线用超大 SRAM 换掉 HBM 访存（代表如 Groq 的 LPU），拿确定性时序换极低延迟。路线之争远未收敛，别急着站队。

## 五、机柜即计算机：互联与功耗的双重天花板

- **Scale-up**：NVL72 这类方案把 72 颗 GPU 用高速背板连成"一台逻辑机器"，单机柜功率直奔 120kW。比较单位从"一颗芯片"变成"一个机柜的 token 产量"。
- 开放生态在追赶：UALink、Ultra Ethernet 正在重新划分"机柜内高速互联、机柜外以太网"的边界，给非 NV 阵营留出组合空间。
- 铜线传不远是物理规律，scale-up 半径见顶后，**共封装光学（CPO）**开始从论文走向机柜。
- 功耗成了第一约束：风冷到顶，液冷从可选项变成必选项；数据中心选址逻辑变成电价、供电容量、散热三件套；新 KPI 是每 token 能耗（J/token）和集群有效利用率。

## 六、冷思考：给三类读者的三条建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/46ae35440b884324.png)

1. **选型/采购的同学**：把 $/M tokens（每百万 token 成本）和实测吞吐当标尺，同时盯死显存容量与带宽——它们才是长上下文时代的第一瓶颈，峰值算力反而不是。
2. **工程/架构的同学**：把业务代码压在 PyTorch、Triton、vLLM 这类抽象层上，给多硬件后端留逃生门。芯片一两年换代一次，软件栈的迁移成本才是长期套在你手上的锁。
3. **观察/研究的朋友**：别只盯算力参数表，真正的增量藏在"隐性供应链"——先进封装产能、HBM 供应、互联标准与散热供电。谁卡住产能，谁掌握定价权。

方向收敛得很清楚：芯片会越来越像一座被精确定义的建筑，而不是一块越雕越大的石头。今天的虾黄就舀到这里，评论区聊聊你更看好哪条技术路线。
