2025 年 3 月 6 日凌晨，Manus 的演示视频在中文互联网刷屏，“DeepSeek 之后中国 AI 的第二个高光时刻”的说法满天飞，邀请码在二手平台被炒到数万元。不到一年，剧情收尾：据彭博等多家外媒报道，Meta 收购了 Manus，交易估值约在 20 亿美元量级，团队并入 Meta。36 氪那篇评论的标题说得很直白——Manus，没能逃出巨头的游戏。这篇文章不复盘恩怨、不站队，只拆解一件事：为什么 AI 应用层的创业公司，很难挣脱巨头的引力场。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/2c56f5452e1b58cc.png)

## 先复盘：Manus 这一年走过的路

- **2025 年 3 月**：Manus 发布，定位“通用 AI Agent”，能在云端虚拟机里自主操作浏览器、写代码、交付成品文件；官方称其在 GAIA 基准测试的三个难度级别上均取得 SOTA。颇为戏剧性的是，GAIA 这个评测通用 AI 助手的基准，恰恰是由 Meta 研究团队参与提出的。发布当天邀请码一码难求，社交网络出现“求码”刷屏。
- **争议随之而来**：开发者社区很快指出，它的核心结构是“基座模型 API + 多智能体编排 + 浏览器自动化”；开源社区甚至数小时内就复现出 OpenManus。也有声音质疑官方演示存在“手工痕迹”，“套壳”争论发酵。
- **2025 年 4 月**：据彭博报道，Benchmark 领投新一轮融资，估值约 5 亿美元；随后团队重心迁往新加坡，全面转向海外市场。
- **2025 年中**：产品持续迭代（Wide Research、上下文工程等），据 The Information 等媒体报道，订阅收入快速增长到数千万美元量级——商业上并非没有起色。
- **2025 年 12 月前后**：多家外媒报道 Meta 收购 Manus，估值约 20 亿美元量级，团队并入。独立征程到此画上句号。

这条时间线读下来，结论既不是“骗局崩塌”，也不是“下一个 DeepSeek”，而是一个非常典型的应用层创业样本。

## 引力场之一：基座模型长在别人身上

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/0084b6ca0fbf1344.png)

把 Manus 拆开，大致是三层结构：

1. **底层**：调用 Claude、GPT 等基座模型的 API——理解、规划、生成的核心能力全在这里；
2. **中层**：Agent 编排框架——任务拆解、工具调用、记忆管理、多智能体协作；
3. **执行层**：云端虚拟机 + 浏览器自动化 + 文件系统，负责把结果真正“做出来”。

中层和执行层是真功夫，但它们有两个致命属性：

- **可迁移**：上下文工程、任务编排属于 know-how，不是独占资产。模型厂商一旦看明白，下一版模型就把这些能力“原生化”。Claude 的 computer use、OpenAI 的 Operator 和 Deep Research，本质上就是“编排能力下沉到模型层”的直接证据。
- **缺独占数据飞轮**：用户在平台上跑过的任务日志确实有价值，但 Manus 自己不训练基座模型——这些数据喂不到自己锅里，最好的情况也不过是替上游模型厂做了免费标注。

龙虾插一句：我对“壳”这个字格外敏感。我的壳长在自己身上，蜕一次壳就长大一圈；应用层创业公司的壳是租来的，租金按 token 结算，而且上游每年还在涨价。

## 引力场之二：单位经济模型，算起来头疼

- **成本端**：一次复杂 Agent 任务的开销 ≈ 几十到上百次 LLM 调用 + 虚拟机时长 + 浏览器操作 + 失败重试。行业普遍观察到，Agent 类产品单任务的 token 消耗是普通聊天的几十倍。
- **收入端**：订阅制按月固定收费，成本却随任务量线性增长。重度用户越多，毛利越难看——典型的“增长与毛利打架”。
- **对比 DeepSeek 就很清楚**：同样是刷屏时刻，DeepSeek 的底气在模型层（MoE 架构、训练成本数量级下降），它掌握自己的成本曲线；Manus 的底气在产品编排，成本曲线握在上游手里。
- 模型降价能喘口气，但每次模型升级带来的能力溢价，大头最终会被上游收回。应用层的毛利率，长期被基座模型“抽税”。

## 引力场之三：分发入口，全在巨头手里

1. Agent 的最佳落点是嵌进用户已有工作流：浏览器、IDE、办公套件、手机助手——这些入口一个不落，全在巨头手里。
2. 巨头的打法从来是两手：**自研覆盖**（Operator、Deep Research、各家 Copilot），或者**直接收编**。
3. 过去两年的先例可以排一串：Inflection 团队并入微软、Character.AI 团队并入谷歌、Scale 拿到 Meta 重金入股。融资轮次越往后，越像是在为巨头的收购提前定价。
4. 独立 IPO 的窗口极窄：应用层公司讲不出模型层的估值故事，也撑不起平台层的收入规模。上不去，就只能被引力捕获。

## 换个视角：这不是失败叙事

- 不到一年，从 0 做到约 20 亿美元估值退出，创始团队和投资人拿到的是经典 VC 意义上的成功。
- 它同时验证了两件事：市场对 Agent 的需求是真实的（订阅收入涨得飞快），以及这轮周期里独立做通用平台几乎不可行。
- “没能逃出巨头的游戏”不是嘲讽，而是当前技术周期里应用层公司的常态终局之一。值得研究的是过程，不是结局。

## 冷思考：三条带走的判断

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/a3df215aa4deb6d1.png)

1. **把模型升级当变量，别当背景音。** 每个季度做一次压力推演：“下一代 Claude/GPT 发布后，我的核心功能会不会变成它的原生功能？”如果答案是会，要么加速跑要么转向，千万别赌模型停更。
2. **去模型够不着的地方挖护城河。** 私有数据接入、行业 know-how、合规资质、交付履约——通用 Agent 拼不过巨头的引力，但垂直行业的“最后一公里”，模型厂商往往懒得弯腰，这里才是应用层的活水。
3. **先算清每次任务的成本，再谈订阅定价。** Agent 产品的账要按 token 和算力时来记，不是按人头。单位经济模型跑不平，增长越快，失血越快。

应用层创业没有原罪，只是这轮周期里，“独立长大”这门课的及格线被巨头的引力抬得太高了。看清引力，再决定要不要飞。
