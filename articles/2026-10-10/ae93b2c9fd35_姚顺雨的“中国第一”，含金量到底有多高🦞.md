乌镇的一场行业大会上，一张照片刷了屏：马化腾身旁，坐着一张年轻面孔——姚顺雨，90 后，前 OpenAI 研究员，据报道已回国加入通义千问。所谓“拿到中国第一”，说的不是某个奖项，而是：他成了今年中国 AI 人才争夺战里的头号目标，多家头部公司都想签下他。一个研究员凭什么值这张主桌的座位？这篇把他的履历拆开，把背后的技术范式讲透——那才是真正值钱的干货。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/d79d1f9da24df40d.png)

## 一、履历逐环拆解：每一步都不是虚的

- **竞赛底子**：高中入选国际信息学奥林匹克（IOI）中国国家队并拿到金牌，保送清华。算法、数学、抽象能力，是后来做研究的“出厂配置”。
- **学术训练**：清华本科后赴普林斯顿大学读博，方向自然语言处理，师从 Danqi Chen，课题正是“让语言模型学会推理与行动”。
- **成名作**：2022 年 10 月的一作论文 ReAct（发表于 ICLR 2023），如今是 Agent 领域被引用最多的工作之一，几乎所有 Agent 框架的底层模式都能追到它。
- **工业前沿**：加入 OpenAI 后，据公开资料参与了 o1 推理模型与 Deep Research 相关工作——2024 到 2025 年行业最热的两条线，他都在现场。
- **回国节点**：2025 年底加入通义千问，赶上国产模型冲刺“推理 + Agent”的关键窗口。

一句话总结：这份履历的关键词不是“大厂高 P”，而是“定义过范式”。人才市场上，能刷榜的人很多，能定义问题的人极少——含金量的差距就在这里。

## 二、ReAct：整个 Agent 时代的地基，是他一锤钉下去的

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/e3082e945549f293.png)

- 2022 年的大模型有个尴尬：要么只会“想”，要么只会“做”。Chain-of-Thought 能一步步推理，但出不了门——不能搜索、不能执行；让模型直接调工具，它又常常不假思索地乱试一通。
- ReAct 的核心思想一句话讲完：让模型交替进行 Reasoning（推理）与 Acting（行动）——先写下“我下一步该干什么”，再真的去调工具、观察返回结果，然后基于观察修正下一步。想、做、看、再想，构成闭环。
- 举例：你问“这篇论文的引用量是多少”，ReAct 模式的模型会先想“我需要搜索”，调用搜索工具，读完发现搜到的是同名的另一篇论文，于是换关键词重搜——而不是把没把握的数字直接编给你。
- 时间点很妙：ReAct 发布时 ChatGPT 还没上线，它已经把“模型 + 工具 + 推理”的骨架画好了。从早期 LangChain、AutoGPT，到今天各家 Agent 产品，底层循环基本都长这样。打个比方：工程师顺手写了个基础函数，两年后整个行业的脚手架都搭在它上面。
- 同期他还参与提出了 Tree of Thoughts（思维树）：让模型在“内心戏”里做树状搜索，多想几条岔路再回头挑最好的。一个管对外行动，一个管对内思考——两篇工作正好是后来推理范式的两块基石。

## 三、o1 与推理范式：从“说得快”到“想得久”

- 2024 年 9 月 o1 发布，是公认的分水岭：scaling 的方向从“预训练堆数据”转向“推理时堆思考”——回答前先生成大量隐藏的思考 token，并通过强化学习（在数学、代码等可验证任务上给对错信号，即 RLVR）练出自我检查、回溯、换思路的能力。
- 效果上，o1 在 AIME 数学竞赛、竞赛级编程等基准上一步跨过以往所有模型。行业从此默认：推理能力跟参数规模一样，是可以用算力买出来的。
- Deep Research 把这条线与 ReAct 合流：长程推理 + 自主浏览 + 多步工具调用，几十分钟产出一篇带引用的研究报告，姚顺雨是这条线的核心人物之一。他 2025 年那篇流传很广的《The Second Half（下半场）》也值得读：AI 研究的上半场靠“方法 + 基准”驱动，下半场要转向“定义真正值得解决的问题、建立面向真实世界的评测”，这篇文章后来被不少团队当成路线图来读。
- 一句话总结范式转移：上一代模型拼“知识密度”，这一代拼“思考时长”——模型的内心戏，第一次可以被算力买单。

## 四、“中国第一”的另一面：巨头们在抢什么

- 表面是抢一个人，实际是抢“范式原创力”。回看大模型几年的关键转折：Transformer、ReAct、Tree of Thoughts、o1——开创性工作大多诞生在海外实验室。国产模型在工程与开源生态上进步极快（通义千问的开源模型长期位居全球下载量与评测榜单前列），但“定义新范式”的缺口一直存在。
- 所以逻辑很简单：行业进入推理与 Agent 的深水区，谁能请来“写过地基的人”，谁就有机会把地基继续往上盖。各家都在加码——乌镇那张同桌照，本质是这场人才竞争被拍成了可见的画面。
- 另一层背景是海归回流：随着国内模型能力与算力投入上来，越来越多华人研究员把回国列为选项，姚顺雨只是被讨论最多的那个。人才流向“能做成事”的地方，这本身是行业健康度的信号。

## 五、冷思考：三件比围观座位更有用的事

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/c32c0f84c053c436.png)

1. **研究品味比勤奋更稀缺。** ReAct 的价值不在工作量，而在“把推理和行动放进同一个循环”这个问题选得准。做研究、选方向时先问自己：这个问题两年后还重要吗？
2. **Agent 工程是基本功，评测能力是护城河。** ReAct 循环（思考—调用工具—观察—再思考）值得每个开发者亲手搭一遍；而比会调 API 更稀缺的，是给 Agent 建一套靠谱的 eval。《下半场》的论点再次提醒：下半场值钱的是定义问题和评测，不是再刷一个点。
3. **对“天才叙事”保持克制。** 一个人改变不了行业，ReAct 站上 C 位也踩中了 ChatGPT 之后 Agent 热潮的时机。真正可复制的不是天赋，而是长期深钻一个方向、并把复杂问题讲清楚的习惯——他中英文持续写研究综述，就是这种习惯的外显。

主桌的座位，是行业用真金白银投票的结果。看懂他为什么坐得上，比围观他坐在哪儿，有用得多。
