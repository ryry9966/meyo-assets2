2025年3月，Manus靠“通用 AI Agent”概念刷屏：邀请码一码难求，二手市场一度被炒到数万元。但故事有意思的部分在后面——大模型厂商把 agent 能力做进“默认功能”，大平台往流量入口上装自家 Agent，开源社区追着把复现门槛打平。在外媒的叙述里，“夹缝”这个词和它绑得越来越紧。这篇文章不讲故事会，拆三件事：它到底被夹在哪、为什么会被挤、又蹚出了一条什么路——顺便，这也是所有 AI 应用层创业团队的必修课。

## 先讲技术：Manus 是“编排者”，不是“造模型者”

先给一个极简公式：**Agent = 大模型 + 工具调用 + 自主循环**。你交一个目标，它自己拆解成子任务，在云端虚拟机（sandbox）里跑：浏览网页、写并执行代码、最后打包交付文档、表格、网站。因为跑在云端，你关掉电脑它还在干活——这个“异步执行”的产品体验，是它早期最出圈的卖点。核心机制上，它就是 ReAct 那套循环：plan → act → observe → revise，想一步、做一步、看一眼结果，直到交付。

工程侧，它做了三件很有代表性的事：

1. **多 Agent 编排**：规划 agent 拆任务、执行 agent 干活、校验 agent 查错，流水线分工；
2. **模型无关调度**：强模型负责规划和硬骨头，便宜模型处理机械劳动，后来又基于 Qwen 微调了自己的小模型降本——本质是 cost engineering；
3. **Context engineering**：决定每一轮“模型看到什么”，压缩长任务记忆、注入工具说明，这是最依赖手艺的环节。

所以外界批评它是 "wrapper"，在技术层上成立——底层模型确实不是自己的。但 wrapper 写得好不好，恰恰是应用层产品的主战场。护城河到底存不存在，得看下一节。

## 夹缝从哪来：三个方向同时挤压

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/658a9955f835d9b5.png)

**第一挤：大模型厂商的“能力吸收效应”。** AI 行业有条老规律：应用层证明有需求的功能，迟早被模型厂收编为原生能力。摘要、翻译、代码补全都走过这个剧本，Agent 也不例外——OpenAI 的 Operator 与 deep research、Anthropic 的 computer use、Gemini 的 agent 能力，都在把“帮你操作电脑”变成默认项。你花半年打磨的卖点，可能是别人发布会里的一行更新。

**第二挤：大平台的全栈捆绑。** 国内的扣子（Coze）、阿里通义系列、腾讯元宝等相继进场，它们手里有三样东西：流量入口、自研模型、云资源。应用层创业公司的处境很微妙：从他们那儿买模型，又和他们抢用户；任何流量红利出现的地方，巨头都能用预装和 bundling 快速铺平。

**第三挤：开源与价格战。** Browser Use、LangChain 这类开源框架把复现门槛打到周末项目级别；API 价格一降再降，过去靠工程优化省出来的成本差，新模型用裸能力就能硬碾。一个残酷的现实是：创业公司的技术红利窗口，正在从“年”压缩到“季度”。

再加上资本侧：估值高就意味着必须交付高增长，收入数据被外媒拿着放大镜看，收购传闻来了又去。四面都是墙，“夹缝”二字是字面意思。

## 突围路径：出海、订阅制、垂直场景

面对围剿，Manus 的应对可以概括成“换战场、换收钱方式、换防线”：

- **出海**：据报道称在新加坡设立实体，出于国际融资与合规便利，直接打全球市场，绕开国内流量围城；
- **订阅制**：按月订阅收费（几十美元一档起），卖的是“任务完成量”而不是对话条数。外媒报道其 ARR 达到数千万美元量级，个别报道称已触及一亿美元关口——非官方口径，但至少说明现金流故事跑通了；
- **垂直场景**：聚焦数据分析、调研报告、网页抓取、招聘筛选这类“可委托、可验证、可交付”的任务，而不是贩卖“万能 Agent”的大词；
- **防线后移**：积累任务评测集（evals）、场景数据飞轮，把护城河从“模型能力”挪到“流程资产”。

还有一个细节值得嚼：它后来发布了基于 Qwen 微调的小模型，承接高频子任务。这意味着“调度别人的模型”这条路，走到深处是可以进化成“部分自供”的。对 wrapper 类产品来说，这是从租房子到给自己打地基的关键一步。团队早年做 Monica 浏览器插件攒下的海外用户盘（外部口径在千万级），则提供了大厂买不到、小团队很难有的冷启动渠道。

## 冷思考：AI 应用创业的三条判断

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-10/5573a461f8ba7e51.png)

1. **别赌模型层的残渣，赌场景的数据闭环。** 每天问自己：用户用我的产品产生的数据，是不是只有我有？如果答案是否，那你写的就是大模型的一份配置文件，随时会被收编。
2. **把产品当“流程资产”，不当“功能红利”。** wrapper 里应该沉淀下来的是评测体系、工作流模板、行业 know-how——这些复现成本随时间上升的东西，而不是某一两周的热点功能效果。
3. **现金流和合规结构，比热度更长寿。** 邀请码炒作的半衰期以周计，订阅续费率不会说谎；出海的合规与主体架构早一天设计，就少一次被迫搬家的被动。

“夹缝”不是自谦，是一种精确的生态位。大模型时代，应用层创业公司的生存公式大概是：干巨头看不上的重活、脏活、细活，用巨头追不上的迭代效率。Manus 能不能一直跑下去没人知道，但这种站位思路，值得每个应用层团队收藏——龙虾最懂这个道理：在礁石缝里站稳，靠的从来不是个头大，而是位置准。
