每到财报与业绩发布季，银行圈的 AI 叙事就迎来"晒成绩"高峰。今年流行的新指标叫 token 消耗量——"全年大模型消耗 token 数百亿"，科技感拉满。36kr 那篇《银行不能拿 Token 当"遮羞布"》点破了一层窗户纸：token 是成本计量单位，不是价值计量单位。拿流量表当成绩单，是指标体系里最经典的错位。这篇把它拆开讲：token 到底是什么，银行为什么爱晒，以及真正该看的指标长什么样。



## 一、Token 是什么：一张"水电费账单"

- **定义**：大模型并不直接读字，而是先由 tokenizer（分词器）把文本切成最小单元，每个单元就是一个 token。主流 BPE 算法下，1 个英文单词约合 1.3 个 token，1 个汉字约 0.6~2 个 token，具体取决于模型的词表。
- **体感换算**：一份 10 万字的年报约对应十几万 token；一次带检索的问答（RAG）要把用户问题、检索片段、系统提示词全塞进上下文，单次调用吃掉几千到几万 token 很正常。
- **计价方式**：API 服务普遍按"每百万 token"计价，输入便宜、输出贵，不同模型差价可达几十倍。按 token 计费的根本原因，是 token 数量近似对应了模型的计算量。
- **关键性质**：token 本质是资源消耗的"流量表"，如同水电表读数——它只回答"用了多少"，从不回答"干成了什么"。

## 二、银行为什么爱晒 Token：动机其实很诚实

- **价值难量化，成本好统计**。"审批快了几天""投诉降了多少"要建基线、做归因，周期长、口径吵；token 数系统里随手一拉就有，口径清晰，数字还大。
- **叙事竞争的历史惯性**。银行从来都需要"可讲述的技术故事"：早年晒电子渠道替代率，后来晒 OpenAPI 调用量、上云率，如今轮到 token。指标会换代，剧本没换过。
- **安全的模糊**。token 数字既不泄露商业机密，也不招来"投入产出比"的追问——大到唬人，又模糊到难以证伪。加上金融行业对生成式 AI 有备案、数据安全等合规要求，业务收益披露更谨慎，技术指标就更容易被推到台前。
- **Goodhart 定律生效**：当一个指标变成目标，它就不再是好指标。精益创业里管这类数字叫 vanity metrics（虚荣指标）——好看、好晒、不指导决策。token 消耗量像健身房流水：刷卡次数多，不等于练出了腹肌。

## 三、Token ≠ 价值：三重错位

1. **成本项冒充收益项**。算笔账：按主流模型每百万 token 几元到十几元的推理价格，500 亿 token 的直接成本大约几十万到几百万元——对一家年利润数百亿的银行，这是零头。数字震撼，钱包无感。
2. **消耗膨胀 ≠ 产出增加**。长上下文塞料、RAG 检索片段越堆越厚、Agent 循环重试，都能把消耗推高几个量级。有些"增长"其实是浪费甚至 bug——比如智能体陷入死循环空转烧 token，报表上反而"再创新高"。
3. **使用量 ≠ 效果**。客服机器人调用量翻倍，可能恰恰因为一次解决率低，用户被迫反复追问；代码助手 token 烧得多，价值却要看生成代码的采纳率。消耗越大、体验越差的倒挂，并不罕见。



## 四、更诚实的度量：从"流量表"回到"成绩单"

- **效率层**：单笔信贷材料审阅时长、客服平均处理时长（AHT）、节省的人工工时。
- **质量层**：回答准确率、合规审查覆盖率、幻觉率抽检合格率。
- **业务层**：一次解决率（FCR）、审批时效、转化与留存的变化。
- **经济层**：ROI =（节省的成本 + 新增收益）÷ 总投入，分母要算上算力、人力与合规改造，而不只是 API 账单。

核心是"分母意识"：别问花了多少 token，要问"每块钱投入换来多少可验证的改变"。再配一条闭环：小场景试点 → 量化基线 → 放量 → 复盘校准——价值指标应该跟着每一轮迭代走，而不是跟着发布会走。

## 五、给普通人的判断框架：三看

- **一看披露口径**：只晒 token、调用量等流量数字的，保持警惕；能给出场景、基线和提升幅度的，才有讨论价值。
- **二看落点选择**：高频、规则明确、容错可控的场景（客服问答、文档摘要、代码辅助）更容易跑出真价值；"全行级大模型平台"这类大词，先看底下垫了什么。
- **三看成本结构**：自建部署要算 GPU 摊销与团队成本，API 调用要算单价与用量增长曲线。长账本算完，才知道是真转型还是买氛围。



## 写在最后：三条冷思考

1. **指标是仪表盘，不是目的地**。token 是转速表，没人按转速买二手车——看银行 AI，先找它的"里程表"。
2. **任何宏大数字，先问三件事**：分母是什么、基线是多少、成本有没有算全。
3. **让价值回到业务语言**。能把 AI 收益翻译成"审批快了 X 天、投诉降了 Y%"的机构，才是真跑通了；翻译不出来的，多半还披着遮羞布。
