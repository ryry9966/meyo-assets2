沉寂一阵之后，肖弘带着 Manus 2.0 重新回到台前。36kr 的报道里，三个信息点拼在一起颇有信息量：Manus 的上线比 OpenAI 的 Codex 更早；Meta 被曝正在做消费级 agent 产品 Muse；而 Manus 这次把一件听起来像段子的事做成了产品——花不到 1 美元，给 AI 办一个能收短信、能打电话的"手机号"。这三件事其实是同一件事：通用智能体的竞争，正在从"模型炫技"转入"身份与基础设施"的深水区。这篇文章拆开讲：Manus 走到了哪一步，"AI 手机号"到底解决什么问题，以及巨头进场之后牌局会怎么变。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-30/9effaaf982774dd0.png)

## 一、"比 Codex 还早"：先发者交过的学费

- **时间线**：2025 年 3 月，Manus 上线，把"交付结果而不是陪你聊天"的 agent 形态带出圈，邀请码一码难求，黄牛一度把它炒成理财产品；同年 5 月，OpenAI 才推出云端编码 agent Codex。所谓"比 Codex 还早"，指的是在"自主执行型 agent"这条产品路线上抢了先。
- **先发的代价**：早期 Manus 复杂任务成功率不稳定，被质疑"只是前沿模型外面的一层壳"，异步体验也偏粗糙。先发者的宿命，往往是先替全行业踩坑。
- **2.0 的方向**（据公开信息）：更快的任务编排、更低的单任务成本、更稳的结果交付，并把"agent 需要自己的身份"这类基础设施能力摆上台面。
- **技术底座**：Manus 并不自研前沿模型，而是调用各家大模型，价值在 multi-agent 编排——规划、执行、校验三者分离，配合沙箱虚拟机、浏览器与终端工具调用、云端异步任务。这套"工程底盘"的成熟度，比单个模型够不够聪明更能决定产品可用性。

## 二、不到 1 美元的手机号：给 AI 上"户口"

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-30/2f3b214905f0dea0.png)

- **现状痛点**：今天的 agent 大多活在"借用人的身份"里——用你的浏览器 Cookie、你的邮箱注册、你的手机号收验证码。一旦任务涉及独立注册、电话沟通、短信确认，链条就断。
- **技术上并不神秘**：VoIP 虚拟号码服务（Twilio 一类）一枚美国本地号码月租约 1.15 美元，批量采购更低，短信按条计费只要几分钱。"不到 1 美元"是报道口径，但成本量级是真实成立的。
- **为什么值得单独拿出来说**：手机号是互联网身份的"原语"。有了它，agent 才能独立完成订餐厅后的电话确认、注册 SaaS 时收验证码、接收服务器告警这类长尾任务——这些恰恰是真实工作流里最常见的"最后一公里"。
- **更深一层是可追责**：微软为企业 agent 推出 Entra Agent ID，相当于发"工牌"；Cloudflare 推 Web Bot Auth，让爬虫和 agent 用加密证书自证身份。"AI 身份层"正在成为新的基础设施赛道，手机号只是最直观的一个切面。

## 三、Meta Muse 入场：巨头和创企在看同一张地图

- **据多家外媒报道**，Meta 正推进代号 Muse 的消费级 AI 助手/agent 产品；加上 OpenAI 的 ChatGPT agent、Anthropic 的 computer use、Google 的 Project Mariner，通用 agent 已经是巨头的标配路线。
- **双方筹码不同**：巨头握着分发（Meta 系应用数十亿月活）、数据与算力；创企靠迭代速度、场景专注和对"结果交付"体验的偏执。Manus 团队一贯的打法是"海外市场 + 快速试错"，这次抢的是身份与落地层的身位。
- **用产业分层看格局**：模型层（能力来源）→ 编排层（任务拆解与工具调用）→ 身份与支付层（真正落地干活）。前两层竞争已经白热化，第三层刚拉开序幕——这也是为什么"办手机号"这种小事会被当成大事来发布。
- **保持冷静**：Muse 的细节多来自媒体报道，尚未完全落地。巨头进场对创企是威胁，同时也是对赛道的确认。

## 四、成本曲线：从订阅席位到按结果付费

- **推理成本持续下探**：业界普遍观察是同等能力模型的调用成本大约一年降一个数量级，单次 agent 任务的完整成本已从几十美元降到几美元甚至几美分。
- **商业模式随之变化**：当单任务成本足够低，"按结果计费"才变得可行——订到会议室、约到人、交付可用报告才算钱。订阅卖的是权限，按结果计费卖的是产能。
- **"1 美元手机号"的隐喻**：agent 落地链条上的每一层基础设施，成本都在滑向"可忽略"；剩下的真瓶颈是可靠性、权限和信任，而不是钱。

## 收尾：三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-30/62dab5fcd3977df4.png)

1. **看 agent 产品先看失败率，不看 demo。** 发布会演示的是上限，生产环境比的是下限：任务成功率、失败时的兜底、异常恢复能力。建议先用两周低风险任务试运行，再决定要不要把关键流程交出去。
2. **"AI 身份"是双刃剑。** 给 agent 办号降低了落地门槛，也同步降低了滥用门槛——养号、短信轰炸、自动化诈骗会跟着升级。开发者接入时务必做好权限最小化和行为审计日志；平台侧的"Know Your Agent"凭证体系会是下一个战场。
3. **个人与团队的上手顺序**：先托管"重复、可验证、低风险"的任务（数据汇总、监控告警、报告初稿），建立人工抽检闭环；再逐步放权给"需要外部身份"的任务（注册、电话、支付）。放权速度应与你的审计能力成正比——这条定律不等人。
