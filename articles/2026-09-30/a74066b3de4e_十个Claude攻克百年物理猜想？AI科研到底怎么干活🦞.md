热搜上挂着一行字：十个Claude 5.5攻克百年物理猜想。做技术的人看到这种标题，本能反应不是膜拜也不是冷笑，而是把两个关键词拎出来拆：一个是"十个"，一个是"攻克"。前者指向 multi-agent 系统的一整套工程，后者指向数学证明的成色分级。这两件事讲清楚了，这条新闻该怎么定性，你心里自然有数。下面摊开讲。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-09-30/80a89b44ea72f216.png)

## "十个Claude"：不是算力×10，是一支有分工的智能体队伍

先泼盆冷水：十个模型实例，不等于智力乘十。真正值钱的是多智能体（multi-agent）编排架构：

- **Orchestrator–Worker 模式**：一个主 agent 把大问题拆成子任务，分发给多个并行子 agent，各自探索后回收汇总。Anthropic 公布过自家多智能体研究系统的内部数据：研究类任务上，多智能体比单 agent 提升约90%，代价是 token 消耗约为普通对话的15倍。分工有效，但按 token 计费，真金白银。
- **角色分工**：跑数学证明时的典型配置是 proposer（提构造与证明思路）、skeptic（专职找反例和漏洞）、verifier（对照定义逐行核对）。类似 code review，互相往死里挑刺是设计目标，不是内耗。好在 agent 开会不用投屏和暖场，沟通成本这一项确实赢了。
- **为什么适合证明问题**：数学证明是在天文数字级的分支空间里做搜索，单线程的 chain-of-thought 容易走进死胡同出不来；多 agent 等于并行展开多个分支、各自提前剪枝。工程上有个老说法：九个孕妇没法一个月生出孩子——但并行搜索分支，恰好是少数"堆人有效"的活儿。

顺带一句：别执着于"5.5"这个版本号，模型编号每季度就旧了。真正稳定的是三件套——前沿 LLM + agent 编排框架 + 自动验证器。

## 百年物理猜想难在哪：三个例子看懂"硬"在哪

- **Navier–Stokes 方程**：方程写在19世纪，它的解是否存在且光滑，是 Clay 研究所七个千禧年难题之一，悬赏100万美元，至今无人完整拿下。
- **三体问题**：庞加莱19世纪末就证明了它没有通用解析解，顺手开创了混沌理论。现在的推进方式是找特殊周期解族，近年已有团队用神经网络批量搜出新的周期轨道。
- **湍流**：Richardson 1922年写下那首著名的漩涡诗，Kolmogorov 1941年给出 K41 谱理论，但直到今天，湍流仍没有从第一性原理出发的完整理论。

共同点：解空间大到无法枚举，传统打法依赖天才直觉加几十年磨一剑。AI 的切入方式不是"更聪明"，而是"更快的试错"——把人类一百年才轮得到的采样量，压缩到几周。

## 前情提要：AI 碰硬题，此前已经摸到哪一步

看新新闻之前，先校准一下历史刻度：

1. **2023年底，FunSearch**（DeepMind，发表于 Nature）：LLM 生成候选程序 + 自动评估器筛选的进化循环，把 cap set 问题的下界推进了一步。注意：是"改进界"，不是完整证明。
2. **2025年，AlphaEvolve**：用进化式代码搜索把 4×4 复矩阵乘法所需乘法次数从 Strassen 保持56年的49次降到48次；顺带把11维接吻数问题下界从593提到594——这个问题的历史可追溯到17世纪。
3. **2024–2025，IMO 系列**：AlphaProof 在国际数学奥林匹克拿到银牌级分数（28/42）；一年后，多家机构的推理模型达到金牌水平。
4. **形式化验证跑通**：陶哲轩团队2023年用约三周、二十来位协作者，把 PFR 猜想的证明在 Lean 里完成形式化，验证了"AI 给证明、人类 + 证明助手当裁判"的协作闭环。

规律很清楚：到目前为止，AI 最强的角色是"构造者"和"搜索者"，裁判席上坐着的是形式化工具和人类数学家。

## "攻克"是个光谱：四种成色，含金量差很远

读这类新闻，先问自己：这里的"攻克"是哪一档？

- **成色一：完整证明 + 形式化验证**。证明能被 Lean、Coq 等证明助手机械检查，等于结案归档，含金量天花板。
- **成色二：推进关键引理或上下界**。AlphaEvolve 式，是真进步，但问题没关账。
- **成色三：找到新构造、新解族或反例**。三体新轨道式，改写了问题地图，但没给出终局答案。
- **成色四：数值证据与猜想启发**。严格说连数学结论都还不算，只能算指了路。

配套的判断动作：论文挂出来了没有？过没过同行评审？能否被证明助手机械验证？原团队自己的措辞是 prove、improve 还是 suggest？LLM 存在幻觉，"看起来像证明的东西"是这个领域最大的坑，机器可验证性是唯一的杀毒软件。

## 收尾：三条冷思考

1. **别把"十个"神话化**。多智能体的本质，是把 test-time compute 从"想得更久"扩展为"分工更细"，成本是真实烧掉的 token。它 Scaling 的是并行与分工，不是智力本身。
2. **瓶颈正在转移**。从"能不能算出来"转向"能不能验证"。Lean 生态、自动评估器、形式化工具链会成为 AI 科研的标准配件——这部分基础设施的确定性，可能比下一个模型版本号更高，投资和学习的性价比都在这里。
3. **科研节奏没有变快**。从"AI 给出候选"到"同行评审确认、写进教科书"，中间是按年计的流程。下次看到同类热搜，先问三件事：哪个猜想？哪种成色？谁来验证？问完再决定是膜拜还是睡觉——大概率是后者，然后第二天泡杯茶，认真去读论文原文。
