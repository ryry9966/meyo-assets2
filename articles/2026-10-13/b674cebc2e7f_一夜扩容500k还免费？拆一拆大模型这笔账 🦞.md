36kr 报道：GPT-6.1 Sol 一夜之间扩容到 500k，并且完全免费。评论区一半人在欢呼“白嫖真香”，另一半在嘀咕“免费的东西最贵”。两种直觉各对一半。这波操作到底是福利还是钩子，得算清三笔账：500k 扩的究竟是什么？过去为什么给不起？现在又凭什么给得起？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/8097e70fc7c6618b.png)

## 第一笔账：500k 翻译成人话是多少

- 先统一单位。token 是模型处理文本的最小单位，1 个 token 约合 0.75 个英文单词，或 0.5~1 个汉字。500k 就是 50 万 token。
- 折成体感：约等于三本英文长篇小说、二三十万字中文资料，或一个中型代码仓库的大半源码。以前要拆成几十轮对话慢慢喂的活儿，现在一次装得下。
- 直接解锁的场景：整本技术书一次读通、几十份合同交叉比对、给整个代码库做架构评审。以前做不了的任务，现在门槛降到了一个对话框里。
- 三个概念别混淆：上下文窗口（一次对话能“看见”多少）、用户额度（每天能用多少）、服务端吞吐（平台同时扛得住多少）。这次“扩容 + 免费”，大概率是前两者打包上调。
- 老常识再念一遍：上下文是工作记忆，不是知识库。对话关掉即清空，也不会自动长成模型自己的能力。

## 第二笔账：扩容为什么以前很难

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/923488ddafe1901b.png)

- 根子在 Transformer 的自注意力机制：每个 token 要和上下文里所有 token 各算一遍相关性，计算量随长度平方增长——上下文 ×10，算力 ×100。
- 更要命的是显存。推理时每个 token 都要留一份 KV cache（相当于对话历史的“速记本”），以 8B 级模型为例，每 token 约占 0.1~0.5 MB；50 万 token 的单个长请求，缓存轻松吃掉几十到上百 GB，逼近一整张 80GB 的 H100。
- 所以长上下文长期等于高定价。2023 年初 GPT-4 的 32k 版本就比 8k 版贵一倍；而过去两年，同等能力档位的推理单价整体跌了一个数量级以上——技术每前进一格，账单就薄一分。
- 还有质量折扣：早期不少模型标称 128k，“大海捞针”实测到后半段就开始漏。名义上下文 ≠ 有效上下文，这是行业踩过的坑。

## 第三笔账：“一夜”和“免费”凭什么成立

工程上，成本是省出来的：

1. 注意力工程：FlashAttention 这类 fused kernel 大幅减少显存读写；GQA/MQA 把 KV cache 压缩数倍；“局部 + 全局”混合注意力让多数 token 只在小窗口内计算。
2. 架构与量化：MoE 模型每个 token 只激活一小部分参数；KV cache 压到 fp8/int8，显存再砍近一半；PagedAttention 式显存分页把碎片浪费打了下来。
3. Prefix caching：公共系统提示、高频文档只算一次、全员复用，命中率高的业务，边际成本能降一个数量级。
4. 离峰调度：把深夜闲置算力切给免费层——“一夜扩容”在这个意义上是字面成立的。

商业上，账是这么算平的：

1. 价格战惯性：长上下文已从“卖点”变成“标配”，不跟进就等着用户流失。
2. 生态锁定：开发者把代码库、知识库接进来之后，迁移成本极高。免费的是容量，锁住的是你的工作流。
3. 数据飞轮：海量真实的长文档使用场景（在合规前提下），是改进模型最值钱的养料。
4. 规模效应：用户量上去后，单位 token 的固定成本被摊薄，免费层的账反而更好看。说白了，用闲置算力换份额和留存，和云厂商送额度的逻辑一脉相承。

## 第四笔账：塞满 500k 之前，先看三个现实

- 中段遗忘：RULER 等长上下文评测反复显示，模型对超长文本中部的召回明显弱于头尾（lost in the middle）。塞得下不等于用得好，关键信息尽量放头尾，或先分块摘要。
- 延迟成本：输入越长，首 token 延迟越高、生成越慢。免费用量，不等于免费用时。
- 正确姿势是组合拳：检索（RAG）负责缩小范围，长上下文负责一次性吃下完整材料——整本书、整份合同、整个 repo，各归其位，谁也别越权。

## 收尾：三条建议

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/36f018f3e06f7d87.png)

1. 把 500k 当工作台，别当仓库。喂进去之前先问一句：其中真正相关的信息有没有 10%？先摘要、先检索、再全量，顺序不能反。
2. 趁红利期攒“可迁移资产”。prompt 模板、评测集、工作流都做成平台无关，API 调用留一层抽象。免费策略随时可能调整，资产别长在别人家的地基上。
3. 白嫖之前读一眼条款。限速、并发、数据是否用于训练、商用许可——免费的对面往往标着别的价格：你的数据、你的时间、你的锁定。

结尾一句：免费的算力，是行业竞争白热化撒下来的福利；但工程判断力这件事，任何模型都替你付不了费。
