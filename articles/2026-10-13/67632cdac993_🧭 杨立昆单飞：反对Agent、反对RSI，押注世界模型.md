2025 年 11 月，深度学习三巨头之一、图灵奖得主 Yann LeCun（杨立昆）被曝即将离开工作十余年的 Meta，创办一家押注“世界模型”的初创公司。而他此前一年的公开表态，几乎是一份行业“反对清单”：反对把 LLM 当作通往人类级 AI 的主干道，反对火热的 Agent 叙事，也反对“AI 递归自我改进”的 RSI 剧本。一位图灵奖得主站到了几乎所有热点的对面，这事值得拆一拆：他反对的到底是什么？拿什么替代？哪些判断对我们有用？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/ee857a1908161fbb.png)

## 一、事件线：不是突然翻脸，是攒了三年的分歧

- **早有伏笔**：2022 年他发表长文 *A Path Towards Autonomous Machine Intelligence*，系统提出 JEPA 架构与“目标驱动 AI”；此后多次公开说“自回归 LLM 注定失败”。
- **路线分岔**：2025 年 Meta 成立超级智能实验室，重金扩招、继续加注 LLM 与算力，LeCun 的路线在内部被边缘化；同年他被曝离职创业，据 FT 等媒体报道，传闻融资规模为数亿美元量级。
- **一句定调**：他把 LLM 比作“通往人类级智能高速公路上的出口匝道（off-ramp）”——能落地、能赚钱，但不是终点。
- **注意对象**：他反对的不是“用 LLM 做产品”，而是“把当前范式等同于通往 AGI 的唯一路径”这个叙事。

## 二、反对 LLM：自回归的三个结构性问题

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/5f4e9d49b2f2467b.png)

1. **误差指数累积**。自回归模型逐 token 生成，每步都有概率损耗：单步 99% 可靠，连续 100 步后只剩 0.99¹⁰⁰ ≈ 37%。这解释了长文本、长任务里“越走越歪”的现象，也解释了他为何否认“堆 token 就能堆出推理”。
2. **缺少世界模型**。LLM 学到的是语言的统计结构，不是世界的因果结构。婴儿看几个月世界就能掌握重力、遮挡、物体恒存性；LLM 吞下数万亿 token 仍会在物理常识上翻车。他的判断：智能的根不在文本里。
3. **幻觉是范式的副作用**。逐 token 预测的优化目标是“最像下文”，不是“最真”，而文本分布里没有真值锚点。在他的框架里，幻觉不是待修复的 bug，而是架构本身的产物。

## 三、反对 Agent 热潮：地基不稳，楼盖不高

- 当下主流 Agent ≈ LLM + 工具调用 + 循环 + 提示工程。
- LeCun 的逻辑：在一个不会规划的底座上叠加“规划流程”，本质是把问题外包给工程补丁；Agent 循环越长，第二节那道 0.99¹⁰⁰ 就越致命——这与大量评测里“长链任务成功率随步数指数衰减”的现象对得上。
- **需要澄清**：他反对的是“基于 LLM 的 Agent 能通往人类级智能”，不是否定 Agent 的商业价值。今天能落地的自动化照样值得做。

## 四、他主张什么：JEPA 与世界模型

- **核心命题**：智能系统需要“世界模型”——给定当前状态与候选动作，预测世界的下一个状态；有了它，才能像最优控制那样在心里搜索动作序列，完成真正的规划。
- **JEPA（Joint-Embedding Predictive Architecture）**：不预测原始像素或词，而在抽象表征空间里做预测。理由很工程：逐像素预测逼着模型把算力浪费在不可预测的细节上，表征空间的预测天然支持抽象。
- **证据点**：Meta 的 V-JEPA 2 用约百万小时视频自监督训练，参数量仅 12 亿级，却能零样本预测物理动态、支撑机械臂抓放规划——他借此论证“抽象比参数堆叠更重要”。
- **完整蓝图**：感知模块 + 世界模型 + 成本模块 + 执行器，以自监督学习为主、少量 RL 微调；他把目标命名为 AMI（高级机器智能），刻意避开 AGI 这个词。

## 五、反对 RSI：他不信“自我改进螺旋”

- **RSI 剧本**：AI 写出更强的 AI → 递归加速 → 奇点。LeCun 认为它建立在一个错误假设上——把智能当成“搜索代码空间”的问题。
- **他的反问**：人类级 AI 还缺好几块拼图——世界模型、持久记忆、规划能力、内在动机。在残缺系统上递归自我改进，只会快速放大缺陷，不会自动长出缺失的部件。
- **时间表反而保守**：人类级 AI 需要数年乃至十年以上，“不是任何一家实验室三年冲刺能解决的事”。
- **对照组**：Hinton 担心失控风险，LeCun 认为这类叙事被过度戏剧化，但两人都支持认真做安全研究——分歧在机制判断，不在态度。

## 六、公允地看：他错过的与他说对的

- **反方证据在增长**：o1 类 reasoning model 用 test-time compute 换来数学与代码能力的跃升，Agent 框架在真实业务里持续产生价值。“LLM 已到天花板”目前是判断，不是实验结论。
- **但他有逆风翻盘的履历**：1980 年代坚持 CNN，被冷落十几年后成为行业基石。“逆着共识走”是他的老剧本，这次的坚持未必是固执。
- **更公允的读法**：LLM 是“工程上够用、科学上缺件”的系统。两拨人吵的其实是不同的问题——一个问明年怎么赚钱，一个问智能还缺什么。

## 七、冷思考：三条带走

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/477892fcaf99fad6.png)

1. **分离产品判断和路线判断**。Agent 今天能降本增效就值得做，但别把发布会叙事当成通往 AGI 的证据链；看评测、失败模式与成本曲线，不看 keynote。
2. **押注可迁移的底层知识**。无论哪条路线赢，表征学习、概率与控制、系统设计都不会作废；纯提示词技巧折旧最快。
3. **给一切时间表打折**。十年派和三年派给的都是信念值，不是实验值。值得跟踪的证据增量：JEPA 系模型能否在机器人上规模化、长链任务成功率能否突破指数衰减、新架构能否用更少数据学会物理常识。

科学史的老经验：当所有人挤在同一条路上时，往往正是分岔口出现之前。LeCun 的价值未必是“他最终对了”，而是逼着行业把两件事分开——当下的热闹，和智能的终点，不是同一个问题。
