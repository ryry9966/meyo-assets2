2025 年 3 月，一个 AI agent 产品靠邀请码刷屏全网，闲鱼上的邀请码一度被炒到数万元；一年多后，据 36kr 等媒体报道，它背后的公司正洽谈新一轮融资，估值传闻约 40 亿美元。同一时间，OpenAI、Anthropic、Google 已经把 agent 从概念做成了平台能力。一边巨头压境，一边高估值融资——这中间的缝隙值得拆开看看：大厂围堵之下，Manus 的 40 亿美元，到底在为哪部分买单？

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/cb964d13a557167a.png)

## 回看 Manus：它到底做对了什么

- **卡位"定义权"**：当行业还在争论 agent 是什么时，Manus 用一支几分钟的 demo 给出了大众能秒懂的答案——把任务整个交出去，在云端虚拟机里异步执行，人下班它干活。这个心智占位比技术本身更值钱。
- **工程化整合**：底层调用 Claude、Qwen 等模型，上层做 multi-agent orchestration：任务拆解、工具调用、浏览器操作、代码执行、失败重试。本质是把模型的"原子能力"组装成一条完整的劳动流水线。
- **增长节奏干净利落**：3 月爆红，4 月据外媒报道拿到 Benchmark 领投的约 7500 万美元（估值约 5 亿美元），年底 ARR 据公开报道达到上亿美元量级。一年多，名义估值涨了约 8 倍。

顺带一个冷知识：邀请码被黄牛炒价那天，市场其实已经替 Manus 完成了一次极早期公开定价——稀缺性不是营销出来的，是被抢出来的。

## "套壳"争议的真相：薄壳会死，厚壳难死

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/4da2036453a16354.png)

"套壳"质疑从上线第一天就有：模型是别人的，Manus 是不是 prompt wrapper？把系统拆开，它至少有四层：

1. **模型层**：借来的"大脑"，Claude/Qwen，这是它最无法自己控制的部分；
2. **编排层**：planner-executor 架构，负责任务规划、并行子任务、结果校验与重试；
3. **环境层**：云端沙箱虚拟机，自带浏览器、终端和文件系统——这是它区别于网页套壳的核心资产；
4. **数据层**：海量真实任务轨迹、失败样本、评测基准，这些是模型厂商发布会写不出来的东西。

这里的物理规律是：模型每升级一代，会自然"吃掉"一部分上层能力，这是所有 wrapper 都要承受的地心引力。但历史反复证明，死掉的是薄壳，活下来的是厚壳：Zapier 在所有 API 巨头眼皮底下活了十几年；Perplexity 在 Google 搜索的腹地里，据报道也长到了两百亿美元量级的估值。在巨头射程内做生意不是原罪，壳的厚度才是生死线。

## 大厂围堵的真实形状：不是围剿，是平台级降维

2025 年大厂的动作能列一长串：OpenAI 推出 ChatGPT Agent 和 AgentKit，把 agent 从产品变成开发者平台；Anthropic 放出 Claude Agent SDK；Google 把 Gemini 的 agent 能力直接塞进办公套件。再加上 token 价格战和开源模型（Qwen、DeepSeek）把基础能力平权化，"做一个 agent"的门槛正在趋近于零。

但围堵的真实形状值得拆清楚：

- **上游威胁**：模型厂商把规划与工具调用做进模型内部（deep agents 路线），直接压缩编排层的价值空间；
- **同层竞争**：Cursor、Devin、Perplexity 等独立玩家，抢的是同一个"任务执行"心智；
- **残酷算术**：大厂不需要"赢下"agent 市场，只需要顺手不差，就能留住大多数轻度用户；独立公司必须"明显更好"，才配继续留在牌桌上。

反过来也有一个反直觉的事实：巨头亲自下场，等于替全行业完成了市场教育，赛道 TAM 被官方盖章。对独立公司而言，围堵既是绞索，也是免费广告。

## 40 亿美元的算术：买的是牌桌位置，不是市盈率

三种算法摆在一起看：

- **算法一，收入倍数**：假设 ARR 1 亿美元，40 亿估值约等于 40x ARR。参照系：成熟 SaaS 通常 5–10x，AI 原生高增长公司 20–40x。也就是说，市场是按"类目赢家＋持续高增长"定价的，一分钱安全边际都没留。
- **算法二，可比公司**：同赛道的 Cursor，据报道 ARR 更高、估值传闻在百亿美元量级。Manus 的相对溢价来自"通用 agent"这个更宽的心智占位。
- **算法三，期权定价**：这轮钱本质在买三个期权——模型继续快速进步（壳随大脑一起升值）、agent 成为下一代流量入口（占位价值）、被大生态收编的退出路径。

风险项同样明确：用户迁移成本低、模型厂商持续上探、海外市场的信任与合规成本，任何一条都足以让倍数直接打折。

## 三条冷思考：怎么判断这类公司值不值

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/d46e21483f39ba30.png)

1. **看壳的厚度，不看壳的有无**。关键指标是私有数据飞轮有没有转起来：任务轨迹、失败样本、垂直评测集。这些决定模型升级之后，它是否仍然不可替代。
2. **看迁移成本，不看用户数**。订阅费 39 美元还是 199 美元不重要，重要的是用户的工作流、数据和记忆有没有沉淀在产品里——离开的理由和留下的理由，哪个更硬。
3. **看迭代速度，不看当前架构**。agent 本质是一门"能力租借"生意，估值是在给迭代速度投票。模型每跳一代，今天的架构可能变成明天的负资产；十二个月后的版本答案，比任何一份商业计划书都重要。

最后一句实话：40 亿美元买的不是现在的 Manus，而是"独立 agent 公司在大厂阴影下还能长多大"这个问题的答案。这个问题值得盯着看——毕竟下一层被围的壳，可能就轮到你自己所在的行业了。
