2025 年夏天，Kimi K2 开源模型在海外开发者社区刷屏，登顶 HuggingFace 趋势榜，一度把官方 API 服务器挤到限流。随后 36kr 用了"挤进决赛圈"这个词来形容月之暗面的处境——百模大战退潮两年后，牌桌上的玩家从上百家收缩到个位数，这家一度被质疑"掉队"的公司又坐了回来。这不是逆袭爽文，而是一次教科书级的战略纠偏。这篇文章拆解三件事：决赛圈是怎么收缩的、月之暗面走过哪些弯路、K2 这张牌为什么有效。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/b6e9b9a755d5acc4.png)

## 决赛圈：一场残酷的供给端出清

- 2023 年国内大模型数量一度超过 200 个，媒体称之为"百模大战"。到 2025 年，仍按 frontier 节奏持续发版的创业公司只剩个位数。
- 曾被并称"大模型六小虎"的梯队明显分化：有的转向行业 to B，有的把预训练收缩、重心挪到应用，有的押注医疗等垂直赛道。
- 出清的动力是硬成本。一次前沿级别的预训练，算力开支以千万乃至亿美元计；DeepSeek 公开的 V3 训练账单（约 557 万美元 GPU 成本，不含研究与试错）既是效率标杆，也划出了入场费的下限。
- 牌桌上留下的席位，基本对应三种能力：持续预训练的工程能力、强化学习（RL）后训练能力、把模型变成收入闭环的分发能力。

## 月之暗面的高开、弯路与转身

- **高开**：2023 年 3 月成立，创始人杨植麟是 Transformer-XL、XLNet 的第一作者，学术履历在国产模型公司里几乎独一档；同年 10 月 Kimi 上线，率先把长上下文推到 20 万字、后来 200 万字，"长文本"心智一举拿下。
- **融资纪录**：2024 年初完成超 10 亿美元融资（阿里领投），投后估值约 25 亿美元，创下当时国内大模型创业公司单轮纪录。
- **弯路一**：To C 流量转化难题。Kimi 靠投放冲到千万级月活，但 AI 助手付费率低，豆包、通义高举免费大旗后，买量的边际收益急转直下——ROI 掉头向下的速度比 loss 收敛还快。
- **弯路二**：治理风波。与老股东之间的股权仲裁争议持续大半年，牵扯管理层精力，后据公开报道已撤回。
- **转身**：2024 年下半年起明显收缩投放，资源挪回模型本体；2025 年 1 月 K1.5 用 RL 训练长链推理，数学与代码成绩一度对标 OpenAI o1；7 月 K2 直接开源。

## K2 的技术牌：开源、MoE 和为 Agent 而生

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/dfa9f11db3cc7cbf.png)

- **架构**：总参数约 1 万亿、激活约 320 亿的 MoE（专家混合）架构，注意力部分采用 MLA（多头潜在注意力）压缩 KV cache，配合自研优化器变体 MuonClip 稳住超大规模训练，预训练数据约 15.5 万亿 token。
- **MoE 为什么省钱**：每个 token 只激活一小部分"专家"网络，相当于把一头万亿参数的巨兽拆成专家池、按需叫人，而不是全员到岗，推理成本远低于同规模稠密模型。
- **后训练押注 Agent**：用大量合成工具调用数据加 RL，让模型学会"先规划、再调工具、再校验结果"的工作流，在 SWE-bench Verified（真实 GitHub 修 bug 任务）上拿到 65% 左右的成绩，冲进开源第一梯队。
- **开源策略**：采用宽松的 modified MIT 协议，权重与技术报告全放，还提供 Anthropic 兼容的 API 端点，海外开发者可以近乎无缝迁移——这解释了 K2 为什么能在海外社区形成自传播。
- **商业逻辑**：开源不等于送钱。它换来的是开发者生态、真实场景反馈和人才吸引力；用户本地部署玩开源权重的同时，API 版仍是主力付费入口，相当于用模型换"地基"。

## 决赛圈的牌型：几家各拿什么

- **字节跳动**：赢在分发和价格。火山引擎披露豆包大模型日均 tokens 调用量 2025 年中已突破 16 万亿，叠加抖音生态，走"模型即水电"路线。
- **阿里**：赢在开源生态加云。Qwen 系列衍生模型数以十万计，居全球开源社区之首，模型本质上是云业务的获客飞轮。
- **DeepSeek**：赢在算法效率叙事，用极致工程把前沿能力做到人人用得起，倒逼全行业降价。
- **月之暗面**：赢在"小而快"。组织小、决策链短，敢 all in 开源和 Agent 这个尚未被大厂锁死的增量方向。
- **共同点**：没有谁再靠发布会定输赢，衡量标准变成真实任务表现、token 调用量和开发者留存。有媒体复盘：仍有能力自研前沿模型的国内创业公司，基本只剩 DeepSeek 和月之暗面两家——这个"只剩"本身就是筛选结果。

## 冷思考：三条实用建议



1. **做应用的开发者：保持多模型架构（multi-model routing）。** 淘汰赛远未结束，把产品逻辑绑死在任何一家 API 上都是风险。抽一层网关，让模型可替换，才有议价权和容错空间。
2. **企业选型者：算总账（TCO）而非单价。** 开源权重私有化省下的 API 费用，要和 GPU 折旧、运维人力、版本升级成本放在一起算。对多数团队，"核心链路自部署 + 长尾调用走 API"的混合方案性价比最高。
3. **观察行业的同学：用三个指标替代估值和热搜。** 模型能力之外，看 API 收入增速、开发者生态留存、Agent 真实任务完成率。大模型下半场比的不再是故事，而是把 token 变成现金的转化率。

决赛圈的意义不在于"谁已经赢了"，而在于行业终于可以开始认真讨论商业模式。牌桌小了，牌反而好看了。
