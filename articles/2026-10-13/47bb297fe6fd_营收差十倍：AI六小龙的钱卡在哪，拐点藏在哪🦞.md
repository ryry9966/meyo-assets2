最近 36kr 把一张账本摆上台面：国内"AI 六小龙"（智谱、月之暗面、MiniMax、百川智能、零一万物、阶跃星辰）的营收加起来，大约只有 OpenAI + Anthropic 的 10%。数字确实扎心，但"赚钱难"和"没机会"是两回事，拆开账本看结构，拐点的信号比差距本身更值得聊。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/200fdb906f4f0640.png)

## 一、先把账本摆平：差的是十倍，更是结构

- OpenAI 2024 年营收约 37 亿美元，ChatGPT 订阅与 API 双轮驱动，2025 年市场预期继续翻倍以上；Anthropic 年化收入从 2024 年底的约 10 亿美元起步，在企业 API（尤其编程场景）带动下高速放量。
- 六小龙没有统一口径，公开信息拼起来，各家年收入多在数千万到数亿元人民币量级，合计与前者正好差一个数量级，这就是"10%"的由来。
- 更值得注意的是收入构成的差异：
  1. OpenAI 的现金牛是全球 C 端订阅（Plus 每月 20 美元）加标准 API；
  2. Anthropic 以高毛利企业单为主，经由 AWS Bedrock、Google Vertex 等云渠道分发；
  3. 国内六小龙则以按量计费的 API 和私有化项目为主，C 端订阅几乎可以忽略。

一句话：这不是同一条跑道上快慢的问题，而是两边在卖不同的东西。

## 二、钱卡在哪：三重结构性困境

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/326b9efb81660f03.png)

1. **C 端收不上价。** ChatGPT 手握数亿周活和成熟的订阅文化；国内大模型产品高度同质化，豆包、DeepSeek 直接免费开放，把 C 端订阅的定价空间基本封死。能免费白嫖的服务，很难让人再掏包月费。
2. **API 卖成了白菜价。** 2024 年 5 月行业打响价格战，主流模型 API 定价普遍下调 90% 以上；DeepSeek 又靠 MoE + MLA 的架构级推理成本优化把底价再砸一档。按 token 计费的模式下毛利极薄，卖得越多越像在给电网打工。
3. **ToB 项目制陷阱。** 私有化部署、定制开发、长回款周期，这类收入是"人力密集"而非"产品密集"，没法像标准软件那样无限复制，规模不经济。
4. **算力成本是刚性的。** 训练烧钱，推理也烧钱。六小龙没有大厂级算力池和云业务输血，每一度 GPU 的电费都得自己扛。

## 三、对照组：OpenAI 和 Anthropic 凭什么收得上钱

- **流量入口**：ChatGPT 是全球级 C 端入口，订阅收入的边际成本极低。
- **场景押注**：编程是当下付费意愿最强的 AI 场景，Claude 拿下了 Cursor、GitHub Copilot 等编程工具的底层模型席位，企业客户跟着场景走，API 用量水涨船高。
- **性能溢价**：模型能力待在第一梯队才有定价权，有定价权才有毛利。
- **付费土壤**：美国企业软件（SaaS）文化成熟几十年，预算体系和采购流程是现成的。

对照下来是个扎心的结论：差距的大头不在模型能力，而在商业环境——订阅意愿、企业预算、云渠道。所以"复刻 OpenAI 路径"在国内走不通，必须换打法。

## 四、拐点已现：三个正在发生的变化

1. **应用爆发拉动 token 消耗。** Agent、编程助手、视频生成让推理调用量指数级增长，单价虽然降了，用量在涨。"卖水人"逻辑从"卖贵水"切换成"卖更多的水"，量价曲线开始重新向上弯折。
2. **出海跑通第二条曲线。** 据公开报道，MiniMax 的海外收入占比已相当可观，海外 C 端产品在全球市场直接变现。这说明国内收不上来的订阅费，海外用户是愿意付的。
3. **从拼基座转向拼落地。** 价格战之后，六小龙普遍把资源转向垂直行业（金融、医疗、制造）和 Agent 应用；智谱完成股改、启动上市辅导，全行业的商业化叙事从"讲模型分"切换到"交收入答卷"。

回头看 2023 年的"百模大战"，两百多家公司挤在模型层卷参数；到今天淘汰赛筛掉了大多数，留下的玩家反而第一次有了可执行的商业路径。收入差距是过去式，token 消耗增速和应用收入曲线才是进行时。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/4d45f222aa7e1a3e.png)

1. **别用绝对值线性外推输赢。** 中美市场处于不同阶段：美国 C 端订阅和企业 SaaS 已成熟，国内应用层刚起跑。当年中国互联网公司跟硅谷比营收同样难看，后来的故事大家都看到了。比营收更该盯的是 token 消耗增速和用户留存。
2. **看毛利质量，不看收入规模。** 一个私有化大单的低毛利收入，质量远低于可持续复购的订阅加 API。判断一家模型公司的成色，先问：收入里有多少是可复制、可续费的？
3. **盯住"谁在为结果付费"。** Agent 时代按 outcome 计费可能重构定价模型，谁能把 token 成本翻译成客户可量化的业务结果，谁就握住下一轮定价权。

差距是真实的，但账本要看动态。模型层的格局远未定型，真正的分水岭是：应用爆发那天到来时，谁手里握着被反复调用的场景。
