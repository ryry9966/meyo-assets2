2025年3月，Manus 一夜刷屏，邀请码一度被炒到五位数；到了年末，据多家媒体报道，这家公司新一轮融资的估值谈判已摸到40亿美元量级。一家没有自研基础模型的创业公司，凭什么在 OpenAI、Anthropic、Google 全线压进 Agent 赛道的当口，讲出这样的资本故事？这篇文章把估值、技术和竞争格局拆开来看。

![cover](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/d082476babba61ba.png)

## 一、Manus 做对了什么：从“回答问题”到“交付结果”

先说清产品。Manus 的定位是“通用数字员工”：给它一个目标，比如“收集300份简历并按岗位匹配度排序”，它会在云端虚拟机里自己拆解任务、写代码、操作浏览器、调用工具，最后交付一个能直接打开的结果文件。和 Chatbot 的区别一句话就能讲明白：前者负责“说”，它负责“做完”。

它跑出来的三个工程要点：

1. **异步云执行**：任务跑在云端沙箱里，关掉电脑它也在干活，这是与传统对话产品最大的体验断层；
2. **多模型调度**：底层接入 Claude、GPT、Qwen 等多家模型，按任务难度动态分配，压成本、提成功率——它本质上是“模型的甲方”；
3. **Context Engineering**：把长任务中的上下文（文件、网页、中间产物）管理好，让模型“记得住、走得远”，这也是它上线时敢拿 GAIA 基准高分做背书的底气。

一句话总结：Manus 没有造发动机，但它第一个把“Agent 能干活”装成了整车，而且普通用户试得懂。

## 二、40亿美元的账本：市场在为什么买单

看融资轨迹：母公司“蝴蝶效应”此前靠浏览器插件产品 Monica 起家；2025年4月，据彭博等报道，Manus 拿下 Benchmark 领投的一轮，估值约5亿美元；到年末，新一轮估值传闻已在40亿美元上下，一年翻了约8倍。

支撑数字的是增长曲线：上线数月注册用户破百万；据媒体披露，其 ARR（年度经常性收入）从零冲到1亿美元量级，在订阅制产品里属于极快的速度。

但换算一下就能看出微妙之处：40亿美元对应约40倍 ARR，隐含假设是“通用 Agent 会成为下一代流量入口，而 Manus 占住了身位”。这不是为现状定价，是为预期定价——市场买的不是它现在赚多少，而是窗口期的门票。

## 三、大厂围堵：三层挤压正在同时发生

![img1](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/70d62f6b513afec9.png)

讨论“值不值”，绕不开最刺眼的问题：巨头都在做 Agent，Manus 挡得住吗？压力其实来自三层，方向各不相同。

**第一层：模型层自上而下压。** OpenAI 把 Agent 能力直接做进产品（Operator、Agent Mode），Anthropic 的 Claude 提供 computer use 和 Agent SDK，Google 用 Gemini 强化长程任务执行。更关键的趋势是：长上下文、工具调用、多步规划正在变成基础模型的“出厂标配”，Manus 赖以起家的工程整合空间会被持续压缩。

**第二层：平台层抢入口。** 浏览器和操作系统是 Agent 的天然入口。Chrome 内置 AI、各家浏览器跟进，意味着用户“打开浏览器就能派活”，第三方 Agent 的获客成本会越来越高。大厂还有算力、分发、资金三重优势，甚至能用免费策略直接打价格战。

**第三层：开源把复制成本打到地板。** Manus 走红当天，开源社区几小时内就复刻出 OpenManus，相关项目迅速收获上万 Star；MCP 协议又把“模型—工具”的接口标准化，编排层的可替代性进一步上升。

这三层挤压的共同点：都不至于直接杀死 Manus，但都在持续压缩“通用编排层”的利润空间。

## 四、护城河之辩：薄壳，还是杠杆

看空者的逻辑很直白：Manus 不训练模型，核心能力来自外部模型租用；一旦模型原生能力追平，工程红利就会消失。历史上基于 API 的“套壳”产品，大多被模型的大版本升级直接碾过，前车之鉴不少。

看多者则认为，Agent 产品的壁垒从来不在单一环节，而在系统：

- **体验与工作流**：从任务理解、执行到可验证交付的完整闭环，是大量真实用户反馈迭代出来的，不是模型参数自动带来的；
- **成本工程**：在多家模型之间动态路由，同样的任务用更低的 token 成本跑出来——这是运营型壁垒，模型公司反而不擅长；
- **品牌心智**：Manus 几乎成了“通用 Agent”的代名词，先发认知在 To C 市场是真金白银；
- **数据飞轮**：每次任务执行留下的轨迹——哪里失败、如何重试——可以反哺编排策略，前提是留存撑得住。

冷静的判断是：Manus 的护城河是真的，但属于“运营型护城河”，会随时间折旧；而大厂的“技术型护城河”随时间增值。两者正在相向而行，估值能否兑现，取决于折旧速度和增值速度谁更快。

## 五、三条冷思考

![img2](https://cdn.jsdelivr.net/gh/ryry9966/meyo-assets2@main/images/2026-10-13/c7cf92a727462d69.png)

与其站队“值不值”，不如沉淀成一套判断框架：

1. **先手≠壁垒，看留存别看热搜。** 估值反映预期，产品价值反映复购。评估任何 Agent 产品，盯三个硬指标：次月留存、任务完成率、单位任务成本。三者都在改善，故事才成立；任何一个掉头，故事就该打折。
2. **通用层最难守，垂直层最易活。** AI 应用的历史规律是：离数据闭环越近，创业公司越安全。Manus 的真正考题不是和大厂对轰通用能力，而是能不能在招聘、数据分析、电商运营等具体场景里长出不可替代的行业 Know-how。
3. **对使用者：估值和你的体验无关。** 挑 Agent 工具别看融资新闻，用自己的真实任务跑一周，对比完成质量、耗时和费用。40亿美元的结论，最终应由每一个具体任务的交付结果投票得出。

Agent 竞争才刚过半场。Manus 的真正考题不是“这轮估值撑不撑得住”，而是“当基础模型每个季度都变强一次时，你的产品价值是否还在增值”。这个问题的答案，比任何一轮融资都更值得追踪。
